### 序論：本章が扱う範囲

本章は、企業の生成AI投資がどれだけ損益に結びついているかを、2024年から2026年の調査で整理します。対象は、コンサルティング会社と調査会社の大規模調査、大学の報告、日本の公的統計です。

[企業の利用の章](12-enterprise-adoption)が「どれだけの企業が使っているか」を扱い、[生産性の実証の章](13-productivity-evidence)が「個人の仕事がどれだけ速くなったか」を扱いました。本章は、その2つの間にある段差を扱います。使っている企業は多く、個人は速くなったと答えるのに、損益に効いたと答える企業は少ない、という段差です。

失敗の理由をどう解釈し、何を変えるべきかは、[各段階で必要なものの章](34-requirements-and-providers)と[運営モデルの進化の章](33-operating-model-evolution)で扱います。本章の本文は、数値とその定義の記述に限ります。

### 1. 「価値を出している企業」は1割から3割

2024年以降、複数の調査機関が「AIから価値を得ている企業の割合」を公表してきました。数値は調査によって異なりますが、方向は一致しています。

ボストン コンサルティング グループの2024年調査では、概念実証(PoC)の段階を超えて何らかの価値を生んでいる企業は22%、大きな価値を生んでいる企業は4%でした。25%はほとんど何もしておらず、49%はPoCの段階にとどまっていました [ [ 179 ] ](https://www.bcg.com/publications/2024/wheres-value-in-ai) 。同社の2025年調査(1,250社超)では、AIから規模のある価値を得ている企業は5%、価値を生み始めた拡大中の企業は35%で、60%はほとんど価値を得ていませんでした [ [ 180 ] ](https://www.bcg.com/publications/2025/are-you-generating-value-from-ai-the-widening-gap) 。

IBMの調査(CEO 2,000人、33か国、2025年2月から4月)では、過去数年のAI施策のうち期待した投資対効果を達成したものは25%、全社に展開できたものは16%でした。一方で85%のCEOは、2027年までに効率化投資が正の投資対効果を生むと期待しています [ [ 178 ] ](https://newsroom.ibm.com/2025-05-06-ibm-study-ceos-double-down-on-ai-while-navigating-enterprise-hurdles) 。

PwCの第29回グローバルCEO調査(4,454人、95か国・地域、2026年1月)では、AIがコストと収益の両方で成果を出したと答えたCEOは12%でした。どちらか一方で成果を得たCEOの割合は33%でした。「大きな財務的便益はまだない」と答えたCEOの割合は56%です [ [ 184 ] ](https://www.pwc.com/gx/en/news-room/press-releases/2026/pwc-2026-global-ceo-survey.html) 。

ガートナーの2026年10月の調査では、AIから「大きな」または「変革的な」価値を実現したと答えたCIOは13%でした。同社は、ユースケースの成功確率が5分の1のままであると述べています [ [ 183 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-10-19-gartner-survey-finds-only-13-percent-of-cios-say-their-enterprise-has-realized-significant-or-transformational-value-from-ai) 。同社の2026年1月から4月の調査(年商5,000万ドル以上、1,303人)では、複数の事業部門でAIを拡大できた組織は22%でした。85%の機能リーダーは2026年にAI支出を増やす予定で、2025年は機能予算の平均12%をAIに充てています [ [ 141 ] ](https://www.gartner.com/en/newsroom/press-releases/gartner-survey-finds-only-22-percent-of-organizations-have-successfully-scaled-ai-across-multiple-business-units) 。

マッキンゼーの2026年調査では、AI利用による営業利益への影響を報告した回答者は37%で前年並みでした。営業利益の5%以上をAIに帰属させる「高業績企業」は約6%で横ばいです [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。

これらの数値を並べると、損益に効いたと答える企業は調査によって12%から37%、大きな価値まで到達した企業は4%から13%の範囲にあります。

### 2. 「95%がゼロリターン」という数値の定義

2025年8月に広く報じられた数値があります。マサチューセッツ工科大学のNANDAプロジェクトの報告は、企業の生成AI投資300億ドルから400億ドルに対して、95%の組織が「ゼロリターン」だと述べました。統合型のパイロットのうち数百万ドル規模の価値を出しているものは5%です [ [ 177 ] ](https://mlq.ai/media/quarterly_decks/v0.1_State_of_AI_in_Business_2025_Report.pdf) 。

この数値には、定義の確認が要ります。同報告の「ゼロリターン」は、損益計算書に測定可能な影響があるかどうかで定義されています。方法は、300件超の公開AI施策のレビュー、52件のインタビュー、153件の調査回答で、期間は2025年1月から6月です。ChatGPTなどの汎用ツールは80%超の組織が検討または試行し、約40%が展開済みですが、効果は個人の生産性向上にとどまると同報告は述べています [ [ 177 ] ](https://mlq.ai/media/quarterly_decks/v0.1_State_of_AI_in_Business_2025_Report.pdf) 。

標本が小さく、企業規模や業種の内訳が開示されていないという批判が報道で指摘されています。本書は、この数値を「損益への影響を測定できた組織が5%だった」という予備的な報告として位置づけ、前節の他の調査と並べて読みます。方向は他の調査と一致しており、水準は定義の厳しさの違いで説明できます。

### 3. 「個人は速くなった、損益には出ない」の同型

前節までの数値を、個人の効果と並べると、同じ型が複数の国の調査で繰り返されていることが分かります。

マッキンゼーの2026年調査では、80%の回答者が個人の生産性向上を報告し、50%が意思決定の改善を報告しました。それに対して、営業利益への影響を報告したのは前述のとおり37%です [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。

日本の情報処理推進機構(IPA)の「DX動向2026」(回収1,799社、2026年4月から6月)では、AI導入の効果として「業務が効率化したり迅速化した」と答えた企業が91.6%でした。それに対して「売上や利益が向上した」は3.9%で、企業価値の創出に関連する効果の回答割合は数%台でした [ [ 123 ] ](https://www.ipa.go.jp/pressrelease/2026/rcu1hd0000016yh4-att/press20260716.pdf) 。同じ調査で、効果が「期待以上」は13.7%、「期待どおり」は18.1%、「一定の効果はあった」は50.6%です。DX投資の効果が投資を上回った企業は14.6%でした [ [ 124 ] ](https://www.ipa.go.jp/digital/chousa/dx-trend/rcu1hd0000017uk8-att/dx-trend-2026.pdf) 。

PwC Japanの2026年春の調査(売上高500億円以上の企業の課長職以上932名)では、生成AIの活用中または推進中は87%でした。しかし「期待を大きく上回る効果」を得た企業は9%で、比較した6か国で最も低い値です。アメリカの値は38%、イギリスの値は32%でした。1年以内の効果発現を想定する割合は日本41%に対しアメリカ66%です [ [ 127 ] ](https://www.pwc.com/jp/ja/knowledge/thoughtleadership/generative-ai-survey2026.html) 。

帝国データバンクの2026年3月の調査(有効回答10,312社)では、活用企業の86.7%が業務への効果が出ていると答えました。主な活用業務は「文章の作成・要約・校正」45.1%、「情報収集」21.8%、「企画立案時のアイデア出し」11.0%です [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。

総務省の令和8年版の情報通信白書によれば、日本で効果を実感する割合は、議事録・メール作成補助で72.3%、社内ヘルプデスクで42.7%、経営で20.1%でした。生成AIによる業務変革について「組織的な取組はない」と答えた割合は約3割弱で、他の3か国より高い値です [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。

個人の作業が速くなったという回答は8割から9割、損益に効いたという回答は数%から4割弱です。この段差は、アメリカと日本の両方で、調査主体を問わず観測されています。

### 4. 失敗の理由として挙げられているもの

調査機関は、損益に届かない理由も報告しています。

ガートナーは2025年6月、エージェント型AIのプロジェクトの40%超が2027年末までに中止されると予測しました。理由として挙げたのは、コストの増加、不明確な事業価値、不十分なリスク管理の3つです [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 。

マッキンゼーの2026年調査では、約20%の回答者が、トークン費用を含むAIの運用コストが利用を制約したと答えました [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。[推論モデルと価格の章](04-reasoning-and-cost-2024)で記述したとおり、単価は下がり続けていますが、利用量の増加が費用を押し上げる局面が現れています。

管理慣行の影響を示す研究もあります。アメリカとヨーロッパの採用格差を分析した研究によれば、格差の大部分は経営慣行によって説明されます。AIの採用は、企業が従業員に利用を積極的に奨励し、ツールを提供しているかどうかと強く関連していました [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。

日本の白書が示した「組織的な取組はない」約3割弱と、社内データを参照させる基盤の構築率が他国より低いこと [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) は、同じ方向の観測です。

### 5. 投資の規模と回収の見通し

投資の側の数値も記録しておきます。

スタンフォードのAI Index 2025によれば、2024年の企業のAI投資は2,523億ドル、生成AIへの民間投資は339億ドルでした [ [ 479 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/economy) 。ベンチャーキャピタルのMenlo Venturesは、企業の生成AI支出が2025年に370億ドルで、2024年の115億ドルの3.2倍になったと推計しています [ [ 417 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise) 。

ベインの2025年の技術報告は、2030年のAI需要を賄う計算能力には年間2兆ドルの収益が必要で、AI関連の節約を織り込んでも8,000億ドル不足すると推計しました。同報告は、先行企業が過去2年でAIの拡大により利払前・税引前・償却前利益を10%から25%改善した一方、大半の企業は実験段階だとも述べています [ [ 185 ] ](https://www.bain.com/about/media-center/press-releases/20252/$2-trillion-in-new-revenue-needed-to-fund-ais-scaling-trend---bain--companys-6th-annual-global-technology-report) 。

一方で、特定の製品の売上は実績として積み上がっています。Salesforceの2027会計年度第2四半期(2026年5月から7月)では、エージェント製品Agentforceの年間経常収益が15億ドルを超え、前年比240%超の増加でした。ただし、この四半期から集計の定義にSlackbotなどを含める変更があります [ [ 442 ] ](https://www.salesforce.com/news/press-releases/2026/08/26/fy27-q2-earnings/) 。[市場の地図の章](18-market-map)で、他の事業者の数値とあわせて整理します。

### 6. ガートナーの期待曲線上の位置

ガートナーは2025年8月5日、AIのハイプ・サイクルの2025年版を発表しました。AIエージェントとAI対応データが「過度な期待のピーク」に位置づけられ、2つは同サイクル上で最も速く進んだ技術とされています [ [ 182 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-08-05-gartner-hype-cycle-identifies-top-ai-innovations-in-2025) 。生成AIそのものが幻滅期に入ったとする記述は複数の二次報道にありますが、発表文の本文は「生成AIを中心とする焦点から基盤的な実現技術への移行」と表現しています。

同社は2028年の見通しとして、日常の業務判断の15%以上がエージェントで自律的に行われ、企業アプリケーションの33%がエージェント型AIを含むと予測しました。2024年の値は1%未満です [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 。中止の予測と拡大の予測は、同じ発表の中に並んでいます。

ハイプ・サイクルという枠組み自体の実証的な検討は、[普及の理論の章](20-diffusion-theory)で扱います。

#### 図の読み方

図は上から下へ4段の階段です。各段は、調査が測った指標と、その指標で「はい」と答えた割合の幅を示します。

1段目は「試行した」で、8割超の組織が該当します。2段目は「個人が速くなった」で、8割から9割です。3段目は「損益に効いた」で、1割から4割弱に落ちます。4段目は「大きな価値を得た」で、1割前後です。段が下がるごとに藍を濃くし、到達した組織が少なくなることを示しています。

各段の幅の出典は、本文の第1節から第3節にあります。2段目と3段目の間で最も大きく落ちる、という点を本章は主張しています。

### 本章の要点と解釈

本セクションは、著者による解釈です。前節までの事実記述とは区別して読んでください。

第一に、「95%が失敗」という数値は、定義を確かめれば他の調査と矛盾しません。損益への測定可能な影響という厳しい定義で5%、何らかの価値という緩い定義で2割から4割、大きな価値で1割前後です。どの定義を使うかで、同じ現実が「失敗だらけ」にも「順調」にも見えます。経営会議で数値を引用するときは、定義を添えることが必要です。

第二に、段差は個人と組織の間にあります。個人の作業が速くなったという回答は、国や調査主体を問わず8割から9割です。損益に出ないのは、速くなった時間が別の価値に変換されていないからです。[汎用技術と生産性Jカーブの章](21-gpt-and-j-curve)で扱う無形資本の議論は、この段差を「補完的な投資が済んでいない状態」として説明します。

第三に、失敗の理由として調査機関が挙げるものは、技術そのものではなく、費用の管理、価値の定義、リスク管理、経営慣行です。これらはすべて、企業が自ら動かせる変数です。

経営層への含意は次のとおりです。自社の生成AIが「使われているか」を測る段階は、多くの企業ですでに終わっています。次に測るべきは、速くなった時間がどこへ行ったかです。削減した時間を別の業務に振り向けたのか、品質に変えたのか、採用を減らしたのか、あるいは何にも変わっていないのか。この問いに数値で答えられる状態が、[3つの現在地の章](32-three-positions)で定義する文化フェーズC4の条件です。筆者は、損益に届かない原因の多くが、この測定の不在にあると考えます。
