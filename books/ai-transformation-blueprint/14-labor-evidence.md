### 序論：本章が扱う範囲

本章は、生成AIが雇用に与えた影響について、2026年10月時点で確認できる実証データを整理します。対象は、アメリカの労働統計を用いた学術研究、人員削減の発表、国際機関の推計、そして日本の白書です。

[生産性の実証の章](13-productivity-evidence)が「個人の仕事がどれだけ速くなったか」を扱ったのに対し、本章は「仕事の数と中身がどう変わったか」を扱います。両者は同じ技術の効果を別の面から測っています。

将来の雇用がどうなるかは、本章では扱いません。それは[言説の分類の章](25-discourse-taxonomy)と[3つの道筋の比較の章](29-paths-comparison-indicators)が、推論として扱います。本章の本文は事実の記述に限り、評価は章末に分離します。

### 1. 2つの信号が同時に観測されている

2026年10月時点の実証研究は、互いに矛盾するように見える2つの結果を同時に報告しています。

第一の信号は「経済全体では識別可能な変化がない」というものです。イェール大学の予算研究所は、ChatGPT公開から33か月間の職業構成の変化を、過去のパソコンとインターネットの普及期と比較しました。その結論は、労働市場全体には識別可能な混乱が起きていない、というものでした [ [ 161 ] ](https://budgetlab.yale.edu/research/evaluating-impact-ai-labor-market-current-state-affairs) 。

第二の信号は「入口で変化が起きている」というものです。スタンフォード大学のデジタル経済研究所は、給与計算会社ADPのデータを用いて、AIへの曝露度が高い職業に就く22歳から25歳の雇用を追跡しました。データは、ADPの顧客企業のうち2021年1月から継続して観測できる企業の個票(月350万〜500万人)で、職業ごとの曝露度はエルンドゥらのGPT-4による評価とAnthropic Economic Indexの利用記録で定義しています [ [ 1760 ] ](https://digitaleconomy.stanford.edu/wp-content/uploads/2025/08/Canaries_BrynjolfssonChandarChen.pdf) 。2026年8月の改訂版によれば、この層の雇用は、曝露度の低い職業の同年齢層と同じ伸びを示した場合と比べて約19%低い水準にあります [ [ 157 ] ](https://digitaleconomy.stanford.edu/news/canariesaug26) 。

この2つは矛盾ではありません。経済全体の雇用者数という粗い指標と、特定の年齢と職業に絞った細かい指標とでは、見えるものが違います。本章は、この2つの信号を順に記述します。

### 2. 若年層の高曝露職で起きていること

スタンフォードの研究は「炭鉱のカナリア」という題名で知られています。初版は2025年8月に公開され、2022年末以降に高曝露職の22歳から25歳の雇用が、企業の固定効果を統制したうえで相対的に13%低下したと報告しました [ [ 158 ] ](https://digitaleconomy.stanford.edu/publication/canaries-in-the-coal-mine-six-facts-about-the-recent-employment-effects-of-artificial-intelligence) 。

その後、数値はデータの時点とともに更新されています。スタンフォードのAI Index 2026は、企業の種類の効果を統制したうえで、22歳から25歳の高曝露職の雇用が低曝露職に比べて約16%低下し、その差は2024年半ばから拡大したと記載しました。同年齢のソフトウェア開発者の雇用は、2024年から20%近く減少しています [ [ 159 ] ](https://hai.stanford.edu/assets/files/ai_index_report_2026_chapter_4_economy.pdf) 。2026年8月の改訂版では、2026年6月までのデータで差が約19%に広がりました [ [ 157 ] ](https://digitaleconomy.stanford.edu/news/canariesaug26) 。

13%、16%、19%という3つの数値は、同じ研究系列の異なる時点の値です。別々の研究が食い違っているのではありません。

改訂版が示した重要な点は、調整の経路です。水準で見ると、2022年11月から2026年6月までに、高曝露の上位2分位の雇用は約11%減り、低曝露の下位3分位は約10%増えました。そしてこの調整は、離職の増加ではなく、採用の減少を通じて起きています [ [ 157 ] ](https://digitaleconomy.stanford.edu/news/canariesaug26) 。

採用の減少という経路には、生成AI以前のAIでの先例があります。アセモグル、オーター、ヘイゼル、レストレポは、2010年以降のアメリカのオンライン求人のほぼ全数を用いて、AIに曝露された事業所がAI以外の職の採用を減らした一方、職業や産業の水準では雇用や賃金の変化と識別可能な関係がなかったと報告しました [ [ 1754 ] ](https://www.nber.org/papers/w28257) 。

同研究所の指標ノートは、職業ごとのAI利用の型との関係も示しています。利用が「自動化」に偏る職業では22歳から25歳の雇用が減少または停滞しました。一方、「拡張」の比率との関係は見られませんでした [ [ 160 ] ](https://digitaleconomy.stanford.edu/app/uploads/2026/06/AIEI_RN01_Jun26.pdf) 。[生産性の実証の章](13-productivity-evidence)で参照した「拡張と自動化」の区別が、雇用の側でも観測されていることになります。

新卒全体の状況も記録しておきます。ニューヨーク連邦準備銀行の指標では、2026年第2四半期の大卒新卒(22歳から27歳)の失業率は約5.6%、不完全就業率は42%でした。2026年3月の5.6%は、2019年3月の3.6%から上昇しています [ [ 164 ] ](https://www.newyorkfed.org/research/college-labor-market) 。この上昇にAIがどこまで寄与したのかを、同連銀の指標だけで判断できません。

### 3. 経済全体では「まだ」識別できない

イェール大学の予算研究所は、2025年10月の報告の後も追跡を続けています。

2026年5月の続報では、AI曝露職と非曝露職とを合成差の差法で比較しても、雇用と実質時給への影響はゼロと区別できませんでした。同報告は、アメリカの失業率が2023年4月の3.4%から2026年3月の4.3%へ上昇し、雇用増が月約2万人にとどまることを認めたうえで、AIが原因とはまだ言えないと述べています [ [ 162 ] ](https://budgetlab.yale.edu/research/ai-probably-not-yet-reason-labor-market-weakening) 。

2026年6月の報告は、求人・労働異動調査(JOLTS)で情報セクターのレイオフ率が2025年12月以降に上昇したことを指摘しました。2025年11月から2026年3月で累計1.2ポイントの上昇で、標準誤差は0.31です。ただし、曝露職と非曝露職の比較では、やはりAIの労働市場効果の証拠は見つかっていません [ [ 163 ] ](https://budgetlab.yale.edu/research/recent-rise-information-sector-layoffs-and-what-it-could-tell-us-about-ai) 。

ヨーロッパの個票データを用いた研究も、同じ方向を示しています。デンマークの11職種、労働者25,000人、7,000職場を雇用主と従業員の接続データに結びつけた研究の2026年3月の改訂版は、AIチャットボットが広く普及した一方で、収入と労働時間への効果はChatGPT公開から2年の時点でゼロと区別できず、2%を超える効果は棄却されると報告しています。雇用主は主に業務を再編しており、採用者の一部は高賃金の職種へ移動しました [ [ 1758 ] ](https://www.nber.org/papers/w33777) 。初版(2025年5月)の推計では、利用者の時間節約は平均2.8%で、そのうち収入に反映されたのは3%から7%でした [ [ 150 ] ](https://www.nber.org/system/files/working_papers/w33777/revisions/w33777.rev0.pdf) 。

### 4. 企業が「AI」を理由に挙げる人員削減

統計で識別できないことと、企業がAIを理由に人員削減を発表することとは、別の事実です。

人材会社チャレンジャー・グレイ・アンド・クリスマスの集計では、2025年にアメリカ企業がAIを理由に挙げた人員削減は54,836人でした。2023年に追跡を始めてからの累計は71,825人です [ [ 167 ] ](https://www.challengergray.com/blog/2025-year-end-challenger-report-highest-q4-layoffs-since-2008-lowest-ytd-hiring-since-2010) 。2026年1月から8月では116,175人となり、全削減の約22%を占め、年初来で最多の理由になりました。ただし8月単月では3,462人で4位に後退しています [ [ 168 ] ](https://www.challengergray.com/blog/challenger-report-august-job-cuts-up-58-consumer-products-food-lead) 。

個別の発表も記録しておきます。Amazonは2025年10月28日、コーポレート部門の約14,000人の削減を発表しました。人事担当の上級副社長のメモは、この世代のAIをインターネット以来最も変革的な技術と位置づけ、階層を減らして少人数で動く必要があると説明しています [ [ 169 ] ](https://www.aboutamazon.com/news/company-news/amazon-workforce-reduction) 。SalesforceのCEOは2025年9月、AIエージェントにより顧客サポート要員を約9,000人から約5,000人に減らしたという趣旨の発言をしたと報じられています [ [ 170 ] ](https://fortune.com/2025/09/02/salesforce-ceo-billionaire-marc-benioff-ai-agents-jobs-layoffs-customer-service-sales) 。Bloombergは2026年7月、AI採用が最も速い金融と情報のセクターで雇用減少が加速し、月平均28,000人に達したと報じました [ [ 171 ] ](https://www.bloomberg.com/news/articles/2026-07-01/tech-and-finance-sectors-losing-28-000-jobs-monthly-show-ai-impact-on-labor) 。

一方、企業の予想と実績の間には差があります。マッキンゼーの2026年調査では、39%の回答者が今後1年でAIにより総雇用が減ると予想し、43%は変化なしと予想しました。前年に減少を予想した割合は、実際に過去1年で減少を報告した割合の約2倍でした [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。

### 5. 構造的な推計の幅

長期の推計は、機関によって前提と結論の両方が異なります。

国際通貨基金のスタッフ分析は、世界の雇用の約40%がAIに曝露されているとしました。先進国では約60%で、その半分が負の影響を受け、残り半分が生産性向上の恩恵を受けると区分しています。新興国の値は40%、低所得国の値は26%です [ [ 165 ] ](https://www.imf.org/en/blogs/articles/2024/01/14/ai-will-transform-the-global-economy-lets-make-sure-it-benefits-humanity) 。

世界経済フォーラムの雇用主調査に基づく推計では、2025年から2030年に1億7,000万の雇用が創出され、9,200万が消失し、純増は7,800万です。構造的な入れ替わりは現在の雇用の22%に相当します。同時に、雇用主の40%は「AIが自動化できる領域で人員を削減する」と予想しました [ [ 166 ] ](https://www.weforum.org/publications/the-future-of-jobs-report-2025) 。

「曝露」は「消失」ではありません。IMFの40%は影響を受けうる範囲の広さを、WEFの22%は入れ替わりの規模を、それぞれ別の定義で測っています。

### 6. 日本で確認できること

日本については、2026年に政府の2つの白書が雇用への影響を分析しました。

厚生労働省の令和8年版の労働経済白書は、先行研究の整理として「大きな雇用の減少が生じている証左は、現時点で得られていない」と述べています。同時に、アメリカではAI曝露度の高い職業の雇用減少が指摘されていることも併記しました。同白書によれば、AI利用者のうち企業の訓練があった割合は、金融・保険業で日本26.9%に対しアメリカ60.5%、製造業で日本33.3%に対しアメリカ62.7%です [ [ 174 ] ](https://www.mhlw.go.jp/content/12602000/001753069.pdf) 。

同白書の本文は、AI導入前期(2016年から2019年)と導入期(2022年から2025年)を比較しています。日本の就業者数の変化率は前期が1.4%増、導入期が0.5%増で、労働時間は減少した一方で就業者数と労働投入量は増加しました。海外研究としては、スウェーデンで高曝露職の22歳から25歳の雇用が5.5%減り、50歳超は1.3%増えた分析を紹介しています [ [ 511 ] ](https://www.mhlw.go.jp/wp/hakusyo/roudou/26/dl/26-1-2.pdf) 。

内閣府が2026年7月に公表した年次の経済財政報告は、事務職の労働需要が長く安定していたものの、定型的な業務を中心としてAIへ代替する動きがみられると分析しました。金融業や情報通信業でAI導入の効果を感じた企業が多いとも述べています [ [ 175 ] ](https://www5.cao.go.jp/keizai3/2026/0724wp-keizai/setsumei00.pdf) 。

日本の雇用を考える際には、供給側の条件が前提になります。リクルートワークス研究所の労働需給シミュレーションは、2030年に約341万人、2040年に約1,100万人の労働供給不足を試算しました。不足率は輸送・機械運転24.2%、建設22.0%、介護25.3%、商品販売24.8%です [ [ 173 ] ](https://recruit-holdings.com/ja/blog/post_20230926_0001) 。人口の構造は[日本の条件の章](19-japan-conditions)で詳しく扱います。

### 7. 一企業の内部データ

AI開発企業の内部でも、雇用の変化が記録され始めています。Anthropicの社内分析では、「社内の仕事のプロセスは自分を最大限生産的にしているか」に同意する従業員が2024年末の44%から2025年11月の58%に増えました。2026年8月時点で、同社の従業員は2030年までにAIが自分の仕事の75%をこなせると予想しており、アメリカの労働者全体の予想は28%でした [ [ 176 ] ](https://www.anthropic.com/research/employment-at-anthropic) 。

これは単一企業の内部データであり、一般化はできません。ただし、AIを最も使う職場でAIへの期待が最も高い、という構図を示す例として記録します。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

第一に、2026年10月時点の実証は「全体では変化なし、入口では変化あり」と要約できます。この2つは矛盾ではなく、測る粒度の違いです。経済全体の統計に変化が出るのを待ってから動くと、入口の変化はすでに数年分進んでいることになります。

第二に、変化の経路は離職ではなく採用減です。企業は既存の従業員を解雇するより先に、新しく雇う人数を減らしています。これは、技能の継承に時間差で効く変化です。今日の採用減は、5年後の中堅層の薄さとして現れます。

第三に、「AIを理由にした」人員削減の発表と、統計で識別できる効果とは別物です。発表は2026年に急増しましたが、研究者は経済全体のデータで因果をまだ確認できていません。企業の予想は実績より大きく、先に動いています。著者は、発表を「企業がAIをどう語っているか」の記録として読み、「AIが何を起こしたか」の証拠としては扱わない方がよいと考えます。

### 経営層への含意

日本では、雇用の減少より労働供給の不足が先に来ます。アメリカで観測された若年層の採用減を、そのまま日本の未来として読むことはできません。一方で、訓練の提供率が日本で低いという白書の数値は、企業が自ら動かせる変数です。新卒採用を減らすかどうかより先に、採用した人をAIとともに育てる仕組みがあるかどうかが、[文化の形成の章](36-culture-formation)で扱う文化フェーズの差として現れます。
