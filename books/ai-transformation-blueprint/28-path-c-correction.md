### 序論：本章が扱う範囲

本章は、3つの道筋のうち3番目のものを提示します。道筋Cは、AIへの投資が売上の伸びに先行しすぎた結果、2026年から2028年にかけて投資が収縮し、供給者が再編される経過です。技術が消える経過ではありません。[言説の分類の章](25-discourse-taxonomy)で「調整」に分類した言説は、金融機関、投資家の一部、批判者に集中しており、その多くは能力の向上そのものを否定していません。

道筋Cの骨格は、[汎用技術と生産性Jカーブの章](21-gpt-and-j-curve)で整理したPerezの理論です。Perezは、技術の大きな転換が約50年の周期で同じ構造を繰り返し、前半の導入期には金融資本が主導してバブルが生じ、その崩壊の後に展開期が来ると論じました [ [ 261 ] ](https://doi.org/10.4337/9781781005323) 。Perez自身は2024年に、AIを新しい技術革命ではなく、1970年代にマイクロプロセッサから始まった情報通信技術(ICT)革命の中の主要な展開と位置づけています [ [ 1853 ] ](https://www.project-syndicate.org/magazine/ai-is-part-of-larger-technological-revolution-by-carlota-perez-1-2024-03) 。本書が転用するのは、金融資本が主導する投資の構造が導入期のバブルに似るという点であり、生成AIへの投資を導入期のバブルとして読むのは著者の判断です。道筋Cは、生成AIが2026〜28年にこの転換点を通る経過です。

構成は前の2章と同じです。前提、2027年前後、2029年前後、2031年前後、企業・労働・市場への帰結、外れる条件、経営層への含意の順に、確度の階層を【階層n】で付します。本章も確率を割り当てません。

### 1. 前提

【階層1】 **投資の規模と直近の売上は、既に確定した事実**。2026年の設備投資の計画は、Meta、Alphabet、Amazonの3社だけで5,000億ドル前後に達します [ [ 80 ] ](https://www.reuters.com/business/meta-expects-annual-capital-expenditures-rise-superintelligence-push-2026-01-28) 。一方、OpenAIの年換算の売上は2026年10月に約500億ドルで、9月に広く報じられた700億ドルは比較のために「グロスアップ」された数値だったと報じられています [ [ 419 ] ](https://www.axios.com/2026/10/08/openai-50-billion-arr-anthropic-revenue-accounting) 。Anthropicの上場申請書類は、2026年上半期の売上163億ドルに対し、転換社債の会計処理を含む純損失807億ドルを示したと報じられています [ [ 422 ] ](https://fortune.com/2026/10/26/anthropics-s-1) 。

【階層3】 **売上の不足額は推計**。Bainは、2030年の計算需要を賄うには年2兆ドルの新規売上が要り、AI由来の節約を含めても8,000億ドル不足すると推計しました [ [ 185 ] ](https://www.bain.com/about/media-center/press-releases/20252/$2-trillion-in-new-revenue-needed-to-fund-ais-scaling-trend---bain--companys-6th-annual-global-technology-report) 。これは2030年の需要の予測であり、確定した事実ではありません。道筋Cは、この不足が埋まらないと仮定します。

【階層2】 **評価は利益の裏付けと資金循環の脆さの間で揺れている**。NVIDIAの2027会計年度第2四半期の売上は962億ドルで前年比106%増です [ [ 402 ] ](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027) 。2026年10月の報道は、NVIDIAが12か月の利益の17倍で取引されており、ドットコム期のCiscoの約100倍とは異なると述べる一方で、新興クラウド事業者の資金需要とAnthropicの上場の成否を再評価の引き金として挙げています [ [ 353 ] ](https://finance.yahoo.com/markets/stocks/articles/nvidias-valuation-giving-ai-bubble-124818372.html) 。

【階層2】 **循環的な取引が需要を見かけより大きく見せている可能性**。NVIDIAからOpenAIへの最大1,000億ドルの出資、AMDからOpenAIへのワラント、Oracleの社債による調達など、供給者が顧客に資金を供給する取引が2025年秋に相次ぎました。経済評論家のNoah Smithは、これをベンダーファイナンスの兆候と呼び、需要が見かけより弱い可能性を指摘しています [ [ 346 ] ](https://www.noahpinion.blog/p/should-we-worry-about-ais-circular) 。

【階層3】 **能力の向上が鈍る、または測れなくなる**。道筋Cは、能力の停滞を必須の前提にはしません。ただし、AAAIの調査では76%が現行手法のスケールアップによるAGIの到達を「ありそうにない」と答えました [ [ 336 ] ](https://aaai.org/wp-content/uploads/2025/03/AAAI-2025-PresPanel-Report-Digital-3.7.25.pdf) 。既知の事前学習の終わりをSutskeverが指摘したという報道もあります [ [ 326 ] ](https://cointelegraph.com/news/age-ai-pre-training-soon-come-end-open-ai-co-founder) 。これらは、投資の期待が切り下がる材料になります。

### 2. 2027年前後

【階層3】 **市場**：Forresterは、2026年にAIが「ティアラをヘルメットに替え」、企業が計画したAI支出の25%を2027年へ繰り延べると予測しました [ [ 351 ] ](https://www.forrester.com/blogs/predictions-2026-ai-moves-from-hype-to-hard-hat-work) 。道筋Cでは、繰り延べではなく削減が起きます。引き金は、IMFがWorld Economic Outlookで述べたとおり、早期採用者のデータによる過度に楽観的な成長期待の修正です [ [ 348 ] ](https://www.aljazeera.com/economy/2025/10/14/imf-says-ai-investment-bubble-could-burst-comparable-to-dot-com-bubble) 。2026年9月、Amodeiの警告を受けた下落の局面があり、NVIDIAは4%、ソフトバンクグループも14%下げました [ [ 352 ] ](https://www.businessinsider.jp/article/2609-ai-warnings-spark-decline-in-tech-stocks-nvidia-slides-/) 。道筋Cでは、この型の下落が2027年に数回重なり、大手クラウド事業者の設備投資の計画が前年比で減少に転じます。

【階層3】 **供給者**：新興のクラウド事業者と、資金調達に依存する基盤モデルの供給者が最初に影響を受けます。Aschenbrennerのヘッジファンドが2026年7月に月間67%の損失を出した事例は [ [ 398 ] ](https://dealroom.co/news/142225-aschenbrenners-situational-awareness-sells-its-public-stock-book-to-cita/) 、加速に賭けた資金が短期で損失を被る型を示しています。道筋Cでは、基盤モデルの供給者のうち、自社で計算資源を持たず、上場や大型の調達に依存する事業者が、大手に吸収されるか提供を縮小します。

【階層2】 **普及**：Gartnerの「2027年末までにエージェント型AIプロジェクトの40%超が中止」という予測は [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 、道筋Cでは上振れします。MIT NANDAが報告した95%のゼロリターン [ [ 345 ] ](https://www.artificialintelligence-news.com/wp-content/uploads/2025/08/ai_report_2025.pdf) が、予算の削減の根拠として企業の内部で使われます。

**この時点で観測されること**：AI関連の株価の下落と、新興事業者の撤退が報道の中心になります。一方で、既に業務に組み込まれた生成AIの利用は減りません。価格が下がり続けているためです。

### 3. 2029年前後

【階層3】 **市場の再編**：Perezの枠組みでは、バブルの崩壊の後に、生き残った基盤の上で展開期が始まります [ [ 261 ] ](https://doi.org/10.4337/9781781005323) 。道筋Cの2029年は、この転換点です。基盤モデルの供給者は、大手クラウド事業者の傘下か、少数の独立した事業者に集約されます。Menlo Venturesの調査で企業のAPI支出のシェアが2年で入れ替わったように [ [ 417 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise) 、集約の過程でも供給者の順位は変わります。

【階層3】 **価格と能力**：投資が収縮しても、既に建設されたデータセンターと、学習済みのモデルは残ります。ドットコム期に敷設された光ファイバーが、その後の20年の通信の基盤になったのと同じ構造です。道筋Cでは、新規の最上位モデルの学習は減りますが、推論の価格は下がり続け、企業にとっての利用の費用はむしろ下がります。Epoch AIの記録では、同じ性能に到達する推論の価格は年9倍から900倍の速さで下がってきました [ [ 425 ] ](https://epoch.ai/data-insights/llm-inference-price-trends) 。

【階層2】 **普及**：企業の利用は、供給者の再編を越えて続きます。[企業の利用の章](12-enterprise-adoption)で整理した利用率は、道筋Cでも下がりません。変わるのは、供給者の選択と、契約の形です。長期の契約と特定の供給者への深い依存を避ける動きが、調達の標準になります。

【階層2】 **労働**：投資の収縮は、AI関連の雇用を直撃します。Challengerの集計で、2026年1〜8月にAIを理由とする人員削減の発表は116,175人で全体の約22%でした [ [ 168 ] ](https://www.challengergray.com/blog/challenger-report-august-job-cuts-up-58-consumer-products-food-lead) 。道筋Cでは、削減の理由が「AIによる代替」から「AI投資の縮小」へ変わります。知識労働の代替による雇用の減少は、道筋Bと同程度に緩やかです。

**この時点で観測されること**：AIは報道の中心から外れ、業務の道具として定着します。電力と計算資源の制約が緩み、価格が下がります。

### 4. 2031年前後

【階層4】 **展開期の始まり**：Perezの枠組みに従えば、2031年は展開期の初期です。生き残った供給者と、安くなった計算資源の上で、業務への組み込みが進みます。到達点は[道筋Bの章](27-path-b-gradual)の2029年に近く、2年から3年の遅れが生じます。

【階層4】 **能力**：道筋Cでは、最上位モデルの学習への投資が減るため、能力の向上は2027年から2029年にかけて鈍ります。ただし、Epoch AIが指摘するとおり、学習期間の限界が計算のスケーリング自体の減速要因になる可能性は、投資の有無にかかわらず存在します [ [ 333 ] ](https://epoch.ai/blog/power-demands-of-frontier-ai-training) 。2031年には、新しい手法の研究が再び前面に出ます。

【階層4】 **制度**：投資の収縮は、規制の強化を伴います。金融安定の観点から、イングランド銀行の金融政策委員会が2025年10月に指摘した市場の集中と評価の問題が [ [ 347 ] ](https://www.theregister.com/2025/10/08/boe_dotcom_bubble_ai/) 、事後の規制の根拠になります。AIの能力への規制ではなく、資金調達と会計への規制が先に来ます。

### 5. 企業・労働・市場への帰結

道筋Cが実現した場合、企業には次の帰結が生じます。

第一に、供給者の存続リスクが調達の中心になります。特定の基盤モデルの供給者に深く依存した企業は、提供の縮小や価格の変更に直面します。[各段階で必要なものの章](34-requirements-and-providers)で扱う供給者の評価に、資金調達の状況と計算資源の自社保有が加わります。

第二に、費用は下がります。道筋Cは、利用者にとっては価格の面で最も有利な経過です。既に建設された基盤の上で、推論の価格は下がり続けます。S2(仕事に適用する)からS3(仕事に組み込む)への移行の費用は、3つの道筋の中で最も低くなります。

第三に、社内のAI予算は削られます。[投資対効果と失敗率の章](15-roi-and-failure)で整理した失敗率が、予算の削減の根拠に使われます。効果を数値で示せる用途だけが残ります。文化フェーズC4(測って運用する)に達していない企業は、効果のある用途まで止めることになります。

第四に、人材の市場が変わります。供給者からの人材の流出が起き、企業がAIの専門人材を採用しやすくなります。日本では、[日本の条件の章](19-japan-conditions)で述べたIT人材の偏在が、この局面で部分的に緩和されます。

図は、左に2本の棒、右に1つの枠を置いています。左の長い棒は、Bainが推計した2030年の計算需要を賄うために必要な年2兆ドルの新規売上です。短い棒は、AI由来の節約を含めても残る8,000億ドルの不足です。道筋Cの枠(この不足の棒)だけを黄土色で塗っているのは本書の図の約束事で、藍、丹、千歳緑の3色に加えて、道筋C(調整)を表す色として使っています。

右の枠は、調整の後に残るものです。建設されたデータセンター、学習済みのモデル、下がり続ける推論の価格です。道筋Cは技術が消える経過ではなく、資金の供給者と事業者が入れ替わる経過である、というのがこの図の主張です。

図の下の添え書きは、Perezの導入期と展開期の区切りを1行で示しています。2026〜28年の調整を転換点とし、2031年を展開期の初期と置いています。

### 本道筋が外れる条件

道筋Cは、次のいずれかが観測されたときに外れます。

第一に、売上が投資に追いつくことです。OpenAIとAnthropicの年換算の売上が2027年も年2倍以上で伸びてBainの推計した不足を縮めれば、調整の前提は崩れます。報道によれば、Goldman Sachsは2025年10月に、バブルの3要素のうち急騰と極端な評価は存在するものの、レバレッジによるシステミックなリスクはまだ始まりつつある段階だと述べています [ [ 343 ] ](https://www.axios.com/2025/10/09/ai-bubble-stock-market) 。レバレッジの拡大を伴わずに利益が追いつけば、道筋Cは[道筋Aの章](26-path-a-acceleration)か[道筋Bの章](27-path-b-gradual)へ移ります。

第二に、能力の節目が投資家の期待を更新することです。2028年末までに8時間(1日分)の作業を80%基準で任せられる水準に達すれば、投資の回収可能性の評価が変わり、調整は先送りされます。

第三に、政府の関与です。Stargateのように政府が関与する計画や [ [ 27 ] ](https://openai.com/index/announcing-the-stargate-project) 、各国の経済安全保障の予算が投資を下支えすれば、民間の資金の収縮は相殺されます。日本のGENIACや計算資源の支援も、この型に当たります。

第四に、調整が起きても再編に至らないことです。株価の下落が一時的で、設備投資の計画が減少に転じなければ、それは道筋Bの範囲内の変動です。道筋Cの判定には、設備投資の前年比の減少と、主要な供給者の提供の縮小の両方が要ります。

### 経営層への含意

道筋Cに備える企業は、次の3点を検討することになります。著者の整理であり、[道筋別の戦略の章](35-strategy-by-path)で他の道筋と合わせて扱います。

第一に、供給者への依存を分散することです。道筋Cは、特定の供給者が消える経過です。基盤モデルを差し替えられる設計、データを自社に置く構成、複数の供給者との契約が、この道筋への備えです。これは道筋Bでも有効な、後悔しない手です。

第二に、効果を数値で示せる用途に集中することです。予算の削減の局面で残るのは、効果を示せる用途だけです。C4(測って運用する)へ先に達しておくことが、道筋Cでの防御になります。

第三に、調整を機会として使うことです。道筋Cでは、費用が下がり、人材が市場に出ます。[運営モデルの進化の章](33-operating-model-evolution)で扱う内製化は、この局面で最も進めやすくなります。

著者は、道筋Cを「悲観」の道筋とは呼びません。利用者である企業にとって、道筋Cは価格と人材の面で有利です。不利なのは、供給者と、供給者に賭けた投資家です。経営層が恐れるべきは、調整そのものではなく、調整の局面で効果の出ている用途まで止めてしまうことです。
