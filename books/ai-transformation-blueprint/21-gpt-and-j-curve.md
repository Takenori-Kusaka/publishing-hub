### 序論：本章が扱う範囲

本章は、[普及の理論の章](20-diffusion-theory)が扱わなかった問いを扱います。技術が広がった後、その効果はいつ、どのような形で生産性の統計に表れるのか、という問いです。

生成AIをめぐる事実には、一見すると矛盾があります。[生産性の実証の章](13-productivity-evidence)で示したとおり、個人を対象にした現場実験では、所要時間の短縮と品質の改善が繰り返し観測されています。一方、[投資対効果と失敗率の章](15-roi-and-failure)で示したとおり、企業の損益への効果は少数の組織でしか確認されていません。国の生産性統計では、アメリカの非農業部門の労働生産性が2023年に1.6%、2024年に2.3%上昇したものの、その上昇をAIに帰属させる根拠は確定していません [ [ 1805 ] ](https://www.bls.gov/opub/ted/2025/productivity-up-2-3-percent-in-2024.htm) 。

この矛盾は、新しい発見ではありません。1880年代の電化と1980年代の計算機で、同じ現象が観測され、理論化されています。本章は、Solowのパラドックス、Davidの電化の研究、BresnahanとTrajtenbergの汎用技術論、Brynjolfssonらの生産性Jカーブ、そしてPerezの技術革命論の5つを取り上げます。各理論について、原典の主張、生成AIの事実への当てはめ、当てはまらない点の順に記述します。理論の選択と当てはめは著者の判断です。

### 1. Solowのパラドックス ―― 統計に表れない計算機

経営判断にとっての意味は、「投資しているのに生産性が上がらない」という状態が、過去の汎用技術でも普通に起きたということです。

1987年7月、経済学者Robert Solowは新聞の書評の中で、計算機への投資が急増しているにもかかわらず1973年以降の生産性成長率の低下が続いていることを一文で指摘しました。「計算機の時代はあらゆる場所に見えるが、生産性統計の中には見えない」という文です [ [ 260 ] ](https://gwern.net/doc/economics/automation/1987-solow.pdf) 。この一文が「生産性パラドックス」の名の由来になりました。

生成AIの事実に当てはめると、2026年の状況はSolowが書いた1987年に似ています。StanfordのAI Index 2026によれば、2025年の世界の企業のAI投資は5,816.9億ドルで、前年から倍増を超えました [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。一方、デンマークの11職種、労働者25,000人を雇用主と従業員の記録に接続した研究があります。AIチャットボットは広く普及した一方で、初版(2025年5月)の推計では利用者の時間節約は平均2.8%にとどまり、収入と記録された労働時間と賃金に有意な効果は見られませんでした [ [ 150 ] ](https://www.nber.org/system/files/working_papers/w33777/revisions/w33777.rev0.pdf) 。2026年3月の改訂版の要旨も、収入と記録上の労働時間への効果は、2%を超える大きさを棄却できる精密なゼロだと記しています [ [ 1758 ] ](https://www.nber.org/papers/w33777) 。投資はあらゆる場所に見え、統計には見えない、という構図です。

### 2. Davidの電化の研究 ―― 発電機から生産性の加速まで40年

経営判断にとっての意味は、効果が出るまでの時間差は「技術の未熟さ」ではなく「仕事の配置の組み替えに要する時間」である、ということです。

Paul Davidは1990年に、1980年代の生産性パラドックスを、1880年代から1920年代の工場の電化の歴史に照らして読みました [ [ 255 ] ](https://ideas.repec.org/p/cla/levarc/115.html) 。発電機の商用化は1880年代でしたが、アメリカの製造業の生産性が加速したのは1920年代で、約40年を要しました。理由は、電動機で蒸気機関を置き換えるだけでは利点が小さかったことです。工場の配置を、1本の軸から動力を分配する「群駆動」から、機械ごとに電動機を置く「単位駆動」へ組み替えて初めて、生産性が出ました。

DavidとGavin Wrightは1999年に、この加速を第一次世界大戦の後の時期に特定し、普及が技術だけでなく、電力価格の低下、工場建築の変化、労働市場の変化の複合で進んだことを示しました [ [ 256 ] ](https://www.nuffield.ox.ac.uk/economics/history/paper31/davidwright.html) 。イギリスとの比較から、同じ技術でも制度と補完的な投資の差で普及が遅れることも示されています。

生成AIの事実に当てはめると、「群駆動のまま電動機を置く」に相当する導入が、現在の主流です。Microsoftと複数の企業が行った56社6,000人の6か月の無作為化された比較試験では、Microsoft 365 Copilotを実際に使った人のメールの時間は週3時間(25%)減りましたが、会議の時間は変わりませんでした [ [ 147 ] ](https://www.microsoft.com/en-us/research/publication/shifting-work-patterns-with-generative-ai) 。既存の仕事の配置のまま、個々の作業が速くなった状態です。会議の時間が変わらないのは、仕事の配置がまだ組み替えられていないことを示します。この組み替えは[組織の内部化の章](22-organizational-internalization)で扱います。

当てはまらない点は、時間の尺度です。電化の40年は、工場という物理的な資産の更新を伴いました。生成AIの導入に要する補完的な投資は、第4節で述べるとおり、物理的な資産ではなく業務手順と技能です。40年という数字をそのまま当てはめる根拠はありません。

### 3. 汎用技術 ―― 蒸気、電力、計算機、そして大規模言語モデル

経営判断にとっての意味は、生成AIが汎用技術であるなら効果は「導入する側の工夫」に依存し、供給者の技術だけでは決まらないということです。

BresnahanとTrajtenbergは1995年に、蒸気機関、電力、半導体のような技術を「汎用技術」と定義しました [ [ 257 ] ](https://doi.org/10.1016/0304-4076%2894%2901598-T) 。3つの基準は、広範な産業で使われること、時間とともに改良され続けること、そして応用側のイノベーションを誘発することです。汎用技術の供給者と応用部門の間には「イノベーションの補完性」があり、双方の投資の揃った時点で初めて成長につながるとされます。したがって、調整の失敗によって普及の遅れる可能性があります。

JovanovicとRousseauは2005年に、電力(1894〜1930年)と情報技術(1971年〜)を2つの汎用技術として比較しました [ [ 258 ] ](https://www.nber.org/papers/w11093) 。両者とも、普及の初期に生産性成長が鈍化し、後に加速する共通のパターンを示しました。Nicholas Craftsは2021年に、蒸気・電力・情報通信技術の普及史を整理しました。汎用技術の生産性効果は発明から数十年遅れて現れ、効果の大きさは補完的な投資と制度に依存し、AIも同じ経路を辿るという論です [ [ 263 ] ](https://doi.org/10.1093/oxrep/grab012) 。

生成AIの事実に当てはめると、大規模言語モデル(LLM)が3つの基準を満たすことは、2023年にEloundouらが示しました [ [ 262 ] ](https://arxiv.org/abs/2303.10130) 。アメリカの職業のタスクごとに「LLMで同品質のまま所要時間を50%以上短縮できるか」を判定した結果、約80%の労働者はタスクの10%以上が影響を受けうるとされました。LLM単体では全タスクの約15%ですが、LLMの上に作られたソフトウェアを含めると47〜56%です。この「上に作られたソフトウェア」が、BresnahanとTrajtenbergの言う応用側のイノベーションに相当します。[市場の地図の章](18-market-map)で示した9つの層のうち、業務アプリ内蔵の層とエージェント基盤の層が、この応用側です。

当てはまらない点は、改良の速度です。[能力の計測の章](07-measuring-capability)で示したとおり、GPT-3.5相当の性能を得る推論の費用は2022年11月から2024年10月までに280分の1に下がりました [ [ 74 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/research-and-development) 。過去の汎用技術で、供給側の改良がこの速度で進んだ例はありません。供給側が速く、応用側が遅いという非対称は、過去より大きいと推定されます。

### 4. 無形資本と生産性Jカーブ ―― 見えない投資が先に積み上がる

経営判断にとっての意味は、導入の初期に生産性の数字が下がって見えるのは失敗の証拠ではなく、測定されない投資をしている証拠でありうる、ということです。ただし、投資をしていなければ、下がったままです。

BrynjolfssonとHittは2000年に、企業レベルのデータから、情報技術への投資の収益が業務プロセス、組織構造、人的資本への補完的な投資とセットで初めて大きくなることを示しました [ [ 270 ] ](https://doi.org/10.1257/jep.14.4.23) 。情報技術1ドルの投資に対し、約9ドルの無形の組織資本が伴うと推定され、この資産は国民経済計算に計上されません。この推定は投資額を直接測ったものではなく、企業の株式市場での評価から逆算したものです [ [ 1759 ] ](https://www.brookings.edu/wp-content/uploads/2002/01/2002a_bpea_brynjolfsson.pdf) 。Bloom、Sadun、Van Reenenは2012年に、ヨーロッパに立地するアメリカ系企業が同じ技術から高い生産性を得ていたことを示し、その差を人材管理の慣行で説明しました [ [ 271 ] ](https://doi.org/10.1257/aer.102.1.167) 。

Brynjolfsson、Rock、Syversonは2021年に、この補完性を「生産性Jカーブ」として定式化しました [ [ 153 ] ](https://www.aeaweb.org/articles?id=10.1257%2Fmac.20180386) 。汎用技術の価値を引き出すには無形資本への投資が要り、この投資は産出として計上されないため、普及の初期には測定された生産性が実力より低く出ます。無形資本が蓄積して収益を生み始めると、生産性は実力より高く出ます。計算機関連の無形資産を調整すると、2017年末のアメリカの全要素生産性の水準は公式統計より15.9%高いと推計されました。

生成AIの事実に当てはめると、3種類の測定値がJカーブの別の場所を測っていると読めます。第一に、個人の実験は補完的な投資を要しない範囲の効果を測ります。専門職のライティング課題で所要時間が37%短縮し [ [ 142 ] ](https://economics.mit.edu/sites/default/files/inline-files/Noy_Zhang_1.pdf) 、顧客サポートで1時間あたりの解決件数が15%増え [ [ 143 ] ](https://www.gsb.stanford.edu/faculty-research/publications/generative-ai-work) 、プログラミングの対照実験で55.8%速く完了した [ [ 144 ] ](https://arxiv.org/abs/2302.06590) という結果は、いずれも作業の単位で測ったものです。第二に、企業の損益は補完的な投資の途中の状態を測ります。MITの2025年の報告では、300〜400億ドルの企業の生成AI投資に対し、95%の組織が損益上の効果を得ていませんでした [ [ 177 ] ](https://mlq.ai/media/quarterly_decks/v0.1_State_of_AI_in_Business_2025_Report.pdf) 。第三に、国の統計はすべてを合算します。Acemogluは既存の推計に基づき、今後10年の全要素生産性(TFP)の上昇を最大0.66%、投資の反応を含むGDPの増加を0.93〜1.16%と推計しました [ [ 151 ] ](https://www.nber.org/papers/w32487) 。Goldman Sachsは10年で世界のGDPを7%押し上げうると推計しました [ [ 152 ] ](https://www.goldmansachs.com/insights/articles/generative-ai-could-raise-global-gdp-by-7-percent) 。同じGDPで並べると、約1%と7%です。日本生産性本部の2026年の報告では、就労者のAI利用率22.3%と利用業務の比率15.9%から、マクロの生産性効果は1.4%と試算されています [ [ 154 ] ](https://www.jpc-net.jp/research/assets/pdf/innocon20260930_nenji2026.pdf) 。推計の幅は、無形資本の蓄積をどう仮定するかの差です。

当てはまらない点が2つあります。第一に、Jカーブは「投資をしている組織」の見かけの生産性が下がる現象です。試行だけで補完的な投資をしていない組織では、曲線は動きません。MITの報告で損益に届かなかった95%のうち、どれだけが投資の途中で、どれだけが投資をしていないかは、この数字からは分かりません。第二に、生成AIの補完的な投資は過去より小さい可能性があります。自然言語で指示できるため、操作の訓練は少なくて済みます。一方で、[投資対効果と失敗率の章](15-roi-and-failure)で示したとおり、出力の評価と統治という過去に無かった投資が要ります。Jカーブの深さと長さは、過去の汎用技術から推定できません。

### 5. Perezの技術革命論 ―― バブルは逸脱ではなく周期の一部

経営判断にとっての意味は、投資の過熱と調整が来ても技術は消えず、調整の後に本格的な展開期を迎えた例は歴史に5回あるということです。ただし、周期の長さと今回の位置は確定していません。

Carlota Perezは2002年に、産業革命以来の5つの技術革命が約50年の周期で同じ構造を繰り返すと論じました [ [ 261 ] ](https://doi.org/10.4337/9781781005323) 。前半の「導入期」は金融資本が主導し、新技術への過剰な投資がバブルと崩壊を生みます。崩壊後の「転換点」で制度の再編が起き、後半の「展開期」は生産資本が主導して技術が経済全体に広がります。同書は、バブルを逸脱ではなく、新しいインフラへの過剰投資を実現する周期の必須の要素と位置づけます。

生成AIの事実に当てはめると、[計算資源・資本・電力の章](08-compute-capital-energy)で示した設備投資の規模と、[言説の分類の章](25-discourse-taxonomy)で示すバブル論の併存は、Perezの導入期の特徴と重なります。Goldman Sachsは2024年6月に、今後数年で約1兆ドルのAI設備投資が見込まれる一方、生成AIがそれに見合う問題を解くようには設計されていないという懐疑を掲載しました [ [ 342 ] ](https://www.goldmansachs.com/insights/top-of-mind/gen-ai-too-much-spend-too-little-benefit) 。Perezの枠組みでは、この懐疑と投資の併存は転換点の前に典型的に現れます。

当てはまらない点は2つあります。第一に、Perez自身は2024年3月の論考で、AIをまだ進化の途中にある情報通信技術(ICT)の革命の中の重要な展開と位置づけており、新しい技術革命の導入期とは呼んでいません [ [ 1807 ] ](https://www.project-syndicate.org/magazine/ai-is-part-of-larger-technological-revolution-by-carlota-perez-1-2024-03) 。本書は、設備投資と懐疑の併存という投資の構造が導入期に似る点だけを転用しています。第二に、Perezの周期は5つの事例からの帰納であり、周期の長さが50年と固定されている根拠が弱いことです。また、Perezの枠組みは「転換点がいつ来るか」を予測しません。本書は、転換点の到来を[道筋Cの章](28-path-c-correction)で1つの道筋として扱い、[3つの道筋の比較の章](29-paths-comparison-indicators)で早期警戒指標を置きます。

### 6. 3つの測定値を1本の曲線に置く

本章の理論を組み合わせれば、[生産性の実証の章](13-productivity-evidence)および[投資対効果と失敗率の章](15-roi-and-failure)の矛盾は、次のように整理できます。

個人の実験で観測される効果は、補完的な投資を要しない範囲の効果であり、Jカーブの出発点の高さを示します。企業の損益で観測される低い実現率は、補完的な投資の途中か、投資をしていないかのどちらかです。国の統計で観測される小さな効果は、普及の初期に汎用技術が常に示したパターンです。

この整理が正しいなら、経営の問いは「生成AIは効くか」ではなく「自社は補完的な投資をしているか」です。何が補完的な投資にあたるかは、次の章で組織の内部化として扱い、[各段階で必要なものの章](34-requirements-and-providers)で具体化します。

#### 図の読み方

この図は、横軸に時間、縦軸に測定される生産性を取った生産性Jカーブの模式図です。曲線は、補完的な投資の期間に一度下がり、投資が収益を生み始めると上がります。

曲線の上に3つの印を置いています。左上の印は個人の実験で、作業の単位で測った効果です。図の「+15〜55%」は、解決件数15%増、所要時間37%短縮、プログラミングの55.8%の短縮という3つの実験の幅を示します。中央の印は企業の損益で、損益上の効果を得ていない組織が95%という報告に対応します。右の印は国の統計で、10年でGDPが約1%から7%という推計の幅に対応します。Acemogluの0.66%は全要素生産性の値で、GDPに直すと約1%です。

曲線の下の帯は、補完的な投資の期間です。業務手順、データ、評価、統治への投資がここで行われ、統計には計上されません。曲線が上がるかどうかは、この帯の投資をしたかどうかで決まります。図中の数値の出典は本文の第4節に記しています。

### 本章の位置づけ

本章で取り上げた理論の選択と、生成AIの事実への当てはめは、著者の判断です。

汎用技術の理論が本書の推論に与える結論は、次の3つです。第一に、個人の効果と企業の効果の乖離は、過去の汎用技術で繰り返し観測された現象であり、生成AIに固有の失敗ではありません。第二に、乖離を埋めるのは技術の改良ではなく、導入する側の補完的な投資です。第三に、補完的な投資の中身は過去と異なり、物理的な資産の更新ではなく、業務手順、データ、評価、統治の整備です。

これらの結論は、[道筋Bの章](27-path-b-gradual)の前提になります。道筋Bは、供給側の改良が続いても、応用側の投資が律速するために普及が10年単位で進むという推論です。同時に、[道筋別の戦略の章](35-strategy-by-path)で「後悔しない手」として補完的な投資を置く根拠にもなります。どの道筋でも、補完的な投資をした組織だけがJカーブの上昇に乗ります。

次の章は、補完的な投資の中身である「組織の内部化」を、段階論として扱います。
