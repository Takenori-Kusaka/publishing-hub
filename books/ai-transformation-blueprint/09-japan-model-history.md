### 序論：本章が扱う範囲

本章は、日本における生成AIの技術開発の経緯を、2021年から2026年10月までの一次資料で整理します。対象は、研究機関と企業による日本語モデルの開発、計算資源を支援する国の事業、そして政府自身が利用者として国産モデルを評価・調達する動きです。

ここまでの章で追ってきた世界の技術史に対して、日本は基盤モデルの開発で先行者ではありませんでした。しかし、2023年以降、研究・商用・政策の3つの経路で独自の動きが並行して進みました。本章は、その経路を時系列で記述します。

本文は、プレスリリース、政策文書、公的機関の発表に基づく事実の記述に限定します。日本の技術開発の位置づけと、企業にとっての意味は、章末で扱います。[日本の条件の章](19-japan-conditions)では、本章の技術史を人口・人材・産業構造の文脈に置き直します。

### 1. 前史：日本語モデルの研究公開(2021〜2023年)

日本語に特化した生成モデルの公開は、世界のChatGPT公開より前から始まっていました。rinnaは2021年4月7日に、日本語のGPT-2(medium)を公開しました。日本語のCC-100とWikipediaを学習データとし、MITライセンスで配布されています [ [ 94 ] ](https://huggingface.co/rinna/japanese-gpt2-medium) 。

ChatGPTの公開から約9か月後の2023年8月18日、東京大学の松尾研究室は、100億パラメータで日英2か国語のWeblab-10Bを公開しました。このモデルは商用利用を認めていません [ [ 95 ] ](https://www.t.u-tokyo.ac.jp/press/pr2023-08-18-001) 。

この時期の日本語モデルは、研究目的の公開が中心でした。商用提供を前提とした開発が本格化するのは、2023年秋以降です。

### 2. 商用モデルの登場(2023年11月〜2024年)

NTTは2023年11月1日に、軽量な大規模言語モデル(LLM)「tsuzumi」を発表しました。6億と70億パラメータの2種で、NTTがゼロから開発した国産モデルであること、1基のGPUで動作する軽量さを特徴として掲げています。商用提供は2024年3月25日に始まりました [ [ 97 ] ](https://group.ntt/jp/newsrelease/2023/11/01/231101a.html) 。

ELYZAは2024年3月12日に、700億パラメータのELYZA-japanese-Llama-2-70bを発表しました。Metaの公開モデルを土台に日本語性能を高めたもので、グローバルモデルに匹敵する性能を主張しています [ [ 99 ] ](https://elyza.ai/news/2024/03/12/%E3%82%B0%E3%83%AD%E3%83%BC%E3%83%90%E3%83%AB%E3%83%A2%E3%83%87%E3%83%AB%E3%81%AB%E5%8C%B9%E6%95%B5%E3%81%99%E3%82%8B700%E5%84%84%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%81%AE%E6%97%A5%E6%9C%AC%E8%AA%9Ellm%E3%82%92) 。

2024年5月10日には、東京工業大学、東北大学、富士通、理化学研究所、名古屋大学、サイバーエージェント、Kotoba Technologiesが、スーパーコンピュータ「富岳」で学習したFugaku-LLMを公開しました。研究と商用のどちらの目的にも利用できます [ [ 100 ] ](https://www.titech.ac.jp/news/2024/069217) 。

ソフトバンクグループのSB Intuitionsは2024年6月14日に、70億、130億、650億から700億パラメータのSarashinaを公開し、2024年度中に3,900億パラメータを目指すと発表しました。その後、2024年度に4,600億パラメータのモデルを完成させ、2025年11月28日から法人向けのSarashina APIの提供を始めています [ [ 101 ] ](https://www.sbintuitions.co.jp/news/press/20240614_01) 。

この時期の開発には、2つの型が見られます。1つは、海外の公開モデルを土台に日本語性能を高める型です。ELYZAがこれにあたります。もう1つは、ゼロから学習する型です。NTTのtsuzumi、Fugaku-LLM、Sarashinaがこれにあたります。

### 3. 計算資源と国の支援(2024年2月〜)

基盤モデルの開発には大規模な計算資源が要ります。経済産業省とNEDOは2024年2月から、GENIAC(Generative AI Accelerator Challenge)として、基盤モデル開発に必要な計算資源の提供支援と開発者コミュニティの運営を始めました [ [ 98 ] ](https://www.meti.go.jp/press/2024/10/20241010001/20241010001.html) 。

採択数は第1期(2024年2〜8月)が10件、第2期(2024年10月〜2025年4月)が20件です。第3期(2025年8月〜2026年3月)は24件、第4期(2026年度)は16件でした [ [ 411 ] ](https://www.meti.go.jp/press/2026/06/20260604003/20260604003.html) 。第3期の公募には43件の申請があり、24件が採択されました。助成はNEDOの「ポスト5G情報通信システム基盤強化研究開発事業」の枠組みで行われています [ [ 504 ] ](https://www.nedo.go.jp/koubo/CD3_100397.html) 。

2026年には、懸賞金型のGENIAC-PRIZE 2026が設けられました。テーマ1は「エッセンシャルワーカーの人手不足解消に資するAIを活用した業務プロセス改革」で、企業・団体を対象に総額6億円です。テーマ2は「フィジカルAIに向けた開発者育成」で、学生を対象に総額3,000万円です。成果物の提出は2026年11月末です [ [ 505 ] ](https://geniac-prize.nedo.go.jp) 。

公的な計算基盤の整備も進みました。産業技術総合研究所は2024年10月10日に、NVIDIA H200を計6,128基、766ノード備えるABCI 3.0を発表し、2025年1月に一般提供を始めました [ [ 102 ] ](https://www.aist.go.jp/aist_j/news/pr20241010.html) 。

安全性の評価については、2024年2月14日にAIセーフティ・インスティテュートがIPAの内部に設立されました。当面の業務は、安全性評価の調査と基準の検討、評価手法の検討、イギリス・アメリカの同種機関との国際連携です [ [ 503 ] ](https://www.meti.go.jp/press/2023/02/20240214002/20240214002.html) 。

### 4. 新興企業と第2世代のモデル(2025〜2026年)

東京で2023年に設立されたSakana AIは、2024年9月にシリーズAで資金を調達し、2025年11月17日にはシリーズBで約320億円(2億米ドル)を調達しました。調達後の評価額は約4,320億円(27億米ドル)です。2025年5月19日には、三菱UFJ銀行と3年を超える戦略的技術パートナーシップを締結しています [ [ 96 ] ](https://sakana.ai/series-a) 。

NTTは2025年10月20日に、tsuzumi 2の提供を始めました。同社の2025年度第1四半期の時点での生成AI関連の受注は、国内外あわせて1,827件です [ [ 97 ] ](https://group.ntt/jp/newsrelease/2023/11/01/231101a.html) 。

Preferred Networksは2026年6月22日に、ゼロから学習した国産モデルPLaMo 3.0 Primeの正式提供を始めました。推論型と非推論型の2種があり、文脈長を64Kから256Kへ拡張しています。同社はこの拡張を、AIエージェントとしての実務利用への対応と説明しています。2026年10月7日にはPLaMo翻訳を53言語対応に更新し、日本総合研究所は2026年10月からPLaMo 3.0 Primeの全社オンプレミス利用を始めました [ [ 103 ] ](https://www.preferred.jp/news/pr20260622) 。

2026年1月には、ソニーグループ、ソフトバンク、NEC、本田技研工業を主要株主とするNoetra株式会社が設立されました。同社は2026年6月に、経済産業省とNEDOの「AIロボット・フィジカルAIを見据えたマルチモーダル基盤モデル開発事業」の実施主体に採択され、三菱UFJ銀行は2026年7月16日に出資契約を締結しました [ [ 105 ] ](https://www.mufg.jp/dam/pressrelease/2026/pdf/news-20260716-001_ja.pdf) 。

### 5. 政府が利用者になる(2023年12月〜2026年)

日本の技術史で特徴的なのは、政府が自ら生成AIの利用者となり、段階的に規模を拡大してきたことです。

デジタル庁は2023年度(2023年12月〜2024年3月)に、行政における生成AIの技術検証を実施しました。複数のLLMを選べるチャット環境を中央省庁の一部職員と一部自治体に提供し、職員自身による業務改善と、個別の用途の2つを検証しました。報告書、投稿されたプロンプトの一覧、テストケースの例が公開されています [ [ 513 ] ](https://www.digital.go.jp/news/19c125e9-35c5-48ba-a63f-f817bce95715) 。

2024年度の技術検証(2024年6月開始)では、機密性2の情報を扱える環境を提供しました。2025年2月の時点で、週間平均の利用者は134名、平均のAPIリクエストは1,877回、職員が作った生成AIアプリは累計85個です。アンケート回答者117名のうち12名が自らアプリを開発し、専門家の伴走支援を受けたチームの70%が業務利用に至りました [ [ 514 ] ](https://www.digital.go.jp/news/527968c1-5f55-42d4-868c-54112776c19f) 。

2026年3月6日、デジタル庁は全府省庁の約18万人の政府職員を対象に、ガバメントAI「源内」の大規模実証を2026年5月から2027年3月まで実施すると発表しました。2025年12月19日の総理指示は「2026年5月から10万人以上の政府の職員が活用できるように」というものでした [ [ 515 ] ](https://www.digital.go.jp/news/2d69c287-2897-46d8-a28f-ea5a1fc9bce9) 。

同日、デジタル庁は源内で試用する国産のLLM7件を、15件の応募から選定したと公表しました。選ばれたのは、tsuzumi 2、CC Gov-LLM、Llama-3.1-ELYZA-JP-70B、Sarashina2 mini、cotomi v3、Takane 32B、PLaMo 2.0 Primeです。試用と評価は2026年8月ごろから2027年3月まで行い、優れたモデルは2027年度に有償で調達する予定です [ [ 104 ] ](https://www.digital.go.jp/assets/contents/node/information/field_ref_resources/10d55c63-b3e1-42b9-9cc5-93a06943ae0e/51df3410/20260306_policies_ai_govai_result_of_the_open_recruitment_process.pdf) 。NECは2026年3月9日に、自社のcotomi v3がこの公募で選定されたと発表しています [ [ 516 ] ](https://jpn.nec.com/press/202603/20260309_03.html) 。

### 6. 政策の枠組み(2025年12月〜2026年7月)

これらの動きを束ねる計画も、短い間隔で改定されています。AI推進法(人工知能関連技術の研究開発及び活用の推進に関する法律)に基づく初の「人工知能基本計画」は、2025年12月23日に閣議決定されました。「世界で最もAIを開発・活用しやすい国」を目標に掲げ、計画は「当面毎年変更」すると明記しています [ [ 490 ] ](https://www.cao.go.jp/press/new_wave/20260206.html) 。

この第Ⅰ期の計画は、日本の現状を「AIが日常の生活や仕事の上で積極的に利活用されるものとなっていない」「AI関連の開発・投資についても、主要国はもちろん経済規模が小さい国にも後塵を拝する」と自己評価しています [ [ 491 ] ](https://www8.cao.go.jp/cstp/ai/ai_plan/aiplan_20251223.pdf) 。

約半年後の2026年7月14日、第Ⅱ期の「人工知能基本計画～日本AX、より強く、より豊かに～」が閣議決定されました。「エージェント型AI」を軸に、業種特化のAIとフィジカルAIを行政と産業の現場へ導入する方針を示しています。源内による「国内最大規模18万人」の政府職員のAI利活用を、その起点と位置づけました [ [ 492 ] ](https://www8.cao.go.jp/cstp/ai/ai_plan/aiplan_20260714.pdf) 。

この図は、上から下へ4つの段階を時系列で並べています。各段階の右側には、その段階を代表する出来事を1つずつ添えています。

第1段は研究の公開です。2021年のrinnaの日本語GPT-2と、2023年の東京大学のWeblab-10Bがここに入ります。第2段は商用化です。2023年11月のNTT tsuzumiの発表から、2024年のELYZA、Fugaku-LLM、Sarashinaまでが続きます。第3段は計算資源の支援です。2024年2月に始まったGENIACの採択数(10件、20件、24件、16件)と、ABCI 3.0を示しています。第4段は政府の調達です。2026年の源内による18万人規模の実証と、国産LLM7件の選定がここに入ります。

図の主張は1つです。日本の技術史は世界の基盤モデル競争への追随ではなく、研究から商用へ、そして政府が自ら利用者になる段階へ順に進んだ独自の経路を持つということです。各段階の数値は本文の第1節から第5節に対応します。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

本章の要点は3つです。

第一に、日本の基盤モデル開発は、ゼロから学習する型と、海外の公開モデルを土台にする型の2つが並行して進みました。両者は競合というより、用途の違いに対応しています。前者は国産であることや軽量さを、後者は性能の早期達成を重視しています。

第二に、国の関与は、規制ではなく計算資源の支援と、政府自身による利用に向かいました。GENIACの採択数の推移と、デジタル庁の検証が134名から18万人へ拡大した経緯が、この方向を示しています。

第三に、2026年の基本計画は「エージェント型AI」を軸に据え、政府の利用を民間展開の起点と位置づけました。計画は毎年改定される前提であり、固定した指針として読むべきものではありません。

著者は、日本の国産モデルが世界の最先端モデルと同じ性能で競うことを目標にしているとは読んでいません。むしろ、政府の調達、データを国内に置く要件、業種特化の用途という、別の競争軸で位置づけられていると考えます。この読み方が正しいかどうかは、2027年度の源内の有償調達の結果と、[市場の地図の章](18-market-map)で整理する国内事業者の収益で検証できます。

### 経営層への含意

日本企業にとっての本章の意味は、基盤モデルの選択肢が「海外の最先端か、国産か」の二択ではなくなったことです。政府が18万人規模で国産モデルを評価するという事実は、国産モデルの品質と運用の実績が、2027年以降に公開情報として蓄積されることを意味します。自社のデータの所在地、業種の要件、費用の観点から、どの層のモデルを使うかを判断する材料が、今後増えていきます。基盤モデルの選択は[各段階で必要なものの章](34-requirements-and-providers)で、政策の前提は[日本の条件の章](19-japan-conditions)で扱います。
