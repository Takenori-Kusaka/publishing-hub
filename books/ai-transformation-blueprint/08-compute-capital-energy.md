### 序論：本章が扱う範囲

本章は、生成AIを支える計算資源、それに投じられている資本、そして消費される電力の規模を整理します。[基盤の成立の章](01-foundations-2017-2020)で述べたスケーリング則は、計算量を投じれば性能が上がることを示しました。本章は、その帰結として実際にどれだけの計算量と資金が投じられ、どれだけの収益が返ってきているかを記述します。

本章の本文は、計測機関の推計、企業の決算、公的機関の統計、そして報道の4種類に限ります。報道の数値は、報道であることを明記します。「この投資は過剰か」という評価は本章では扱いません。それは[道筋Cの章](28-path-c-correction)で、言説の分類とともに扱います。

### 1. 学習に投じられる計算量

計測機関Epoch AIは2024年5月28日、注目すべきAIモデルの学習計算量が2010年から2024年5月まで年4倍から5倍で成長してきたと報告しました。2020年以降の最上位の言語モデルに限ると、年5倍、つまり5.2か月で倍増しています [ [ 72 ] ](https://epoch.ai/publications/training-compute-of-frontier-ai-models-grows-by-4-5x-per-year) 。StanfordのAI Index 2025も、学習計算量が5か月ごと、学習データが8か月ごとに倍増していると記しています。同報告によれば、2024年の注目モデルの約90%は産業界から生まれました。2023年は60%でした [ [ 75 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report) 。

年5倍の成長を5年続けると、計算量は3,000倍を超えます。計算資源の調達が、この成長を支える前提になっています。

### 2. 電力

計算量の成長は、電力の需要として現れます。Epoch AIによれば、最上位モデルの学習に要する電力は年2.2倍で増え、最大の学習は既に100メガワットを超えています [ [ 83 ] ](https://epoch.ai/publications/power-demands-of-frontier-ai-training) 。

国際エネルギー機関(IEA)は2025年4月の報告「Energy and AI」で、世界のデータセンターの電力消費が2030年に約945テラワット時へ倍増超になると見込みました。これは現在の日本の総消費電力をやや上回る量です [ [ 76 ] ](https://www.iea.org/reports/energy-and-ai/executive-summary) 。2026年の報告では、2025年のデータセンターの電力需要は17%増え、AI特化のデータセンターだけなら50%増えたとしています。2025年の485テラワット時から2030年の950テラワット時へ、ほぼ倍増する見込みです [ [ 77 ] ](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary) 。

### 3. 設備投資

計算資源への投資は、クラウド事業者の設備投資として決算に現れます。

IEAの2026年の報告は、大手5社の設備投資が2025年に4,000億ドルを超え、2026年にはさらに75%増える見込みだと記しています [ [ 77 ] ](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary) 。個別には、Alphabetの2025年の設備投資は914.5億ドルでした。報道によれば、Alphabet、Meta、Microsoft、Amazonの2025年の見通しの合計は3,800億ドルを超えていました [ [ 79 ] ](https://www.reuters.com/business/alphabets-cloud-unit-beats-quarterly-revenue-estimates-strong-ai-demand-2026-04-29) 。

2026年の計画は、各社の決算発表で示されています。Alphabetは2026年2月4日の決算説明で、2026年の設備投資を1,750億ドルから1,850億ドルの範囲と見込みました [ [ 90 ] ](https://abc.xyz/investor/events/event-details/2026/2025-Q4-Earnings-Call-2026-Dr_C033hS6/default.aspx) 。報道によれば、Metaは1,150億ドルから1,350億ドル、Amazonは約2,000億ドルを見込み、4社の合計は5,000億ドルを超えるとされています [ [ 80 ] ](https://www.reuters.com/business/meta-expects-annual-capital-expenditures-rise-superintelligence-push-2026-01-28) 。

投資の計画は、クラウド事業者の外にも広がりました。OpenAIは2025年1月21日、4年間で5,000億ドルをアメリカのAIの計算基盤に投じるStargate計画を発表しました [ [ 27 ] ](https://openai.com/index/announcing-the-stargate-project) 。同社は2025年10月13日にBroadcomと提携し、自社設計の計算用の半導体を10ギガワット分展開すると公表しています [ [ 82 ] ](https://openai.com/index/openai-and-broadcom-announce-strategic-collaboration) 。

### 4. 民間投資の規模

AI Index 2026の経済の章によれば、2025年の世界の企業によるAI投資は5,816.9億ドルで、前年の2倍を超えました。アメリカの民間AI投資は2,858.8億ドルで、中国の124.1億ドルの23倍です。同じ報告は、OpenAIとAnthropicの2025年の計算資源への支出をそれぞれ163億ドルと68億ドルと記しています [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

資金調達の規模も記録を更新しています。2026年2月27日、OpenAIは1,100億ドルの資金調達を公表しました。Amazonが500億ドル、NVIDIAとSoftBankが各300億ドルを出資し、調達前の評価額は7,300億ドルでした [ [ 85 ] ](https://techcrunch.com/2026/02/27/chatgpt-reaches-900m-weekly-active-users) 。報道によれば、OpenAIは2026年3月31日に1,220億ドルの調達を完了し、調達後の評価額は8,520億ドルとなりました [ [ 88 ] ](https://www.businesstoday.in/technology/story/openai-raises-122-billion-funding-ahead-of-ipo-buzz-523445-2026-04-01) 。報道によれば、Anthropicは2026年5月28日に650億ドルを調達し、評価額は9,650億ドルとなりました [ [ 89 ] ](https://www.reuters.com/technology/anthropic-revenue-run-rate-tops-65-billion-source-says-2026-08-17) 。Anthropicは2026年10月26日、新規株式公開へ向けた登録届出書をアメリカのSEC(証券取引委員会)へ提出したと公表しています [ [ 57 ] ](https://www.anthropic.com/news/announcements) 。

### 5. 収益

投資に対して、収益がどれだけ返っているかは、公式の発表と報道の数値が食い違う領域です。本書は両方を記します。

OpenAIの公式ページは、週間アクティブユーザー9億人超、有料会員5,000万人超、月間売上20億ドル、企業向けが売上の40%超と記しています [ [ 86 ] ](https://openai.com/index/accelerating-the-next-phase-ai) 。月間売上20億ドルは年に換算すると240億ドルです。報道によれば、OpenAIの年間経常収益は2025年6月、100億ドルに達しました [ [ 87 ] ](https://www.cnbc.com/2025/06/09/openai-hits-10-billion-in-annualized-revenue-fueled-by-chatgpt-growth.html) 。2026年9月末の時点については、約500億ドルとする報道と約700億ドルとする報道が並立しており、差はクラウド経由の売上をどう算入するかの違いによるとされています。本書は、どちらか一方を採用しません。

Anthropicについては、報道によれば年間経常収益は2025年末の約90億ドルから、2026年5月の470億ドル超、2026年7月末の650億ドル超へ増えました [ [ 89 ] ](https://www.reuters.com/technology/anthropic-revenue-run-rate-tops-65-billion-source-says-2026-08-17) 。一方、同じ報道機関が入手した新規株式公開の目論見書の草案を引く別の報道は、2025年の通年の売上を46億ドル、純損失を420億ドルとしています。年間経常収益は直近の月の売上を12倍した値であり、通年の実績とは定義が異なります。急成長する企業では、この2つの値は大きく開きます。

AI Index 2026が記した2025年の計算資源への支出(OpenAI 163億ドル、Anthropic 68億ドル)と、これらの収益の数値を並べると、2025年の時点では支出が収益を上回っていたことになります。2026年の収益の報道値は、この関係が逆転しつつあることを示しますが、純損失の数値と整合する公式の決算は、本書の執筆時点では公表されていません。

### 6. 市場の評価

計算資源の供給側では、NVIDIAの時価総額が節目を更新しました。報道によれば、2025年7月9日に初めて4兆ドルへ到達し、2025年10月29日には5兆ドルへ達しました [ [ 78 ] ](https://www.reuters.com/world/china/nvidia-becomes-first-company-clinch-4-trillion-market-value-2025-07-09) 。

市場の評価は一方向ではありません。[推論モデルと価格の章](04-reasoning-and-cost-2024)で述べたとおり、2025年1月27日にはDeepSeekの報告を受けてNVIDIAの時価総額が1日で約5,930億ドル減ったと報じられました [ [ 26 ] ](https://www.reuters.com/markets/us/nasdaq-futures-tumble-chinas-ai-push-rattles-big-tech-2025-01-27) 。DeepSeek-V3の技術報告が示した278万8,000 GPU時間という学習の計算量は、投資の前提を揺らす材料として受け止められました [ [ 24 ] ](https://arxiv.org/abs/2412.19437) 。

### 7. 投入と回収の整理

| 項目 | 規模 | 時点 | 出典の種類 |
| --- | --- | --- | --- |
| 学習計算量の成長 | 年4〜5倍 | 2010〜2024年 | 計測機関 |
| データセンターの電力 | 485→950テラワット時 | 2025→2030年(見込み) | 公的機関 |
| 大手5社の設備投資 | 4,000億ドル超、2026年は75%増の見込み | 2025年 | 公的機関 |
| 世界の企業AI投資 | 5,816.9億ドル | 2025年 | 年次報告 |
| OpenAIの月間売上 | 20億ドル | 2026年 | 公式 |
| Anthropicの年間経常収益 | 650億ドル超 | 2026年7月 | 報道 |

投入の数値は公的機関と決算で裏づけられています。回収の数値は、公式の発表が限られ、報道と定義の差に依存しています。この非対称が、本章の記述の構造です。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、学習計算量は年4倍から5倍で増え、設備投資は2025年に4,000億ドルを超え、2026年にはさらに75%増える見込みです。第二に、電力の需要は2030年に2025年の2倍に達する見込みで、計算資源の制約は電力の制約として現れ始めています。第三に、投入の数値は公的機関と決算で裏づけられる一方、回収の数値は報道と定義の差に依存しており、投入と回収の情報の質に非対称があります。

著者は、この非対称そのものを、経営層が知っておくべき構造だと考えます。投入の確かさと回収の不確かさの同居は、提供事業者の側へ財務の圧力をかけます。圧力は、価格の改定、製品の統廃合、提供事業者の再編として、利用者の側に及びます。[競争の構造化の章](03-competition-2023)で述べた「差は固定されない」という構造に、「提供事業者の財務も固定されない」という構造が重なります。

### 経営層への含意

生成AIの導入計画は、提供事業者の存続と価格の安定を前提にできません。これは悲観の勧めではなく、設計の前提です。特定の提供事業者に依存しない構成、契約の単位の短縮、そして電力と計算資源の制約が自社の業務に及ぶ経路の把握が、本章の事実から導かれる実務上の対応です。[道筋Cの章](28-path-c-correction)では、この圧力が現実になった場合の経過を推論します。
