### 序論：本章が扱う範囲

本章は、日本で生成AIの導入を考える経営層が前提にすべき、日本固有の条件を整理します。対象は、法律と政策、労働供給と人口、IT人材の分布と産業構造、普及の実態、先行企業の経過、行政と教育の方針です。情報源は、法令、政府の計画と白書、公的統計、企業の一次発表に限ります。

世界の普及率と比べて日本がどこにいるかは、[個人の利用の章](11-individual-adoption)と[企業の利用の章](12-enterprise-adoption)で扱いました。本章は、その差を生んでいる条件の側を記述します。条件をどう戦略に反映するかは、[道筋別の戦略の章](35-strategy-by-path)で扱います。

本章の末尾には、条件を10項目に要約した一覧を置きます。一覧は著者の整理です。

### 1. 法律は推進法であり、罰則も企業の義務もほぼない

日本初のAIに関する基本法「人工知能関連技術の研究開発及び活用の推進に関する法律」(以下、AI推進法)は、2025年5月28日に成立し、6月4日に公布、9月1日に全面施行されました。全28条で、罰則の規定はありません [ [ 487 ] ](https://laws.e-gov.go.jp/law/507AC0000000053) 。内閣府は、この法律の趣旨を、国内のAI開発と活用が遅れ、多くの国民がリスクに不安を抱えている状況への対応と説明しています [ [ 488 ] ](https://www8.cao.go.jp/cstp/ai/ai_act/ai_act.html) 。

同法の第3条2項は、AIを行政事務と民間の事業活動の効率化と高度化をもたらす基盤技術であり、安全保障の観点からも重要な技術と位置づけます。第7条は、AIを業務で利用する「活用事業者」に国の施策への協力の責務を定めており、企業に直接義務を課す条文はこれだけです [ [ 487 ] ](https://laws.e-gov.go.jp/law/507AC0000000053) 。

守るべき水準は、拘束力のない指針が示します。同法第13条に基づく「適正性確保に関する指針」は2025年12月19日に決定され、「一義的な定義や絶対的な水準を定めるものではなく」、人間中心や公平性など10の要素と4つの基本方針を示して、各主体の自主的な取り組みを求めています [ [ 493 ] ](https://www8.cao.go.jp/cstp/ai/ai_guideline/ai_gl_2025.pdf) 。総務省と経済産業省の「AI事業者ガイドライン」は、第1.0版の2024年4月19日から第1.2版の2026年3月31日まで改定を重ねてきました [ [ 494 ] ](https://www.meti.go.jp/shingikai/mono_info_service/ai_shakai_jisso/index.html) 。同ガイドラインは自らを「非拘束的なソフトロー」と位置づけ、AIの開発、提供、利用を担うすべての者を対象とします [ [ 495 ] ](https://www.soumu.go.jp/main_content/001002576.pdf) 。第1.2版では、AIエージェントとフィジカルAIの定義、便益、リスクが追記され、チェックリストとワークシートが公開されました [ [ 496 ] ](https://www.meti.go.jp/shingikai/mono_info_service/ai_shakai_jisso/20260331_report.html) 。

欧州連合のAI規則(EU AI Act)のような規制対応ではなく、自社でガバナンスの水準を決める構造です。規制の国際比較は[統治と規制の章](17-governance-regulation)で扱います。

### 2. 国の計画は毎年書き換わり、2026年に「AX」が公式の語になった

AI推進法第18条に基づく初の「人工知能基本計画」(第Ⅰ期)は、2025年12月23日に閣議決定されました。副題は「『信頼できるAI』による『日本再起』」で、「世界で最もAIを開発・活用しやすい国」を目標に掲げ、「当面毎年変更」すると明記しています [ [ 490 ] ](https://www.cao.go.jp/press/new_wave/20260206.html) 。計画は日本の現状を、AIが日常の生活や仕事で積極的に利活用されるものになっておらず、開発と投資でも主要国に後れを取っていると自己評価しています [ [ 491 ] ](https://www8.cao.go.jp/cstp/ai/ai_plan/aiplan_20251223.pdf) 。

第Ⅱ期の計画「日本AX、より強く、より豊かに」は、第Ⅰ期から約半年後の2026年7月14日に閣議決定されました。エージェント型AIを軸に、業界特化のAIとフィジカルAIを行政と産業の現場へ導入する方針を示し、政府職員18万人がAIを使う体制を起点に位置づけています [ [ 492 ] ](https://www8.cao.go.jp/cstp/ai/ai_plan/aiplan_20260714.pdf) 。

政府自身の利用も段階を踏んでいます。デジタル庁は2023年度に、複数の大規模言語モデルを選べるチャット環境を一部の職員に提供して検証しました [ [ 513 ] ](https://www.digital.go.jp/news/19c125e9-35c5-48ba-a63f-f817bce95715) 。2024年度の検証では、2025年2月時点で週間平均134名が利用し、生成AIアプリが累計85個作られ、専門家の伴走支援を受けたチームの70%が業務利用に至りました [ [ 514 ] ](https://www.digital.go.jp/news/527968c1-5f55-42d4-868c-54112776c19f) 。2026年3月6日には、全府省庁の約18万人を対象にガバメントAI「源内」の大規模実証を2026年5月から2027年3月に実施すると発表しました [ [ 515 ] ](https://www.digital.go.jp/news/2d69c287-2897-46d8-a28f-ea5a1fc9bce9) 。

計算資源の支援も続いています。経済産業省とNEDOのGENIACは2024年2月に始まりました。基盤モデル開発への計算資源支援の採択数は第1期から順に10件・20件・24件・16件です [ [ 411 ] ](https://www.meti.go.jp/press/2026/06/20260604003/20260604003.html) 。

### 3. 学習目的のデータ利用は、法律上の許容範囲が広い

著作権法第30条の4は、著作物に表現された思想または感情の享受を目的としない利用を、許諾なく行えると定めています。情報解析はこれに含まれます。ただし、著作権者の利益を不当に害する場合は除かれます。文化庁はこれを「柔軟な権利制限規定」と呼んでいます [ [ 497 ] ](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html) 。文化審議会の「AIと著作権に関する考え方について」(2024年3月15日)は、開発と学習の段階と、生成と利用の段階を分けて整理しました。法的な拘束力はありません [ [ 498 ] ](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94037901_01.pdf) 。同文書の概要は、「作風」が共通しても著作権侵害にならない一方、特定の作者を狙った学習や海賊版と知りながらの収集は規定の適用外になりうるとしています [ [ 499 ] ](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94057901_01.pdf) 。

個人情報については、個人情報保護委員会が2023年6月2日に注意喚起を公表しました。個人データを含む入力が利用目的の範囲内かを確認し、提供事業者が機械学習に利用しないことを確認するよう求めています [ [ 500 ] ](https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert) 。2026年7月10日には個人情報保護法の改正が成立し、7月17日に公布されました [ [ 501 ] ](https://www.ppc.go.jp/files/pdf/260731_shiryou-1.pdf) 。改正の柱は、統計作成等と整理できるAI開発等にのみ利用する場合に本人同意を不要とすること、重大な違反への課徴金、16歳未満の個人情報の規律、顔特徴データの周知義務の4つです [ [ 502 ] ](https://www.ppc.go.jp/files/pdf/260717_kaiseihounitsuite.pdf) 。

金融分野では、金融庁が2025年3月にAIディスカッションペーパーの第1.0版を、2026年3月3日に第1.1版を公表しました。同庁の基本姿勢は技術中立です [ [ 509 ] ](https://www.fsa.go.jp/news/r7/sonota/20260303/aidp.html) 。

### 4. 労働供給は構造的に減る

人口の年齢構成は、すでに確定した与件です。国立社会保障・人口問題研究所の令和5年推計(出生中位・死亡中位)では、総人口は2020年の1億2,615万人から2070年に8,700万人へ減ります。15歳から64歳の人口は、2020年の7,509万人から2070年の4,535万人へ減り、2032年に7,000万人、2043年に6,000万人を割ります [ [ 517 ] ](https://www.ipss.go.jp/pp-zenkoku/j/zenkoku2023/pp2023_gaiyou.pdf) 。この推計は、前回より出生率の仮定を下げた一方、外国人の入国超過の増加を反映して、2070年の総人口を前回の8,323万人から上方修正しています [ [ 518 ] ](https://www.mhlw.go.jp/content/12601000/001093650.pdf) 。

リクルートワークス研究所の労働需給シミュレーションは、労働需要がほぼ横ばいのまま供給が減り、2030年に約341万人、2040年に約1,100万人の労働供給不足が生じると試算しました。同研究所はこれを、景気による一時的な人手不足ではなく、生活を維持するサービスが回らなくなる構造的で慢性的な不足と定義しています [ [ 173 ] ](https://recruit-holdings.com/ja/blog/post_20230926_0001) 。職種別の2040年の不足率は、輸送・機械運転・運搬24.2%、建設22.0%、商品販売24.8%、介護サービス25.3%です [ [ 519 ] ](https://www.works-i.com/research/report/item/forecast2040.pdf) 。同研究所によれば、人口に占める15歳から24歳の比率は2025年に9.3%で、先進7か国で最も低い値です [ [ 525 ] ](https://www.works-i.com/research/project/recruitment-training/issues/detail001.html) 。

この条件は、企業の導入目的に表れています。2026年版の中小企業白書によれば、省力化投資のうちAI活用に取り組んだ中小企業は全体の約3割で、目的は「業務時間の節減」が8割超、次いで「人手不足の解消」「業務の属人化解消」でした [ [ 531 ] ](https://www.chusho.meti.go.jp/pamflet/hakusyo/2026/chusho/b2_2_2.html) 。NEDOの懸賞金型事業GENIAC-PRIZE 2026も、エッセンシャルワーカーの人手不足解消に資する業務プロセス改革を第一の主題にしています [ [ 505 ] ](https://geniac-prize.nedo.go.jp) 。

### 5. IT人材の約4分の3がベンダー側にいる

情報処理推進機構(IPA)の日米比較によれば、情報処理・通信に携わる人材のうちIT企業に所属する割合は、日本で73.6%(2020年)、アメリカで35.1%(2021年)です。日本ではIT人材の約4分の1しか利用企業側にいません [ [ 520 ] ](https://www.ipa.go.jp/archive/press/2022/press20230316-2.html) 。

産業の構造も記録しておきます。経済産業省の2018年の「DXレポート」は、複雑化し老朽化した既存システムを放置すると、2025年以降に最大で年12兆円の経済損失が生じうるとして、これを「2025年の崖」と呼びました [ [ 506 ] ](https://www.meti.go.jp/policy/it_policy/dx/20180907_01.pdf) 。同レポートの本文は、ベンダー企業が既存システムの保守に人員を割かれ、「人月商売の多重下請構造から脱却できない」と予想しています [ [ 507 ] ](https://www.meti.go.jp/policy/it_policy/dx/20180907_03.pdf) 。

日本情報システム・ユーザー協会の「企業IT動向調査2026」(東証に上場する企業等のIT部門長、回答957社)の序文は、「2025年の崖」とされた2025年が到来し、複雑化するシステムへの対応に苦戦する企業が多数あると述べています [ [ 523 ] ](https://juas.or.jp/cms/media/2026/04/JUAS_IT2026.pdf) 。

### 6. 「使っている」は急増したが、効果は文書作業に偏る

企業の利用率は、[企業の利用の章](12-enterprise-adoption)で定義差とともに整理しました。本章では、効果の中身に関する数値を記録します。

総務省の令和8年版の情報通信白書(2025年度調査)によれば、日本で生成AIの効果を実感する割合は、議事録・メール作成補助で72.3%、社内ヘルプデスクで42.7%、製造・生産で39.8%、経営で20.1%でした。同じ白書で「組織的な取組はない」と答えた割合が3割弱と他の3か国より高く、社内データの基盤の構築率も低いこと [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) は、[企業の利用の章](12-enterprise-adoption)で述べたとおりです。

IPAの「DX動向2026」では、AIを導入または試験利用している企業は58.0%で、用途は「文書・音声の要約・翻訳・校正」82.5%、「文書・レポートの作成」80.5%が上位でした。利用部署はITシステム71.9%、経営企画69.0%に対し、製造35.7%、調達31.3%、流通23.9%です。AIエージェントの利用はいずれの部署でも低い水準でした [ [ 124 ] ](https://www.ipa.go.jp/digital/chousa/dx-trend/rcu1hd0000017uk8-att/dx-trend-2026.pdf) 。

帝国データバンクの2026年3月の調査(有効回答10,312社)では、活用企業の86.7%が業務への効果が出ていると答えた一方、悪影響として「使いこなし格差の拡大」を挙げた企業が18.8%ありました。懸念の最上位は「情報の正確性」50.4%です [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。

経済産業省は2024年6月、国内企業の生成AIの社内利活用が1年で大きく進んだ一方、「日常業務への組み込み、新サービス創出、これを後押しする経営層の関与が停滞(世界平均より低い)」と総括しました [ [ 226 ] ](https://www.meti.go.jp/press/2024/06/20240628006/20240628006.html) 。

### 7. 企業規模と業種で活用率に2倍近い差がある

帝国データバンクの同じ調査では、生成AIを業務で活用している企業は全体で34.5%でした。大企業46.5%に対し中小企業32.4%、小規模企業28.0%で、従業員1,000人超では63.6%、5人以下では29.6%です。業界別ではサービス業47.8%に対し、建設26.4%、運輸・倉庫27.5%でした [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。

総務省の令和7年版の白書(2024年度調査)でも、生成AIの活用方針を定めた企業は大企業約56%に対し中小企業約34%でした [ [ 106 ] ](https://www.soumu.go.jp/main_content/001019264.pdf) 。中小企業白書は、活用する業務のイメージができず活用していない事業者の存在を指摘しています [ [ 531 ] ](https://www.chusho.meti.go.jp/pamflet/hakusyo/2026/chusho/b2_2_2.html) 。

人材の訓練にも差があります。令和8年版の労働経済白書によれば、AI利用者のうち企業の訓練があった割合は、金融・保険業で日本26.9%に対しアメリカ60.5%でした [ [ 174 ] ](https://www.mhlw.go.jp/content/12602000/001753069.pdf) 。労働政策研究・研修機構のフォーラムでは、日本では生成AIに関する従業員向けガイドラインを策定していない企業の多さが示されました [ [ 512 ] ](https://www.jil.go.jp/event/ro_forum/20260120/houkoku/01-keynote-toda.html) 。

### 9. 行政と教育は「禁止しない」で統一された

行政の利用は、自治体から始まりました。横須賀市は2023年4月20日に全国の自治体で初めてChatGPTの全庁的な活用実証を始め、6月5日に本格実装へ移行しました。約半数の職員が実際に使い、回答者の約8割は効率の向上と継続利用を答えました。一方で、向かない「検索用途」は約3割あり、6%程度の職員は概ね不適切な回答が返ると答えました [ [ 554 ] ](https://www.city.yokosuka.kanagawa.jp/0835/nagekomi/20230605_chatgpt2.html) 。神戸市は条例と基本指針により、利用前のリスク評価と、安全性が確認されていない生成AIへの機密情報の入力禁止を制度化しています [ [ 556 ] ](https://www.city.kobe.lg.jp/a08691/20231121_ai.html) 。

総務省の調査(2025年10月31日時点、1,788団体すべてが回答)では、生成AIを導入済みの団体は都道府県と指定都市で100%、その他の市区町村で45.6%でした。実証中や検討中を含めると約88%が導入に向けて取り組んでいます [ [ 557 ] ](https://www.soumu.go.jp/main_content/001070295.pdf) 。

教育では、文部科学省が2023年7月に暫定的なガイドラインを、2024年12月26日に第2.0版を公表しました [ [ 560 ] ](https://www.mext.go.jp/a_menu/other/mext_02412.html) 。東京大学は2023年4月28日、言語生成系AIツールの教育現場での利用を一律に禁止しない方針を示し [ [ 561 ] ](https://utelecon.adm.u-tokyo.ac.jp/docs/ai-tools-in-classes) 、2026年度からは課題ごとにAI利用の許可範囲をラベルで提示する仕組みを導入しています [ [ 562 ] ](https://utelecon.adm.u-tokyo.ac.jp/gen-ai/education/ai-use-policy-levels) 。資格試験では、日本ディープラーニング協会のG検定の2026年第5回に14,908名が受験し [ [ 563 ] ](https://www.jdla.org/news/20260924001/) 、IPAは2024年の試験から生成AIの項目を出題範囲に加えました [ [ 564 ] ](https://www.ipa.go.jp/shiken/syllabus/henkou/2023/20230807.html) 。

#### 図の読み方

図は左右2列です。左の列は、導入を後押しする条件で、法律の緩さ、データ利用の広い許容、労働供給の不足、国の推進計画の4つを置いています。右の列は、導入を遅らせる条件で、IT人材のベンダー側への偏り、効果の文書作業への偏り、企業規模による差、組織的な取り組みの不在の4つです。

左右のどちらも、条件そのものは本文の事実に基づきます。「後押し」と「遅らせる」という分け方は著者の整理で、同じ条件が立場によって逆に働くこともあります。たとえば労働供給の不足は導入の動機になる一方、導入を担う人材の不足でもあります。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

第一に、日本の制度は「禁止されないが、求められもしない」という状態です。法律に罰則はなく、指針は自主的な取り組みを求め、行政と教育は禁止しない方針で揃いました。これは、動かない理由を外部に求められない状態でもあります。

第二に、導入の動機と導入の能力が分離しています。労働供給の不足は、導入の動機として世界で最も強い部類です。一方で、IT人材の4分の3がベンダー側にいる構造は、導入を自社で設計する能力を弱めています。動機は強く、能力は外部にある、という組み合わせが日本の特徴です。

第三に、先行企業と全体の差が開いています。先行企業は4年で「全社展開から顧客への提供」までを一周しました。全体では効果は文書作業に偏り、組織的な取り組みのない企業も約3割あります。[企業の利用の章](12-enterprise-adoption)で扱った調査の定義差は、この二極化を反映しています。

### 経営層への含意

日本で導入を設計するときは、世界の調査が前提にしている条件のいくつかが成り立ちません。アメリカの研究が示す若年層の採用減は、人手不足の国では同じ形で現れません。EU AI Actを前提にした統治の設計は、日本では自社の指針に置き換える必要があります。そしてIT人材の偏在は、[運営モデルの進化の章](33-operating-model-evolution)で扱う「SaaSからIT部門へ、そして事業部へ」という経路のうち、IT部門の段階を外部のベンダーが担う形になりやすいことを意味します。著者は、その段階で知見を社内に残す設計をするかどうかが、日本企業の文化フェーズを分ける分岐点だと考えます。
