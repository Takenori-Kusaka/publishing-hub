### 序論：本章が扱う範囲

第Ⅲ部は、第Ⅰ部と第Ⅱ部で整理した事実を読むための枠組みを扱います。本章はその最初として、新しい技術が社会と組織にどう広がるかを説明する理論を整理します。

対象は、普及の速度と順序を扱う理論です。Rogersの普及理論、Mooreのキャズム、Bassの拡散モデルとGrilichesの収益性仮説、DavisとVenkateshの技術受容モデル、Gartnerのハイプ・サイクル、そしてAmaraに帰される格言の6つを取り上げます。広がった後に組織の内部で何が変わるかは、[汎用技術と生産性Jカーブの章](21-gpt-and-j-curve)と[組織の内部化の章](22-organizational-internalization)が扱います。

各理論について、第一に原典の主張を要約し、第二に[個人の利用の章](11-individual-adoption)と[企業の利用の章](12-enterprise-adoption)で示した生成AIの事実にどう当てはまるかを示し、第三に当てはまらない点を示します。理論の選択と当てはめは著者の判断であり、各節の冒頭に、その理論が経営判断にとって何を意味するかを1文で置きます。

### 1. Rogersの普及理論 ―― 誰が、どの順に採用するか

経営判断にとっての意味は、自社の従業員と顧客のうち「まだ使っていない多数派」が何を見て採用を決めるかを、理論が教えてくれることです。

Everett Rogersは1962年の『Diffusion of Innovations』で、普及を「イノベーションがある社会システムの成員の間で時間をかけて特定のチャネルを通じて伝達される過程」と定義しました [ [ 246 ] ](https://openlibrary.org/works/OL718011W) 。同書は、採用の速さを決める5つの属性を挙げています。既存の手段に対する相対的優位性、既存の価値観や経験との両立性、理解と使用の複雑性の3つに加え、小規模に試せる試行可能性と採用の結果が他者に見える観察可能性です。

採用者は、採用の早さに応じて5つに分類されます。革新者2.5%、初期採用者13.5%、前期多数派34%、後期多数派34%、遅滞者16%という構成です。累積の採用率はS字曲線を描きます。個人の採用の決定は、後の版では知識・説得・決定・実行・確認の5段階として整理されています。

生成AIの事実に当てはめると、5つの属性のうち4つが、過去の情報技術と比べて際立って高い水準にあります。相対的優位性は[生産性の実証の章](13-productivity-evidence)で示した現場実験が裏づけます。両立性と複雑性については、自然言語で指示できるため、専門の訓練を要しません。試行可能性については、無料で使える公開サービスが2022年11月30日に提供されました [ [ 11 ] ](https://openai.com/index/chatgpt/) 。観察可能性については、公開から2か月後の2023年1月に月間利用者が1億人に達したと報じられています [ [ 12 ] ](https://www.youtube.com/watch?v=Tbd-u9EsRn8) 。

採用者のカテゴリに照らすと、個人の利用は多数派の領域に入っています。総務省の調査では、生成AIを使った経験のある日本の個人は2024年度の26.7%から2025年度の58.8%へ上昇しました。ただし2025年度は対象に15〜19歳が加わっており、20歳以上に限ると52.2%です [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。アメリカでは、2024年後半に18〜64歳の約40%が生成AIを使い、就業者の23%が前の週に仕事で使っていました [ [ 108 ] ](https://www.nber.org/system/files/working_papers/w32966/w32966.pdf) 。Rogersの分類に照らせば、革新者と初期採用者の16%を超え、前期多数派の領域へ入った段階に見えます。なお、Rogersのカテゴリは最終的な採用者のうちの比率で定義されており、母集団全体の利用率への当てはめは目安です。

当てはまらない点が2つあります。第一に、Rogersの「採用」は継続的な利用を前提としますが、調査の「使った経験がある」は1回の試用を含みます。利用経験率は、採用率の上限であって採用率そのものではありません。第二に、Rogersの理論は個人の採用を主な対象とし、組織の採用は意思決定の構造が異なります。組織の採用については、次節以降と[組織の内部化の章](22-organizational-internalization)で扱います。

### 2. Mooreのキャズム ―― 初期採用者と多数派の間の断絶

経営判断にとっての意味は、先行企業の成功事例を見て自社に当てはめるとき、その事例が断絶のどちら側にあるかを見分けなければならない、ということです。

Geoffrey Mooreは1991年の『Crossing the Chasm』で、Rogersの採用者カテゴリをハイテク市場に当てはめ、各カテゴリの間に割れ目があると論じました [ [ 247 ] ](https://openlibrary.org/works/OL30695W) 。最大の割れ目は、初期採用者と前期多数派の間にあります。初期採用者は変革を求めて未完成の製品を買いますが、前期多数派は同業者の採用実績と完全な製品を求めます。同じ売り方では、この割れ目を渡れません。渡る戦略は、特定の用途に集中して完全な製品を揃え、そこから隣接する用途へ広げることです。

生成AIの企業導入に当てはめると、[企業の利用の章](12-enterprise-adoption)で示した調査間の開きが、キャズムの両岸を測っていると読めます。大企業の管理職を対象にした調査では、自社の何らかの業務で生成AIを使う企業は86.4%に達します [ [ 122 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf) 。一方、全国1万社超を対象にした調査では、業務で「活用している」企業は34.5%で、従業員5人以下では29.6%です [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。アメリカでも、国勢調査局の事業所調査におけるAIの利用率は、2026年5月の時点で全国19.8%、従業員250人以上の企業で37%でした [ [ 133 ] ](https://www.census.gov/library/stories/2026/05/ai-use-businesses.html) 。先行企業は渡り終え、多数派はまだ対岸にいる、という構図です。

さらに、企業の内部にも同じ構図があります。McKinseyの2026年調査では、9割近くの組織が少なくとも1つの業務機能でAIを常用する一方、「全社でスケール中」と答えたのは44%でした [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。Gartnerの2026年調査では、複数の事業部門でAIをスケールした組織は22%です [ [ 141 ] ](https://www.gartner.com/en/newsroom/press-releases/gartner-survey-finds-only-22-percent-of-organizations-have-successfully-scaled-ai-across-multiple-business-units) 。試行する部門は多く、全社に広がった組織は少ない。これはキャズムが組織の内側にも走っていることを示します。

当てはまらない点は、Mooreの理論が「製品を売る側」の戦略論であることです。導入する企業の側から見ると、キャズムを渡るのは製品ではなく自社の業務です。「完全な製品」に相当するのは、ツールそのものではなく、業務手順、データ、評価、統治を揃えた状態です。この点は[各段階で必要なものの章](34-requirements-and-providers)で具体化します。

### 3. Bassの拡散モデルとGrilichesの収益性仮説 ―― 普及の速度は何で決まるか

経営判断にとっての意味は、普及の速度が「技術の良さ」ではなく「採用者にとっての収益性」と「既採用者からの影響」で決まる、ということです。

Frank Bassは1969年に、耐久消費財の初回購入の時期を2つの係数で記述する数理モデルを示しました [ [ 248 ] ](https://doi.org/10.1287/mnsc.15.5.215) 。革新係数は、広告などの外部の影響で自発的に採用する確率です。模倣係数は、既に採用した人からの口コミで採用する確率です。模倣係数が革新係数より大きいとき、採用の曲線は釣鐘型になり、累積はS字を描きます。

それより前の1957年に、Zvi Grilichesはアメリカ各州でのハイブリッドコーンの普及を分析し、普及の開始時期は種苗会社にとっての収益性で、普及の速度と上限は農家にとっての収益性で説明できることを示しました [ [ 254 ] ](https://doi.org/10.2307/1905380) 。技術の普及が「遅れ」ではなく、経済的に合理的な過程であるという見方の原点です。

生成AIの事実に当てはめると、国の間の普及の差が、この2つの理論で部分的に説明できます。2026年1〜2月の7か国の労働者調査では、仕事で生成AIを使う労働者はアメリカの43%に対し、ヨーロッパ平均は32%でした。差の大部分は、企業がAIの利用を奨励しツールを提供するかという人事管理の慣行で説明されます [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。Grilichesの言葉を借りれば、採用者にとっての収益性は、企業がツールを提供するかどうかで変わります。Bassの言葉を借りれば、職場で既に使っている同僚の存在が模倣係数を高めます。

当てはまらない点は、Bassモデルが初回購入の時期だけを扱うことです。生成AIでは、利用の深さが結果を左右します。週1回の利用と毎日の利用と業務手順への組み込みとでは、それぞれ意味が異なります。Anthropicの2026年3月の報告は、長期の利用者ほど複雑な作業で使う傾向があると記述しています [ [ 118 ] ](https://www.anthropic.com/research/economic-index-march-2026-report) 。初回の採用の後に、利用の深化という別の曲線があります。

### 4. TAMとUTAUT ―― 個人が受け入れる条件

経営判断にとっての意味は、従業員が使うかどうかを決めるのは「使いやすさ」より「役に立つという信念」であり、その信念は組織が条件を整えるかどうかで変わる、ということです。

Fred Davisは1989年に技術受容モデル(TAM)を提案し、情報システムの利用を予測する2つの信念を定義しました [ [ 249 ] ](https://doi.org/10.2307/249008) 。知覚された有用性は「そのシステムを使えば自分の職務の成果が上がると信じる程度」です。知覚された使いやすさは、使うのに努力を要しないと信じる程度です。1つの現場調査と1つの実験で、有用性は利用と強く相関し、使いやすさは有用性を介して間接的に効くことが示されました。

Venkateshらは2003年に、TAMを含む8つの受容モデルを統合したUTAUTを提案しました [ [ 250 ] ](https://doi.org/10.2307/30036540) 。利用の意図を決める中核の要因は、成果期待、努力期待、社会的影響、促進条件の4つです。4組織の縦断データで、このモデルは利用の意図の分散の約70%を説明しました。2012年のUTAUT2は、消費者向けに快楽的動機、価格価値、習慣の3つを加えました [ [ 251 ] ](https://doi.org/10.2307/41410412) 。

生成AIの事実に当てはめると、4つの要因のうち促進条件が、企業の間の差を最もよく説明します。前節で参照した7か国の調査が示したとおり、企業がツールを提供し利用を奨励するかどうかが、労働者の利用率の差の大部分を説明します [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。一方、促進条件が整わない組織では、従業員が自前のツールを持ち込みます。MicrosoftとLinkedInの2024年の31か国調査では、職場でAIを使う人の78%が会社の提供でないAIツールを持ち込み、52%は重要な業務でのAI利用を開示するのをためらっていました [ [ 296 ] ](https://www.microsoft.com/en-us/worklab/work-trend-index/ai-at-work-is-here-now-comes-the-hard-part) 。成果期待は高いが促進条件が無い、という状態です。この現象は[文化の形成の章](36-culture-formation)で、文化フェーズC2として位置づけます。

当てはまらない点は、TAMとUTAUTが利用の有無を説明し、利用の正しさを説明しないことです。[生産性の実証の章](13-productivity-evidence)で示したとおり、AIの能力の外にあるタスクでは、AIを使った群の正答率が19ポイント低下しました [ [ 145 ] ](https://mitsloan.mit.edu/sites/default/files/2023-10/SSRN-id4573321.pdf) 。有用性の信念が高いほど、能力の境界の外でも使ってしまう危険があります。受容モデルは、受容の後の使い方を扱いません。

### 5. ハイプ・サイクル ―― 期待の過熱と幻滅

経営判断にとっての意味は、周囲の期待の温度と技術の実力は別の曲線であり、幻滅期は撤退の合図ではなく実装の時期である、ということです。ただしこの図式は実証モデルではありません。

ハイプ・サイクルは、GartnerのアナリストJackie Fennが1995年の研究ノートに示した図式であり、2008年に書籍として体系化されました [ [ 252 ] ](https://openlibrary.org/works/OL11983657W) 。新技術への期待は、技術の引き金、過度な期待のピーク、幻滅期、啓発期、生産性の安定期の5段階を辿るとされます。書籍は、この曲線を「期待の過熱」と「技術の成熟」という2つの曲線の重ね合わせとして説明しています。

DedehayirとSteinertは2016年に、ハイプ・サイクルに関する学術文献を体系的に検討しました [ [ 253 ] ](https://doi.org/10.1016/j.techfore.2016.04.005) 。実証研究が示すのは、すべての技術が5段階を順に辿るわけではないこと、曲線の形は技術と文脈で異なること、そしてGartnerによる配置が後から検証できる形で公開されていないことです。

生成AIの事実に当てはめると、2025年と2026年のGartner自身の発表が、期待と実力の2つの曲線のずれを示しています。2025年8月のAIのハイプ・サイクルでは、AIエージェントとAI向けのデータ整備が「過度な期待のピーク」に置かれました [ [ 182 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-08-05-gartner-hype-cycle-identifies-top-ai-innovations-in-2025) 。同じ2025年6月、Gartnerはエージェント型AIのプロジェクトの40%超が2027年末までに中止されると予測しました [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 。2026年10月の調査では、AIから「大きな」または「変革的な」価値を実現したと答えたCIOは13%でした [ [ 183 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-10-19-gartner-survey-finds-only-13-percent-of-cios-say-their-enterprise-has-realized-significant-or-transformational-value-from-ai) 。期待の曲線はエージェントで新しいピークを作り、実力の曲線は生成AI全体で緩やかに上がっている、と読めます。

当てはまらない点は、ハイプ・サイクルが期待を測る尺度を持たないことです。Gartnerの配置はアナリストの判断であり、[企業の利用の章](12-enterprise-adoption)で示したような測定可能な指標ではありません。本書は、幻滅期にあるかどうかを論じる代わりに、[投資対効果と失敗率の章](15-roi-and-failure)で測定された数値を使います。

### 6. Amaraに帰される格言と、技術予測の体系的な誤り

経営判断にとっての意味は、1〜2年の計画は期待を割り引き、5〜10年の計画は期待を割り増すべきだ、という経験則です。ただし確定した出典はありません。

「技術の効果を短期的には過大評価し、長期的には過小評価しがちだ」という格言は、未来研究所の所長だったRoy Amaraに帰されます。Quote Investigatorの調査によれば、最古の類似表現は1965年のJ. C. R. Lickliderの著書にあり、Amara名義での文書化は1983年の新聞記事以降です。Amaraが主要な普及者であることは確認できますが、原著者であることは文書で示せません [ [ 304 ] ](https://quoteinvestigator.com/2019/01/03/estimate/) 。

Rodney Brooksは2017年に、AI予測の7つの誤りを挙げ、その第一にこの格言を置きました。残りは、魔法を想像すること、実績と能力の混同、多義的な語、指数関数の想定、映画のような筋書き、そして導入速度の見誤りです [ [ 1302 ] ](https://www.technologyreview.com/2017/10/06/241837/the-seven-deadly-sins-of-ai-predictions/) 。

Steven Schnaarsは1989年に、1950年代から1980年代の技術予測を事後に検証し、大半が外れた理由を分析しました [ [ 299 ] ](https://openlibrary.org/works/OL2679626W) 。共通の誤りは、技術の魅力に目を奪われて需要と価格と代替品を軽視すること、変化の速度を一様に速いと仮定すること、そして現在の流行を直線的に延長することです。実際の普及は、予測よりずっと遅いか、起きませんでした。

生成AIの事実に当てはめると、[言説の分類の章](25-discourse-taxonomy)で示すとおり、2024年から2025年にかけての短期予測には、2026年10月の時点で後ろ倒しになったものが目立ちます。一方で、個別の能力の到達は予測より早い例があります。この非対称は、Brooksの「実績と能力の混同」と「導入速度の見誤り」で説明できます。能力の実証と、業務への導入は、別の速度で進みます。

当てはまらない点は、この格言が短期と長期の境目を言わないことです。1〜2年の範囲は、Lickliderの原文の「1年でできることを過大評価し、5〜10年でできることを過小評価する」に基づく目安です。本書は、[予測の方法の章](24-forecast-method)で、この境界を確度の階層として扱います。

### 🗺️ 図：個人は多数派へ、組織の全社展開は2〜4割

![個人の利用は前期多数派の領域に入り、組織の全社展開は22〜44%にとどまる](/images/ai-transformation-blueprint/20-diffusion-theory.png)

#### 図の読み方

この図は、Rogersの5つの採用者カテゴリを1本の累積の柱として積み、生成AIの2つの現在地を重ねたものです。柱は下から革新者2.5%、初期採用者13.5%、前期多数派34%、後期多数派34%、遅滞者16%で、縦の位置が累積の採用率を表します。横軸に時間はありません。初期採用者と前期多数派の境(累積16%)に引いた点線が、Mooreのキャズムです。

太い横線と丸印は個人の利用です。日本の個人の利用経験率は2025年度に58.8%(20歳以上で52.2%)で、革新者と初期採用者の合計16%を超え、前期多数派の領域にあります。

灰色の帯は組織の全社展開で、Gartnerの「複数事業部門でスケール」22%からMcKinseyの「全社でスケール中」44%までの幅です。帯は点線の上にありますが、組織がキャズムを渡り終えたことを意味しません。帯は「全社に広げた組織の比率」であり、母集団と定義が個人の線とは別です。Rogersのカテゴリは最終的な採用者に占める比率で定義されるため、どちらの当てはめも目安です。本章が「キャズム」と呼ぶ断絶は、第2節で述べたとおり、各組織の内側の「試行から全社へ」の間に走っています。

個人の線と組織の帯の距離が、本章の主張です。個人の採用と組織の採用は、同じ技術でも別の曲線を描きます。図中の数値は本文の第1節と第2節に出典とともに記しています。

### 本章の位置づけ

本章で取り上げた理論の選択と、生成AIの事実への当てはめは、著者の判断です。

普及の理論が本書の推論に与える結論は、次の3つです。第一に、個人の採用は多数派の段階に入っており、「使うかどうか」は経営の論点ではなくなりました。第二に、組織の採用は「試行から全社へ」の断絶(キャズム)を渡る途中にあり、渡る条件は、ツールではなく業務手順、データ、評価、統治の整備です。第三に、普及の速度は技術の良さではなく、採用者にとっての収益性と、組織が整える促進条件で決まります。

これらの結論は、[生成AIの導入段階の章](30-genai-adoption-stages)で導入フェーズS1〜S6を定義する根拠になります。S1(触れる)とS2(仕事に適用する)は個人の採用、S3(仕事に組み込む)以降は組織の採用であり、S2とS3の間にキャズムが走ります。

普及の理論は、広がった後に組織の内部で何が変わるかを説明しません。次の章は、汎用技術が生産性に表れるまでの時間差を扱います。
