### 序論：本章が扱う範囲

本章は、[第Ⅳ部](25-discourse-taxonomy)で示した3つの道筋と、[3つの現在地の章](32-three-positions)で示した自社の位置を重ねて、次の一手を決める方法を扱います。

3つの道筋は、A「加速」、B「漸進」、C「調整」です。[道筋Aの章](26-path-a-acceleration)は能力の倍増が続く世界を、[道筋Bの章](27-path-b-gradual)は生産性のJカーブの底を歩く世界を、[道筋Cの章](28-path-c-correction)は投資の収縮と再編の世界を描きました。本書はこのうち1つを正解として選びません。どの道筋になるかは、[3つの道筋の比較の章](29-paths-comparison-indicators)で示した早期警戒指標を追いながら、年ごとに更新するものです。

正解を選ばずに戦略を決めるには、手の種類を分ける必要があります。本章は手を3種類に分けます。どの道筋でも損にならない「後悔しない手」、将来の選択の幅を買う「選択権を買う手」、特定の道筋に投資する「賭ける手」です。この分類と、現在地と道筋の組み合わせごとの表は、著者による整理です。

### 1. なぜ正解を選ばないか

戦略を1つの未来予測に賭けることは、予測が外れたときの損失を最大にします。[第Ⅳ部](25-discourse-taxonomy)で整理したとおり、2024年から2025年にかけての短期の予測は、2026年10月の時点で後ろ倒しになったものが目立ちます。一方で、個別の能力の到達は予測より早いものがありました。予測は、方向と時期の両方で当たり外れがあります。

Teeceらは1997年に急速に変化する環境で優位を保つ源泉を、内外の能力を統合し、構築し、組み替える企業の能力(動的能力)と定義しました [ [ 274 ] ](https://doi.org/10.1002/%28SICI%291097-0266%28199708%2918:7%3C509::AID-SMJ882%3E3.0.CO;2-Z) 。この定義は、特定の未来を当てることではなく、どの未来が来ても組み替えられることを優位の源泉と見ています。O'ReillyとTushmanは2004年に、既存事業の深化と新規事業の探索を同時に行う組織を「両利き」と呼び、2008年の論文で、両利きの経営をこの能力の1つの形として位置づけました [ [ 275 ] ](https://hbr.org/2004/04/the-ambidextrous-organization) 。

本章の3種類の手は、この考え方を生成AIの導入に当てはめたものです。後悔しない手は、どの道筋でも要る能力を作ります。選択権を買う手は、道筋が決まったときに素早く動ける状態を作ります。賭ける手は、特定の道筋での優位を取りに行きます。

### 2. 後悔しない手

後悔しない手は、3つの道筋のどれが来ても無駄にならない投資です。本書は次の7つを挙げます。

**S1からS2、S2からS3への移行**。会社として契約し(S1からS2)、業務手順に書き込み、社内文書を参照できるようにすること(S2からS3)です。会社の契約がまだないS1の会社は、契約が最初の一歩です。道筋Cで投資が収縮しても、すでに広がった利用は戻りません。McKinseyの2026年の調査では、9割近くの組織が少なくとも1つの業務機能でAIを常用しています [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。常用が前提になった世界では、S3までは競争条件ではなく参加条件です。

**社内データの整理**。[各段階で必要なものの章](34-requirements-and-providers)で述べたとおり、社内文書の整理と権限の設計は買えません。どの道筋でも、整理されたデータは使えます。日本企業がこの点で他国に遅れている統計 [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) は、逆に言えば、ここに手を打つ企業が相対的に進む余地を示しています。

**評価の能力**。何を良い出力と見なすかを定め、測り続ける能力です。OpenAIの手引きが第一に置く「評価から始める」 [ [ 209 ] ](https://cdn.openai.com/business-guides-and-resources/ai-in-the-enterprise.pdf) は、モデルが変わっても、事業者が変わっても使い回せる能力です。道筋Cで事業者が再編されたとき、評価の能力があれば乗り換えられます。

**文化フェーズをC3へ**。利用規程、学ぶ場、推進者の3つをそろえることです。[文化の形成の章](36-culture-formation)で扱います。文化は技術より遅く変わり、技術より長く残ります。

**効果・費用・誤りの計測(C4)**。業務ごとに、かかった時間と件数と誤りの率を測り、費用と比べることです。BCGは、業務の流れを再設計する段階にある企業ほど、AIが生んだ価値を追跡していると報告しています [ [ 193 ] ](https://www.bcg.com/publications/2025/ai-at-work-momentum-builds-but-gaps-remain) 。測った結果は、道筋Bでは次に組み込む業務を選ぶ材料に、道筋Cでは残す案件を選ぶ材料になります。

**AIを使わない仕事の設計**。何をAIに任せないかを決めることです。Microsoftの2026年の調査では、Microsoftが「Frontier」と呼ぶ、個人の利用と組織の整備がともに進んだ層は、AIでやらない仕事を意図的に残す割合が他より高いという結果でした [ [ 205 ] ](https://assets-c4akfrf5b4d3f4b7.z01.azurefd.net/assets/2026/05/2026_Work_Trend_Index_Annual_Report_050526-7_69fc5b1c4e265.pdf) 。道筋Aで能力が伸びるほど、任せない判断の価値が上がります。

**提供事業者に依存しない組み込み**。S4で基盤モデルのAPIを呼ぶとき、特定の提供事業者だけが持つ機能への深い依存を避ける設計にすることです。企業向けのAPI支出のシェアは2023年から2025年の間に大きく動き、OpenAIの50%から27%へ、Anthropicの12%から40%へ変わりました [ [ 417 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise) 。2年でシェアが入れ替わる市場では、乗り換えられる設計はどの道筋でも無駄になりません。道筋Cで提供事業者が再編されても、乗り換えられます。

### 3. 選択権を買う手

選択権を買う手は、道筋が決まった時点で素早く動けるようにする投資です。費用はかかりますが、使わなければ損失は費用の範囲にとどまります。本書は次の3つを挙げます。

**小さな本番**。試行で止めず、小さな範囲で本番に出して運用の経験を積むことです。Gartnerは、成熟度の高い組織の45%がAIの案件を3年以上本番で維持していると報告しました [ [ 186 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-30-gartner-survey-finds-forty-five-percent-of-organizations-with-high-artificial-intelligence-maturity-keep-artificial-intelligence-projects-operational-for-at-least-three-years) 。本番で維持する経験は、道筋Aで急いでS5に進むときにも、道筋Bでゆっくり広げるときにも使えます。

**探索事業への適用**。成熟事業とは別に、失敗の損失が小さい探索事業でS4やS5を試すことです。両利きの経営の考え方 [ [ 275 ] ](https://hbr.org/2004/04/the-ambidextrous-organization) に沿い、探索の部門を成熟事業の指標で評価しない構造を作ります。道筋Aが来れば探索事業が先行の利益を得ます。来なければ、損失は探索の範囲にとどまります。

**買うか作るかの基準**。MIT NANDAの2025年の報告は、生成AIの導入で外部から購入した組織の成功率が67%、内製した組織はその3分の1だったと述べています [ [ 345 ] ](https://www.artificialintelligence-news.com/wp-content/uploads/2025/08/ai_report_2025.pdf) 。Wardleyの地図の考え方では、商品化が進んだ部品は買い、自社に固有の部品だけを作ります [ [ 279 ] ](https://learnwardleymapping.com/book/) 。基盤モデルと業務アプリは買い、自社の業務の設計と評価は作る、という線引きを先に決めておくことは、道筋によらず使える基準です。

初期(S1からS2)にある会社、とくに技術者が数人しかいない会社では、3つのうち打てる選択権は買うか作るかの基準の決定だけで足ります。小さな本番と探索事業への適用は、S3に進んでから打ちます。

### 4. 賭ける手

賭ける手は、特定の道筋での優位を取りに行く投資です。外れた道筋に賭けた場合、損失は大きくなります。したがって、賭ける手は早期警戒指標の確認と対にして打ちます。

**道筋Aに賭ける手**。S5とS6へ先行して進むことです。AIが顧客との取引を完結する製品を作り、事業のモデルを組み替えます。能力の倍増が続けば、先行した企業が顧客接点を取ります。指標は、[3つの道筋の比較の章](29-paths-comparison-indicators)で示したAIの時間地平の推移と、22〜25歳のAI曝露職の雇用です。

**道筋Bに賭ける手**。S3とS4を業務の数で広げることです。生産性のJカーブの底では、組織資本の蓄積が差になります。Brynjolfssonらが論じたとおり、汎用技術の効果は補完的な投資が蓄積した後に現れます [ [ 259 ] ](https://doi.org/10.1257/mac.20180386) 。指標は、企業利用率の伸びと投資対効果の実現率の推移です。

**道筋Cに賭ける手**。費用の規律と、事業者の再編に備える手です。契約の期間を短くするか、長期の契約でも席数の増減と解約時のデータの返還を条項で確保し、国内の推論環境や複数の提供事業者を併用し、投資の回収期間を短く設定します。Gartnerの40%中止の予測 [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) が当たる世界では、中止されなかった案件が優位になります。指標は、AI関連の設備投資の増減と主要な事業者の資金調達の状況です。

賭ける手は、現在地によって打てる範囲が決まります。賭ける手は、後悔しない手と選択権を買う手の上に乗ります。S2の企業が道筋Aに賭けてS6を目指すなら、評価の能力と統治が先に要ります。これは段階を飛ばせないという主張ではなく、手の順序の主張です。評価と統治のない賭けは、外れたときの損失を測れません。

### 5. 現在地と道筋の組み合わせ

次の表は、導入フェーズと文化フェーズの組み合わせを3つに縮め、道筋ごとの次の一手を示したものです。著者による整理です。

| 現在地 | 道筋A：加速 | 道筋B：漸進 | 道筋C：調整 |
| --- | --- | --- | --- |
| 初期(S1〜S2、C1〜C2) | 後悔しない手をすべて打つ。探索事業があれば、そこで小さな本番を1つ作る | 後悔しない手をすべて打つ。S3を1業務ずつ広げる | 後悔しない手のうちS3とデータ整理を優先。契約は短く |
| 中間(S3〜S4、C3) | 提供事業者に依存しない設計でS4を広げ、探索事業でS5を試す | S4の評価と費用管理を整え、業務の数で広げる | 費用の規律を先に。本番で維持できた案件に集中する |
| 先行(S4〜S5、C4以上) | S6へ進み、顧客接点の取引をAIに任せる範囲を決める | S5の製品の品質指標を顧客の成果指標に接続する | 複数の事業者を併用し、国内の推論環境を選択肢に持つ |

表の読み方には注意が要ります。表の行(現在地)は自社が決められます。列(道筋)は自社が決められません。したがって実際の一手は、自社の行の後悔しない手と選択権を買う手を打ちつつ、列のどれに近いかを指標で見ながら賭ける手の配分を変える形になります。

事業フェーズの軸は、この表には入れていません。事業ごとに行が違うため、事業ごとに表を当てます。成熟事業が「中間」で探索事業が「初期」という企業では、成熟事業の行と探索事業の行を別々に読みます。

### 6. 配分の目安

後悔しない手、選択権を買う手、賭ける手の配分は、現在地と道筋への見立ての度合いで決まります。AIに充てる年間の予算と担当者の時間の配分の目安は、後悔しない手6、選択権を買う手3、賭ける手1です。これは調査から導いた値ではなく著者の判断で、3つの道筋への見立てが割れている状態の出発点です。見立てが1つの道筋に傾くほど、賭ける手の比率を上げます。小さな会社では、賭ける手がゼロでかまいません。

根拠は2つあります。第一に、日本企業の分布です。[生成AIの導入段階の章](30-genai-adoption-stages)で述べたとおり、日本ではS2までが広がりS3から先が細い分布です。多くの企業にとって、後悔しない手の範囲にまだ打つべき手が残っています。第二に、価格の低下です。Epoch AIの推計では、同じ性能に到達するための推論価格は年9倍から900倍のペースで下がっています [ [ 425 ] ](https://epoch.ai/data-insights/llm-inference-price-trends) 。賭ける手を急ぐ費用は、待てば下がります。待つ損失は、先行した競合に顧客接点を取られることであり、それは道筋Aでのみ大きくなります。

### 経営層への含意

3種類の手の分類と、現在地と道筋の組み合わせの表は、著者による整理です。Teece、O'ReillyとTushmanの理論は組み替える能力の価値を示しますが、生成AIの導入における具体的な手を指定するものではありません。表の各欄は、本書の事実と理論から著者が導いた判断です。

経営層が本章から持ち帰るべき点は3つです。

第一に、未来を1つに決めてから動く必要はありません。後悔しない手と選択権を買う手は、道筋が決まる前に打てます。日本企業の多くは、後悔しない手の範囲にまだ打つべき手が残っています。

第二に、賭ける手は指標と対にします。道筋Aに賭けるなら能力と採用の指標を、道筋Bに賭けるなら利用率と投資対効果の指標を、道筋Cに賭けるなら設備投資と資金調達の指標を、それぞれ年に数回は確かめます。指標が反対を向いたら、配分を変えます。

第三に、賭ける手は後悔しない手と選択権を買う手の上に乗ります。評価の能力と統治が先に要り、それがない賭けは外れたときの損失を測れません。これは手の順序の主張であり、順序を守ることが、外れたときの損失を小さくします。
