### 序論：本章が扱う範囲

本章は、生成AIの普及を読むための物差しとして、過去の汎用技術がどのように広がり、いつ生産性に現れたかを整理します。対象は、19世紀末からの工場の電化、1970年代からの計算機、そして1990年代からのインターネットです。

ここまでの章では、生成AIの技術そのものの系譜を追ってきました。本章は視点を変え、技術が社会と企業に浸透する過程を扱います。[個人の利用の章](11-individual-adoption)と[企業の利用の章](12-enterprise-adoption)で示す現在の利用率を、どの物差しで読むべきかを先に決めておくためです。

本文は、経済史と経済学の一次資料に基づく事実の記述に限定します。生成AIがこれらの先例と同じ経路をたどるかどうかの評価は、章末で扱います。

### 1. 普及の速さは何で決まるか

技術普及の経済学は、1957年のグリリカスによるハイブリッドコーンの研究から始まりました。アメリカの各州でのハイブリッドコーンの普及をロジスティック曲線で記述し、普及の開始時期・速度・上限の地域差を、種苗会社と農家にとっての収益性で説明しました。普及の遅れは農家の無知ではなく、経済合理的な判断の結果だと示した研究です [ [ 254 ] ](https://doi.org/10.2307/1905380) 。

この研究が確立した見方は、2つあります。第一に、普及はS字の曲線を描くことです。第二に、曲線の形は技術の魅力ではなく、採用する側の収益性で決まることです。以後の普及研究は、この2点を前提にしています。

### 2. 電化の40年

発電機が商用化されたのは1880年代です。しかし、アメリカの製造業の生産性が目に見えて加速したのは1920年代でした。経済史家ポール・デイビッドは1990年の論文で、この約40年の遅れの理由を分析しました。電動機で蒸気機関を置き換えるだけでは利点が小さく、工場の配置を「群駆動」から「単位駆動」へ組み替えて初めて生産性が出たためです [ [ 255 ] ](https://ideas.repec.org/p/cla/levarc/115.html) 。

デイビッドは、1980年代の「計算機は生産性統計に現れない」という逆説を、この電化の歴史に照らして読みました。計算機も、組織と工程の再設計を伴う普及の初期段階にあると論じたのです。

デイビッドとライトは1999年の論文で、第一次世界大戦の後のアメリカ製造業の生産性加速を、電動化された生産システムの普及で説明しました。普及は技術だけでなく、電力価格の低下、工場建築の変化、労働市場の変化の複合で進みました。同じ技術でも、制度と補完投資の差で普及が遅れることを、イギリスとの比較から示しています [ [ 256 ] ](https://www.nuffield.ox.ac.uk/economics/history/paper31/davidwright.html) 。

### 3. 汎用技術という概念

1995年にブレスナハンとトラフテンバーグは、蒸気機関・電力・半導体のような技術を「汎用技術」と定義しました。条件は3つです。広範な産業で使われること、時間とともに改良され続けること、応用側の技術革新を誘発することです。汎用技術の供給者と応用部門の間には補完性があり、双方の投資がそろって初めて成長が出ます。そのため、調整の失敗で普及が遅れうると論じました [ [ 257 ] ](https://doi.org/10.1016/0304-4076%2894%2901598-T) 。

ヨバノビッチとルソーは2005年に、電力(1894〜1930年)と情報技術(1971年〜)を2大汎用技術として比較しました。両者とも普及初期に生産性成長が鈍化し、後に加速する共通の型を示します。価格の下落は情報技術のほうが急であり、技術的に革命的だと評価しました [ [ 258 ] ](https://www.nber.org/papers/w11093) 。

クラフツは2021年に、蒸気・電力・情報通信技術の普及史からAIを論じました。汎用技術の生産性効果は発明から数十年遅れて現れ、効果の大きさは補完的投資と制度に依存します。過去の経験に基づけば、AIの生産性寄与は当面緩やかであり、急加速は歴史的に例外的だと評価しています [ [ 263 ] ](https://doi.org/10.1093/oxrep/grab012) 。

大規模言語モデル(LLM)がこの定義を満たすかについては、2023年にエルンドゥらが検証しました。アメリカの職業のタスクごとに、LLMで同じ品質のまま所要時間を半分以下にできるかを判定した研究です。約80%の労働者はタスクの10%以上が、約19%は50%以上が影響を受けうると推定しました。LLM単体では全タスクの約15%、LLM上のソフトウェアを含めると47〜56%が高速化しうるとし、LLMは汎用技術の3条件を満たすと結論しています。採用時期の予測は行っていません [ [ 262 ] ](https://arxiv.org/abs/2303.10130) 。

### 4. 生産性パラドックスとJカーブ

経済学者ロバート・ソローは1987年の書評で、計算機への投資は急増しているのに生産性統計には現れない、と一文で指摘しました。この一文が「生産性パラドックス」の名の由来です [ [ 260 ] ](https://gwern.net/doc/economics/automation/1987-solow.pdf) 。

ブリニョルフソンとヒットは2000年に、企業レベルのデータでこの逆説の一端を説明しました。情報技術への投資の収益は、業務プロセス・組織構造・人的資本への補完投資とセットで初めて大きくなります。情報技術1ドルの投資に対し、企業は約9ドルの無形の組織資本を伴って投資しており、この資本は国民経済計算に計上されません [ [ 270 ] ](https://doi.org/10.1257/jep.14.4.23) 。

ブルーム、サドゥン、ヴァン・リーネンは2012年に、1995年以降のアメリカの生産性成長がヨーロッパを上回った原因を検証しました。ヨーロッパに立地するアメリカ系多国籍企業は、同じ場所で同じ情報技術を使っても、情報技術資本1単位あたりの生産性が高かったのです。その差は人材管理の慣行で説明できました。技術の収益は経営慣行に依存するという実証です [ [ 271 ] ](https://doi.org/10.1257/aer.102.1.167) 。

これらを一般化したのが、ブリニョルフソン、ロック、サイバーソンによる2021年の「生産性Jカーブ」です。汎用技術の価値を引き出すには無形資本への補完投資が要ります。この投資は統計上「産出」として計上されないため、普及初期には測定される生産性が実力より低く出ます。無形資本が蓄積して収益を生み始めると、今度は実力より高く出ます。計算機関連の無形資産を調整すると、2017年末のアメリカの全要素生産性は公式統計より15.9%高いと推計しました [ [ 153 ] ](https://www.aeaweb.org/articles?id=10.1257%2Fmac.20180386) 。

### 5. バブルと技術革命の周期

経済学者カルロタ・ペレスは2002年の著書で、産業革命以来の5つの技術革命が約50年周期で同じ構造を繰り返すと論じました。前半の「導入期」は金融資本が主導し、新技術への過剰投資がバブルと崩壊を生みます。崩壊後の「転換点」で制度の再編が起き、後半の「展開期」は生産資本が主導して技術が経済全体に広がります。ペレスは、バブルを逸脱ではなく、新しい基盤への過剰投資を実現する周期の必須要素と位置づけました [ [ 261 ] ](https://doi.org/10.4337/9781781005323) 。

一方、技術予測が普及を速く見積もりすぎる傾向も記録されています。シュナーズは1989年に、1950〜1980年代の技術予測を事後検証しました。大半が外れた共通の原因は、技術の魅力に目を奪われて需要・価格・代替品を軽視すること、変化の速度を一様に速いと仮定すること、現在の流行を直線的に延長することでした [ [ 299 ] ](https://openlibrary.org/works/OL2679626W) 。

### 6. 生成AIの普及速度の実測

以上の物差しに対して、生成AIの普及はどう測られているでしょうか。

ビック、ブランディン、デミングは、アメリカの全国代表サンプル調査を使い、2024年後半に18〜64歳の約40%が生成AIを使い、就業者の23%が前週に仕事で使っていたと報告しました。仕事での利用率27%は、IBM PC発売3年後の1984年にPCを仕事で使っていた25%と同程度の速さです。全体の採用速度は、PCとインターネットの初期を上回っています [ [ 108 ] ](https://www.nber.org/system/files/working_papers/w32966/w32966.pdf) 。

スタンフォード大学のAI Index 2026は、生成AIが公開から3年で世界人口の53%に普及し、PCやインターネットより速いと整理しています。ただし国別の差は大きく、アメリカは28.3%で24位です [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

Anthropicの2026年1月の報告は、アメリカの州間の利用格差が縮小しており、このペースなら2〜5年で人口あたりの利用が州間で均等化すると推計しました。20世紀の主要技術の約10倍の速さです [ [ 117 ] ](https://www.anthropic.com/research/anthropic-economic-index-january-2026-report) 。

一方、普及の速さと生産性への反映は別の問題です。アグラワル、ガンズ、ゴールドファーブは2022年の著書で、AIの導入が既存の意思決定を置き換える「点の解決策」にとどまり、意思決定の相互依存を組み直す「システムの解決策」に至っていないと論じました。電化が工場の配置換えを要したのと同様、現在は技術の実証と本格的な普及の間の「狭間の時代」にあると位置づけています [ [ 281 ] ](https://store.hbr.org/product/power-and-prediction-the-disruptive-economics-of-artificial-intelligence/10580) 。

### 🗺️ 図：使われるのは速く、効くのは遅い

#### 図の読み方

この図は、上下2段で構成されています。上段は「使われる速さ」、下段は「生産性に効くまでの時間」です。

上段には、電化、PC、生成AIの3つを並べています。生成AIは公開から3年で世界人口の53%に達し、PCの初期と同程度か、それより速い普及を示しています。この数値は本章の第6節で示したAI Index 2026とビックらの研究によります。

下段は、電化の商用化から製造業の生産性加速までの約40年と、計算機で観察された生産性パラドックスとJカーブを示しています。無形資本への補完投資が先に要り、統計上の生産性は後から現れます。この構造はデイビッド、ブリニョルフソンらの研究によります。

図の主張は1つです。生成AIが「使われる速さ」の記録を更新していることと、「効くまでの時間」が短縮されるかどうかは、別の問いだということです。後者は、[生産性の実証の章](13-productivity-evidence)で現在の証拠を確認します。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

本章の要点は3つです。

第一に、普及の速さは技術の魅力ではなく、採用側の収益性と補完投資で決まります。グリリカス以来の普及研究と、ブリニョルフソンらの無形資本の研究が、この点で一致しています。

第二に、過去の汎用技術は、普及から生産性への反映まで数十年を要しました。電化は約40年、計算機は1970年代から1990年代後半までです。遅れの原因は、技術ではなく、組織と工程の再設計に時間がかかったことでした。

第三に、生成AIは「使われる速さ」において過去の技術を上回っています。しかし、この速さは個人が無料のチャットを試す速さであり、企業が業務とシステムを組み替える速さではありません。アグラワルらの言う「狭間の時代」は、まさにこの2つの速さの差を指しています。

著者は、本章の先例が生成AIの未来を決めるとは考えていません。生成AIには、過去の汎用技術と異なる点が少なくとも2つあります。導入の初期費用が極めて低いこと、そして自然言語で使えるため専門的な訓練を要しないことです。この違いが、Jカーブの底を短くする方向に働く可能性はあります。一方で、ペレスの周期論とシュナーズの検証は、技術予測が一貫して普及を速く見積もりすぎてきたことを示しています。先例は、楽観と悲観のどちらにも使える物差しであり、[予測の方法の章](24-forecast-method)で扱う階層の考え方とあわせて使うべきものです。

### 経営層への含意

本章の先例が示す最も実務的な点は、生産性の効果は技術の購入ではなく、仕事の組み替えへの投資から出てくるということです。電化で生産性を出した工場は、電動機を買った工場ではなく、配置を変えた工場でした。生成AIの契約数や利用率は、電動機の設置台数に相当します。効果を測る指標は、仕事の手順と組織がどれだけ変わったかに置くべきです。この視点は、[組織の内部化の章](22-organizational-internalization)と[生成AIの導入段階の章](30-genai-adoption-stages)で具体化します。
