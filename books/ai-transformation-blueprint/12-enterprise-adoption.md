### 序論：本章が扱う範囲

本章は、企業が生成AIをどれだけ導入しているかを、日本、アメリカ、世界の調査から整理します。この問いには、調査によって2割から9割までの答えがあります。本章の目的は、どの数値が正しいかを決めることではなく、数値の差が母集団と設問の違いからどう生じるかを明らかにし、自社と比べるときにどの数値を使うべきかを判断できるようにすることです。

対象は、総務省、情報処理推進機構(IPA)、中小企業庁などの公的調査、信用調査会社と業界団体の調査、コンサルティング会社の調査、そしてアメリカ国勢調査局の事業所調査です。調査ごとに、何を測ったか、誰に聞いたか、いつ聞いたかを併記します。

本文は、調査結果の記述に限定します。日本企業の導入が進んでいるのか遅れているのかという評価は、章末で扱います。

### 1. 日本：同じ年の「導入率」に、9つの答え

2025年度から2026年にかけて公表された日本企業の生成AI「利用」または「導入」の割合を、高い順に並べます。

| 数値 | 何を測ったか | 母集団・回答者 | 調査時点 |
| --- | --- | --- | --- |
| 86.4% | 自社の何らかの業務で生成AIを利用 | デジタル化に着手済みで従業員10名以上の企業の管理職以上、日本477件(回答515件から「わからない」を除く) | 2026年1〜2月 |
| 87% | 生成AIを「活用中・推進中」 | 売上高500億円以上の企業の課長職以上で導入に関与、932名 | 2026年2月 |
| 7割超 | 全社的にAIを導入 | 日本生産性本部の人事関連の活動に参加する企業 | 2026年 |
| 59.6% | 「導入している」44.0%と「試験利用中」15.6%の合計 | 国内企業の経営層・情報システム部門・DX部門、1,799社 | 2026年4〜6月 |
| 53.4% | 言語系生成AI「導入済み」33.9%と「試験導入中・導入準備中」の合計 | 東証の上場企業などのIT部門長、957社 | 2025年9〜10月 |
| 34.5% | 生成AIを業務で「活用している」 | 全国の企業10,312社(大企業から小規模まで) | 2026年3月 |
| 31.1% | 会社主導の導入16.3%と、個人利用を会社が推奨14.9%の合計 | 商工中金の取引先の中小企業3,892社 | 2026年1月 |
| 20.4% | AI(生成AIに限らない)を全社または一部業務で導入 | 全国の中小企業1万社に配布、回答1,647社 | 2025年11〜12月 |
| 20.3% | 生成AIを「会社として活用を推進」 | 全国の企業6,327社(うち中小企業5,872社) | 2026年3〜4月 |

各行の出典は次のとおりです。総務省の令和8年版の情報通信白書は、2025年度調査で、自社の何らかの業務で生成AIを利用している割合を日本86.4%、アメリカ90.9%、ドイツ91.6%、中国98.1%と報告しています。調査対象は、従業員10名以上で2025年までにデジタル化に着手した企業の管理職以上のモニターで、日本は515件(大企業353、中小企業162)です。86.4%は、この515件のうち「わからない」と答えた回答を除いた477件で集計した値です。「利用を禁止している」と答えた企業を除くと、全社、部署、個人業務のいずれかの単位で組織的に活用に取り組む企業は65.6%でした [ [ 122 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf) 。

PwC Japanの2026年春の調査は、売上高500億円以上の企業の課長職以上で生成AI導入に関与する932名を対象に、「活用中・推進中」が87%と報告しました。同社の経年値は、2023年春22%、2024年春43%、2025年春56%、2026年春87%です [ [ 127 ] ](https://www.pwc.com/jp/ja/knowledge/thoughtleadership/generative-ai-survey2026.html) 。日本生産性本部の調査は、同本部の人事関連活動に参加する企業を対象とし、7割超が全社的にAIを導入したと報告しています [ [ 131 ] ](https://www.jpc-net.jp/research/detail/008214.html) 。

IPAの「DX動向2026」は、1,799社の回答で、生成AIを「導入している」企業が2024年度の22.6%から2025年度の44.0%へ増え、「試験利用中」の15.6%とあわせて59.6%と報告しています [ [ 124 ] ](https://www.ipa.go.jp/digital/chousa/dx-trend/rcu1hd0000017uk8-att/dx-trend-2026.pdf) 。日本情報システム・ユーザー協会(JUAS)の「企業IT動向調査2026」は、IT部門長957社の回答で、言語系生成AIの「導入済み」が33.9%、「試験導入中・導入準備中」を含めて53.4%と報告しました。売上高1兆円以上では「導入済み」が85.1%です [ [ 126 ] ](https://juas.or.jp/news/topics/6124) 。

帝国データバンクの2026年3月の調査は、全国23,349社を対象に10,312社の有効回答を得て、生成AIを業務で「活用している」企業を34.5%と報告しました。内訳は「非常に活用」4.4%、「やや活用」30.2%です。規模別では、大企業46.5%、中小企業32.4%、小規模企業28.0%、従業員1,000人超63.6%、5人以下29.6%でした [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。

商工中金の取引先の中小企業3,892社への調査では、会社主導で導入している企業が16.3%、「会社としての導入はなく個人の利用を推奨」が14.9%で、あわせて31.1%でした。「個人の判断に任せる」が64.9%で最多です [ [ 129 ] ](https://www.shokochukin.co.jp/report/research) 。中小企業基盤整備機構の調査では、AIを全社または一部の業務で導入した中小企業は20.4%で、導入を検討している18.6%とあわせて39.0%でした [ [ 128 ] ](https://www.smrj.go.jp/research_case/questionnaire/fbrion0000002pjw-att/202603_AI_point.pdf) 。東京商工リサーチの調査では、「会社として活用を推進」が20.3%、「方針は決めていない」が37.5%でした。組織的な活用は大企業59.1%、中小企業32.3%です [ [ 130 ] ](https://www.tsr-net.co.jp/data/detail/1202766_1527.html) 。

表の「中小企業」の定義は調査ごとに異なります。東京商工リサーチは、資本金1億円以上を大企業、1億円未満(個人企業等を含む)を中小企業と定義しています [ [ 130 ] ](https://www.tsr-net.co.jp/data/detail/1202766_1527.html) 。帝国データバンクは、規模別のほかに従業員数別の内訳を公表しています [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。従業員100〜300人の企業が自社と比べるなら、帝国データバンクの中小企業32.4%と、東京商工リサーチの中小企業32.3%の値で読んでください。

### 2. 差はどこから来るか

9つの数値の差は、主に3つの要因から生じています。

第一に、母集団です。デジタル化に着手済みの企業、売上高500億円以上の企業、上場企業のIT部門長を対象にすると8〜9割になります。規模を問わず全国の企業を対象にすると3割台、中小企業に限ると2〜3割になります。帝国データバンクの規模別の内訳が示すとおり、従業員1,000人超と5人以下では2倍以上の差があります。

第二に、設問です。「何らかの業務で利用している」は、従業員の誰かが使っていれば該当します。「会社として活用を推進」は、経営の意思決定を要します。「全社的に導入」は、さらに狭い定義です。商工中金の調査で「個人の判断に任せる」が64.9%を占めたことは、利用はあっても会社の方針を持たない企業の多さを示しています。

第三に、回答者です。管理職や導入担当者に聞くと、自社の利用を知っている分だけ高く出ます。経営者や総務担当者に聞くと、現場の個人利用を把握していない分だけ低く出ます。

総務省の白書は、方針についても経年で報告しています。生成AIを活用する方針(積極活用と領域限定の合計)を定めている日本企業は、2023年度42.7%、2024年度49.7%、2025年度68.9%と推移しました。2024年度の日本は大企業約56%、中小企業約34%でした。同年度の全体の値は、アメリカ84.8%、ドイツ76.4%、中国92.8%です [ [ 106 ] ](https://www.soumu.go.jp/main_content/001019264.pdf) 。

同じ白書は、業務変革について「組織的な取組はない」と答えた割合が日本で3割弱と、他の3か国より高いことも報告しています。「社内データを学習させたり参照可能なデータベースを構築」の回答割合も、他国より顕著に低いとしています [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。

### 3. 日本：利用の内容と効果

利用率のほかに、何に使い、どんな効果があったかも計測されています。

IPAの調査では、生成AIの用途は「文書・音声の要約・翻訳・校正」82.5%と「文書・レポートの作成」80.5%が上位でした。利用部署は、情報システム71.9%、経営企画69.0%、総務・法務68.4%に対し、製造35.7%、調達31.3%、流通23.9%です。AIエージェントの利用は、いずれの部署でも低い水準でした [ [ 124 ] ](https://www.ipa.go.jp/digital/chousa/dx-trend/rcu1hd0000017uk8-att/dx-trend-2026.pdf) 。

効果については、同調査で「業務が効率化・迅速化した」が91.6%である一方、「売上や利益が向上した」は3.9%でした。「期待以上」と「期待どおり」の合計は31.8%、「一定の効果はあった」が50.6%です [ [ 123 ] ](https://www.ipa.go.jp/pressrelease/2026/rcu1hd0000016yh4-att/press20260716.pdf) 。

PwC Japanの6か国比較では、「期待を大きく上回る効果」を得た企業は日本9%で最下位でした。アメリカ38%、イギリス32%です。「まだ評価できていない」は日本13%で、アメリカは0%でした [ [ 127 ] ](https://www.pwc.com/jp/ja/knowledge/thoughtleadership/generative-ai-survey2026.html) 。

総務省の白書では、日本企業が生成AIに期待する影響は「作業時間の短縮などによる業務の効率化」61.6%が最多で、「製品・サービスの質の向上」32.2%、「人員不足の解消」26.8%を大きく上回りました。他の3か国では「質の向上」が最多です [ [ 122 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf) 。

帝国データバンクの調査では、活用企業の86.7%が業務への効果を認めています。主な用途は「文章の作成・要約・校正」45.1%、「情報収集」21.8%でした。懸念は「情報の正確性」50.4%が最も高く、悪影響としては「使いこなし格差の拡大」を挙げた企業が18.8%ありました [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。

経済産業省は2024年6月の時点で、国内企業の社内利活用は1年で大きく進展した一方、「日常業務への組み込み、新サービス創出、これを後押しする経営層の関与が停滞」していると総括しています [ [ 226 ] ](https://www.meti.go.jp/press/2024/06/20240628006/20240628006.html) 。

### 4. アメリカ：1割と2割が並ぶ理由

アメリカでは、国勢調査局の事業所調査(BTOS)が企業のAI利用率を隔週で測っています。AIを財・サービスの生産に使う企業の割合は、2023年秋の3.7%から2025年8月初めの9.7%へ上昇しました [ [ 116 ] ](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report) 。

ところが、2025年11月から設問の文言が改定され、以後の数値は旧系列と直接比較できなくなりました [ [ 132 ] ](https://www.census.gov/hfp/btos/data) 。改定後の利用率は、2025年末で約18%です [ [ 109 ] ](https://www.federalreserve.gov/econres/notes/feds-notes/monitoring-ai-adoption-in-the-u-s-economy-20260403.html) 。2025年12月から2026年5月は17〜20%で推移しました。2026年5月3日時点の利用率は、従業員250人以上が37%、4人以下だと20%未満です。情報産業39.7%、金融・保険33.9%です [ [ 133 ] ](https://www.census.gov/library/stories/2026/05/ai-use-businesses.html) 。

国勢調査局の研究論文は、もう1つの定義差を示しています。2025年11月から2026年1月の補足調査で、過去2週間にAIを使った企業は、企業数で加重すると約18%ですが、雇用で加重すると32%でした。平均的な企業は未採用でも、平均的な従業員の勤め先は採用しています [ [ 134 ] ](https://www2.census.gov/library/working-papers/2026/adrm/ces/CES-WP-26-25.pdf) 。Programs.comの二次集計では、2026年10月4日までの2週間の利用率は23.8%と報告されています [ [ 135 ] ](https://programs.com/resources/business-ai-adoption) 。

ヨーロッパでは、EUの企業調査で「生産にAIを使う」企業は2025年にスウェーデン9%からセルビア1%の範囲でした。「何らかのAI技術を何かの目的で使う」という広い設問では平均20%です [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。

### 5. 世界の企業調査：88%から6%まで

コンサルティング会社と調査会社の調査は、さらに高い数値と低い数値の両方を示します。

McKinseyの2026年調査(97か国、1,719人、2026年5〜6月)では、9割近くが少なくとも1つの業務機能でAIを常用し、44%が「全社でスケール中」でした。年商10億ドル超の大企業では40%がAIエージェントをスケールしており、前年の27%から増えています。小規模組織は22%で横ばいです [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。AI Index 2026は、McKinseyの前年(2025年)の調査に基づき、2025年に世界の組織の88%がAIを採用したと整理しています [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

一方、Gartnerの2026年1〜4月の調査(年商5,000万ドル以上、1,303人)では、複数の事業部門でAIをスケールした組織は22%でした。85%の機能リーダーが2026年にAI支出を増やす予定で、2025年は機能予算の平均12%をAIに充てています [ [ 141 ] ](https://www.gartner.com/en/newsroom/press-releases/gartner-survey-finds-only-22-percent-of-organizations-have-successfully-scaled-ai-across-multiple-business-units) 。KPMGの2026年第2四半期の調査では、AIエージェントを展開済みの組織は53%でした。同じ調査のエージェント展開率は、2025年第1四半期11%(同四半期の発表では12%)、第3四半期42%、第4四半期26%と大きく変動しています [ [ 138 ] ](https://kpmg.com/us/en/media/news/q2-ai-pulse-2026.html) 。

Deloitteの2026年版調査では、AIで生産性が向上した組織は66%、収益増を実現した組織は20%でした。74%は収益増を「将来の期待」としています [ [ 139 ] ](https://www.deloitte.com/us/en/what-we-do/capabilities/applied-artificial-intelligence/content/state-of-ai-in-the-enterprise.html) 。

McKinseyの調査で、営業利益(EBIT)への影響を報告する回答者は37%で前年並み、EBITの5%以上をAIに帰属させる企業は約6%で横ばいでした。一方、80%が個人の生産性の向上を報告しています [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。「個人は速くなったが企業の損益には出ない」という構図は、IPAの91.6%対3.9%と同じ型です。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

本章の要点は3つです。

第一に、「日本企業の生成AI導入率」という単一の数値は存在しません。2割から9割までの数値は、どれも誤りではなく、母集団と設問が違うだけです。

第二に、どの調査でも一貫している事実があります。企業規模による差が2倍以上あること、用途が文書作業に偏っていること、そして「個人の効率化」は9割が認めるのに「売上・利益への効果」は1桁台にとどまることです。

第三に、アメリカの事業所調査が示す「企業数の加重なら18%、雇用の加重なら32%」という差は、普及の実態を決めるのが企業の数ではなく、従業員の働く場所であることを示しています。大企業が先に導入し、そこに多くの人が働いているという構造です。

著者は、日本の企業導入が「遅れている」という評価を、調査を選ばずに下すことには反対です。総務省の最新調査では、利用の有無における主要国との差はほぼ消えています。しかし、方針の有無、組織的な取り組み、社内データの整備、そして効果の実感では差が残っています。[先例の章](10-precedents-electricity-pc-cloud)の枠組みで言えば、日本企業は「使う」段階を終え、「仕事を組み替える」段階の入口にいます。この段階は、どの国でも遅れて進むものです。

### 経営層への含意

自社の現在地を測るときは、次の3つを分けて問うことを勧めます。従業員の何割が使っているか、会社として方針と道具を提供しているか、業務の手順に組み込んでいるか、です。この3つは、本書の[生成AIの導入段階の章](30-genai-adoption-stages)のS1、S2、S3にそれぞれ対応します。多くの調査で「個人は速くなったが損益に出ない」という結果が出ているのは、S2で止まっている企業が多数派だからだと著者は考えます。S3以降へ進むために何が要るかは、[各段階で必要なものの章](34-requirements-and-providers)で扱います。
