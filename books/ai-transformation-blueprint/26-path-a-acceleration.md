### 序論：本章が扱う範囲

本章は、3つの道筋のうち最初のものを提示します。道筋Aは、AIの能力が年単位で倍増し続け、AIエージェントが知的労働の広い範囲を代替する経過です。最も蓋然性が高いという意味ではありません。[言説の分類の章](25-discourse-taxonomy)で「加速」に分類した言説が描く未来を、本書の手続で推論し直したものです。

この道筋を支える言説は、AI企業の経営者、基盤の供給者、投資家、予測文書に集中しています。Amodeiは強力なAIが早ければ1〜2年先と述べています [ [ 309 ] ](https://darioamodei.com/essay/the-adolescence-of-technology) 。AI Futures Projectは2027年に超人的なコーダー、その約1年後に超知能という筋書きを示しました。2027年は、著者らの見立てで最も可能性の高い年(最頻値)です。著者らの中央値はそれより遅く、2025年12月の更新でさらに後ろへずれています [ [ 307 ] ](https://ai-2027.com/) 。Sequoia Capitalは長い時間地平のエージェントを機能的なAGIと呼び、2026年をその年としました [ [ 395 ] ](https://inferencebysequoia.substack.com/p/ais-trillion-dollar-opportunity-sequoia) 。本章は、これらの言説を根拠にするのではなく、言説が依拠している観測可能な傾向から出発します。

構成は、前提、2027年前後、2029年前後、2031年前後、企業・労働・市場への帰結、外れる条件、経営層への含意です。各項目には、[予測の方法の章](24-forecast-method)の手続に従い、確度の階層を【階層n】で付します。階層1は既に確定した事象、階層2は傾向が持続する場合の外挿、階層3は発生の有無が不確実な条件付きの事象、階層4は原理的に予測が困難な事象です。本章は確率を割り当てません。

### 1. 前提

道筋Aは、次の前提を置きます。

【階層2】 **時間地平の倍増が続く**。METRは、AIが50%の成功率で完了できるソフトウェアのタスクの長さが、2019年以降およそ7か月ごとに倍増していると示しました [ [ 60 ] ](https://arxiv.org/abs/2503.14499) 。2026年1月の更新では、2024年以降の倍増期間を89日と推定しています [ [ 62 ] ](https://metr.org/blog/2026-01-29-time-horizon-1-1) 。道筋Aは、この倍増が2031年まで途切れないと仮定します。

【階層2】 **計算資源の投資が続く**。2026年の設備投資の計画は、Metaが1,150〜1,350億ドル、Alphabetが1,800〜1,900億ドル、Amazonが約2,000億ドルです [ [ 80 ] ](https://www.reuters.com/business/meta-expects-annual-capital-expenditures-rise-superintelligence-push-2026-01-28) 。国際エネルギー機関は、データセンターの電力需要が2025年の485TWhから2030年に950TWhへ増えると見込んでいます [ [ 77 ] ](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary) 。道筋Aは、この投資が資金と電力の制約に突き当たらないと仮定します。

【階層2】 **費用の低下が続く**。同じ性能に到達する推論の価格は、課題によって年9倍から900倍の速さで下がっています [ [ 425 ] ](https://epoch.ai/data-insights/llm-inference-price-trends) 。2026年9月に公開された最上位モデルの価格は、100万トークンあたり入力4ドル、出力20ドルで、前の世代より典型的な処理で40%安くなりました [ [ 54 ] ](https://www.anthropic.com/claude-opus-5-5) 。道筋Aは、能力の向上と価格の低下が同時に続くと仮定します。

【階層3】 **技術的な壁が現れない**。現行手法のスケールアップでAGIに至るのは「ありそうにない」と、AAAIの調査では回答者の76%が答えています [ [ 336 ] ](https://aaai.org/wp-content/uploads/2025/03/AAAI-2025-PresPanel-Report-Digital-3.7.25.pdf) 。道筋Aは、この懸念が当たらないか、別の手法が間に合うと仮定します。この前提は階層3であり、道筋Aの最も弱い部分です。

### 2. 2027年前後

【階層2】 **能力**：時間地平の倍増が続けば、2026年2月時点で約12時間とされた公開モデルの時間地平は [ [ 64 ] ](https://metr.org/notes/2026-03-19-org-uplift-game) 、2027年末には数週間分の人間の作業に相当する長さへ達します。ただし、2026年5月のMETRの注記によれば、現行の課題群で16時間を超える測定は信頼できません。METRは同年9月に時間地平のページの更新を止めました [ [ 63 ] ](https://metr.org/time-horizons) 。2027年の能力は、既存の指標では測れない領域に入ります。

【階層2】 **普及**：Gartnerは、2028年に企業ソフトの33%がエージェント型AIを含み、日常の業務判断の15%以上がエージェントで自律的に行われると予測しています [ [ 181 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 。道筋Aでは、この予測が上振れします。2026年のMcKinseyの調査で、大企業の40%がエージェントをスケール中と答えた水準から [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 、2027年には過半に達します。

【階層3】 **労働**：Amodeiが2025年5月に述べた「1〜5年で新卒ホワイトカラー職の半分が消える」という予測は [ [ 310 ] ](https://www.axios.com/2025/05/28/ai-jobs-white-collar-unemployment-anthropic) 、道筋Aでは2027年に最初の統計的な確認を得ます。既に、AI曝露度の高い職業の22〜25歳の雇用は、低曝露の同年齢層と同じ伸びだった場合より約19%低いと報告されています [ [ 157 ] ](https://digitaleconomy.stanford.edu/news/canariesaug26) 。道筋Aでは、この差が26歳以上の層へ広がります。

【階層2】 **市場**：OpenAIの年換算の売上は、2025年6月の100億ドルから [ [ 87 ] ](https://www.cnbc.com/2025/06/09/openai-hits-10-billion-in-annualized-revenue-fueled-by-chatgpt-growth.html) 、2026年10月には約500億ドルに伸びたと報じられています [ [ 419 ] ](https://www.axios.com/2026/10/08/openai-50-billion-arr-anthropic-revenue-accounting) 。Anthropicは2026年10月26日に上場の申請書類を提出し、2026年上半期の売上は163億ドルと報じられました [ [ 422 ] ](https://fortune.com/2026/10/26/anthropics-s-1) 。道筋Aでは、両社の売上が2027年も年2倍以上で伸び、投資の回収可能性に対する懸念が後退します。

**この時点で観測されること**：変化は、まず開発者と知識労働者の仕事の中身に現れます。コードを書く、文書を作る、調べるといった作業の大半がエージェントに委ねられ、人は目標の設定と結果の確認に回ります。経済全体の統計には、まだ現れません。

### 3. 2029年前後

【階層3】 **能力**：Forecasting Research Instituteのパネルは、METRの80%基準で8時間の課題をAIがこなす時期を、専門家の中央値で2030年、超予測者で2028年と置いています [ [ 338 ] ](https://forecastingresearch.substack.com/p/leap-wave-8-ai-timelines) 。道筋Aでは、2028年末までに8時間(1日分)の作業を80%基準で任せられる水準に達し、2029年には人の確認が事後の監査へ移ります。Altmanが2025年6月に「2027年には実世界で作業するロボット」と書いた予測は [ [ 313 ] ](https://blog.samaltman.com/the-gentle-singularity) 、道筋Aでも物理的な作業の普及は2029年以降です。AI Index 2026によれば、家庭内の実タスクでのロボットの成功率は2026年時点で12%にとどまっています [ [ 68 ] ](https://hai.stanford.edu/news/inside-the-ai-index-12-takeaways-from-the-2026-report) 。

【階層3】 **普及**：IDCは、2027年に大企業の職務の40%がエージェントと協働し、2030年に組織の45%がエージェントを大規模に統合運用すると予測しています [ [ 394 ] ](https://my.idc.com/getdoc.jsp?containerId=prUS53883425) 。道筋Aでは、Nadellaが述べた「業務アプリという概念の崩壊」が [ [ 319 ] ](https://medium.com/@iamdavidchan/did-satya-nadelle-really-say-saas-is-dead-fa064f3d65d1) 、2029年に主要な業務領域で現実になります。席数で課金するSaaSから、成果や会話の単位で課金するエージェントへ、支出が移ります。

【階層3】 **労働**：世界経済フォーラムの雇用主調査は、2030年までに9,200万の雇用の消失と1.7億の雇用の創出を見込んでいます [ [ 166 ] ](https://www.weforum.org/publications/the-future-of-jobs-report-2025) 。道筋Aでは、消失が先行し創出は遅れます。Hintonが述べた「新卒の失業率が2〜3年で25%」という水準には [ [ 329 ] ](https://fortune.com/article/godfather-of-ai-geoffrey-hinton-massive-unemployment-warning-big-tech-replacing-workers) 、アメリカの一部の職種で近づきます。日本では、[日本の条件の章](19-japan-conditions)で整理した労働供給の不足が、代替の衝撃を吸収する方向に働きます。

【階層3】 **市場**：基盤モデルの供給者が、業務アプリ、業界特化のサービス、開発ツールの各層へ垂直に拡張します。[市場の地図の章](18-market-map)の9つの層のうち、中間の層の事業者は、上位の供給者に吸収されるか、業界の知識と顧客の関係で差別化するかの選択を迫られます。

**この時点で観測されること**：企業の組織図から、知識労働の階層が1〜2段消えます。Amazonが2025年10月に約14,000人の削減を発表した際の説明は、階層を減らし少人数で動く必要があるというものでした [ [ 169 ] ](https://www.aboutamazon.com/news/company-news/amazon-workforce-reduction) 。道筋Aでは、この型の再編が業種を越えて一般化します。

### 4. 2031年前後

【階層4】 **能力**：Hassabisが2026年の対談で述べた「2030年までにAGI」という時期を [ [ 318 ] ](https://www.youtube.com/watch?v=PqVbypvxDto) 、道筋Aは2031年に通過します。何をもって到達とするかは、[言説の分類の章](25-discourse-taxonomy)で述べたとおり定義に依存します。本書は、ここを階層4として扱います。

【階層4】 **普及と経済**：報道によれば、Nadellaは、世界または先進国の経済成長率が10%になるまでAGIの呼称を使うべきでないと述べています [ [ 320 ] ](https://benzinga.com/z/43838071) 。Goldman Sachsの推計では、生成AIは10年で世界のGDPを7%押し上げうるとされ [ [ 354 ] ](https://www.gspublishing.com/content/research/en/reports/2023/03/27/d64e052b-0f6e-45d7-967b-d7be35fabd16.html) 、Acemogluの推計では10年の全要素生産性の上昇は0.66%にとどまります [ [ 151 ] ](https://www.nber.org/papers/w32487) 。道筋Aは、2031年の統計が前者に近づく経過です。ただし、[汎用技術と生産性Jカーブの章](21-gpt-and-j-curve)で述べたとおり、過去の汎用技術では能力の到達から統計への反映まで数十年のずれがありました。道筋Aでも、2031年の統計に現れるのは一部です。

【階層4】 **労働と制度**：Amodeiの2026年1月の論考は、経済的な混乱を5つのリスクの1つに挙げ、政府と企業に備えを求めました [ [ 309 ] ](https://darioamodei.com/essay/the-adolescence-of-technology) 。道筋Aでは、2031年までに所得の再分配、労働時間、教育の制度について、主要国で立法の議論が本格化します。日本のAI推進法は罰則を持たない推進法であり、[統治と規制の章](17-governance-regulation)で述べたとおり、規律は指針と自主的な統治に委ねられています。道筋Aでは、この構造が維持できるかが問われます。

### 5. 企業・労働・市場への帰結

道筋Aが実現した場合、企業には次の帰結が生じます。

第一に、[生成AIの導入段階の章](30-genai-adoption-stages)で定義する導入の深さのうち、S4(システムに組み込む)以降まで進んだ企業と、S2(仕事に適用する)で止まった企業の間で、費用構造の差が開きます。前者は知識労働の単価がエージェントの実行費用に近づき、後者は人件費のままです。

第二に、[AIエージェントの導入の章](31-agent-adoption-stages)で定義する自律性のうち、A3(定めた範囲で自律実行、事後監査)が標準になります。人の承認(human-in-the-loop)を毎回求めるA2の運用は、速度で劣ります。権限、ID、監査の仕組みを先に整えた企業だけが、A3へ移れます。

第三に、提供事業者の層が再編されます。基盤モデルの供給者が業務アプリと業界特化のサービスへ拡張し、中間の層は吸収されます。企業にとっては、特定の供給者への依存が深まる局面です。

第四に、労働の構成が変わります。新卒の採用が減り、経験者の仕事は目標の設定、結果の検証、例外の処理へ寄ります。日本では労働供給の不足が衝撃を和らげますが、若年層の入口が狭まる問題は残ります。

#### 図の読み方

図は、上段に道筋Aの前提を1行で置き、その下に2027年、2029年、2031年の3つの段を縦に並べています。各段の左に年、右にその時点の能力と人の役割を書いています。

上段の前提は、時間地平の倍増と設備投資の継続です。この2つが途切れないという仮定が、図全体を支えています。

3つの段は、人の役割の移り方を示しています。2027年は人が目標を設定し結果を確認する段階、2029年は確認が事後の監査へ移る段階、2031年は到達の定義そのものが問われる段階です。2027年の「数週間分」は50%基準の時間地平、2029年の段に置いた「1日分」は80%基準の時間地平であり、基準が違うため後退ではありません。1日分の到達時期は、本文の第3節と同じく2028年末までです。右端の色が段ごとに濃くなるのは、確度の階層が2から4へ下がることを表しています。

図の下の添え書きは、次の節の「外れる条件」の要約です。設備投資の減少は、それだけでは道筋Cへ近づく印であり、道筋Cの判定には主要な供給者の提供の縮小も要ります。

### 本道筋が外れる条件

道筋Aは、次のいずれかが観測されたときに外れます。

第一に、時間地平の倍増期間が明確に長くなることです。METRは、2026年3月の注記で、課題群の飽和により結果が分析上の選択に左右されやすくなり、正則化の修正で直近モデルの推定が最大20%低下すると述べています [ [ 332 ] ](https://metr.org/blog/2025-03-19-measuring-ai-ability-to-complete-long-tasks) 。新しい課題群で倍増期間が12か月を超えて観測されれば、道筋Aの第1の前提が崩れます。

第二に、設備投資の減速です。Bainは、2030年の計算需要を賄うには年2兆ドルの新規売上が要り、AI由来の節約を含めても8,000億ドル不足すると推計しています [ [ 185 ] ](https://www.bain.com/about/media-center/press-releases/20252/$2-trillion-in-new-revenue-needed-to-fund-ais-scaling-trend---bain--companys-6th-annual-global-technology-report) 。大手クラウド事業者の設備投資の計画が前年比で減少に転じれば、道筋Aは[道筋Cの章](28-path-c-correction)へ近づきます。道筋Cと判定するには、[3つの道筋の比較の章](29-paths-comparison-indicators)で定めるとおり、主要な供給者の提供の縮小も要ります。

第三に、技術的な壁です。Appleの研究部門は、推論モデルが一定の複雑さを超えると精度が完全に崩壊すると報告しました [ [ 65 ] ](https://machinelearning.apple.com/research/illusion-of-thinking) 。報道によれば、Sutskeverは、既知の事前学習は終わり、データは頭打ちだと述べています [ [ 326 ] ](https://cointelegraph.com/news/age-ai-pre-training-soon-come-end-open-ai-co-founder) 。新手法が間に合わず、主要な指標が2年以上停滞すれば、道筋Aは外れます。

第四に、普及の壁です。Gartnerの2026年10月の調査では、AIから大きな価値を実現したと答えたCIOは13%で、用途の成功確率は5分の1のままです [ [ 183 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-10-19-gartner-survey-finds-only-13-percent-of-cios-say-their-enterprise-has-realized-significant-or-transformational-value-from-ai) 。能力が上がっても、この比率が2028年まで改善しなければ、道筋Aではなく[道筋Bの章](27-path-b-gradual)の経過です。

第五に、規制です。EU AI Actの高リスク用途の義務が予定どおり適用され、主要国で自律的なエージェントの用途に事前の許認可が導入されれば、能力の加速と普及の加速が切り離されます。

### 経営層への含意

道筋Aに備える企業は、次の3点を検討することになります。著者の整理であり、[道筋別の戦略の章](35-strategy-by-path)で他の道筋と合わせて扱います。

第一に、S4への移行を前倒しすることです。道筋Aでは、APIで自社システムに基盤モデルを組み込み、評価と監視と費用管理を備えた企業だけが、エージェントの自律性を上げられます。SaaSの利用(S2)で止まる企業は、能力の向上の恩恵を供給者の価格で受け取るだけになります。

第二に、権限と監査の仕組みを先に作ることです。A3の運用は、エージェントのID、権限の範囲、操作の記録、事後の監査が前提です。[AIエージェントの現在地の章](16-agents-today)で整理した事故のうち、評価環境からの逸脱と開発環境の破壊的な操作は、この仕組みの欠如から起きています。

第三に、若年層の採用と育成を続けることです。道筋Aでは新卒の採用を減らす誘因が強まりますが、[雇用の実証の章](14-labor-evidence)で述べたとおり、技能の継承が途切れる費用は数年後に現れます。日本では労働供給の不足がこの判断を後押しします。

道筋Aは、能力の加速だけでは実現しません。条件は、企業の側の受け入れ能力が追いつくことです。著者は、この条件が日本の多くの企業で満たされていないと考えます。この点は、[3つの現在地の章](32-three-positions)で扱います。
