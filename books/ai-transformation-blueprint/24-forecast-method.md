### 序論：本章が扱う範囲

第Ⅳ部からは推論の領域に入ります。本章はその前に、推論の方法を開示します。どの手続で結論を導くのか、どの範囲で妥当性を主張するのか、どのような場合に外れるのかを先に示します。

この方法は、著者の前著『未来予測の設計図』で用いたものと同じです。確度の階層を明示し、問いを分解し、基準率を参照し、観測可能な指標で更新します。前著は国家と社会の20年を対象にしましたが、本書は生成AIと企業の5年を対象にします。対象が違っても方法を変えない理由は、方法が対象ではなく予測という行為の性質に基づくからです。前著の方法の章は[『未来予測の設計図』の第Ⅲ部-1](https://zenn.dev/takenori_kusaka/books/sovereign-resilience-blueprint/viewer/future-method)にあります。

本章は、予測の精度に関する実証研究、確度の階層、専門家調査の使い方、シナリオ・プランニングの手順、早期警戒指標の条件、そして本書が採る手続の順に記述します。方法の選択は著者の判断です。

### 1. 予測の精度に関する実証研究 ―― 専門家は当たらない、しかし改善できる

経営判断にとっての意味は、AIの専門家や経営者の予測をそのまま計画の前提にすべきではなく、予測の作り方を見て信頼度を決めるべきだ、ということです。

Philip Tetlockは1984年から2003年にかけて284名の専門家から約28,000件の政治と経済の予測を集め、確率的に採点しました [ [ 297 ] ](https://press.princeton.edu/books/paperback/9780691175973/expert-political-judgment) 。専門家の予測の精度は、単純な外挿をわずかに上回る程度で、専門分野の知識は精度をほとんど上げませんでした。精度を分けたのは認知の様式です。1つの大きな理論で説明する「ハリネズミ」より、多様な情報源を折衷して自説を疑う「キツネ」のほうが一貫して正確でした。メディアへの露出が高い専門家ほど精度が低い傾向もありました。

TetlockとGardnerは2015年に、アメリカの情報機関が主催した予測トーナメントで、一般の参加者の上位2%が情報機関の分析官を上回る精度を示したと報告しました [ [ 298 ] ](https://openlibrary.org/works/OL18233878W) 。精度の高い予測者の特徴は、問題を分解すること、外側の視点である基準率から始めて内側の視点で調整すること、小刻みに確率を更新すること、そして結果を採点して学ぶことです。

Armstrongが2001年に編集した予測の原則集は、40名の研究者が実証研究から抽出した139の原則をまとめています [ [ 300 ] ](https://doi.org/10.1007/978-0-306-47630-3) 。主要な原則は、複数の手法の予測を組み合わせること、構造化された判断を使うこと、予測者の前提を明示すること、保守的に予測すること、そして予測の誤差を事後に測ることです。Schnaarsが1989年に示した技術予測の体系的な誤りは、[普及の理論の章](20-diffusion-theory)で述べたとおり、技術の魅力に目を奪われ、変化の速度を一様に速いと仮定し、現在の流行を直線的に延長することでした [ [ 299 ] ](https://openlibrary.org/works/OL2679626W) 。

生成AIの事実に当てはめると、[言説の分類の章](25-discourse-taxonomy)で示す予測の多くは、Tetlockが精度の低さと結びつけた特徴を持ちます。発言者の多くは単一の枠組み(能力の指数的な向上、または構造的な限界)に依拠し、メディアへの露出が高く、利害関係を持ちます。本書がこれらの言説を分類するだけで採用しないのは、この実証研究に基づきます。

### 2. 確度の階層 ―― 何を予測でき、何を予測できないか

未来に関する記述は、確度によって4つの階層に分けられます。本書は第Ⅳ部の各記述に、この階層を付します。

**階層1：既に確定している事象**。公開されたモデルの能力は、公開後に下がりません。2024年10月までに実現した推論の費用の低下は、[能力の計測の章](07-measuring-capability)で示したとおり既に起きた事実です [ [ 74 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/research-and-development) 。日本の生産年齢人口の2040年の規模は、既に生まれた世代の構成から導かれます。この階層は、どの道筋でも共通の前提になります。

**階層2：傾向が持続する場合に導かれる事象**。METRが2025年3月に示した「AIが50%の成功率で完了できるタスクの長さが約7か月ごとに倍増する」という傾向は、この階層です [ [ 60 ] ](https://arxiv.org/abs/2503.14499) 。2026年1月の更新では、タスク数を228に増やして全期間の倍増時間を196.5日と再推定し、2024年以降に限ると89日でした [ [ 62 ] ](https://metr.org/blog/2026-01-29-time-horizon-1-1) 。企業の利用率の伸び、設備投資の規模の推移も、この階層です。傾向が持続するという仮定が明示されている限り、検証できます。仮定が破られれば外れます。

**階層3：発生の有無が不確実な事象**。投資の大規模な調整、規制の強化、能力の頭打ち、主要な事業者の資金繰りの悪化がこれに該当します。発生の時期は特定できませんが、発生した場合の影響は評価できます。本書はこの階層を「予測」ではなく「条件つきの影響の評価」として扱い、3つの道筋の分岐条件に置きます。

**階層4：予測が原理的に困難な事象**。汎用人工知能(AGI)の到来時期は、定義に依存するため、この階層です。[言説の分類の章](25-discourse-taxonomy)で示すとおり、同じ2026年の事実を見て「機能的なAGIは既に来た」と「2050年まで来ない」という正反対の結論が並立するのは、定義の差です。雇用の構造的な変化の帰結、社会的な価値観の変化、政策の方針転換もこの階層です。本書は、この階層の事象について時期を述べません。

### 3. 専門家調査の使い方 ―― 点ではなく分布として

経営判断にとっての意味は、「AGIは2027年」という1つの数字ではなく、調査の回答の分布の幅そのものが情報である、ということです。

DalkeyとHelmerは1963年に、専門家の集団判断を対面の会議を避けて得るDelphi法を報告しました [ [ 305 ] ](https://doi.org/10.1287/mnsc.9.3.458) 。匿名の質問票を複数回繰り返し、前回の回答の分布を参加者に戻して収斂させる手法で、権威への追従や声の大きい人の支配を避けることが狙いです。

AI研究者を対象にした大規模な調査には、この系譜のものがあります。Graceらは2023年秋に、主要なAIの学会で発表した研究者2,778名を調査しました [ [ 306 ] ](https://arxiv.org/abs/2401.02843) 。あらゆるタスクで機械が人を上回る確率は、2027年までに10%と集計されました。同じ確率が50%に達するのは2047年で、前年の調査より13年早まりました。全職業の完全な自動化は、10%なら2037年、50%なら2116年です。人工知能学会(AAAI)が2025年3月に公表した報告では、回答者の76%が「現在のAIの手法の規模を拡大すること」でAGIに到達するのは「ありそうにない」か「まずありえない」と答えました [ [ 336 ] ](https://aaai.org/wp-content/uploads/2025/03/AAAI-2025-PresPanel-Report-Digital-3.7.25.pdf) 。Forecasting Research Institute(FRI、独立の予測研究機関)の2026年の調査では、専門家の「2100年までにAGI」の確率は80%、条件つきの中央値は2050年で、四分位は2039年から2065年に広がっていました [ [ 338 ] ](https://forecastingresearch.substack.com/p/leap-wave-8-ai-timelines) 。

これらの調査から本書が採るのは、中央値ではなく幅です。2047年と2050年という中央値は、前節の階層4に属し、本書の5年の射程の外にあります。本書が使うのは、「5年以内」に相当する分布の左端に、専門家の集合的判断が10%程度の確率を置いているという事実です。これは、[道筋Aの章](26-path-a-acceleration)を無視できない理由であり、同時に基準の道筋にしない理由です。

### 4. シナリオ・プランニング ―― 当てるためではなく、備えるために

経営判断にとっての意味は、3つの道筋が「どれが当たるか」を競うものではなく、どれが来ても困らない手と特定の道筋に賭ける手を分けるための道具だということです。

Pierre Wackは1985年に、Royal Dutch/Shellの企画部門が1970年代から開発してきたシナリオの手法を回顧しました [ [ 301 ] ](https://hbr.org/1985/09/scenarios-uncharted-waters-ahead) 。予測を土台にした計画は1950年代と1960年代には機能しましたが、1970年代以降は失敗が増えました。シナリオは未来を当てるためではなく、経営者の心の中のモデルを変えて不確実性に備えるためのものです。1973年の石油危機をShellが他社より早く察知できたのは、シナリオの効果だとWackは述べています。

Peter Schwartzは1991年に、シナリオを作る8段階の手順を示しました [ [ 302 ] ](https://openlibrary.org/works/OL514578W) 。焦点となる意思決定の特定、環境の主要な要因、駆動力の整理、重要性と不確実性による分類、シナリオの論理の選択、各シナリオの具体化、含意の検討、そして先行指標の選定です。Schoemakerは1995年に、意思決定の過信と視野の狭さへの処方として、10段階の手順を体系化しました [ [ 303 ] ](https://sloanreview.mit.edu/article/scenario-planning-a-tool-for-strategic-thinking/) 。

生成AIの分野で、採点可能なシナリオとして提示された例が『AI 2027』です。Kokotajloらは2025年4月に、傾向の外挿、机上演習、専門家の意見に基づき、2025年のエージェントから自動化されたAI研究までを1本の筋書きで描きました [ [ 307 ] ](https://ai-2027.com/) 。著者らは「予測の正確さ」を目標に掲げ、検証され反論されるべき予測として提示しました。[言説の分類の章](25-discourse-taxonomy)で示すとおり、著者らは2025年12月に中央値を後ろへ修正しています。本書はこれを、シナリオが採点され更新された例として扱います。

本書の3つの道筋は、Schwartzの手順に沿って作ります。焦点となる意思決定は「企業が生成AIとAIエージェントにどの深さまで投資するか」です。駆動力は、能力の進度、普及の速度、経済効果、雇用の4軸です。不確実性の高い軸は能力の進度と投資の持続であり、この2つの組み合わせが3つの道筋を分けます。本書は、シナリオ・プランニングでいう「シナリオ」を「道筋」と呼びます。

### 5. 早期警戒指標 ―― 指標の条件

シナリオは、どの道筋に入りつつあるかを観測できなければ、計画の道具になりません。Schwartzの手順の最後の段階である先行指標の選定は、本書では早期警戒指標として[3つの道筋の比較の章](29-paths-comparison-indicators)に置きます。

指標には3つの条件を課します。第一に、公表されていること。第二に、定期的に更新されていること。第三に、定義が安定していること。この3条件を満たさない指標は、道筋の判定に使えません。

条件の重要さを示す例が、本書の執筆中に起きました。METRの時間地平のページは、2026年5月に「16時間を超える測定は現行のタスク群では信頼できない」と注記し、2026年9月に「このページは更新を停止した」と明記しました [ [ 63 ] ](https://metr.org/time-horizons) 。階層2の最も有力な傾向の指標が、タスク群の飽和によって更新を止めたのです。本書は、この指標を道筋Aの分岐条件に使いますが、後継の指標が現れるまで、判定の根拠としての重みを下げます。

企業の利用率についても、[企業の利用の章](12-enterprise-adoption)で示したとおり、アメリカの国勢調査局の事業所調査は2025年11月に設問の文言を改定し、以後の数値は旧系列と直接比較できません [ [ 132 ] ](https://www.census.gov/hfp/btos/data) 。指標の定義の変更は、傾向の判定を中断させます。本書は、指標ごとに系列の断絶を注記します。

### 6. 本書が採る手続

以上を踏まえ、第Ⅳ部は次の6つの手続で推論します。

**手続1：問いを分解する。** 「5年後の生成AIはどうなるか」を、能力の進度、普及の速度、経済効果、雇用の4軸に分解します。[言説の分類の章](25-discourse-taxonomy)が示すとおり、同じ発言者が軸ごとに別の方向に属するため、分類は人物ではなく主張と軸の組み合わせで行います。

**手続2：階層を明示する。** 各記述に、第2節の4階層のどれに属するかを付します。階層1と2の記述は3つの道筋に共通の前提とし、階層3の記述を道筋の分岐条件に置き、階層4の記述については時期を述べません。

**手続3：基準率を参照する。** 生成AIの普及の速度を推定する外側の視点として、[汎用技術と生産性Jカーブの章](21-gpt-and-j-curve)で示した過去の汎用技術の経過を使います。過去の汎用技術で、個人の効果が国の統計に表れるまでに10年未満だった例はありません。この基準率を、内側の視点である[普及の理論の章](20-diffusion-theory)の「PCやインターネットより速い採用」で調整します。

**手続4：言説を利害つきで分類する。** 第1節の実証研究に基づき、予測を採用するのではなく分類します。発言者の利害関係、根拠、期限、そして2026年10月の時点での検証の結果を併記します。

**手続5：指標で更新する。** 各道筋に、第5節の3条件を満たす早期警戒指標と、道筋の切り替えを判断する閾値を置きます。本書の推論は、公開の時点の指標に基づく暫定のものであり、指標の更新によって改訂されることを前提とします。

**手続6：外れる条件を明示する。** 3つの道筋の各章の末尾に「本道筋が外れる条件」の節を置きます。

採用しない手続もあります。本書は、各道筋に確率を割り当てません。TetlockとGardnerが有効性を示した数値の記録は、採点のために同じ問いを長期に追う仕組みがあって機能します。本書は1回の刊行物であり、採点の仕組みを持ちません。確率の代わりに、指標の追跡と外れる条件の明示で代替します。

### 🗺️ 図：予測ではなく、階層つきの推論

![確度の4階層のうち、階層1と2が3つの道筋の共通の前提、階層3が分岐条件、階層4は時期を述べない](/images/ai-transformation-blueprint/24-forecast-method.png)

#### 図の読み方

この図は、上から下へ4つの帯を積んだものです。各帯は確度の階層で、上ほど確度が高く、下ほど低くなります。

上の2つの帯、すなわち階層1(既に確定した事象)と階層2(傾向の外挿)は、右側に「3つの道筋に共通の前提」と記しています。公開されたモデルの能力、実現済みの価格低下、人口の構成、そして明示された仮定のもとでの傾向が、ここに入ります。

3つ目の帯、階層3(発生が不確実な事象)は、右側に「道筋の分岐条件」と記しています。投資の調整、規制、能力の頭打ちが、ここで道筋A、B、Cを分けます。

最下段の帯、階層4(原理的に困難な事象)は、右側に「時期を述べない」と記しています。AGIの到来時期と雇用の構造の帰結は、本書の推論の外に置きます。各階層の例は本文の第2節に記しています。

### 本章の位置づけ

本章で示した方法の選択は、著者の判断です。方法そのものは、Tetlock、Armstrong、Wack、Schwartzの研究に基づき、前著と同じものです。

予測の方法が本書の推論に与える制約は、次の3つです。第一に、本書は未来を当てることを目標にせず、どの道筋に入りつつあるかを観測できる状態を作ることを目標にします。第二に、本書の推論は階層1と2の事実に基づく範囲で検証可能であり、階層3の分岐条件が満たされるかどうかで外れます。第三に、本書は確率を割り当てず、指標の追跡で代替します。

この制約のもとで、次の章は言説を分類し、続く3つの章が道筋A、B、Cを記述します。[道筋別の戦略の章](35-strategy-by-path)は、どの道筋でも後悔しない手、選択権を買う手、特定の道筋に賭ける手を分けます。この区分は、本章の第4節で述べたシナリオの目的、すなわち「当てるためではなく備えるため」から導かれます。
