### 序論：本章が扱う範囲

本章は、生成AIとAIエージェントをめぐる法令、指針、標準、そして企業の内部統治の道具を、2026年10月時点で整理します。対象は、欧州連合、日本、アメリカ、中国、韓国の法令と政策、国際標準と、事業者が提供する統治の仕組みです。

法令の記述は、条文と公的機関の公表に基づきます。法の解釈や、自社が規制の対象になるかどうかの判断は、本章の範囲外です。本章は「何がいつから適用されるか」と「何が義務で何が任意か」を、発行元の言葉で記録します。本文は事実の記述に限り、評価は章末に分離します。

### 1. 欧州連合：包括的な規制と、その延期

欧州連合のAI規則(以下、EU AI Act)は2024年7月12日に官報で公布され、同年8月1日に発効しました。当初の予定では、禁止事項とAIリテラシーの義務が2025年2月2日、汎用AIモデルとガバナンスの規定が2025年8月2日、残りの規定が2026年8月2日から適用されることになっていました [ [ 647 ] ](https://artificialintelligenceact.eu/implementation-timeline/) 。

この予定は、2026年に変わりました。欧州委員会は2025年11月19日にDigital Omnibus on AIを提案しました。2026年5月の政治合意を経て、改正法は2026年7月27日に発効しました。附属書IIIに該当する高リスクAIの規定の適用は2027年12月2日へ、附属書Iの製品組み込み型は2028年8月2日へ延期されています [ [ 649 ] ](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai) 。法律事務所の解説によれば、改正法は2026年7月24日の官報に掲載され、3日後に発効しました [ [ 650 ] ](https://www.lewissilkin.com/en/insights/2026/07/27/the-digital-omnibus-on-ai-enters-into-force-today-102nedo) 。延期されたのは高リスクAIの規定であり、禁止事項とAIリテラシーの義務(2025年2月2日)、汎用AIモデルの義務(2025年8月2日)、第50条の透明性の義務(2026年8月2日)は予定どおり適用されています。2026年8月2日より前から市場にある合成コンテンツの生成システムは、第50条第2項の遵守を2026年12月2日まで猶予されています [ [ 647 ] ](https://artificialintelligenceact.eu/implementation-timeline/) 。

同規則は域外にも適用されます。第2条は、EU域内でAIシステムを市場に出すか供用する事業者をEU域内に所在するか否かを問わず対象とし、第三国に所在する事業者と展開者も、AIシステムの出力がEU域内で使われる場合は対象にします [ [ 1811 ] ](https://artificialintelligenceact.eu/article/2/) 。

エージェントの統治に直接関わる条文として、第14条「人間による監督」があります。高リスクAIシステムは、使用期間中に自然人が効果的に監督できるよう設計される必要があります。そのうえで同条は、監督者が出力を無視し、覆し、「停止」ボタンまたは同等の手続きで介入し中断できることを求めています [ [ 648 ] ](https://artificialintelligenceact.eu/article/14/) 。

### 2. 日本：推進法と、拘束力のない指針

日本では、2025年に初めてAIに関する基本法が成立しました。「人工知能関連技術の研究開発及び活用の推進に関する法律」(令和7年法律第53号、以下AI推進法)は、2025年5月28日に成立し、6月4日に公布、9月1日に全面施行されました。全28条で、罰則の規定はありません [ [ 487 ] ](https://laws.e-gov.go.jp/law/507AC0000000053) 。

同法の第3条は、AIを行政と民間の事業活動の効率化と新産業の創出をもたらす基盤技術であり、安全保障の観点からも重要な技術と位置づけます。第7条は、AIを事業活動において活用しようとする「活用事業者」に、活用による事業活動の効率化と高度化に努めること(努力義務)と、国と地方公共団体の施策に協力すること(協力義務)を定めています。第16条は、不正な目的または不適切な方法によるAIの活用で国民の権利利益の侵害が生じた事案を国が分析し、活用事業者などに指導、助言、情報の提供その他の必要な措置を講じると定めています。罰則はありませんが、企業は国の施策への協力義務を負い、権利利益の侵害事案については国の調査と指導・助言の対象になります [ [ 487 ] ](https://laws.e-gov.go.jp/law/507AC0000000053) 。内閣府は、国内のAIの開発と活用が遅れており、多くの国民がリスクに不安を抱えている状況への対応として、イノベーションの促進とリスクへの対応の両立を掲げています [ [ 488 ] ](https://www8.cao.go.jp/cstp/ai/ai_act/ai_act.html) 。

同法に基づき、内閣に人工知能戦略本部が置かれました。本部長は内閣総理大臣、構成員は全国務大臣です [ [ 655 ] ](https://www8.cao.go.jp/cstp/ai/ai_hq/konkyo.html) 。初めての人工知能基本計画は2025年12月23日に閣議決定され、「世界で最もAIを開発・活用しやすい国」を目標に掲げ、計画を当面毎年変更すると明記しました [ [ 490 ] ](https://www.cao.go.jp/press/new_wave/20260206.html) 。約半年後の2026年7月14日には、第Ⅱ期の計画「日本AX、より強く、より豊かに」が閣議決定されました。エージェント型AIを軸に、行政と産業の現場へAIを導入する方針を示し、政府職員18万人が利用するガバメントAI「源内」を起点に位置づけています [ [ 492 ] ](https://www8.cao.go.jp/cstp/ai/ai_plan/aiplan_20260714.pdf) 。

企業が参照する指針は2つあります。第一に、AI推進法第13条に基づく「人工知能関連技術の研究開発及び活用の適正性確保に関する指針」(2025年12月19日、人工知能戦略本部の決定。以下、適正性確保に関する指針)です。人間中心、公平性、安全性、透明性など10の要素と4つの基本方針を示し、各主体の自主的な取り組みを求めるもので、「一義的な定義や絶対的な水準を定めるものではない」と記しています。ISO/IEC 42001にも言及しています [ [ 493 ] ](https://www8.cao.go.jp/cstp/ai/ai_guideline/ai_gl_2025.pdf) 。第二に、総務省と経済産業省の「AI事業者ガイドライン」です。第1.0版が2024年4月19日、第1.1版が2025年3月28日、第1.2版が2026年3月31日に公表されました [ [ 657 ] ](https://www.soumu.go.jp/main_sosiki/kenkyu/ai_network/02ryutsu20_04000019.html) 。同ガイドラインは、3つの先行文書を統合した「非拘束的なソフトロー」で、事業活動においてAIの開発、提供、利用を担うすべての者を対象とし、業務外の利用者とデータを提供する者は対象に含みません [ [ 495 ] ](https://www.soumu.go.jp/main_content/001002576.pdf) 。第1.2版は、AIエージェントとフィジカルAIの定義、便益、リスクを追記し、チェックリストとワークシートを公開しています [ [ 496 ] ](https://www.meti.go.jp/shingikai/mono_info_service/ai_shakai_jisso/20260331_report.html) 。

データと著作権については、既存の法令が土台になります。著作権法第30条の4は、著作物に表現された思想または感情の享受を目的としない利用(情報解析を含む)を、必要と認められる限度で許諾なく行えると定め、著作権者の利益を不当に害する場合を除外します。文化庁はこれを「柔軟な権利制限規定」と呼んでいます [ [ 497 ] ](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html) 。文化審議会の「AIと著作権に関する考え方について」(2024年3月15日)は、学習の段階と生成の段階を分けて整理した文書で、法的拘束力はありません [ [ 498 ] ](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94037901_01.pdf) 。同文書の概要は、享受する目的が併存する利用には第30条の4が適用されないとしています [ [ 499 ] ](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94057901_01.pdf) 。

個人情報については、個人情報保護委員会が2023年6月2日に、生成AIサービスの利用に関する注意喚起を公表しました。個人情報を含む入力が利用目的の範囲内か、個人データを含む入力が応答の出力以外(学習など)に使われないかを確認するよう求めるものです。併せて同委員会は、OpenAIに対し、要配慮個人情報の取得と利用目的の通知について注意喚起を行いました [ [ 500 ] ](https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert) 。2026年7月10日には「個人情報の保護に関する法律等の一部を改正する法律」が成立し、7月17日に公布されました [ [ 501 ] ](https://www.ppc.go.jp/files/pdf/260731_shiryou-1.pdf) 。改正の主な項目は、統計作成等と整理できるAI開発等にのみ利用される場合に、公表、書面による合意、目的外利用と再提供の禁止などの担保措置を条件として、個人データの第三者提供と公開された要配慮個人情報の取得について本人同意を不要とすること、重大な違反に対する課徴金の制度などです。特例の具体的な範囲は委員会規則で定まります。施行期日は、原則として公布の日から2年を超えない範囲内において政令が定める日とされ、2026年10月時点では未施行です(一部の規定を除く) [ [ 502 ] ](https://www.ppc.go.jp/files/pdf/260717_kaiseihounitsuite.pdf) 。

生成AIの利用に関わる既存の規律は、ほかにもあります。個人情報保護法の第25条は、個人データの取扱いを委託する場合に委託先への必要かつ適切な監督を求めます。第28条は、外国にある第三者へ個人データを提供する場合にあらかじめ本人の同意を求め、委員会規則の基準に適合する体制を整備した相手への提供と委員会規則が定める国への提供を例外とします [ [ 1904 ] ](https://laws.e-gov.go.jp/law/415AC0000000057) 。不正競争防止法の第2条第6項は、営業秘密を「秘密として管理されている」事業活動に有用な技術上または営業上の情報で公然と知られていないものと定義しており、秘密として管理されていることが要件です [ [ 1801 ] ](https://laws.e-gov.go.jp/law/405AC0000000047) 。従業員の利用記録の取得については、個人情報保護委員会のQ&Aがモニタリングの留意点を4つ挙げています。目的をあらかじめ特定して社内規程等で定め従業者へ明示すること、実施の責任者と権限を定めること、ルールを策定して運用者へ徹底すること、ルールどおり適正に行われているかを確認することです [ [ 1802 ] ](https://www.ppc.go.jp/all_faq_index/faq1-q5-7/) 。

業種別では、金融庁が2025年3月に「AIディスカッションペーパー」第1.0版を公表し、2026年3月3日に第1.1版へ改訂しました。基本の姿勢を「技術中立」とし、2024年11月の調査時点ではほとんど行われていなかった顧客向けサービスへの利用が、範囲を絞った提供と検討の段階に至ったと記しています [ [ 509 ] ](https://www.fsa.go.jp/news/r7/sonota/20260303/aidp.html) 。第1.1版の概要は、顧客向けサービスを念頭にしたリスク低減の取り組みを、提供前の「設計と事前検証」、提供時の「顧客への適切な説明・注意喚起」、提供後の「検証・モニタリング」と、全体を支える「ガバナンス」の4つの局面に整理しています。経営トップが先導して利活用を具体的な取り組みとして進めるフェーズにあること、質の高いデータの整備が重要であることも挙げています [ [ 1804 ] ](https://www.fsa.go.jp/news/r7/sonota/20260303/aidp_version1.1_summary.pdf) 。行政では、デジタル庁が2026年6月12日に生成AIの調達と利活用のガイドライン第2.0版を決定しました。同ガイドラインの本体は2.2.2節で、AIエージェントなどを「AIガバナンスの枠組みの対象」としつつ、具体的な対応事項は定めていません [ [ 231 ] ](https://www.digital.go.jp/news/decb64eb-f26e-41cb-8d37-f3dd173108b8) 。

### 3. アメリカ、中国、韓国、国際機関

アメリカでは、2025年1月23日に大統領令14179が署名され、アメリカのAI覇権の維持と強化を政策とし、2023年の大統領令14110を撤回しました [ [ 658 ] ](https://www.whitehouse.gov/presidential-actions/2025/01/removing-barriers-to-american-leadership-in-artificial-intelligence/) 。2025年7月23日には「America's AI Action Plan」が公表され、3本柱で90超の連邦政策行動を示しています [ [ 659 ] ](https://www.whitehouse.gov/articles/2025/07/white-house-unveils-americas-ai-action-plan/) 。2025年12月11日の大統領令14365は、州のAI法に異議を申し立てるタスクフォースの設置を司法長官に指示しました [ [ 660 ] ](https://www.presidency.ucsb.edu/documents/executive-order-14365-ensuring-national-policy-framework-for-artificial-intelligence) 。

連邦の標準としては、NIST(アメリカ国立標準技術研究所)のAIリスク管理フレームワーク(AI RMF 1.0)が2023年1月26日に公開されています。自発的で、権利を保全し、特定の分野や用途に依存しない枠組みと位置づけられます [ [ 652 ] ](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10) 。2024年7月26日には生成AI向けのプロファイル(NIST AI 600-1)が公開され、生成AIに固有または生成AIにより悪化するリスクを定義しました [ [ 653 ] ](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf) 。

中国では、生成AIサービス管理暫定弁法が2023年7月10日に公布され、同年8月15日に施行されました。世論への影響力や社会的な動員能力を持つ生成AIサービスには、安全評価とアルゴリズムの届け出を求めています [ [ 661 ] ](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm) 。2025年3月には、AIが生成した内容への標識に関する弁法が公布され、同年9月1日に施行されました。利用者が明確に知覚できる標識と、ファイルに技術的に付加する標識の2種類を定めています [ [ 662 ] ](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) 。

韓国のAI基本法は2026年1月22日に施行され、高影響AIの事業者に事前評価、説明、人間の介入と監督の仕組みを求めます。行政罰の賦課までには1年の猶予期間が示されました [ [ 668 ] ](https://www.cooley.com/news/insight/2026/2026-01-27-south-koreas-ai-basic-act-overview-and-key-takeaways) 。

国際機関では、OECDのAI原則が2019年5月に採択され、2024年5月に改定されました。包摂的な成長、人権と民主的な価値、透明性と説明可能性、頑健性と安全、説明責任の5つを価値の基盤とし、47の国と地域が支持しています [ [ 663 ] ](https://oecd.ai/en/ai-principles) 。

### 4. 国際標準：ISO/IEC 42001

ISO/IEC 42001:2023は、AIマネジメントシステムの要求事項を定める国際標準で、2023年12月に発行されました。AIマネジメントシステムを確立し、実装し、維持し、継続的に改善するための要求事項と指針を規定します [ [ 654 ] ](https://www.iso.org/standard/42001) 。日本の「適正性確保に関する指針」が、この標準に言及していることは第2節で述べました。2026年に入り、AI事業者による認証の取得が相次いでいます [ [ 467 ] ](https://finance.yahoo.com/news/maven-agi-achieves-iso-iec-130000204.html) 。

### 5. 企業の内部統治：ID、権限、承認

法令と標準が「何を守るべきか」を示すのに対し、エージェントの統治には「誰が、何を、どこまで実行できるか」を機械的に決める道具が要ります。2025年から2026年にかけて、その道具が製品として現れました。

**エージェントのID**。Microsoftは2025年5月19日にEntra Agent IDを発表し、Copilot StudioとAzure AI Foundryで作成されたエージェントに、人やアプリケーションとは区別されたIDを自動で付与するとしました [ [ 664 ] ](https://www.microsoft.com/en-us/security/blog/2025/05/19/microsoft-extends-zero-trust-to-secure-the-agentic-workforce/) 。Oktaは2024年10月に、エージェントが利用者に代わってAPIを呼び出す仕組みと、人が承認または拒否する非同期の認可を示し、2026年9月にエージェント向けのシングルサインオンなどを一般提供しました [ [ 665 ] ](https://www.okta.com/newsroom/press-releases/okta-helps-builders-easily-implement-auth-for-genai-apps-secure-how/) 。

**承認の設計**。AnthropicのClaude Codeは段階的な許可の仕組みを採用し、作業ディレクトリ内の読み取りは承認不要、コマンドの実行やファイルの変更は実行前に承認を求めます [ [ 666 ] ](https://code.claude.com/docs/en/permissions) 。OpenAIのAgents SDKでは、道具に承認が必要である旨を設定すると、機微な呼び出しの直前で実行を一時停止し、人が承認または拒否するまで状態を保存します [ [ 667 ] ](https://openai.github.io/openai-agents-python/human_in_the_loop/) 。2026年9月に発表されたOpenAIのdotsは、いつ自律的に動きいつ承認を求めるかの規則を組み込み、利用者が行動ごとに許可、承認必須、遮断を設定できます [ [ 674 ] ](https://openai.com/index/introducing-dots) 。同年10月のClaude Duetは、支払い、署名、削除の前に承認を待ち、証券取引と口座間送金は承認があっても行いません [ [ 675 ] ](https://claude.com/resources/articles/claude-duet) 。

**利用規約**。Anthropicは2026年10月8日に利用ポリシーの改定を公表しました(11月12日発効)。健康や金融などの高リスク用途では、資格のある「人の承認(human in the loop)」とAI利用の本人への通知を求める既存の要件に加え、Claudeが自律的に物理的な動作をする場合には、資格のある操作者が機器を観察し停止できることを求めています [ [ 669 ] ](https://www.anthropic.com/news/2026-usage-policy-update) 。

**統制の整備状況**。ボストン コンサルティング グループの2026年10月の調査では、エージェントに必要な統制をすべて整備している企業は5%でした [ [ 617 ] ](https://prtimes.jp/main/html/rd/p/000000049.000145445.html) 。KPMGの2026年第3四半期の調査では、49%が、エージェントの自律的な意思決定を許さない高リスク用途を定義済みです [ [ 612 ] ](https://kpmg.com/us/en/media/news/q3-ai-pulse-2026.html) 。Gartnerは2026年10月20日に、2028年までに企業のセキュリティ侵害の25%が、管理されない機械の権限と旧来の認証情報の運用によるエージェントの悪用に起因すると予測しました [ [ 672 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-10-20-gartner-identifies-the-top-strategic-technology-trends-for-2027) 。

日本では、IPAが2024年3月に行った調査で、生成AIの利用に関するセキュリティの規則を策定済みの企業は20%未満でした [ [ 622 ] ](https://www.ipa.go.jp/pressrelease/2024/press20240704.html) 。労働政策研究・研修機構の2026年1月のフォーラムでは、生成AIに関する従業員向けガイドラインを策定していない日本企業の多いことが示されています [ [ 512 ] ](https://www.jil.go.jp/event/ro_forum/20260120/houkoku/01-keynote-toda.html) 。

### 🗺️ 図：外の規則は3層、中の統治は3つの道具

#### 図の読み方

この図は、左右2列の対比です。左列「外の規則」には、上から法令、指針、標準の3層を置いています。法令はEU AI Act(高リスクの適用は2027年12月へ延期。禁止事項、汎用AIモデル、透明性の義務は適用済み)と日本のAI推進法(罰則なし)、指針はAI事業者ガイドライン第1.2版と「適正性確保に関する指針」、標準はISO/IEC 42001とNIST AI RMFです。

右列「中の統治」には、企業が自ら整える3つの道具を置いています。IDはエージェントに人とは別の身分を与えること、権限は読める範囲と実行できる範囲を分けること、承認は不可逆な操作の前に人が止められることです。右列の「承認」の枠だけを丹で塗っているのは、本書の図の約束事で、人が判定する場所を示すためです。

左列と右列をつなぐ矢印は、外の規則が任意か義務かにかかわらず、中の統治が必要であることを示しています。統制を整備済みの企業が5%という数値が、その矢印の現在地です。補助ラベルの数値の出典は、本文の第1節、第2節、第5節にあります。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

第一に、日本の法制度は「推進法と拘束力のない指針」の構造です。守るべき水準を国が一義的に決めず、各社が指針を参照して自ら決める形になっています。これは規制が緩いという意味ではなく、守る水準を決める責任が企業の側にあるという意味です。EU AI Actの適用延期も、企業が待っていればよい理由にはなりません。

第二に、エージェントの統治は、法令より先に製品が答えを出しました。ID、権限、承認の3つの道具は、2025年から2026年に各社が製品として提供し始めたもので、その設計は[AIエージェントの現在地の章](16-agents-today)で記録した事故への応答として読めます。著者は、企業がエージェントを導入する際、最初に決めるべきは、モデルの選択ではなく、この3つの道具をどう整えるかだと考えます。

第三に、統制の整備は進んでいません。整備済みが5%、高リスク用途を定義済みが49%という数値は、導入の速度に統治が追いついていない状態を示しています。日本では、そもそも従業員向けのガイドラインを持たない企業が多い、という段階です。

第四に、ISO/IEC 42001の認証の取得は任意です。取得を検討する条件は、顧客、監督当局、取引先が求めるかどうかだと著者は考えます。また、第2節で挙げた委託先の監督、越境移転、営業秘密の秘密管理性、従業員のモニタリングの4点は、日本企業が生成AIを使い始めるとき、最初に問われる法的な論点だと著者は整理します。本書は法的な助言ではなく、個別の適用は弁護士等の専門家に確認してください。

### 経営層への含意

統治は、導入を遅らせる手続きではなく、任せる範囲を広げるための前提です。承認の位置を決め、IDと権限を分けた企業が、[AIエージェントの導入の章](31-agent-adoption-stages)で示す自律性の段階を上げることができると著者は考えます。各段階で必要な統治は、同章の第5節に置きます。統治の設計には、第2節で挙げた委託先の監督、越境移転、営業秘密、従業員のモニタリングを含めてください。日本の指針が自主的な取り組みを求めている以上、その設計は各社の経営判断です。
