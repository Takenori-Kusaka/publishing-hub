### 序論：本章が扱う範囲

第Ⅳ部は推論の領域です。[予測の方法の章](24-forecast-method)で開示した手続に従い、本章から4つの章で2031年までの未来を扱います。

本章は、その出発点として、生成AIの未来について公表されている言説を整理します。対象は、AI企業の経営者、投資家、学術研究者、金融機関、調査会社、批判者、日本の研究者とシンクタンク、そして Zenn や note に投稿された個人の見解です。2024年から2026年10月までに公表された100件余りの言説を、著者が収集して読みました。

本章は言説の当否を判定しません。誰が、いつ、どの利害関係のもとで何を、どの根拠で述べたかを並べます。そのうえで、言説を「人物」ではなく「主張 × 軸」で分類します。同じ人物が、能力については加速を、投資については過熱を述べている例が多いためです。章末では、2024年から2025年に出された短期の予測を、2026年10月時点の事実と突き合わせます。

この整理が、次の[道筋Aの章](26-path-a-acceleration)、[道筋Bの章](27-path-b-gradual)、[道筋Cの章](28-path-c-correction)の材料になります。

### 1. 分類の方法：人物ではなく、主張と軸で分ける

言説を読むと、同一の発言者が文脈によって異なる方向を向いていることがすぐに分かります。OpenAI のCEOである Sam Altman は、2025年6月の論考で「離陸は始まった」と述べ、2026年に新規の洞察を見つけるシステム、2027年に実世界で作業するロボットが現れうると書きました [ [ 313 ] ](https://blog.samaltman.com/the-gentle-singularity) 。同じ人物が2025年8月には、投資家が全体として過熱しているかという問いに「私の意見ではそうだ」と答え、誰かが途方もない額を失うと述べています [ [ 314 ] ](https://www.cnbc.com/2025/08/18/openai-sam-altman-warns-ai-market-is-in-a-bubble.html) 。能力については加速、投資については調整という二重の立場です。

Meta の主任AI科学者であった Yann LeCun は、自己回帰型の大規模言語モデルは人間水準の知能に至る道ではないと繰り返し述べました。一方で、AI全体は印刷術に匹敵する変化をもたらすとも述べています [ [ 322 ] ](https://www.newsweek.com/nw-ai/ai-impact-interview-yann-lecun-artificial-intelligence-2054237) 。現行手法には停滞、AI全体には漸進という立場です。

このため本書は、言説を人物単位で「楽観派」「悲観派」に分けません。次の4つの軸を立て、軸ごとに主張を分類します。

| 軸 | 問い | 3つの方向 |
| --- | --- | --- |
| 1. 能力の進度 | 人間の広い範囲の知的作業をこなす AI は、いつ来るか | 2026〜28年 / 2030年代 / 2040年代以降か別の手法が要る |
| 2. 普及の速度 | 企業の業務と製品に、どの速さで組み込まれるか | 2〜3年で主流 / 10年単位で浸透 / 試行の大半が止まる |
| 3. 経済効果と投資 | 経済への効果はどれだけ大きく、投資は回収されるか | 効果は大きい / 効果は小さい / 投資が先行し調整が来る |
| 4. 雇用 | 仕事はどう変わるか | 短期に大きく失われる / 再配分される / 今のところ変化なし |

3つの方向は、本書の3つの道筋に対応します。加速(A)、漸進(B)、調整(C)です。ただし、方向の対応は軸ごとに決まるのであって、人物ごとには決まりません。

もう1つの列が、発言者の利害関係です。AI企業の経営者と投資家の発言は、自社や自分のファンドの価値に直結します。調査会社の予測は、助言サービスの需要に結びつきます。批判者の発言も、書籍や有料の購読者に結びつきます。利害関係があることは発言が誤りであることを意味しません。しかし、利害関係を書かずに言説を並べることは、本書の規範に反します。

### 6. 日本の言説の位置

日本で公表された言説は、能力の進度よりも普及の速度の軸に集中しています。

東京大学の松尾豊教授は、内閣府の AI 戦略会議の座長であり、松尾研究室発の新興企業を支援する立場でもあります。2026年4月のインタビューで、AGI は「遅かれ早かれ普及する」と述べ、日本の勝機は産業の知識と AI の統合にあるとし、3〜5年先は「正直、何が起こるかはわからない」と述べました [ [ 359 ] ](https://www.businessinsider.jp/article/2604-prof-matsuo-agi-100-startups-mission/) 。

ソフトバンクグループの孫正義会長は、OpenAI と Stargate への最大級の投資家です。報道によれば、孫会長は2024年10月の講演で、AGI の実現時期を前年の「10年以内」から「2〜3年以内」へ前倒ししました。AGI の1万倍の性能を持つ超知能は、10年以内に実現するとも述べています [ [ 379 ] ](https://businessnetwork.jp/article/23247) 。

Preferred Networks の社長である岡野原大輔氏は、国産の基盤モデルと半導体を手がける企業の経営者です。2024年5月の講演資料では、スケーリング則と創発を根拠に、現在の仕事の50%が自動化されうると述べています [ [ 366 ] ](https://hillbig.github.io/AIEXPO2024spring_okanohara.pdf) 。2025年11月に収録された対談では、基盤モデル各社は先行投資をしており、回収は2028年や2030年を見越していると述べています [ [ 1402 ] ](https://www.youtube.com/watch?v=Vlj0K7r1qkY) 。能力については加速、回収については条件付きという立場です。

慶應義塾大学の栗原聡教授は、人工知能学会の前会長です。生成AI の次が AIエージェントだと考えるのは「大間違い」と述べ、自律型への道は道具型の延長ではないと主張しています [ [ 368 ] ](https://businessnetwork.jp/article/36783) 。駒澤大学の井上智洋教授は、AGI が2030年頃に完成し、その前後から日本でも雇用の変化が顕在化すると予測しています [ [ 377 ] ](https://www.adeccogroup.jp/power-of-work/385) 。

シンクタンクでは日本総合研究所が、10年以内に汎用AI が実現する場合の段階を3つに整理しました。2024〜26年に必要な能力を徐々に獲得し、2027〜29年にデジタル空間で、2030年以降に実世界で自律性を獲得するという段階です [ [ 373 ] ](https://www.jri.co.jp/file/advanced/advanced-technology/pdf/15089.pdf) 。三菱総合研究所は、信頼性の確保を前提に5つの産業で約21兆円の付加価値が得られると試算しています [ [ 372 ] ](https://www.mri.co.jp/knowledge/insight/policy/20240828_2.html) 。大和総研は、将来の生成AI は平均的なビジネスパーソンの成果物を一定部分は代替できるが、本人の代替にはならないと展望しています [ [ 374 ] ](https://www.dir.co.jp/report/column/20241017_012167.html) 。

個人の発信では、方向が分かれます。Zenn では、AI 2027 を「SF ではなく現実の技術トレンドに基づく予測」として紹介する記事 [ [ 382 ] ](https://zenn.dev/taku_sid/articles/20250411_ai2027_forecast) と、Karpathy の「10年」説を解説する記事 [ [ 384 ] ](https://zenn.dev/m_nakano_teppei/articles/c8fdbb583948e8) が並びます。note では、2025年を「AIエージェント元年でした？」と問い、人の監督を前提にした運用の主流化を予想する投稿があります [ [ 386 ] ](https://note.com/aiessay/n/n22280c8a29b8) 。中小企業に「2026年は追いつける最後のチャンスかもしれない」と呼びかける投稿もあります [ [ 387 ] ](https://note.com/arukuwa/n/n9e9f61eeb3ae) 。30年の変化を3年に換算し、3年で大きな転換は起きないものの実用化と標準化は確実に進む、とみる投稿もあります [ [ 390 ] ](https://note.com/marupotech/n/nf61c8a858e7f) 。

AI 分野の実務者であるシバタアキラ氏は、2026年の予測を扱う22の情報源から267件の予測を集計し、悲観論は思いのほか少なく、バブルは落ち着いたか続くとする意見が多いと報告しています [ [ 370 ] ](https://ashibata.substack.com/p/2026ai) 。

### 🗺️ 図：言説は人物ではなく、主張と軸で読む

![4つの軸ごとに、加速・漸進・調整の3つの方向に言説が分かれる。同じ発言者が軸ごとに別の方向に立つ](/images/ai-transformation-blueprint/25-discourse-taxonomy.png)

#### 図の読み方

図は、4つの軸を上から下へ並べ、各軸の横棒を加速・漸進・調整の3つの区画に分けています。各区画には、その方向の代表的な主張を短く書いています。

上から順に、能力の進度、普及の速度、経済効果と投資、雇用です。同じ発言者が複数の区画に現れることが、この図の主張です。本文の第1節で挙げた Altman は、能力の軸では左(加速)、投資の軸では右(調整)に立ちます。LeCun は、能力の軸で現行手法については右、AI全体については中央に立ちます。

図の下の添え書きは、第7節の検証結果です。個別の能力の節目は予測より早く、包括的な到来と雇用の崩壊は予測より遅い、という非対称を1行で示しています。

### 本章の位置づけ

本章は、言説を分類しただけであり、どの方向が正しいかを述べていません。分類から読み取れることを、筆者の整理として3点記します。

第一に、発言者の利害関係は方向と強く対応しています。能力と普及の加速を述べるのは、AI企業の経営者、基盤の供給者、投資家、調査会社に集中しています。漸進を述べるのは、学術の調査、独立の研究者、日本のシンクタンクと実務者です。調整を述べるのは、金融機関と批判者です。この対応は、どの方向が正しいかを決めませんが、言説を読むときの基準率になります。

第二に、軸を分けると矛盾の多くが消えます。「効果は大きいのに投資は過剰」「能力は加速しても普及は遅い」「今は雇用に変化がなくても数年後に変わりうる」は、いずれも両立します。3つの道筋は、軸ごとの方向の組み合わせとして定義する必要があります。

第三に、短期予測の外れ方には方向があります。個別の能力は早く、包括的な変化は遅い。この非対称は、[道筋Aの章](26-path-a-acceleration)から[道筋Cの章](28-path-c-correction)で、各道筋が外れる条件を書くときの基準になります。

次の章から、3つの道筋を順に提示します。確度の階層と、外れる条件を各章に付します。
