### 序論：本章が扱う範囲

本章は、個人が生成AIをどれだけ使っているかを、日本、アメリカ、そして世界の調査から整理します。企業の導入を考える前に個人の利用を見る理由は、生成AIの普及が企業の意思決定より先に、個人の試用として始まったからです。

対象とする調査は、総務省の情報通信白書、アメリカの中央銀行と調査機関、研究者による全国調査、そしてAI事業者自身が公開する利用データです。調査ごとに母集団と設問が異なるため、本章では数値を並べるときに必ず定義と時点を添えます。

本文は、調査結果の記述に限定します。日本の利用率が低かったことの意味と、2025年度の急上昇をどう読むかは、章末で扱います。企業の利用は[企業の利用の章](12-enterprise-adoption)で、利用が生産性に与えた効果は[生産性の実証の章](13-productivity-evidence)で扱います。

### 1. 日本：2年で9.1%から58.8%へ

総務省の情報通信白書は、日本・アメリカ・ドイツ・中国の4か国で同じ設問の調査を毎年行っています。令和7年版(2024年度調査、2025年1〜2月実施)では、生成AIサービスを使ったことがある個人の割合は、日本26.7%、アメリカ68.8%、ドイツ59.2%、中国81.2%でした。前年の2023年度調査では、日本9.1%、アメリカ46.3%、ドイツ34.6%、中国56.3%です。日本の20代に限ると44.7%でした [ [ 106 ] ](https://www.soumu.go.jp/main_content/001019264.pdf) 。

令和8年版(2025年度調査、2026年1〜2月実施)では、日本の利用経験率は58.8%に上昇しました。ただし、この調査から15〜19歳が対象に加わっています。20歳以上に限ると52.2%です。概要の図表によれば、アメリカ75.6%、ドイツ75.6%、中国93.6%でした。「ほぼ毎日」使う人は約3割、「ほぼ毎日1時間以上」は1割超です [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。

同じ白書の本文によれば、「ほぼ毎日」利用する割合は日本で約3割であり、アメリカ、ドイツ、中国はいずれも4割を超えています。日本の利用理由は「無料又は安い」53.9%、「作業の効率が上がる」42.8%、「多様な発想や視点」34.1%の順でした [ [ 527 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1110000.pdf) 。

民間の調査も同じ方向を示しています。NTTドコモ モバイル社会研究所の全国15〜69歳の調査では、生成AIの利用率は2025年2月の27%から2026年2月の51%へほぼ倍増しました。プライベートでの利用が46%、仕事・学業での利用が38%です [ [ 535 ] ](https://www.moba-ken.jp/project/lifestyle/20260406.html) 。

利用の中身にも変化が見られます。電通が2025年11月に行ったAI利用経験者3,000人への調査では、AIで得た情報を事実確認している人は63.2%、AIに勧められて商品を購入した経験がある人は26.3%でした。一般企業の従事者の63.4%が仕事の効率の向上を実感しています [ [ 534 ] ](https://www.dentsu.co.jp/news/release/2025/1223-010990.html) 。

### 2. アメリカ：仕事での利用が4割に

アメリカでは、研究者による全国代表サンプルの調査が継続しています。ビック、ブランディン、デミングの調査では、2024年後半に18〜64歳の約40%が生成AIを使い、就業者の23%が過去1週間に仕事で使っていました。毎勤務日に使う人は9%です [ [ 108 ] ](https://www.nber.org/system/files/working_papers/w32966/w32966.pdf) 。

同じ調査の2025年11月時点では、仕事での生成AI利用は「何らかの利用」が40.7%、「先週毎日」が12%、「先週1回以上」が35.2%でした。前年比で9.7ポイントの増加です。仕事以外の利用は人口の約50%でした [ [ 109 ] ](https://www.federalreserve.gov/econres/notes/feds-notes/monitoring-ai-adoption-in-the-u-s-economy-20260403.html) 。

世論調査機関のPew Research Centerの2026年2月の調査では、ChatGPTを使ったことがある成人は44%でした。2023年18%、2024年23%、2025年34%と毎年増えています。何らかのAIチャットボットの利用は49%です。なお、2026年は設問の文言が変更されています [ [ 111 ] ](https://www.pewresearch.org/internet/2026/06/17/americans-and-ai-2026-chatbots-smart-devices-and-views-on-impact) 。

従業員調査では、Gallupが2026年5月時点で、15%が毎日、30%が週に数回以上、52%が年に数回以上、仕事でAIを使うと報告しています [ [ 112 ] ](https://www.gallup.com/699797/indicator-artificial-intelligence.aspx) 。同社の2025年6月の分析では、年に数回以上の利用は2023年の21%から2025年第2四半期の40%へ倍増しました。ホワイトカラーの頻繁な利用が27%であるのに対し、生産・現場職は11%から9%と横ばいです [ [ 113 ] ](https://www.gallup.com/workplace/691643/work-nearly-doubled-two-years.aspx) 。

### 3. アメリカとヨーロッパの差

同じ研究者らによる2026年1〜2月の7か国調査では、仕事で生成AIを使う労働者はアメリカ43%、ヨーロッパ平均32%でした。イギリス36%からイタリア26%の幅があります。この差の大部分は、企業がAIの利用を奨励しツールを提供しているかという人事管理の慣行で説明されると報告しています [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。

### 4. 世界：人口の1割から5割へ

OpenAIとデミングによる2025年9月の論文は、ChatGPTが2025年7月時点で世界の成人人口の約10%に採用され、週間アクティブユーザーが7億人に達したと報告しました。150万件の会話の分析では、2024年1月に女性名のユーザーは37%でしたが、2025年7月には52%になっています [ [ 114 ] ](https://www.nber.org/system/files/working_papers/w34255/w34255.pdf) 。

スタンフォード大学のAI Index 2026は、生成AIが公開から3年で世界人口の53%に普及したと報告しています。国別ではシンガポール61%、アラブ首長国連邦64%に対し、アメリカは28.3%で24位です。この数値は人口ベースの利用率推計であり、Pewの44%(成人・ChatGPT)や総務省の58.8%(15〜69歳・利用経験)とは母集団と定義が異なります [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

Anthropicが2025年9月に公表した国別の利用指数では、人口あたりの利用はイスラエル、シンガポール、オーストラリア、ニュージーランド、韓国が上位でした。アメリカは総利用の21.6%を占めます [ [ 116 ] ](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report) 。2026年3月の報告では、国の間では利用がむしろ集中しており、人口調整後の上位20か国のシェアが45%から48%に上昇しました [ [ 118 ] ](https://www.anthropic.com/research/economic-index-march-2026-report) 。

### 5. 何に使っているか：拡張と自動化

利用率だけでなく、使い方の構成も計測されています。Anthropicの2025年2月の初回報告では、Claude.aiの会話の57%が「拡張」(AIが人の作業を補助する)、43%が「自動化」(AIが作業を直接行う)でした。職業の約36%で関連タスクの4分の1以上にAI利用があり、4分の3以上にある職業は約4%です [ [ 115 ] ](https://www.anthropic.com/research/the-anthropic-economic-index) 。

同社の2025年9月の報告は、企業がAPIを通じて使う場合には77%が自動化の型であり、Claude.aiの利用者の約50%より高いと報告しています。個人の対話と企業のシステム組み込みでは、使い方の構成が異なるということです [ [ 116 ] ](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report) 。

利用者の自己評価も公表されています。2026年6月の報告では、回答者の86%が速度、82%が範囲、69%が品質の向上を報告しました。68%が「AIで学びが増えた」、57%が「スキルの市場価値が上がった」と答えています [ [ 119 ] ](https://www.anthropic.com/research/economic-index-june-2026-report) 。

一方、期待の差も計測されています。2026年9月のアメリカ成人10,980人への調査では、労働者は平均して「2030年までにAIが自分の仕事の28%をこなせる」と予想しました。同じ問いに、Anthropicの社員は75%と答えています [ [ 120 ] ](https://www.anthropic.com/research/ai-expectations-gap) 。

### 🗺️ 図：日本の個人利用は2年で6倍、ただし「毎日」は3割

#### 図の読み方

この図は、左右2つの部分で構成されています。左側は日本の個人の利用経験率の推移で、2023年度9.1%、2024年度26.7%、2025年度58.8%の3本の棒を縦に並べています。右側は、2025年度調査の4か国の「ほぼ毎日」利用の割合で、日本の約3割と、他の3か国の4割超を対比しています。

左側の棒は、利用経験という最も緩い定義の数値です。2025年度の棒には、調査対象に15〜19歳を加えた影響が含まれており、20歳以上に限ると52.2%です。この注記は本文の第1節にあります。

右側は、利用の深さを示します。使ったことがあるかどうかでは差が縮まりましたが、日常的に使うかどうかでは差が残っています。この構造が、[企業の利用の章](12-enterprise-adoption)で見る「利用はしているが効果が出ない」という日本の企業調査の結果と対応しています。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

本章の要点は3つです。

第一に、日本の個人利用は、2023年度から2025年度の2年間で、主要国との差を大きく縮めました。利用経験率では、アメリカやドイツとの差が40ポイント以上から20ポイント弱まで縮まっています。

第二に、縮まったのは「使ったことがある」という浅い指標であり、「毎日使う」という深い指標では差が残っています。日本の利用理由の1位が「無料又は安い」であることも、利用の動機がまだ試用の段階にあることを示唆しています。

第三に、個人の対話と企業のシステム組み込みでは、使い方の構成が異なります。対話は拡張が半分以上であり、APIは自動化が8割近くです。個人の利用率の上昇が、そのまま企業の自動化の進展を意味するわけではありません。

著者は、2025年度の急上昇を、日本が普及の遅れを取り戻した証拠と読むことには慎重です。[先例の章](10-precedents-electricity-pc-cloud)で示したとおり、使われる速さと効くまでの時間は別の曲線です。アメリカとヨーロッパの差が企業の人事慣行で説明されるという研究は、個人の利用の次の段階が、企業がどれだけ利用を奨励し、仕事の手順に組み込むかで決まることを示しています。

### 経営層への含意

自社の従業員の過半数は、すでに生成AIを使ったことがあります。これは2026年の日本の全国調査が示す事実です。したがって、経営の問いは「使わせるか」ではなく「会社として奨励し、道具を提供し、手順に組み込むか」に移っています。アメリカとヨーロッパの利用率の差を生んでいるのは、この一点でした。個人の試用から組織的な利用へ移る段階は、[生成AIの導入段階の章](30-genai-adoption-stages)のS1からS3に相当し、文化の面では[文化の形成の章](36-culture-formation)のC2からC3への移行に相当します。
