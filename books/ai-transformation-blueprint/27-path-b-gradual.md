### 序論：本章が扱う範囲

本章は、3つの道筋のうち2番目のものを提示します。道筋Bは、AI の能力が向上し続けながらも、企業と社会への浸透が10年単位で進み、生産性の統計への反映が2030年代にずれ込む経過です。[言説の分類の章](25-discourse-taxonomy)で「漸進」に分類した言説が描く未来であり、学術の調査、独立の研究者、日本のシンクタンクと実務者の多くがこの方向にいます。

道筋Bの骨格は、[汎用技術と生産性 J カーブの章](21-gpt-and-j-curve)で整理した理論です。Brynjolfsson らは、汎用技術の価値を引き出すには業務手順や訓練などの無形資本への補完投資が要り、その投資は統計上の産出に計上されないため、普及の初期には生産性が実力より低く測られると論じました [ [ 259 ] ](https://doi.org/10.1257/mac.20180386) 。David は、発電機の商用化から米国製造業の生産性の加速まで約40年を要したと記述しています [ [ 255 ] ](https://ideas.repec.org/p/cla/levarc/115.html) 。道筋Bは、生成AI がこの先例に従う経過です。

構成は[道筋Aの章](26-path-a-acceleration)と同じです。前提、2027年前後、2029年前後、2031年前後、企業・労働・市場への帰結、外れる条件、経営層への含意の順に、確度の階層を【階層n】で付します。本章も確率を割り当てません。

### 1. 前提

【階層2】 **能力は向上するが、節目は測定の外へ出る**。道筋Bも能力の向上を否定しません。ただし、時間地平の倍増が続くという仮定は置かず、METR が2026年9月に時間地平のページの更新を止めた事実を [ [ 63 ] ](https://metr.org/time-horizons) 、測定が追いつかない段階に入った印として扱います。Karpathy は、エージェントの年ではなく「エージェントの10年」であり、継続学習などの認知的な欠陥の解決は可能だが難しいと述べました [ [ 384 ] ](https://zenn.dev/m_nakano_teppei/articles/c8fdbb583948e8) 。

【階層2】 **普及は組織の側の制約で決まる**。McKinsey の2026年の調査で、9割近くの組織が少なくとも1つの業務機能で AI を常用し、44%が全社でスケール中と答える一方 [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 、Gartner の2026年の調査では複数の事業部門で AI をスケールした組織は22%でした [ [ 141 ] ](https://www.gartner.com/en/newsroom/press-releases/gartner-survey-finds-only-22-percent-of-organizations-have-successfully-scaled-ai-across-multiple-business-units) 。IPA の2026年の調査では、AI導入の効果として「業務が効率化・迅速化した」が91.6%なのに対し、「売上や利益が向上した」は3.9%です [ [ 123 ] ](https://www.ipa.go.jp/pressrelease/2026/rcu1hd0000016yh4-att/press20260716.pdf) 。道筋Bは、この差が補完投資の不足によるものであり、埋まるのに年単位の時間がかかると仮定します。

【階層2】 **労働市場への影響は緩やか**。デンマークの25,000人の労働者を追った研究では、AIチャットボットは広く普及したものの、利用者の時間の節約は平均2.8%でした。収入、労働時間、賃金のいずれにも有意な影響はありませんでした [ [ 150 ] ](https://www.nber.org/system/files/working_papers/w33777/revisions/w33777.rev0.pdf) 。Yale Budget Lab の2026年5月の続報でも、AI曝露職と非曝露職の比較で、雇用や時給への影響はゼロから区別できない水準でした [ [ 162 ] ](https://budgetlab.yale.edu/research/ai-probably-not-yet-reason-labor-market-weakening) 。道筋Bは、この状態が続きつつ、職種の内側で仕事の中身が入れ替わると仮定します。

【階層3】 **投資は減速するが途切れない**。Forrester は、2026年に企業が計画した AI支出の25%を2027年へ繰り延べると予測しました [ [ 351 ] ](https://www.forrester.com/blogs/predictions-2026-ai-moves-from-hype-to-hard-hat-work) 。道筋Bは、設備投資の伸びが鈍化しても、前年比で減少には転じないと仮定します。この前提は[道筋Cの章](28-path-c-correction)との分岐点です。

### 2. 2027年前後

【階層2】 **能力**：主要な供給者が年に複数回モデルを更新する状況は続きます。ただし、企業の業務で使える範囲を決めるのは、最上位モデルの能力ではなく、信頼性と費用です。Forecasting Research Institute の記録では、2026年5月時点で最上位モデルの80%基準の時間地平は3時間6分でした [ [ 338 ] ](https://forecastingresearch.substack.com/p/leap-wave-8-ai-timelines) 。道筋Bでは、2027年の企業での利用は、80%の信頼性で半日以内の作業に限られます。

【階層2】 **普及**：Gartner は2025年のハイプ・サイクルで、生成AI を幻滅期に、AIエージェントを過度な期待のピークに置きました [ [ 350 ] ](https://finance.yahoo.com/news/gartner-hype-cycle-identifies-top-120000473.html) 。2026年版のエージェント型AI のハイプ・サイクルでは、AIエージェントを導入済みの組織は17%で、60%超が2年以内の導入を見込むと記されています [ [ 624 ] ](https://www.gartner.co.jp/ja/articles/hype-cycle-for-agentic-ai) 。道筋Bでは、2027年にエージェントが幻滅期に入ります。試行の多くが止まり、[投資対効果と失敗率の章](15-roi-and-failure)で述べた「購入は内製より成功率が高い」という観測が、供給者の製品に組み込まれた形での普及を後押しします。

【階層2】 **日本**：総務省の2025年度の調査で、日本の個人の生成AI利用経験率は58.8%(20歳以上では52.2%)へ上昇しましたが、米国とドイツの75.6%、中国の93.6%には届きません [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。企業では、帝国データバンクの2026年3月の調査で、生成AI を業務で活用している企業は34.5%、小規模企業では28.0%です [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。道筋Bでは、2027年にこの比率が大企業と中小企業の間で開いたまま、全体として緩やかに上がります。

**この時点で観測されること**：知識労働者の多くが日常的に生成AI を使い、1人あたりの作業時間は短くなります。しかし、組織の産出と利益への反映は、業務の手順と評価が変わっていないために限られます。

### 3. 2029年前後

【階層2】 **能力と普及**：日本総合研究所は、2027〜29年にデジタル空間で自律性を獲得した汎用AI、2030年以降に実世界で自律性を獲得した汎用AI、という段階を置いています [ [ 373 ] ](https://www.jri.co.jp/file/advanced/advanced-technology/pdf/15089.pdf) 。道筋Bでは、2029年にデジタル空間での自律的な作業が、一部の業種と業務で標準になります。範囲は、入出力がデジタルで完結し、結果の検証が機械で可能な業務に限られます。

【階層3】 **組織**：Agrawal らは、AI の普及が遅いのは、導入が既存の意思決定を置き換える「点の解決策」に留まり、意思決定の相互依存を組み直す「システムの解決策」に至っていないからだと論じました [ [ 281 ] ](https://openlibrary.org/works/OL27412019W) 。道筋Bでは、2029年にシステムの解決策へ進む企業が、各業界で少数現れます。McKinsey の調査で「high performers」と呼ばれる上位6%前後の企業が [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 、この少数に相当します。

【階層2】 **労働**：世界経済フォーラムの雇用主調査は、2030年までの純増を7,800万と見込み、既存の技能の39%が変化または陳腐化するとしています [ [ 166 ] ](https://www.weforum.org/publications/the-future-of-jobs-report-2025) 。道筋Bでは、雇用の総量は大きく変わらず、技能の入れ替えが主な変化です。厚生労働省の令和8年版の労働経済白書は、AI導入期の日本で労働時間が減る一方で就業者数と労働投入量は増えたと記述しています [ [ 511 ] ](https://www.mhlw.go.jp/wp/hakusyo/roudou/26/dl/26-1-2.pdf) 。道筋Bでは、この型が2029年まで続きます。

【階層3】 **市場**：基盤モデルの価格は下がり続け、Menlo Ventures の調査では企業の API支出の供給者のシェアが2年で入れ替わりました [ [ 417 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise) 。道筋Bでは、基盤モデルは商品化(コモディティ化)へ向かい、価値は業務に組み込む層と、業界の知識を持つ層へ移ります。[市場の地図の章](18-market-map)の L4(業務アプリ内蔵)と L9(業界特化)が伸び、L3(基盤モデル)の利益率は下がります。

**この時点で観測されること**：企業の間で、同じ道具を使いながら成果が分かれます。差を生むのは、業務の手順と評価と人の役割を組み直したかどうかです。これは、[組織の内部化の章](22-organizational-internalization)で整理した Orlikowski の「技術は結果を決めず、使い方が決める」という知見のとおりです。

### 4. 2031年前後

【階層3】 **能力**：Hassabis が2025年3月に述べた「5〜10年」の範囲の前半に入ります [ [ 317 ] ](https://www.cnbc.com/2025/03/17/human-level-ai-will-be-here-in-5-to-10-years-deepmind-ceo-says.html) 。道筋Bでは、2031年に「広い範囲の知的作業を人と同等以上にこなす」と多くの専門家が認める水準には達します。ただし、Grace らの調査の中央値である2047年 [ [ 335 ] ](https://arxiv.org/html/2401.02843v1) やForecasting Research Institute の2050年 [ [ 338 ] ](https://forecastingresearch.substack.com/p/leap-wave-8-ai-timelines) が示す「あらゆる課題」の水準には達しません。

【階層3】 **経済**：IMF は、AI が2025〜30年の世界成長を年0.1〜0.8ポイント押し上げると見込んでいます [ [ 357 ] ](https://www.imf.org/-/media/files/publications/weo/2025/april/english/ch1.pdf) 。Acemoglu は10年の全要素生産性の上昇を0.66%と推計しました [ [ 151 ] ](https://www.nber.org/papers/w32487) 。道筋Bの2031年は、この範囲の上側です。J カーブの底を過ぎ、補完投資が産出として現れ始める時期ですが、Goldman Sachs の7%には遠い水準です。

【階層4】 **制度**：雇用の総量が大きく変わらないため、所得再分配の立法は本格化しません。代わりに、AI の出力の責任、エージェントの権限、データの利用に関する規則が、業種ごとの指針として積み上がります。日本の AI推進法と指針の体系は、この経過と整合的です。

### 5. 企業・労働・市場への帰結

道筋Bが実現した場合、企業には次の帰結が生じます。

第一に、競争の差は道具ではなく組織に現れます。同じ基盤モデル、同じ SaaS を使う企業の間で、業務の手順と評価を組み直した企業だけが利益に結びつけます。MIT NANDA が報告した「95%がゼロリターン」という状態は [ [ 177 ] ](https://mlq.ai/media/quarterly_decks/v0.1_State_of_AI_in_Business_2025_Report.pdf) 、道筋Bでは2029年まで緩やかにしか改善しません。

第二に、[3つの現在地の章](32-three-positions)で定義する文化フェーズが、導入フェーズより重要になります。C4(測って運用する)に達した企業は、効果の小さい用途を止め、効く用途に集中できます。C2(個人の試行)に留まる企業は、利用率は高くても成果が出ません。

第三に、供給者の選択の重要性は相対的に下がります。基盤モデルは商品化し、乗り換えの費用は下がります。重要なのは、特定の供給者に依存しない形で業務に組み込む設計です。

第四に、労働では技能の入れ替えが続きます。新卒の採用は減らず、仕事の中身が変わります。日本では、労働供給の不足を補う目的での導入が主流であり続けます。[日本の条件の章](19-japan-conditions)で整理したとおり、中小企業の AI活用の目的は「業務時間の節減」が8割超です。

### 🗺️ 図：道筋B ―― 能力は上がり、成果は補完投資の後に来る

![生産性 J カーブ。普及の初期は補完投資が産出に計上されず測定生産性が下がり、2030年代に上向く。曲線の底に2027〜29年を置く](/images/ai-transformation-blueprint/27-path-b-gradual.png)

#### 図の読み方

図は、横軸に年、縦軸に測定される生産性を取った1本の曲線です。曲線は2027年前後で最も低くなり、2029年から上向き、2031年以降に上昇が続きます。J の字の形です。

曲線の下の区間には「補完投資」と書いています。業務手順の組み直し、訓練、評価の仕組みへの投資であり、統計には産出として現れません。この区間に企業がいる間は、利用率が高くても利益に結びつかないように見えます。

曲線の上の点線は、能力の向上を表しています。能力は図の全期間で上がり続けます。この図の主張は、能力と成果の間に時間差があることです。

図の右端の添え書きは、上昇の到達点が[道筋Aの章](26-path-a-acceleration)より低く、次の節の「外れる条件」が上下どちらにも開いていることを示しています。

### 本シナリオが外れる条件

道筋Bは、上下どちらの方向にも外れます。

上方向、すなわち道筋Aへ移る条件は、第一に時間地平の倍増が新しい課題群でも確認され、80%基準で1日分の作業を任せられる時期が2028年より前に来ることです。第二に、Gartner の調査で AI から大きな価値を実現したと答える CIO の比率が、2026年の13% [ [ 183 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-10-19-gartner-survey-finds-only-13-percent-of-cios-say-their-enterprise-has-realized-significant-or-transformational-value-from-ai) から2年以内に3割を超えることです。第三に、22〜25歳の AI曝露職の雇用の低下 [ [ 157 ] ](https://digitaleconomy.stanford.edu/news/canariesaug26) が、26歳以上の層と非曝露職へ広がることです。

下方向、すなわち道筋Cへ移る条件は、第一に、大手クラウド事業者の設備投資の計画が前年比で減少に転じることです。第二に、基盤モデルの主要な供給者の資金調達が滞り、価格の引き上げや提供の縮小が起きることです。第三に、能力の主要な指標が2年以上停滞することです。

道筋Bに固有の外れ方もあります。補完投資が進んでも生産性が上向かない場合です。Solow は1987年、「コンピュータの時代は生産性の統計以外のあらゆる場所に見える」と書きました [ [ 260 ] ](https://gwern.net/doc/economics/automation/1987-solow.pdf) 。この状態が2031年を過ぎても続くなら、道筋Bの J カーブの仮定そのものが疑われます。その場合、生成AI は汎用技術ではなく、特定の業務向けの道具だったことになります。

### 経営層への含意

道筋Bに備える企業は、次の3点を検討することになります。筆者の整理であり、[道筋別の戦略の章](35-strategy-by-path)で他の道筋と合わせて扱います。

第一に、補完投資を先に計画することです。道筋Bでは、道具の導入より、業務の手順と評価と役割の組み直しが成果を決めます。道具の費用は下がり続けるため、急いで買う理由は薄く、組み直す力を社内に作る理由は濃くなります。

第二に、効果を測る仕組みを作ることです。IPA の調査で「効率化した」が9割、「売上や利益が向上した」が4%という差は、測っていないことの表れでもあります。文化フェーズを C4 へ上げることが、道筋Bでの最も確実な投資です。

第三に、供給者に依存しない設計を選ぶことです。基盤モデルは商品化へ向かいます。特定の供給者の製品に業務を深く結びつけるより、乗り換えられる形で組み込むほうが、道筋Bでは有利です。

筆者は、2026年10月時点の観測に最も近いのは道筋Bだと考えます。ただし、[言説の分類の章](25-discourse-taxonomy)で述べたとおり、個別の能力の節目は予測より早く来ています。道筋Bを前提にしながら、道筋Aへの移行を知らせる指標を追うことが、[3つの道筋の比較の章](29-paths-comparison-indicators)の主題です。
