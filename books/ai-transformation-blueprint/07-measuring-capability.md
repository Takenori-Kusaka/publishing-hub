### 序論：本章が扱う範囲

本章は、生成AIの能力がどのように測られ、計測の結果が2023年から2026年にかけてどう動いたかを整理します。前章までの技術史は「何が発表されたか」を扱いました。本章は「それがどれだけできるか」を、第三者の計測を中心に扱います。

計測には3つの種類があります。第一に、決まった問題集に対する正答率(ベンチマーク)です。第二に、どれだけ長い作業を任せられるかという時間の尺度(時間地平)です。第三に、誤りや不正直さといった限界の計測です。本章はこの順に記述し、最後に計測そのものの限界を記します。

本章の本文は、計測の方法と数値に限ります。数値が示す到達点をどう受け止めるかは章末で解釈し、未来の推論は[道筋Aの章](26-path-a-acceleration)以降に委ねます。

### 1. ベンチマーク：尺度の飽和と更新

ソフトウェアの修正能力を測るSWE-benchは、2023年10月の公開時点で最良のモデルが1.96%しか解けませんでした [ [ 58 ] ](https://arxiv.org/abs/2310.06770) 。StanfordのAI Index 2025によれば、SWE-benchの解決率は2023年の4.4%から2024年の71.7%へ上がりました。同じ報告は、大学院水準の科学の問題集GPQAで48.9ポイントの上昇を記録し、2025年初めに公開された難問集Humanity's Last Exam(HLE)の最高スコアは8.80%、数学の難問集FrontierMathは2%だったと記しています [ [ 59 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/technical-performance) 。

HLEは、Center for AI SafetyとScale AIが2025年1月24日に公開した2,500問の問題集で、数学、人文科学、自然科学など数十の分野を含みます。2026年1月には学術誌Natureに掲載されました [ [ 66 ] ](https://arxiv.org/abs/2501.14249) 。AI Index 2026によれば、最上位のモデルのHLEの成績は1年で30ポイント上がりました [ [ 67 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance) 。

2026年の各社の発表は、これらの尺度の上限に近づいた数値を示しています。Anthropicは2026年4月7日、未公開モデルClaude Mythos PreviewがSWE-bench Verifiedで93.9%、Terminal-Bench 2.0で82.0%に達したと公表しました [ [ 44 ] ](https://www.anthropic.com/glasswing) 。OpenAIは2026年9月3日、GPT-6 AstraがGPQA Diamondで96.0%、ツールを使ったHLEで57.2%、FrontierMathの最難関層で97.6%に達したと公表しました [ [ 51 ] ](https://openai.com/index/gpt-6-astra) 。

尺度が上限に近づくと、新しい尺度が作られます。抽象的な推論を測るARC-AGIは、2024年12月にOpenAIのo3が初版で75.7%から87.5%を記録しました [ [ 23 ] ](https://arcprize.org/blog/oai-o3-pub-breakthrough) 。第2版では、OpenAIが2026年3月にGPT-5.4の73.3%を公表しています [ [ 42 ] ](https://openai.com/index/introducing-gpt-5-4/) 。運営団体は2026年3月25日に第3版を公開しました。第3版は、エージェントが未知の環境を探索し、経験から学ぶ能力を測る対話型の尺度です [ [ 43 ] ](https://arcprize.org/arc-agi/3) 。

### 2. 時間地平：どれだけ長い作業を任せられるか

ベンチマークの正答率は、問題集が変わると比較できなくなります。非営利の評価団体METRは、これとは別の尺度を提案しました。人が行えば一定の時間を要する作業を集め、AIが50%の確率で完了できる作業の長さを「時間地平」と定義する方法です。

METRの2025年3月の論文によれば、最上位のモデルの時間地平は2019年以降、およそ7か月ごとに倍増してきました [ [ 60 ] ](https://arxiv.org/abs/2503.14499) 。2025年7月の分析では、科学の問答、数学、ソフトウェアといった知的な領域の時間地平は50分から200分で、2か月から6か月ごとに倍増しているとされています。一方、画面を見て計算機を操作する作業の時間地平は、それより40倍から100倍短いものでした [ [ 61 ] ](https://metr.org/blog/2025-07-14-how-does-time-horizon-vary-across-domains) 。

2026年1月29日の改訂版では、作業の数を170から228に増やしたうえで、全期間の倍増時間を196.5日、2023年以降を131日、2024年以降を89日と推定しました。2025年11月のClaude Opus 4.5の時間地平は320分、2025年8月のGPT-5は214分でした [ [ 62 ] ](https://metr.org/blog/2026-01-29-time-horizon-1-1) 。2026年3月のMETRの記録は、2026年2月時点の公開モデルの時間地平を約12時間と記しています [ [ 64 ] ](https://metr.org/notes/2026-03-19-org-uplift-game) 。

この尺度には、計測側の明示した限界があります。METRの時間地平のページは、2026年5月に「16時間を超える計測は、現在の作業群では信頼できない」と注記し、2026年9月8日に更新の停止を明記しました [ [ 63 ] ](https://metr.org/time-horizons) 。倍増の傾向は2026年前半まで続いたものの、それより先は同じ方法では測れなくなっています。

### 3. 計算機の操作と実世界

言語の問題集と、画面を見て計算機を操作する作業とでは、到達点が異なります。

AI Index 2026によれば、計算機の画面操作を測るOSWorldの精度は、約12%から66.3%へ上がりました。同じ尺度での人の基準は72.35%です [ [ 67 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance) 。同報告の要約は、端末での作業を測るTerminal-Benchでのエージェントの成功率が2025年の20%から77.3%へ上がり、サイバーセキュリティの課題の解決率が2024年の15%から93%へ上がった一方で、家庭内の実作業でのロボットの成功率は12%だったと記しています [ [ 68 ] ](https://hai.stanford.edu/news/inside-the-ai-index-12-takeaways-from-the-2026-report) 。

Anthropicは2026年2月のSonnet 4.6の発表で、2024年10月の計算機操作の公開から16か月でOSWorldの成績が着実に上がったとしつつ、「最も熟練した人間にはまだ及ばない」と述べています [ [ 70 ] ](https://www.anthropic.com/news/claude-sonnet-4-6) 。各社の自己申告の表も、同じ尺度で並べると差が見えます。Anthropicの2026年9月22日の表では、Terminal-Bench 4.0の成績はClaude Opus 5.5が66.4%、Claude Fable 5.1が55.8%、GPT-6 Astraが57.9%でした [ [ 54 ] ](https://www.anthropic.com/claude-opus-5-5) 。

### 4. 限界の計測：誤り、崩壊、不正直

能力の上昇と並行して、限界も計測されています。

Appleの研究者は2025年6月7日に「The Illusion of Thinking」を公開しました。推論モデルは、問題の複雑さが一定の水準を超えると精度が完全に崩壊し、しかも使う推論の量まで減ると報告しています [ [ 65 ] ](https://machinelearning.apple.com/research/illusion-of-thinking) 。

AI Index 2026の責任あるAIの章によれば、新しい正確性の尺度において、上位26のモデルの幻覚(事実と異なる出力)の率は22%から94%の幅にありました。また、基盤モデルの透明性を採点する指標の平均は、2024年の58から2025年の40へ下がりました [ [ 69 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/responsible-ai) 。

Apollo Researchは2024年12月6日、最上位のモデルが文脈のなかで「策略(scheming)」と呼ばれる振る舞いを示し、追及の質問の85%超で欺きを維持し得ると報告しました [ [ 71 ] ](https://arxiv.org/abs/2412.04984) 。能力が上がるほど、出力の検証が難しくなることを示す計測です。

### 5. 計測そのものの限界

ここまでの計測には、4つの構造的な限界があります。

第一に、尺度は1年から2年で飽和します。SWE-benchは3年で1.96%から93.9%へ達し、HLEは1年で30ポイント上がりました。飽和した尺度は、モデル間の差を示せなくなります。

第二に、時間地平は16時間を超えると測れなくなりました。計測団体自身が、2026年9月に更新を止めています。

第三に、最上位の数値の多くは、提供事業者の自己申告です。Mythos Previewの93.9%、GPT-6 Astraの96.0%はいずれも開発元の公表値であり、第三者が同じ条件で再現した値ではありません。

第四に、問題集の成績と、実際の業務での成果は別のものです。計算機操作の精度が66.3%であることは、業務の3分の2を任せられることを意味しません。業務での効果の実証は[生産性の実証の章](13-productivity-evidence)で扱います。

### 6. 計測の整理

| 計測の種類 | 代表的な尺度 | 2023年 | 2026年 | 限界 |
| --- | --- | --- | --- | --- |
| 問題集の正答率 | SWE-bench、GPQA、HLE | SWE-bench 1.96% | SWE-bench Verified 93.9%(自己申告) | 飽和、自己申告 |
| 時間地平 | METRの作業群 | 数十分 | 約12時間(2026年2月) | 16時間超は測れない |
| 計算機の操作 | OSWorld、Terminal-Bench | 約12% | 66.3%(人は72.35%) | 業務の成果とは別 |
| 限界 | 幻覚率、崩壊、策略 | ― | 幻覚率22〜94% | 検証の難しさが増す |

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、問題集の正答率は3年でほぼ上限に達し、尺度の更新が繰り返されています。第二に、任せられる作業の長さは2026年前半まで数か月ごとの倍増を続け、約12時間に達したところで計測の方法が限界を迎えました。第三に、幻覚、複雑さによる崩壊、策略といった限界も同時に計測されており、能力が上がるほど検証は難しくなっています。

著者は、計測の結果を経営判断に使うときの要点を「どの尺度が自社の業務に対応するか」を先に決めることだと考えます。GPQAの96.0%は、博士課程の科学の問題に答える能力です。OSWorldの66.3%は、画面を見て操作する能力です。自社の業務がどちらに近いかで、参照すべき数値は変わります。尺度を決めずに「AIは人間を超えた」「まだ使えない」と判断することは、どちらも計測の誤用だと著者は考えます。

### 経営層への含意

導入の判断に使う能力の数値は、提供事業者の発表ではなく、自社の業務に近い作業で自ら測ったものを基準にすべきです。幻覚率が22%から94%まで幅を持つ事実は、同じモデルでも用途によって信頼性が大きく異なることを意味します。[各段階で必要なものの章](34-requirements-and-providers)で述べる評価の仕組みは、この自前の計測を導入フェーズごとに組み込むためのものです。
