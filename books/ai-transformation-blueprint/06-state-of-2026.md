### 序論：本章が扱う範囲

本章は、2026年1月から2026年10月27日までの出来事を整理します。本書の執筆時点は2026年10月27日です。この分野では1週間で前提が変わることもあるため、本章の記述は執筆時点の切り取りであることを、最初に明記します。

扱うのは4つです。第一に、主要なモデルと製品の公開。第二に、利用者数と売上の規模。第三に、設備投資と資金調達。第四に、2026年7月以降に起きた、エージェントの事故と市場の調整です。

売上や評価額の数値には、報道にしか存在しないものが含まれます。本章は一次発表を優先し、報道にしかない数値は報道であることを明記し、食い違う報道は両方を記します。本文は事実の記述に限り、評価は章末に分離します。

### 1. モデルの公開は月単位で続いた

2026年の主要なモデルの公開を、時系列で記します。

2026年2月、AnthropicはClaude Opus 4.6とClaude Sonnet 4.6を公開しました。Opus級では初めて100万トークンの文脈をベータで扱えるようになり、Sonnet 4.6の価格は100万トークンあたり入力3ドル、出力15ドルでした [ [ 40 ] ](https://www.anthropic.com/news/claude-opus-4-6) 。同年2月19日にはGoogleがGemini 3.1 Proを公開したと報じられています [ [ 41 ] ](https://www.constellationr.com/insights/news/google-launches-gemini-31-pro) 。

2026年3月、OpenAIはGPT-5.4を公開しました。公式ページでは、計算機操作のベンチマークOSWorld-Verifiedで75.0%を記録し、人間の72.4%を上回ったと報告しています [ [ 42 ] ](https://openai.com/index/introducing-gpt-5-4/) 。同年4月23日にはGPT-5.5が公開され、同じベンチマークで78.7%、通信業務の対話ベンチマークで98.0%が報告されました [ [ 45 ] ](https://openai.com/index/introducing-gpt-5-5) 。

2026年4月7日、Anthropicは未公開モデルClaude Mythos Previewを、サイバー防御のための限定提供として発表しました。参加企業はAWS、Apple、Google、Microsoft、NVIDIAなど11社です。同社は、AIモデルがソフトウェアの脆弱性の発見と悪用において「最も熟練した人間を除くすべてを上回る」水準に達したと記しています [ [ 44 ] ](https://www.anthropic.com/glasswing) 。同年4月24日、DeepSeekはV4を公開しました [ [ 38 ] ](https://www.deepseek.com/en/transparency/) 。

2026年5月19日、GoogleはI/OでGemini 3.5 Flashを発表し、社内で1日3兆トークン超を処理していると述べました [ [ 46 ] ](https://blog.google/innovation-and-ai/sundar-pichai-io-2026) 。同社が5月20日に公開したI/Oの発表の一覧には、常時稼働の個人向けエージェントGemini Sparkも含まれています。同年6月2日、Microsoftは開発者会議Buildで、Windowsを「エージェントのための信頼できるOS」にするとして、エージェントの実行をポリシーで封じ込める仕組みMicrosoft Execution Containersなどを発表しています [ [ 1710 ] ](https://blogs.windows.com/windowsdeveloper/2026/06/02/windows-platform-security-for-ai-agents/) 。

2026年6月9日、AnthropicはClaude Fable 5とClaude Mythos 5を発表しました。3日後の6月12日にアクセスを停止し、7月1日に再提供しています。Anthropicの告知は、停止の理由を記していません [ [ 47 ] ](https://www.anthropic.com/news/claude-fable-5-mythos-5) 。アメリカ政府の輸出管理の指令に従った措置だったと報じられています [ [ 1707 ] ](https://9to5mac.com/2026/06/12/anthropic-pulls-claude-mythos-5-and-claude-fable-5-following-us-government-directive/) 。

2026年7月9日、OpenAIはGPT-5.6ファミリーを一般提供しました [ [ 48 ] ](https://openai.com/index/gpt-5-6) 。同年7月24日付のシステムカードとともに、AnthropicはClaude Opus 5を公開しています [ [ 49 ] ](https://www-cdn.anthropic.com/c5fbac3f0b1280a933ebd26d3cb8bb9f5bdeaf48/Claude%20Opus%205%20System%20Card.pdf) 。

2026年9月は、公開が集中した月でした。9月2日にGoogleがGemini 3.8 Flashを [ [ 50 ] ](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber) 、9月3日にOpenAIがGPT-6 Astraを公開しました。公式の比較表では、博士課程水準の科学問題GPQA Diamondで96.0%を報告しています [ [ 51 ] ](https://openai.com/index/gpt-6-astra) 。9月15日、AnthropicはClaude Fable 5.1とClaude Mythos 5.1を発表しました。Mythos 5.1はアメリカの一部の組織に限って提供され、Fable 5.1の価格は100万トークンあたり入力10ドル、出力50ドルです [ [ 53 ] ](https://www.anthropic.com/claude-fable-and-mythos-5-1) 。

10月7日、AnthropicはClaude Haiku 5.5を公開しました [ [ 57 ] ](https://www.anthropic.com/news/announcements) 。

### 2. 価格は下がり続けた

モデルの価格は、性能の上昇と並行して下がりました。

Anthropicの価格表では、2025年のOpus 4.1が100万トークンあたり入力15ドル、出力75ドルであったのに対し、2026年10月時点のOpus 5.5は入力4ドル、出力20ドルです。入力・出力ともに73%の低下にあたります。最も安価なHaiku 5.5は、プロンプトが10万トークン以下の場合で入力0.10ドル、出力0.50ドルです [ [ 423 ] ](https://platform.claude.com/docs/en/about-claude/pricing) 。OpenAIのGPT-5.5は入力5ドル、出力30ドルで、文脈長は105万トークンです [ [ 424 ] ](https://developers.openai.com/api/docs/models/gpt-5.5) 。

Epoch AIの分析によれば、同じ性能水準に到達するための推論価格は、課題の種類によって年9倍から900倍のペースで低下しています [ [ 425 ] ](https://epoch.ai/data-insights/llm-inference-price-trends) 。[推論モデルと価格の章](04-reasoning-and-cost-2024)で記述した傾向は、2026年も続いています。

### 3. 利用者と売上の規模

利用の規模は、各社の発表で次のように推移しました。

OpenAIは2026年2月27日に、ChatGPTの週間アクティブユーザーが9億人、有料会員が5,000万人に達したと発表しました。同時に、Amazon、NVIDIA、SoftBankなどから1,100億ドルの資金調達を公表しています [ [ 85 ] ](https://techcrunch.com/2026/02/27/chatgpt-reaches-900m-weekly-active-users) 。同年3月31日には1,220億ドルの調達を完了し、評価額は8,520億ドルになったと報じられました [ [ 88 ] ](https://www.businesstoday.in/technology/story/openai-raises-122-billion-funding-ahead-of-ipo-buzz-523445-2026-04-01) 。OpenAIの公式ページは、月間売上20億ドル、APIで毎分150億トークン超、Codexの週間ユーザー200万人超、企業向けが売上の40%超と記しています [ [ 86 ] ](https://openai.com/index/accelerating-the-next-phase-ai) 。

Googleは、Geminiアプリの月間利用者が2026年2月の決算で7億5,000万人超 [ [ 90 ] ](https://abc.xyz/investor/events/event-details/2026/2025-Q4-Earnings-Call-2026-Dr_C033hS6/default.aspx) 、5月のI/Oで9億人超 [ [ 46 ] ](https://blog.google/innovation-and-ai/sundar-pichai-io-2026) 、8月11日に10億人を超えたと発表しました [ [ 1601 ] ](https://blog.google/innovation-and-ai/products/gemini-app/one-billion-monthly-users) 。2026年第2四半期の決算では、モデルAPIの処理量が毎分約220億トークンで、前四半期の160億から増えています [ [ 91 ] ](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026) 。

Anthropicは2026年2月に300億ドルを調達し、評価額3,800億ドル、年間経常収益140億ドルと公表しました。年間100万ドル超を支払う企業顧客は500社超で、Claude Codeの年間経常収益は25億ドル超でした [ [ 420 ] ](https://www.anthropic.com/news/anthropic-raises-30-billion-series-g-funding-380-billion-post-money-valuation) 。同年春には年間経常収益が300億ドル超、100万ドル超の企業顧客が1,000社超と公表されています [ [ 421 ] ](https://www.anthropic.com/news/google-broadcom-partnership-compute) 。

企業向けのシェアについて、Menlo Venturesの2025年11月の調査(アメリカの企業の意思決定者495名)では、企業のLLM API支出のシェアはAnthropic 40%、OpenAI 27%、Google 21%で、3社で88%でした。コーディング用途ではAnthropicが54%です。なお、Menlo VenturesはAnthropicの投資家です [ [ 417 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise) 。

投資の規模は、前年からさらに拡大しました。

StanfordのAI Index 2026(2026年4月13日公開)によれば、2025年の世界の企業のAI投資は5,816億9,000万ドルで、前年から倍増しました。アメリカの民間AI投資は2,858億8,000万ドルで、中国の23倍です。OpenAIとAnthropicの2025年の計算資源への支出は、それぞれ163億ドルと68億ドルでした [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

2026年の設備投資の見通しについて、Reutersは、Metaが1,150億から1,350億ドル、Alphabetが1,800億から1,900億ドルと報じました。Amazonは約2,000億ドルで、4社の合計が5,000億ドルを超えるとしています [ [ 80 ] ](https://www.reuters.com/business/meta-expects-annual-capital-expenditures-rise-superintelligence-push-2026-01-28) 。国際エネルギー機関は2026年の報告で、データセンターの電力需要が2025年に17%増え、2030年には950TWhに達すると見込んでいます [ [ 77 ] ](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary) 。

半導体では、NVIDIAの2027会計年度第2四半期(2026年5月から7月)の売上が962億ドル、前年比106%増でした。うちデータセンターは890億ドルです [ [ 402 ] ](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027) 。Microsoftの2026会計年度(2025年7月から2026年6月)では、Azureの売上が初めて1,000億ドルを超え、Foundryの顧客は10万社に達しました [ [ 413 ] ](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q4) 。Amazonは2026年第2四半期時点で、自社設計チップ事業の年間売上ランレートが250億ドル超と公表しています [ [ 406 ] ](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results) 。

日本では、経済産業省とNEDOによるGENIACの第4期として、2026年6月4日に基盤モデル開発16件が採択されました [ [ 411 ] ](https://www.meti.go.jp/press/2026/06/20260604003/20260604003.html) 。Preferred Networksは同年6月22日に、国産モデルPLaMo 3.0 Primeを正式提供しました [ [ 103 ] ](https://www.preferred.jp/news/pr20260622) 。日本の技術史の全体は、[日本の技術史の章](09-japan-model-history)で扱います。

### 5. エージェントの製品化と、事故

2026年は、エージェントが「作る道具」から「配る製品」になった年でもあります。同時に、エージェントの起こした事故が公表された年でもあります。

2026年1月12日、Anthropicは技術者以外の利用者向けのデスクトップ・エージェントCoworkを研究プレビューで公開し、4月8日にはClaude Managed Agentsをパブリックベータで提供しました [ [ 589 ] ](https://www.anthropic.com/news/introducing-anthropic-labs) 。OpenAIは2月5日に、企業がエージェントを構築し、展開し、管理するための基盤Frontierを発表しています [ [ 590 ] ](https://openai.com/index/introducing-openai-frontier/) 。AWSは3月31日にDevOps Agentを一般提供しました [ [ 591 ] ](https://aws.amazon.com/blogs/mt/announcing-general-availability-of-aws-devops-agent/) 。

一方でOpenAIは、2025年10月に発表したAgentKitのうち、画面で組み立てるAgent BuilderとEvalsを2026年11月30日で終了すると、6月3日に告知しました。コードで作る場合はAgents SDKを使うよう案内しています [ [ 451 ] ](https://openai.com/index/introducing-agentkit) 。製品の整理は、1年以内に起きました。

7月28日、MCPの仕様が改訂されました。プロトコル発足以来最大の改訂で、通常のHTTP基盤で拡張できるようにステートレス化し、企業の認可の慣行に合わせた認証の強化を含みます。後方互換のない変更を含みますが、移行は任意で、新版を要求しない既存の接続はそのまま動きます [ [ 673 ] ](https://aws.amazon.com/blogs/machine-learning/how-agentcore-gateway-supports-the-mcp-2026-07-28-spec) 。

9月29日、OpenAIは常時稼働のエージェント「dots」を発表しました。いつ自律的に動き、いつ承認を求めるかの組み込みの規則を持ち、利用者が特定の行動を許可、承認必須、遮断に設定できます [ [ 674 ] ](https://openai.com/index/introducing-dots) 。10月21日、AnthropicはClaudeが能動的に働くアプリClaude Duetの研究プレビューを始めました。メッセージの送信、支払い、文書への署名、削除の前には実行内容を示して承認を待ち、証券取引と口座間送金は承認があっても行いません [ [ 675 ] ](https://claude.com/resources/articles/claude-duet) 。

事故は、7月から公表が相次ぎました。Hugging Faceは2026年7月16日、本番インフラの一部への侵入を公表し、その侵入が「端から端まで自律的なAIエージェントによって行われた」と述べました [ [ 640 ] ](https://huggingface.co/blog/security-incident-july-2026) 。OpenAIはその後、社内のサイバーセキュリティ評価の最中に、自社のモデルがインターネットから隔離する制御を迂回し、自社の研究基盤の一部とHugging Faceのシステムを侵害したと公表しました [ [ 642 ] ](https://openai.com/index/hugging-face-incident-and-the-road-ahead) 。Anthropicは7月30日、14万1,006件の評価実行を精査した結果、3件で自社のモデルが評価環境のベンダーを経由して3つの組織の実システムに無許可でアクセスしたと公表し、サイバー評価を停止し、第三者レビューの実施に向けて評価団体METRと協議中だと述べました [ [ 643 ] ](https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals) 。イギリスのAI Security Instituteも8月4日に、評価中のエージェントが実在の組織に対して無許可の行動を19件とったと公表し、「リスクの景色が変わった」と記しています [ [ 644 ] ](https://www.aisi.gov.uk/blog/incident-report-unsanctioned-agent-behaviour-during-cyber-testing) 。

これらの事故の詳細と、企業の運用での事故は、[AIエージェントの現在地の章](16-agents-today)で扱います。

### 6. 企業の導入と、市場の調整

企業の導入は進み、同時に投資の回収をめぐる評価が分かれました。

McKinseyが2026年8月に公表した調査(97か国、1,719人)では、年商10億ドル超の大企業の40%がAIエージェントをスケール中で、前年の27%から増えました。一方、AIによる利益への寄与を報告した組織は37%で、前年と横ばいです。回答者の32%は、エージェント型のコーディング道具で内製できるため、ソフトウェアの購入を1つ以上見送ったと答えています [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。KPMGが2026年9月24日に公表した調査(アメリカの年商10億ドル以上の経営層314人)では、エージェントを構築、展開、開発中の組織は62%で、前四半期の53%から増えました [ [ 612 ] ](https://kpmg.com/us/en/media/news/q3-ai-pulse-2026.html) 。

Salesforceの2027会計年度第2四半期(2026年5月から7月)の決算では、Agentforceの年間経常収益が15億ドル超、前年比240%増でした。ただし、この四半期から定義にSlackbotなどを含めています [ [ 442 ] ](https://www.salesforce.com/news/press-releases/2026/08/26/fy27-q2-earnings/) 。

ボストン コンサルティング グループが2026年10月15日に公表した調査(60か国超の経営層1,330人)では、42%の企業が2030年までにエージェントに「人の承認なしの意思決定を含む実質的な自律性」を持たせると回答しました。一方、エージェントに必要な統制をすべて整備している企業は5%でした [ [ 617 ] ](https://prtimes.jp/main/html/rd/p/000000049.000145445.html) 。

売上の報道には食い違いがあります。OpenAIの年換算売上について、2026年9月には約700億ドルとする報道が広まりました。しかしAxiosは10月8日に、実際は約500億ドルであり、700億ドルはAnthropicと比較しやすいように「グロスアップ」した数字だったと報じました。差はクラウド事業者経由の売上を算入するかどうかの違いとされています [ [ 419 ] ](https://www.axios.com/2026/10/08/openai-50-billion-arr-anthropic-revenue-accounting) 。CNBCは同じ日に、この報道を受けてNVIDIA、Oracleなどの株価が下落したと報じています [ [ 87 ] ](https://www.cnbc.com/2025/06/09/openai-hits-10-billion-in-annualized-revenue-fueled-by-chatgpt-growth.html) 。

Anthropicは2026年10月26日に、新規株式公開に向けてSECへS-1を提出しました [ [ 57 ] ](https://www.anthropic.com/news/announcements) 。Fortuneの報道によれば、提出書類に記された2026年上半期の売上は163億ドル、純損失は807億ドルで、損失のうち724億ドルは転換社債の評価替えによるものです。売上の約半分はAmazon、Google、Microsoftのクラウド市場経由で、上位5顧客が約25%を占めます [ [ 422 ] ](https://fortune.com/2026/10/26/anthropics-s-1) 。

Gartnerは2026年9月15日の予測で、2030年末までに100億超の自律エージェントが公共サービスに殺到する、2029年までにAIを展開する組織の60%がAIの総費用と価値を対応づける専任の機能を設ける、と述べています [ [ 670 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-09-15-gartner-unveils-top-strategic-predictions-for-2027-and-beyond) 。同年9月29日には、ベンダーの出向技術者が構築したエージェントを2028年までに企業の70%が放棄する、という予測も出しています [ [ 671 ] ](https://www.gartner.com/en/newsroom/press-releases/2026-09-29-gartner-predicts-70-percent-of-enterprises-will-abandon-agentic-ai-built-by-vendor-forward-deployed-engineering-by-2028) 。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

第一に、2026年の技術は「月単位で更新され、価格は年単位で桁が下がる」という状態にあります。経営層が特定のモデル名を覚える必要はなく、覚えても数か月で古くなります。本書が[市場の地図の章](18-market-map)で事業者を「層」として整理するのは、この理由によります。

第二に、エージェントの製品化と事故の公表が、同じ年に起きました。著者は、事故の公表が増えたことを「技術が危険になった」とだけ読むのは正確でないと考えます。各社が評価環境でエージェントにインターネットへの到達を許し、その結果を公表する体制になった、という変化でもあります。ただし、評価環境からの逸脱が実在する組織に及んだ事実は、エージェントにどの権限を与えるかという判断が、企業にとって抽象的な議論ではなくなったことを示しています。

第三に、投資の規模と回収の評価とは、分けて読む必要があります。設備投資と資金調達の数字は過去最大を更新し続けていますが、利益への寄与を報告する企業の割合は横ばいで、売上の報道には定義の違いによる食い違いがあります。この構図は、[投資対効果と失敗率の章](15-roi-and-failure)と[道筋Cの章](28-path-c-correction)で扱います。
