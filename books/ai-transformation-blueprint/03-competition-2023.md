### 序論：本章が扱う範囲

本章は、ChatGPTの公開に続く2023年の1年間に、生成AIの供給側がどのような構造に落ち着いたかを整理します。2022年末の時点で、対話型の生成AIを一般に提供していたのは実質的にOpenAI 1社でした。2023年末には、閉鎖モデルを提供する複数の企業と、重みを公開するモデルの系列と、そして能力を測る共通の尺度が並び立っていました。

本章の本文は、各社の発表と、第三者による計測の2種類の事実に限ります。「どのモデルが優れているか」という評価は扱いません。競争の構造が企業の調達にどう関わるかは章末で解釈し、市場の全体像は[市場の地図の章](18-market-map)に委ねます。

### 1. 2023年3月14日：GPT-4とClaude

2023年3月14日、2つの発表が同じ日にありました。

OpenAIはGPT-4を発表しました。翌15日に公開された技術報告は、GPT-4の性能の一部を、1,000分の1以下の計算量で学習した小さなモデルから事前に予測できたと記しています [ [ 15 ] ](https://openai.com/index/gpt-4-research/) 。[基盤の成立の章](01-foundations-2017-2020)で述べたスケーリング則が、製品の開発工程に組み込まれたことを示す記述です。

同日、AnthropicはClaudeの一般提供を始めました。Notion、Quora、DuckDuckGoなどの企業との限定的な試験を数か月行ったうえでの提供です [ [ 14 ] ](https://www.anthropic.com/news/introducing-claude) 。AnthropicはOpenAIの元メンバーが2021年に設立した企業であり、この時点で対話型の生成AIの提供事業者は2社になりました。

### 2. 重みを公開するモデルの登場

2023年2月27日、MetaはLLaMAを公開しました。70億から650億パラメータの4つの大きさがあり、130億パラメータの版が、1,750億パラメータのGPT-3を多くの評価で上回ったと論文は報告しています [ [ 13 ] ](https://arxiv.org/abs/2302.13971) 。学習済みの重みは研究者向けに配布されました。

同年7月18日、MetaはLlama 2を公開しました。70億から700億パラメータの範囲で、対話向けに調整した版も含まれます [ [ 16 ] ](https://arxiv.org/abs/2307.09288) 。Llama 2は、一定の条件のもとで商用利用を許す形で配布されました。

これにより、生成AIの供給は2つの系列に分かれました。1つは、開発元がモデルを手元に置き、APIを通じて利用させる閉鎖モデルです。もう1つは、学習済みの重みを配布し、利用者が自分の計算機で動かせるオープンウェイトのモデルです。本書は後者を「オープンソース」とは呼びません。学習データと学習の手順は公開されていないことが多く、公開されているのは重みだからです。オープンウェイトのモデルは、利用者が自分の設備で動かせるため、データを外部へ送らずに済みます。その代わり、計算機の調達と運用は利用者の責任になります。この違いは、[各段階で必要なものの章](34-requirements-and-providers)で導入の形を選ぶときの軸の1つになります。

### 3. Geminiとマルチモーダル

2023年12月6日、GoogleはGeminiを発表しました。Ultra、Pro、Nanoの3つの大きさがあり、文章だけでなく画像、音声、動画を最初から扱えるように設計されたとGoogleは説明しています。Gemini ProのAPIは12月13日から開発者と企業に提供されました [ [ 17 ] ](https://blog.google/technology/ai/google-gemini-ai/) 。

これにより、閉鎖モデルの提供事業者はOpenAI、Anthropic、Googleの3社になりました。画像の入力については、OpenAIが2023年9月25日にChatGPTへの画像入力の提供を始めると発表し [ [ 1702 ] ](https://openai.com/index/chatgpt-can-now-see-hear-and-speak/) 。Googleは前述のとおりGeminiを最初から画像や音声を扱うよう設計したと説明しました。Anthropicは、2024年3月4日のClaude 3で画像の入力に対応しています [ [ 1701 ] ](https://www.anthropic.com/news/claude-3-family) 。「マルチモーダル」という語は、このように複数の種類の入力と出力を1つのモデルで扱うことを指します。

### 4. 能力を測る尺度の始まり

競争が複数社になると、第三者による計測が始まりました。2023年10月10日、Princeton大学の研究者らはSWE-benchを公開しました。GitHub上の実際のソフトウェアの不具合報告を与え、モデルが修正を書けるかを測る尺度です。公開時点で最も成績のよかったClaude 2でも、解決できたのは1.96%でした [ [ 58 ] ](https://arxiv.org/abs/2310.06770) 。

この数値は、2023年末の時点での到達点を示します。[能力の計測の章](07-measuring-capability)で述べるとおり、同じ尺度での成績は翌年に大きく上がります。本章で記すのは、尺度そのものがこの時期に整ったという事実です。

### 5. 差の縮小

StanfordのAI Index 2025は、2023年末から2025年初めにかけての2つの差の推移を報告しています。

第一に、閉鎖モデルとオープンウェイトのモデルの差です。利用者の投票で順位をつけるChatbot Arenaにおいて、最上位の閉鎖モデルと最上位のオープンウェイトのモデルの差は、2024年1月の8.04%から2025年2月の1.70%へ縮小しました。第二に、アメリカと中国のモデルの差です。知識を測るMMLUでの最上位モデルの差は、2023年末の17.5ポイントから2024年末の0.3ポイントへ縮小しました [ [ 59 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/technical-performance) 。

翌年のAI Index 2026は、2026年3月の時点でアメリカの最上位モデルが中国の最上位モデルを2.7%上回るのみで、差は一桁にとどまると記しています(同じ報告の見出しは、差は「事実上解消した」と表現しています)。一方、閉鎖モデルとオープンウェイトのモデルの差は、2024年8月の0.5%から3.3%へ再び広がりました [ [ 67 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance) 。差は一方向に縮み続けるのではなく、新しいモデルの公開のたびに開いては縮む動きを繰り返しています。

### 6. 日本の参入

2023年は、日本の組織が独自のモデルを公開し始めた年でもあります。東京大学の松尾研究室は2023年8月18日に、100億パラメータで日本語と英語を扱うWeblab-10Bを公開しました。商用利用は許されていません [ [ 95 ] ](https://www.t.u-tokyo.ac.jp/press/pr2023-08-18-001) 。NTTは2023年11月1日に、6億と70億パラメータの軽量なモデルtsuzumiを発表しました。NTTはこれを、1基のGPUで動く純国産のモデルだと説明しています [ [ 97 ] ](https://group.ntt/jp/newsrelease/2023/11/01/231101a.html) 。

これらの規模は、同じ年のGPT-4やLlama 2の700億パラメータと比べると小さいものです。日本の参入は、最上位の性能を競うのではなく、日本語への適応と、少ない計算資源で動くことを狙いとして始まりました。その後の経過は[日本の技術史の章](09-japan-model-history)で扱います。

### 7. 2023年末の構造

ここまでの事実を、供給側の構造として整理します。

| 系列 | 2023年末の提供事業者 | 利用の形 | 2023年の節目 |
| --- | --- | --- | --- |
| 閉鎖モデル | OpenAI、Anthropic、Google | APIと対話サービス | GPT-4、Claude、Gemini |
| オープンウェイト | Metaほか | 重みを配布、自前で運用 | LLaMA、Llama 2 |
| 第三者の計測 | 大学、非営利団体 | 共通の尺度で順位づけ | SWE-bench、Chatbot Arena |

この3つの系列は、2026年の現在まで維持されています。提供事業者の顔ぶれは増え、[推論モデルと価格の章](04-reasoning-and-cost-2024)で述べるとおり中国の企業も加わりました。しかし、閉鎖と公開の並立、そして第三者による計測という構造は、2023年に定まったものです。

### 🗺️ 図：閉鎖とオープンの差は、開いては縮む

#### 図の読み方

この図は、左から右へ時間順に並んだ3本の棒で構成されています。各棒の高さは、利用者の投票による順位づけ(Chatbot Arena)で、最上位の閉鎖モデルが最上位のオープンウェイトのモデルをどれだけ上回っていたかを示します。左から、2024年1月の8.04%、2025年2月の1.70%、2026年3月の3.3%です。

最初の2本は本文の第5節で引用したAI Index 2025、最後の1本はAI Index 2026の数値です。AI Index 2026は2024年8月の差を0.5%としており、2025年2月の1.70%とは時点と計測の基準が異なります。図では2025年2月の値を使っています。

読み順は左から右です。差は一度ほぼ消え、その後に再び開きました。図の添え書きにあるとおり、差は一方向には動いていません。閉鎖モデルの提供事業者が新しいモデルを出すと差は開き、オープンウェイトの側が追いつくと縮みます。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、2023年の1年間で、閉鎖モデルの提供事業者は1社から3社に増え、重みを公開する系列が並び立ちました。第二に、第三者が共通の尺度で能力を測る慣行が始まり、各社の主張ではなく計測で比較できるようになりました。第三に、閉鎖とオープンの差、アメリカと中国の差は、ともに縮小したあと、新しいモデルの公開のたびに開いては縮む動きを繰り返しています。

著者は、2023年に定まった構造のうち、企業にとって最も重要なのは「差が固定されない」ことだと考えます。ある時点で最上位にあるモデルは、半年後には別のモデルに追い抜かれます。オープンウェイトのモデルは常に数か月の遅れで追いつきます。この構造のもとでは、特定の提供事業者に長期の前提を置く調達は、技術の面でも費用の面でも不利になりやすいと著者は考えます。

### 経営層への含意

生成AIの調達は、サーバや業務システムの調達と同じ時間感覚では扱えません。契約の単位を短くし、モデルを切り替えられる構成にしておくことが、2023年に定まった構造への合理的な対応です。[各段階で必要なものの章](34-requirements-and-providers)では、この切り替え可能性を、導入フェーズごとに具体的な要件として示します。
