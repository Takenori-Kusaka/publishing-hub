### 序論：本章が扱う範囲

本章は、2024年から2025年にかけて起きた2つの変化を整理します。1つは、答える前に長く考える「推論モデル」の登場です。もう1つは、同じ性能を得るための費用が、1年半で数百分の1に下がったことです。

[競争の構造化の章](03-competition-2023)で述べた構造は、この2年間で変わっていません。変わったのは、能力の伸ばし方と、費用の水準です。2023年までは、モデルを大きく学習させることが能力を伸ばす主な手段でした。2024年9月以降、答えるときに計算を多く使うという第二の手段が加わりました。同時に、中国の企業が少ない計算量で同等の性能を示し、市場が反応しました。

本章の本文は、各社の発表、第三者の計測、価格表の3種類の事実に限ります。AIエージェントに関わる2024年10月以降の発表は、[エージェントの年の章](05-year-of-agents-2025)で扱います。

### 1. 2024年前半：速さと安さ

2024年4月18日、Meta は Llama 3 を公開し、7月23日には4,050億パラメータで12万8,000トークンの文脈を扱う Llama 3.1 を公開しました [ [ 18 ] ](https://ai.meta.com/blog/meta-llama-3) 。オープンウェイトの系列が、閉鎖モデルの最上位に近い規模へ達した時期です。

2024年5月13日、OpenAI は GPT-4o を発表しました。音声の入力に対する応答は平均320ミリ秒で、人の会話の間合いに近づきました。API の価格は、前の世代の GPT-4 Turbo より50%安く設定されました [ [ 19 ] ](https://openai.com/index/hello-gpt-4o/) 。性能を保ったまま価格を半分にする動きは、この時点から各社に広がります。

### 2. 推論モデル：答える前に考える

2024年9月12日、OpenAI は o1 を発表しました。o1 は強化学習によって学習され、利用者へ答える前に長い内部の思考の連鎖を生成します [ [ 20 ] ](https://openai.com/index/learning-to-reason-with-llms/) 。本書はこの種類のモデルを「推論モデル」と呼びます。

推論モデルの意味は、能力を伸ばす手段が増えたことにあります。それまでは、学習に投じる計算量を増やすことが主な手段でした。推論モデルは、答えるときに使う計算量を増やすことでも能力を伸ばせることを示しました。この2つは独立しており、両方を同時に増やせます。

ただし、答えるときの計算量は、そのまま費用になります。2024年12月20日、ARC Prize は、OpenAI の o3 が抽象的な推論の課題 ARC-AGI-1 で75.7%を記録し、計算量を172倍にした構成では87.5%に達したと発表しました。後者の構成では、1つの課題を解く費用が平均で約3,400ドルかかったとされています [ [ 23 ] ](https://arcprize.org/blog/oai-o3-pub-breakthrough) 。能力と費用が1つの軸で結ばれたことを示す数値です。

### 3. DeepSeek：少ない計算量での到達

2024年12月27日、中国の DeepSeek は DeepSeek-V3 の技術報告を公開しました。報告によれば、学習の全体に要した計算は、輸出規制に対応した H800 という GPU で278万8,000 GPU 時間でした [ [ 24 ] ](https://arxiv.org/abs/2412.19437) 。この時点の米国の最上位モデルと同等とされる性能を、公表された範囲でははるかに少ない計算量で達成したという報告です。

2025年1月22日、DeepSeek は推論モデル DeepSeek-R1 の論文を公開しました。この論文は後に学術誌 Nature の645巻に掲載されています [ [ 25 ] ](https://arxiv.org/abs/2501.12948) 。R1 は重みを公開する形で配布されました。推論モデルという最新の手法が、公開から4か月でオープンウェイトの側へ現れたことになります。

市場は直ちに反応しました。2025年1月27日、NVIDIA の株価は17%下落し、時価総額で約5,930億ドルを失ったと報じられました。1日の損失としては米国の企業で過去最大とされています [ [ 26 ] ](https://www.reuters.com/markets/us/nasdaq-futures-tumble-chinas-ai-push-rattles-big-tech-2025-01-27) 。この下落は、少ない計算量で同等の性能が出るなら計算資源への需要が減るという見方によるものです。後の経過は[計算資源と資本の章](08-compute-capital-energy)で扱います。

### 4. 価格の低下の実測

同じ性能を得る費用がどれだけ下がったかは、2つの計測があります。

投資会社 a16z は2024年11月に、同等の性能の言語モデルを使う推論の費用が毎年10分の1のペースで下がっていると報告しました。知識を測る MMLU で83点の水準では、2023年3月の GPT-4 以降、約62分の1になったとしています [ [ 73 ] ](https://a16z.com/llmflation-llm-inference-cost) 。

Stanford の AI Index 2025 は、より具体的な数値を示しています。MMLU で GPT-3.5 相当(64.8点)の性能を得る推論の費用は、2022年11月には100万トークンあたり20ドルでした。2024年10月には、Google の Gemini 1.5 Flash 8B で0.07ドルになりました。約18か月で280倍超の低下です。課題の種類によって、低下の速さは年に9倍から900倍の幅があります [ [ 74 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report/research-and-development) 。

この低下は、最上位のモデルの価格が下がったことを意味しません。ある時点の最上位の性能が、1年から2年後には安価なモデルで得られるようになった、という意味です。最上位のモデルの価格は、次節のとおり別の動きをしています。

Google は2025年3月25日に Gemini 2.5 を発表し、利用者の投票による順位づけで1位になったと述べています [ [ 30 ] ](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/gemini-model-thinking-updates-march-2025) 。Meta は2025年4月5日に Llama 4 を公開し、扱える文脈の長さを Llama 3 の12万8,000トークンから1,000万トークンへ広げたとしています [ [ 31 ] ](https://ai.meta.com/blog/llama-4-multimodal-intelligence) 。Anthropic は2025年5月に Claude Opus 4 と Sonnet 4 を発表し、価格は Opus が100万トークンあたり入力15ドルと出力75ドル、Sonnet が入力3ドルと出力15ドルでした [ [ 33 ] ](https://www.anthropic.com/news/claude-4) 。OpenAI は2025年8月7日に GPT-5 を公開しました [ [ 34 ] ](https://openai.com/index/introducing-gpt-5/) 。Anthropic は2025年9月に Claude Sonnet 4.5 を公開しました [ [ 35 ] ](https://www.anthropic.com/news/claude-sonnet-4-5) 。Google は2025年11月18日に Gemini 3 を発表しました [ [ 36 ] ](https://blog.google/products-and-platforms/products/gemini/gemini-3) 。Anthropic は2025年11月に Claude Opus 4.5 を公開し、価格を100万トークンあたり入力5ドル、出力25ドルに引き下げました [ [ 37 ] ](https://www.anthropic.com/news/claude-opus-4-5) 。DeepSeek は2025年12月1日に V3.2 を公開しました [ [ 38 ] ](https://www.deepseek.com/en/transparency/) 。

最上位のモデルの価格に注目すると、Anthropic の例では2025年5月の出力75ドルから、同年11月の25ドルへ、半年で3分の1になりました。最上位の価格もまた下がっています。ただし、推論モデルは1つの答えに使うトークンが多いため、1トークンあたりの価格が下がっても、1つの課題あたりの費用は必ずしも下がりません。

### 6. 2つの曲線

ここまでの事実を、2本の曲線として整理します。

| 曲線 | 向き | 根拠 | 注意点 |
| --- | --- | --- | --- |
| 能力 | 上昇 | 推論モデルの登場、各社の世代交代 | 答えるときの計算量が費用になる |
| 同じ性能の単価 | 低下 | 18か月で280倍超の低下 | 最上位の性能は常に高価 |

企業の導入にとって重要なのは、この2本が同時に動いていることです。ある業務に必要な性能が決まっているなら、その性能を得る費用は時間とともに下がります。一方で、常に最上位の性能を求めるなら、費用は下がりません。

### 本章の要点と解釈

本セクションは、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、2024年9月の推論モデルの登場により、能力を伸ばす手段が「学習の計算量」から「学習と推論の両方の計算量」へ広がりました。第二に、2025年1月の DeepSeek は、少ない計算量で同等の性能に達し得ることと、最新の手法が数か月でオープンウェイトの側に現れることを示しました。第三に、同じ性能を得る費用は18か月で280分の1に下がる一方、最上位の性能は常に高価であり続けています。

筆者は、この2年間の最も重要な帰結を「費用の見積もりが、性能の固定によって初めて可能になった」ことだと考えます。どの性能で足りるかを決めない導入は、常に最上位を追いかけ、費用が下がりません。業務ごとに必要な性能を決めれば、その費用は毎年下がります。これは、[投資対効果と失敗率の章](15-roi-and-failure)で扱う「効果が出ない」事例の一部を説明します。

経営層への含意は次のとおりです。生成AIの費用は、導入の時点ではなく、業務ごとに「どの性能で足りるか」を決めた時点で見積もれるようになります。したがって、導入の初期に全社で最上位のモデルを契約するより、業務の棚卸しと必要な性能の見極めへ先行して投資するほうが、費用の面で合理的です。この見極めの手順は、[各段階で必要なものの章](34-requirements-and-providers)で扱います。
