title: "第13章　生産性の実証 ―― 誰に、どの仕事で、どれだけ効いたか"

### 序論：本章が扱う範囲

本章は、生成AIが仕事の生産性に与えた効果について、実験と観察による実証研究を整理します。対象は、2023年から2026年までに公表された、無作為化した比較試験(RCT)、現場実験、行政データを用いた観察研究、そしてマクロ経済への影響の推計です。

生産性の効果については、「開発者が55%速くなった」から「経験豊富な開発者は19%遅くなった」まで、相反する数値が引用されています。本章の目的は、これらの数値がどのような条件で得られたかを明らかにし、自社の仕事にどの結果が当てはまりうるかを判断できるようにすることです。

本文は、研究の設計と結果の記述に限定します。結果をどう一般化できるかの評価は、章末で扱います。雇用への影響は[雇用の実証の章](14-labor-evidence)で、投資対効果は[投資対効果と失敗率の章](15-roi-and-failure)で扱います。

### 1. 実証研究の読み方

本章で扱う研究は、設計によって4つに分けられます。

第一に、実験室型のRCTです。参加者を募集し、無作為に生成AIの利用群と対照群に分け、定められたタスクの所要時間と品質を測ります。因果を特定できますが、タスクが単一で短く、現場の長期的な効果とは異なります。

第二に、現場実験です。実際の企業の従業員を対象に、段階的に導入するか無作為に割り当て、業務の成果を測ります。因果と現実性を両立しますが、対象企業と職種に結果が依存します。

第三に、観察研究です。行政データや調査データを使い、利用者と非利用者の差を統計的に推定します。母集団が広い一方、因果の特定は設計に依存します。

第四に、マクロの推計です。タスク単位の効果をモデルで積み上げ、経済全体への影響を推計します。前提の置き方で結果が桁で変わります。

### 2. 実験室型のRCT：文章と定型のコード

ノイとチャンは2023年に、大卒の専門職444人に職業別の文章作成タスクを割り当てました。ChatGPT(GPT-3.5)の利用群は、所要時間が対照群の平均27分から17分へ(10分、37%)短縮し、評価者の採点が0.45標準偏差上昇しました。成績の低かった参加者ほど改善し、参加者間の格差が縮小しています。Science誌の掲載版では、時間40%短縮、品質18%向上と記載されています [ [ 142 ] ](https://economics.mit.edu/sites/default/files/inline-files/Noy_Zhang_1.pdf) 。

ペンらは2023年に、GitHub Copilotの対照実験を報告しました。募集した開発者にJavaScriptでHTTPサーバを実装させたところ、Copilot利用群は対照群より55.8%速く完了しました。ただし、95人規模で、単一の定型タスクです [ [ 144 ] ](https://arxiv.org/abs/2302.06590) 。

### 3. 現場実験：コールセンター、コンサルタント、開発者

ブリニョルフソン、リ、レイモンドは、Fortune 500企業のカスタマーサポート担当5,172人に生成AIの会話アシスタントを段階的に導入した準実験を報告しました。1時間あたりの解決件数は平均15%増加しました。経験の浅い担当者と低スキルの担当者は速度と品質の両方が改善し、最も経験豊富な層は速度がわずかに上がり品質がわずかに低下しています [ [ 143 ] ](https://www.gsb.stanford.edu/faculty-research/publications/generative-ai-work) 。

デラクアらは、BCGのコンサルタント758人を対象にした現場実験を2023年に報告しました。AIの能力の範囲内にある18のタスクでは、GPT-4の利用群がタスク完了数12.2%増、所要時間25.1%短縮、品質40%超の向上を示しました。改善幅は、平均以下の成績者が43%、平均以上の成績者だと17%でした。一方、能力の範囲外に設定したタスクでは、AI利用群の正答率が19ポイント低くなりました。著者らはこの境界を「ギザギザの技術フロンティア」と呼んでいます [ [ 145 ] ](https://mitsloan.mit.edu/sites/default/files/2023-10/SSRN-id4573321.pdf) 。

ツイらは、Microsoft、Accenture、匿名のFortune 100企業で行った3件のRCT(開発者計4,867人)を統合し、AIコーディング支援を得た開発者の完了タスク数が26.08%増えたと報告しました。標準誤差は10.3%であり、95%信頼区間はおよそ6%から46%です。経験の浅い開発者ほど採用率と効果が高い結果でした [ [ 146 ] ](https://economics.mit.edu/sites/default/files/inline-files/draft_copilot_experiments.pdf) 。

Microsoft Researchは、56社・6,000人の知識労働者を対象にした6か月のRCTを報告しました。Microsoft 365 Copilotを実際に使った人は、メールに使う時間が週3時間(25%)減りました。文書作成はやや速くなりましたが、会議の時間は有意に変わりませんでした。個人で変えられる行動は変わり、他者との調整が要る行動は変わらなかったと整理しています [ [ 147 ] ](https://www.microsoft.com/en-us/research/publication/shifting-work-patterns-with-generative-ai) 。

### 4. 効果が出なかった実験と、その後

METRは2025年7月に、経験豊富なオープンソース開発者16人が自身のリポジトリの実タスク246件に取り組んだRCTを報告しました。AIの利用を許可された場合、所要時間は19%長くなりました。開発者は事前に24%の高速化を予想し、事後も20%速くなったと信じていました [ [ 148 ] ](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study) 。

同じ組織は2026年2月に、追跡研究で深刻な選択効果が生じたと報告しました。開発者の30〜50%が「AIなしではやりたくない」タスクを提出せず、AIに最も楽観的な開発者ほど参加しなくなっていました。2026年初頭の開発者は2025年初頭より速くなっている可能性が高いものの、データは弱い証拠にすぎないとして、実験の設計を変更しています [ [ 149 ] ](https://metr.org/blog/2026-02-24-uplift-update) 。

### 5. 観察研究：広く使われても、賃金は変わらない

フムルムとヴェスタゴーは、デンマークの11職種、労働者25,000人、7,000職場の調査を雇用主と従業員のマッチデータに接続しました。2026年3月の改訂版の要旨によれば、曝露された職種の雇用主の大半がチャットボットの導入施策を採り、労働者は生産性の便益を報告した一方、収入と労働時間への効果は、ChatGPT公開から2年の時点で2%を超える効果を棄却できる精度でゼロでした。雇用主は主に業務を再編しており、採用者の一部は高賃金の職種へ移動しています [ [ 1758 ] ](https://www.nber.org/papers/w33777) 。初版(2025年5月)の推計では、利用者の時間節約は平均2.8%で、そのうち収入に反映されたのは3〜7%でした [ [ 150 ] ](https://www.nber.org/system/files/working_papers/w33777/revisions/w33777.rev0.pdf) 。

同じ研究と、ビックらのアメリカとヨーロッパの比較は、共通の要因を指摘しています。雇用主がAIの利用を奨励しツールを提供している職場では、報告される便益が一貫して大きいという点です [ [ 110 ] ](https://www.brookings.edu/articles/mind-the-gap-ai-adoption-in-europe-and-the-us) 。

日本では、森川正之氏が就労者調査に基づく試算を示しています。AIの業務利用者の比率22.3%、利用業務のシェア15.9%、業務効率化の効果24.4%から、利用者の生産性効果は6.2%、マクロの生産性効果は1.4%と計算されました。5〜10年で利用が進んだとすれば、労働生産性の上昇率を年率0.2〜0.3ポイント高めた計算です [ [ 154 ] ](https://www.jpc-net.jp/research/assets/pdf/innocon20260930_nenji2026.pdf) 。同氏の前年の推計(経済産業研究所のディスカッション・ペーパー、2024年12月)では、AIを仕事で使う人は約8%、経済全体の労働生産性の押し上げは0.5〜0.6%でした [ [ 1752 ] ](https://www.rieti.go.jp/jp/publications/dp/24j033.pdf) 。1年で、利用率と効果の推計が大きく動いています。

経験の浅い層で効果が大きいという型は、生成AI以前のAIでも観察されています。金澤、川口、繁岡、渡辺は2022年に、需要の高い経路を提案するAIがタクシー乗務員の空車時間を短縮し、その効果は低技能の乗務員だけに生じて、高技能の乗務員との生産性の差を14%縮めたと報告しました [ [ 1753 ] ](https://www.nber.org/papers/w30612) 。

日本経済研究センターと日本経済新聞の経済学者パネル(約50人、2026年3月)では、「AIの普及は向こう5年で日本の就業者1人あたりの生産性を引き上げる」に「強くそう思う」「そう思う」が計82%でした。「失業率を押し上げる」は「どちらともいえない」が48%です [ [ 155 ] ](https://www.jcer.or.jp/policy-proposals/20260313.html) 。

### 6. マクロの推計：GDPで約1%と7%

タスク単位の効果を経済全体に積み上げる推計は、前提によって桁が異なります。

アセモグルは2024年に、タスクベースのモデルと、どのタスクがAIの影響を受けるかの既存の推計から、今後10年の全要素生産性(TFP)の上昇を最大0.66%、年率約0.064%と推計しました。投資の反応を含めたGDPの増加は0.93〜1.16%です。学習が困難なタスクを考慮すると、TFPの上昇は0.53%未満です [ [ 151 ] ](https://www.nber.org/papers/w32487) 。

Goldman Sachsは2023年に、生成AIが10年間で世界のGDPを7%(約7兆ドル)押し上げ、生産性成長率を年1.5ポイント引き上げる可能性があると推計しました。フルタイム換算で3億人分の仕事が自動化に曝露されるとしています [ [ 152 ] ](https://www.goldmansachs.com/insights/articles/generative-ai-could-raise-global-gdp-by-7-percent) 。この1.5ポイントは、同社の報告ではアメリカの労働生産性の年間成長率についての値です [ [ 1755 ] ](https://www.gspublishing.com/content/research/en/reports/2023/10/30/2d567ebf-0e7d-4769-8f01-7c62e894a779.html) 。

ブリニョルフソン、ロック、サイバーソンは、汎用技術の初期には生産性が統計の上で過小評価される「生産性Jカーブ」を示しました。計算機関連の無形資産を調整すると、2017年末のアメリカの全要素生産性は公式統計より15.9%高いと推計しています [ [ 153 ] ](https://www.aeaweb.org/articles?id=10.1257%2Fmac.20180386) 。

### 7. 総括的な整理

スタンフォード大学のAI Index 2026は、これらの実証研究を総括し、AIの生産性効果は構造化され測定しやすい業務で最大であると整理しています。数値は、カスタマーサポート14〜15%、ソフトウェア開発26%、マーケティングの産出量50%です。深い推論を要する業務の効果は小さく、AIへの過度の依存が長期的な学習の損失を生む懸念も指摘しています。なお、マーケティングの数値について、同報告書のウェブ版は50%、章のPDF版は73%と不一致です [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。

労働市場での評価も変化しています。PwCの求人データ分析(約10億件)では、AIスキルを要する職の賃金プレミアム(求人票に提示された賃金の、他の職との差)は2025年に62%で、前年の57%から上昇しました [ [ 156 ] ](https://www.pwc.com/gx/en/issues/artificial-intelligence/job-barometer/2026/2026-global-ai-jobs-barometer-full-report.pdf) 。

#### 図の読み方

この図は、横軸に「仕事の型」、縦軸に「人の経験」をとった4つの象限です。横軸の左は定型で測りやすい仕事、右は非定型で判断を要する仕事です。縦軸の下は経験の浅い人、上は経験豊富な人です。

左下の象限が、効果が最も大きく観測された領域です。コールセンターの15%、文章作成の37%、定型コードの55.8%がここに入り、いずれも経験の浅い層で効果が大きくなっています。右上の象限が、効果が小さいか負になった領域です。経験豊富な開発者の実タスクで19%の遅延、コンサルタントの能力範囲外タスクで19ポイントの正答率低下がここに入ります。

図の2つの軸は、本文の第2節から第4節の研究から著者が抽出したものです。研究ごとに測り方が異なるため、象限の境界は目安にとどまります。自社の仕事がどの象限に多いかを考えるための整理です。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

本章の要点は3つです。

第一に、効果は仕事の型に依存します。定型で測りやすい仕事では15〜55%の改善が繰り返し観測され、非定型で判断を要する仕事では効果が小さいか負になります。

第二に、効果は人の経験に依存します。ほぼすべての研究で、経験の浅い層ほど効果が大きく、経験豊富な層では小さいか負でした。定型で測りやすいタスクの実験では、生成AIは格差を縮める方向に働いています。ただし、逆の結果もあります。オーティスらがケニアの中小事業者640人で行った無作為化実験では、平均の効果はなく、成績上位の事業者はAIの助言で2割強改善し、下位の事業者は約1割悪化しました。下位の層が、より難しい課題で助言を求めたためです [ [ 1751 ] ](https://www.hbs.edu/ris/download.aspx?name=24-042.pdf) 。格差が縮むか広がるかは、誰がどの課題に使うかで決まります。

第三に、個人の効果は企業の損益に直結しません。デンマークの研究では収入と労働時間のどちらにも効果が見られず、Microsoftの実験では個人の行動は変わっても会議は変わりませんでした。効果を組織の成果に変えるには、個人の外側にある手順と調整の仕組みを変える必要があります。

著者は、「55%速くなる」と「19%遅くなる」の両方を引用する言説に注意を促します。前者は単一の定型タスクの実験室の結果であり、後者は16人の熟練者の実タスクの結果で、後に選択効果が報告されています。どちらも自社の仕事の平均的な効果ではありません。自社に当てはめるなら、仕事の型と担当者の経験の分布を先に把握し、図の象限ごとに期待値を置くべきです。

マクロの推計について補います。アセモグルとGoldman Sachsの差は、著者の整理では3点から生じています。費用対効果の面で実際に自動化されるタスクの比率、タスクあたりの費用節減率、そして指標がTFPかGDPかの違いです。また、Jカーブの枠組みに立てば、現在の統計に生成AIの効果が現れていないことは、効果がないことを意味しません。

### 経営層への含意

本章の研究が一致して示す実務上の点は3つです。効果が出やすい仕事から始めること、経験の浅い層の底上げに使うこと、そして雇用主として利用を奨励し道具を提供することです。3つ目は、アメリカとヨーロッパの利用率の差の大部分を統計的に説明した要因でもありました。効果を損益に結びつける段階は、[組織の内部化の章](22-organizational-internalization)の補完投資の考え方と、[生成AIの導入段階の章](30-genai-adoption-stages)のS3以降で扱います。
