### 1. なぜ、いま生成AIの系譜と現在地を整理するのか

生成AIをめぐる言説は、1週間で入れ替わります。新しいモデルの公開、企業の導入事例、投資の規模、雇用への懸念、バブルの警告が、毎日のように流れてきます。経営層がこの流れの中で判断を下すとき、困るのは情報の不足ではありません。情報の過剰と、その情報がどの前提に立っているかが見えないことです。

同じ「導入率」でも、調査によって数値は4倍以上開きます。総務省の2025年度調査では、デジタル化に着手した従業員10名以上の企業に勤める管理職のうち、自社の何らかの業務で生成AIを利用していると答えた割合は86.4%でした [ [ 122 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf) 。一方、全国の1万社あまりを対象にした帝国データバンクの2026年3月調査では、生成AIを業務で活用している企業は34.5%です [ [ 125 ] ](https://www.tdb.co.jp/report/economic/20260514-genai) 。東京商工リサーチの2026年3〜4月調査で「会社として活用を推進」と答えた企業は20.3%でした [ [ 130 ] ](https://www.tsr-net.co.jp/data/detail/1202766_1527.html) 。どれも正しい数値です。母集団と設問が違うだけです。この違いを読み解かずに「日本企業の8割は導入済み」とも「2割にとどまる」とも言えてしまうところに、現在の判断の難しさがあります。

個人の利用についても同じです。日本の個人の生成AI利用経験率は、2024年度の26.7%から2025年度には58.8%へ上昇しました。ただし2025年度の調査は15〜19歳を新たに含めており、20歳以上に限ると52.2%です [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。伸びは事実ですが、伸び幅の一部は調査設計の変更です。

投資対効果についても、相反する調査が並びます。MITの研究チームは2025年に、企業の生成AI投資の95%が損益に効果をもたらしていないと報告しました [ [ 177 ] ](https://mlq.ai/media/quarterly_decks/v0.1_State_of_AI_in_Business_2025_Report.pdf) 。McKinseyの2026年調査では、回答組織の44%が全社でAIをスケール中と答えています [ [ 136 ] ](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) 。どちらも調査として成立しており、見ている対象が違います。

本書は、こうした数値と言説を1つずつ出典に戻し、前提をそろえて並べ直すことから始めます。そのうえで、企業が生成AIをどう導入してきたか、次に来るAIエージェントはどう導入されるのかを、段階として整理します。

### 2. 本書の設計思想：砂時計アーキテクチャ

本書は、著者の前著『未来予測の設計図』と同じ構造を採ります。過去・現在・未来を、1本の推論の連鎖として扱う砂時計の構造です。

砂時計の上半分は「過去」です。2017年のTransformerから2026年10月までの、技術・市場・制度の系譜を事実として整理します。

砂時計のくびれは「現在」です。普及の現在地、生産性と雇用の実証、投資対効果、AIエージェントの実態、規制、市場の地図、日本固有の条件を、公的統計と一次資料から確かめます。

砂時計の下半分は「未来」です。2031年までの5年間を、1つの予言ではなく3つの道筋として描きます。加速、漸進、調整です。どの道筋に進むかを本書は決めません。本書が示す分岐条件と早期警戒指標を、読者が観測し続けて見分けます。

この砂時計に、本書はもう1つの層を重ねます。「導入」の層です。社会全体の系譜と未来は、各企業にとっては外部環境です。企業が実際に動くのは、自社の現在地から次の段階へ進むときです。そこで本書は、生成AIの導入を6つの深さ、AIエージェントの導入を5つの自律性、組織の文化を5つの段階として定義し、経営層が自社の現在地を特定して次の一手を選べるようにします。

### 3. 記述規範：事実と推論の厳格な分離

**規範1：過去と現在の記述は、事実のみで構成します。** 第1章から第19章までの本文は、出来事、統計、公表された文書の内容に限ります。著者の解釈は、各章末の「本章の要点と解釈」に隔離し、冒頭に免責の文を置きます。

**規範2：出典は、当該記述の直後にインラインで示します。** 数値や事実の文末に、一次資料への外部リンクを直接配置します。番号は巻末の参考文献と対応しますが、読者は本文からリンクを1回たどるだけで根拠に到達できます。

**規範3：情報源は、一次資料・公的資料・査読論文・発行元の公式発表に限定します。** 統計は政府機関と調査会社の原典、技術は論文と公式の発表、企業の事例は当該企業のプレスリリースか決算資料を参照します。報道しか存在しない数値は、報道であることを明記します。

**規範4：予測や意見は、誰が、いつ、どの立場で述べたかを明記します。** AI企業の経営者、投資家、学術研究者、金融機関、批判者では、利害関係が異なります。本書は言説を人物ではなく「主張×軸」で分類し、1つの正解に収束させません。

**規範5：確度の階層を明示し、確率は割り当てません。** 未来の記述には【階層1】から【階層4】までの確度を付します。階層1は既に確定した事象、階層2は傾向が持続する場合に導かれる事象、階層3は発生の有無が不確実な事象、階層4は予測が原理的に困難な事象です。この階層は『未来予測の設計図』の方法を踏襲しています。

**規範6：可読性を優先します。** 各章に1枚の図を置き、1つの主張だけを示します。経営層が各章の要点と解釈を10分で読めるよう、表と箇条書きを使います。散文での列挙を規範にした前著とは、この点が異なります。

### 4. 本書の構成

本書は、5つの部と総括、2つの付録で構成されます。

**第Ⅰ部：過去 ―― 生成AIの系譜(第1章〜第10章)**
基盤技術の成立、ChatGPTの転換点、競争の構造化、推論モデルと価格の低下、エージェントの年、2026年の到達点、能力の計測、計算資源と資本、日本の技術史、そして電化や計算機といった先例の普及曲線を整理します。

**第Ⅱ部：現在 ―― 普及の現在地(第11章〜第19章)**
個人と企業の利用率、生産性と雇用の実証、投資対効果と失敗率、AIエージェントの現在地、統治と規制、市場の地図、日本の条件を確かめます。

**第Ⅲ部：枠組み ―― 普及と導入を読む理論(第20章〜第24章)**
普及の理論、汎用技術と生産性Jカーブ、組織の内部化、成熟度モデル、予測の方法を、原典に戻って整理します。第Ⅰ部と第Ⅱ部の事実を、第Ⅳ部と第Ⅴ部で使うための読み方を与える部です。

**第Ⅳ部：未来 ―― 2031年までの3つの道筋(第25章〜第29章)**
言説を分類したうえで、加速・漸進・調整の3つの道筋を、2027年・2029年・2031年の像として描きます。各道筋が外れる条件と、分岐を見分ける早期警戒指標を示します。

**第Ⅴ部：導入 ―― 企業のAXフェーズ論(第30章〜第38章)**
生成AIの導入の6段階、AIエージェントの導入の自律性5段階、3つの現在地(事業・導入・文化)、運営モデルの進化、各段階で必要なものと提供事業者を示します。続けて、道筋別の戦略、文化の形成、AXプロジェクトの立ち上げ手順(現在地・道筋・次の一手・統治)を示します。最後に、会議資料の1枚の型、費用の試算、90日計画を示します。本書でAXと呼ぶのは、AIトランスフォーメーション、すなわち生成AIとAIエージェントを前提に事業と組織を組み替えることです。

**総括**では、第Ⅰ部から第Ⅴ部までの推論の連鎖を1本に接続し、本書が答えていない問いを列挙します。**付録A**は用語集、**付録B**は参考文献です。

### 5. 想定する読者

本書は、次の読者を想定しています。

自社の生成AIとAIエージェントへの取り組みについて、経営会議で方針を決める立場にある人。情報システム部門やDX推進部門で、全社の導入を取りまとめる人。そして、断片的な言説ではなく、検証できる事実から自分の判断を組み立てたいすべての人です。

AIの技術的な知識は前提にしません。第Ⅰ部は歴史として読めるよう書き、専門用語は初出で説明し、付録Aで定義します。

### 6. 本書とともに使う道具：AXコンパス

本書の第Ⅴ部の枠組みを、Webアプリ「AXコンパス」として公開しています。自社の現在地を3つの軸で診断し、前提に置く道筋を仮に決め、次の一手と必要なもの、関係する提供事業者の層を、会議体に出せる1枚の資料として出力します。使い方は[AXプロジェクトの立ち上げの章](37-launching-ax-project)で、1枚の資料の型は[会議資料と90日計画の章](38-meeting-pack)で説明します。

アプリと本書は診断の目安を提供するものであり、各社の判断を代替しません。本書が示すのは、判断の材料と、その材料がどの出典に立っているかです。結論を受け入れることを求めるのではなく、読者が自身の前提を置いて推論をやり直せることを目指します。
