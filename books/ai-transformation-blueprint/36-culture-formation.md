### 序論：本章が扱う範囲

本章は、[3つの現在地の章](32-three-positions)で定義した文化フェーズのC1からC5を詳しく扱います。各段階の定義と、その根拠となる組織文化の研究と、段階を1つ上げる施策です。

文化を別の物差しにする理由は、文化が技術より遅く変わり、技術より長く残るからです。サービスを配ることは契約で済みます。しかし従業員が使い方を学び、失敗を共有し、効果を測り、AIを前提に仕事を設計し直すことは契約によって起こせません。日本企業の統計は、配ったあとに止まる企業が多いことを示しています。

本章が扱わないのは、席とトークンの単価です。それは[各段階で必要なものの章](34-requirements-and-providers)で扱いました。推進組織の人数は、[運営モデルの進化の章](33-operating-model-evolution)と同章の公表例(本書に既出の一次資料)を参照して各社が決めます。本章の5段階の定義と、各段階を上げる施策の対応は、著者による整理です。

### 1. 文化とは何を指すか

組織文化の研究で広く参照される定義は、Scheinによるものです。Scheinは組織文化を、集団が外部への適応と内部の統合の問題を解く中で学習し、妥当と見なされて新しい成員に教えられる、共有された基本的な前提のパターンと定義しました。文化は3つの層で観察されます。表層の人工物、中層の標榜された価値、深層の基本的な前提です [ [ 290 ] ](https://openlibrary.org/works/OL17382601W) 。

この3層を生成AIに当てると、次のようになります。表層の人工物は、配られたサービスと利用規程です。中層の標榜された価値は、経営層が語る方針です。深層の基本的な前提は、従業員が「この仕事はAIに任せてよいか」「誤りを報告してよいか」について無意識に持っている信念です。Scheinの定義に従えば、深層は表層からは読めません。サービスが配られていることは、文化が変わったことを意味しません。

Westrumは2004年に、組織が情報をどう扱うかで文化を3つに分けました。権力志向で情報を隠す「病理的」、規則志向で縄張りを守る「官僚的」、業績志向で情報を求め失敗から探究する「生成的」の3つです [ [ 293 ] ](https://doi.org/10.1136/qshc.2003.009522) 。DORAはこの類型を測定の尺度として採用し、生成的な文化がソフトウェアの提供の性能を予測することを複数年の調査で示しています。同じDORAの2024年の報告は、AIの採用が個人の生産性と職務満足を高める一方、ソフトウェア提供の安定性とスループットに負の影響を与えたと述べました [ [ 1501 ] ](https://dora.dev/research/2024/dora-report/) 。個人の利用が組織の成果に直結しないという知見は、[生成AIの導入段階の章](30-genai-adoption-stages)で示した段差と同じです。

### 2. C1からC5の定義

| 段階 | 名前 | 定義 | 観察できる事実 |
| --- | --- | --- | --- |
| C1 | 禁止・無関心 | 組織として禁じているか、方針がない | 利用規程がない。問われたことがない |
| C2 | 個人の試行 | 従業員が個人の判断で使い、組織は黙認している | 自前のツールの持ち込みがある。開示をためらう |
| C3 | 公認の試行 | 利用規程、学ぶ場(研修か公認の試行の場)、推進者の3つがそろった状態。3つがそろってC3、1つでも欠ければC3の手前 | 利用規程がある。学ぶ場がある。推進者が任命されている |
| C4 | 測って運用 | 効果と費用と誤りを数値で追い、業務ごとに改善している | 業務ごとの指標がある。誤りの共有が手順に反映される |
| C5 | AI・データネイティブ | 全員が作り手で、学習と改善が制度として続いている | 仕事の設計がAI前提。AIに任せない仕事を意図して残す |

C2は、組織が決める前に成立します。Microsoftの2024年の調査では、職場でAIを使う人の78%が自前のツールを持ち込み、52%は重要な業務でのAI利用を開示するのをためらっていました [ [ 296 ] ](https://www.microsoft.com/en-us/worklab/work-trend-index/ai-at-work-is-here-now-comes-the-hard-part) 。HaagとEckhardtは2017年に、IT部門の承認の外で従業員が導入する情報技術をシャドーITと整理し、禁止ではなく統治の対象とする研究の方向を示しました [ [ 295 ] ](https://doi.org/10.1007/s12599-017-0497-x) 。生成AIにおけるC2は、シャドーITの現代版です。

C3は、多くの日本企業が止まる段階です。総務省の2024年度の調査では、日本企業の導入時の懸念として最も多かったのは「効果的な活用方法がわからない」でした [ [ 526 ] ](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r07/html/nd112220.html) 。規程を作り、配ったあとに「どう使えば効くか」の分からない状態が、C3とC4の間にあります。C3に達していない企業も少なくありません。[企業の利用の章](12-enterprise-adoption)で見たとおり、「組織的な取組はない」と答えた日本企業は3割弱で、他の3か国より多い値です [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。この3割弱は、C2かC3の手前にある企業の割合と読めます。利用率を見ることは、C3の条件ではなく、C3からC4へ移る最初の指標として扱います。

「どう使えば効くか分からない」という壁の中身を、著者は4つに分けて整理します。第一に、業務に合う用途が示されていないことです。第二に、入力してはいけない情報の範囲が広すぎて実務で使えないことです。第三に、研修がなく、使い方は個人任せになっていることです。第四に、効果を測っていないので次に組み込む業務を選べないことです。配ったあとに利用率が上がらない企業は、この4つのどれに当たるかを先に確かめます。

C4は、効果を測る段階です。PwC Japanの2026年春の調査では、日本企業の生成AIの活用・推進度は87%に達した一方、「期待を大きく上回る効果」を得た企業の割合は調査した6か国で最も低いという結果でした [ [ 127 ] ](https://www.pwc.com/jp/ja/knowledge/thoughtleadership/generative-ai-survey2026.html) 。測らなければ、効果は上がりません。BCGは、業務の流れを再設計するReshapeの段階にある企業ほど、AIが生んだ価値を追跡していると報告しています [ [ 193 ] ](https://www.bcg.com/publications/2025/ai-at-work-momentum-builds-but-gaps-remain) 。

C5は、仕事の設計がAI前提になった段階です。「AI-native」という語は業界で広く使われていますが、学術的な定義の一次資料は確認できていません。本書はこの語を業界用語として使います。実例としては、メルカリが社員の95%がAIを使いコード生成の約70%をAIが担う状態でも、現在を「AI-Native」とは捉えていないと自己評価している点が参考になります [ [ 240 ] ](https://engineering.mercari.com/blog/entry/20251225-mercari-ai-native-company) 。C5は利用率ではなく、仕事の設計で判定します。

### 3. 段階を1つ上げる施策

段階を上げる施策は、段階ごとに異なります。本書は4つの移行について、一次資料で確認できる施策を挙げます。

**C1からC2へ、C2からC3へ：禁止ではなく公認する**。C2は組織が決める前に起きているため、C1からC3への移行は「黙認を公認に変える」ことです。日本ディープラーニング協会は2023年5月に生成AIの利用ガイドラインの雛形を公開し、各組織が目的に照らして修正して使うことを求めました [ [ 230 ] ](https://www.jdla.org/document/) 。横須賀市やデジタル庁など行政も、禁止しない方針で利用を始めました。労働政策研究・研修機構のフォーラムでは、日本は従業員へのガイドラインを策定していない企業が多いと指摘されています [ [ 512 ] ](https://www.jil.go.jp/event/ro_forum/20260120/houkoku/01-keynote-toda.html) 。規程を作ることが、C3への最初の一歩です。

**C3を固める：学ぶ場と推進者**。利用規程に学ぶ場と推進者を加えて、C3の3つがそろいます。LINEヤフーは、必須のeラーニングの合格を利用の条件にし、全部署に推進者を置きました [ [ 238 ] ](https://www.lycorp.co.jp/ja/news/release/018121) 。ソフトバンクは、全社員に1人100個のAIエージェントを作る取り組みで、AIを使うことを日常の行動に変える文化づくりを狙いとしました。同社のアンケートでは9,207名のうち約9割が理解の深まりを答えています [ [ 241 ] ](https://www.softbank.jp/sbnews/entry/20251204_01) 。NTTデータグループは、段位制の認定を持つ人材育成の枠組みを2027年度までに全社員約20万人へ広げます [ [ 243 ] ](https://www.nttdata.com/global/ja/news/release/2025/102900) 。学ぶ場は、規程の次に要るものです。なお、AIの利用を人事の評価や目標へ入れる施策は、C3の条件に含めません。それには人事制度の改定が要り、労働組合のある企業では労使協議が要ります。本書はこれを、推進者と学ぶ場がそろったあとに検討する施策として扱います。

**C3からC4へ：測る**。パナソニック コネクトは、利用回数と削減時間を年次で公表しています。2025年度は利用回数361万回、削減効果78.8万時間で、年間の総労働時間の3.4%に相当します [ [ 537 ] ](https://news.panasonic.com/jp/press/jn260729-1) 。発表は「利用データを分析した結果」としており、削減時間の算出の方法は示されていません。著者の整理では、C4の測り方は2つに分かれます。選んだ業務で前後を比べる実測と、利用者の申告に基づく推計です。推計は全社の傾向を追うのに向き、実測は1つの業務へ組み込む判断に向きます。会議資料には、どちらの方法かを明記します。測ることで、どの業務で効いているかが分かり、次に組み込む業務を選べます。Davenportは2006年に、分析能力を競争の中核に据える企業の条件として、経営陣の関与と全社的な分析を挙げました [ [ 291 ] ](https://hbr.org/2006/01/competing-on-analytics) 。生成AIの効果を測る仕組みは、この条件の現代版です。

**C4からC5へ：失敗を共有し、仕事を設計し直す**。Edmondsonは1999年に、チームの心理的安全性が「助けを求める」「誤りを認める」「実験する」といった学習行動を促し、学習行動はチームの業績を媒介することを示しました [ [ 294 ] ](https://doi.org/10.2307/2666999) 。AIの誤りを報告できる環境がなければ、誤りは隠され、評価は機能しません。Microsoftの2024年の調査で52%が開示をためらっていた事実 [ [ 296 ] ](https://www.microsoft.com/en-us/worklab/work-trend-index/ai-at-work-is-here-now-comes-the-hard-part) は、心理的安全性の不足を示しています。仕事の設計し直しは、メルカリが全社を33の領域に分けて各領域で業務の流れを組み替えている例 [ [ 240 ] ](https://engineering.mercari.com/blog/entry/20251225-mercari-ai-native-company) が参考になります。

### 4. 変革の手順

文化の変化は、手順を踏みます。Kotterは1995年に、100社超の変革の観察から、変革の失敗が8つの誤りに対応すると論じ、8段階の手順を示しました。「危機感を高める」「推進する連合を作る」「ビジョンを作る」「伝える」「行動する権限を与える」「短期的な成果を生む」「改善を定着させる」「新しい方法を制度化する」の8つです。段階を飛ばすと速く見えますが、満足な結果になりません [ [ 292 ] ](https://hbr.org/1995/05/leading-change-why-transformation-efforts-fail-2) 。

本書の文化フェーズをKotterの手順に当てると、次のようになります。C2からC3への移行は、推進する連合を作りビジョンを伝える段階です。C3からC4への移行は、短期的な成果を生み測る段階です。C4からC5への移行は、改善を定着させ制度化する段階です。Kotterの観察が正しければ、C3を飛ばしてC4を目指す企業や、C4を飛ばしてC5を宣言する企業は、速く見えて定着しません。

経営層の関与は、どの段階でも要ります。経済産業省は2024年に、日本では経営層の関与が世界平均より停滞していると総括しました [ [ 226 ] ](https://www.meti.go.jp/press/2024/06/20240628006/20240628006.html) 。Microsoftの2026年の調査では、個人の能力だけが高いBlocked agencyが利用者の10%にありました [ [ 205 ] ](https://assets-c4akfrf5b4d3f4b7.z01.azurefd.net/assets/2026/05/2026_Work_Trend_Index_Annual_Report_050526-7_69fc5b1c4e265.pdf) 。従業員が先に進み、組織が追いつかない状態を解くのは、経営層の仕事です。

### 5. 文化フェーズと導入フェーズの関係

文化フェーズと導入フェーズは別に動きますが、互いに制約します。

C3がなければ、S3は定着しません。業務手順にAIの利用を書き込んでも、学ぶ場と推進者がなければ手順は守られません。C4がなければ、S4は維持されません。評価と監視の仕組みを作っても、誤りを共有する文化がなければ、仕組みは形だけになります。Gartnerの調査が示す45%対20%の差([運営モデルの進化の章](33-operating-model-evolution)) [ [ 186 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-30-gartner-survey-finds-forty-five-percent-of-organizations-with-high-artificial-intelligence-maturity-keep-artificial-intelligence-projects-operational-for-at-least-three-years) は、維持する文化の有無を反映していると著者は考えます。

逆に、導入フェーズが文化フェーズを引き上げることもあります。パナソニック コネクトでは、活用が「聞く」から「頼む」へ移ったと公表されています [ [ 232 ] ](https://news.panasonic.com/jp/press/jn240625-1) 。S2の道具が業務に入ることで、従業員の前提が変わった例です。

### 経営層への含意

文化フェーズの5段階と、各段階を上げる施策の対応は、著者による整理です。Schein、Westrum、Edmondson、Kotterの研究は生成AIを対象としたものではなく、本書はそれらを生成AIの導入に当てはめています。当てはめの妥当性は、今後の実証研究で検証されるべきものです。

経営層が本章から持ち帰るべき点は3つです。

第一に、文化の現在地は、組織が決める前からC2にあります。78%が自前のツールを持ち込んでいるという統計は、禁止か黙認かを選ぶ段階がすでに過ぎていることを示します。選べるのは、公認するかどうかです。

第二に、日本企業の壁はC3とC4の間にあります。利用規程、学ぶ場、推進者を整えたあとに「どう使えば効くか」が分からず、効果を測っていない状態です。壁を越える手は、業務ごとに効果と費用と誤りを測ることです。測った結果を公表しているパナソニック コネクトの例は、測ることが次に組み込む業務を選ぶ材料になることを示しています。

第三に、文化は飛ばせません。Kotterの観察に従えば、C3を飛ばしてC4を目指す企業や、C4を飛ばしてC5を宣言する企業は定着しません。文化フェーズを1段ずつ上げる計画を、導入フェーズの計画と並べて持つことが、[会議資料と90日計画の章](38-meeting-pack)で示す会議体の資料の要件になります。
