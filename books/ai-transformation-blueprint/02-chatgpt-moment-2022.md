### 序論：本章が扱う範囲

本章は、2022年に起きた2つの出来事を整理します。1つは、モデルが人の指示に従うように学習させる方式(RLHF)の成立です。もう1つは、その方式を使った対話型の製品ChatGPTの公開と、それに続く普及の速度です。

[基盤の成立の章](01-foundations-2017-2020)で述べたとおり、2020年の時点で1,750億パラメータのモデルは存在していました。しかし、それは研究者と一部の開発者がAPIを通じて使うものでした。2022年に変わったのは、モデルの規模ではなく、人との接点の形です。

本章の本文は、技術の成立、製品の公開、普及の実測値の3つに限って記述します。普及の速度が過去の技術と比べてどう位置づけられるかの解釈は章末で扱い、理論的な枠組みは[普及の理論の章](20-diffusion-theory)に委ねます。

### 1. 指示に従うモデル：RLHFの成立

2022年3月4日、OpenAIのOuyangらはInstructGPTの論文を公開しました。GPT-3は「次の語を当てる」ように学習されているため、質問に対して質問を続けるなど、利用者の意図とずれた出力をしばしば返しました。InstructGPTは、人が書いた模範回答を使った追加学習のあと、複数の出力に人が順位をつけたデータから報酬モデルを学習し、その報酬を最大化するように強化学習を施しました。この手順が、人のフィードバックによる強化学習(RLHF)です。

論文の結果で注目されたのは規模の逆転です。13億パラメータのInstructGPTの出力は、1,750億パラメータのGPT-3の出力より、評価者に好まれました [ [ 9 ] ](https://arxiv.org/abs/2203.02155) 。モデルを大きくするのではなく、人の意図に合わせる学習を加えるだけで、利用者から見た品質は大きく変わることが示されました。

この結果は、[基盤の成立の章](01-foundations-2017-2020)で述べたスケーリング則と矛盾しません。スケーリング則が扱うのは「次の語を当てる」誤りの大きさであり、RLHFが扱うのは「人が望む答えかどうか」です。前者が能力の土台を、後者が製品としての使いやすさを決めました。

### 2. 同時に進んだ画像生成

言語モデルのRLHFと同じ年に、画像生成も一般の利用者に届きました。OpenAIは2022年4月13日にDALL·E 2を発表し、利用者を徐々に増やしたうえで2022年7月にベータ版として提供を始めました [ [ 8 ] ](https://openai.com/index/dall-e-2/) 。

一方、2021年12月に公開された潜在拡散モデルの論文は、2022年8月に公開されるStable Diffusionの基礎となりました [ [ 7 ] ](https://arxiv.org/abs/2112.10752) 。Stable Diffusionは、学習済みの重みを公開し、商用利用も許す方式で配布されました。言語モデルで後に起きる「閉鎖モデルとオープンウェイトの並立」は、画像生成で先に起きています。

### 3. 2022年11月30日：ChatGPT

OpenAIは2022年11月30日にChatGPTを公開しました [ [ 11 ] ](https://openai.com/index/chatgpt/) 。InstructGPTと同じ方式で学習したモデルを、ブラウザから無料で使える対話の形式で提供したものです。

公開時点のモデルは、GPT-3の系列を対話向けに調整したものでした。能力の面で2020年から断絶があったわけではありません。変わったのは、利用に必要な前提です。APIを呼ぶための開発の知識は不要になり、文章で話しかければ文章で返ってくる形式になりました。

公開から2か月後の2023年1月に、ChatGPTの月間利用者が1億人に達したと、投資銀行UBSの分析を引いて報じられました。報道は、消費者向けアプリとして史上最速の到達だとしています [ [ 12 ] ](https://www.youtube.com/watch?v=Tbd-u9EsRn8) 。この数値はOpenAIの公式発表ではなく、第三者の推計の報道です。本書は公式の数値として扱いません。

### 4. 普及の速度：先例との比較

普及の速度を、過去の技術と同じ基準で測った研究があります。Bick、Blandin、Demingは、アメリカの全国代表サンプルに対する調査で、2024年後半の時点で18歳から64歳の約40%が生成AIを使っていると報告しました。就業者のうち、前の1週間に仕事で生成AIを使った人は23%、毎勤務日に使った人は9%です。同じ研究は、2024年の仕事での利用率27%が、IBMのPCが発売されて3年後の1984年にPCを仕事で使っていた25%と同程度だと比較しています [ [ 108 ] ](https://www.nber.org/system/files/working_papers/w32966/w32966.pdf) 。生成AIの場合、公開から2年でこの水準に達しました。

StanfordのAI Index 2026は、生成AIが公開から3年で世界人口の53%に普及し、PCやインターネットより速いと報告しています。同じ報告で、国別の利用率はアメリカが28.3%で24位でした [ [ 81 ] ](https://hai.stanford.edu/ai-index/2026-ai-index-report/economy) 。この53%と28.3%は人口を母集団にした推計であり、就業者を母集団にした前段の数値とは定義が異なります。

OpenAIとDemingによる2025年9月の論文は、ChatGPTが2025年7月の時点で世界の成人人口の約10%に採用され、週間アクティブユーザーが7億人に達したと報告しています [ [ 114 ] ](https://www.nber.org/system/files/working_papers/w34255/w34255.pdf) 。

### 5. 利用者数の推移：2023年から2026年

ChatGPTの週間アクティブユーザー(WAU)の推移は、OpenAIの発表を報道が引用する形で記録されています。

| 時点 | 週間アクティブユーザー | 出典の種類 |
| --- | --- | --- |
| 2025年2月 | 4億人 | 報道(The Verge) |
| 2025年10月 | 8億人 | 報道(OpenAI DevDayの発表) |
| 2026年2月 | 9億人 | 報道(TechCrunch、OpenAIの発表) |

2025年2月の4億人への到達はThe Vergeが報じています [ [ 84 ] ](https://www.theverge.com/archives/ai-artificial-intelligence/2025/2/3) 。2026年2月27日、OpenAIは週間アクティブユーザー9億人と有料会員5,000万人を発表しました。同時に、Amazonなどから1,100億ドルの資金調達も公表しています [ [ 85 ] ](https://techcrunch.com/2026/02/27/chatgpt-reaches-900m-weekly-active-users) 。OpenAI自身の公式ページも、週間アクティブユーザー9億人超、有料会員5,000万人超、月間売上20億ドルと記しています [ [ 86 ] ](https://openai.com/index/accelerating-the-next-phase-ai) 。

これらの数値には注意点があります。週間アクティブユーザーはOpenAIが定義する指標であり、他社の月間アクティブユーザーとは直接比較できません。また、報道が引用する数値と公式ページの数値は時点が異なります。本書は、公式ページの数値を基準とし、報道の数値は推移の目安として扱います。

### 6. 日本の個人利用

日本の個人の利用率は、総務省が情報通信白書で毎年公表しています。令和7年版(2025年7月)によれば、2024年度の調査(2025年1月から2月に実施)で、生成AIサービスを使ったことがある個人の割合は日本26.7%、アメリカ68.8%、ドイツ59.2%、中国81.2%でした。前年の2023年度の調査では日本9.1%、アメリカ46.3%、ドイツ34.6%、中国56.3%です。日本の20代に限ると44.7%でした [ [ 106 ] ](https://www.soumu.go.jp/main_content/001019264.pdf) 。

令和8年版(2026年7月)では、2025年度の調査(2026年1月から2月に実施)で日本の利用経験率は58.8%に上昇しました。ただし、この調査は15歳から19歳を新たに対象に加えています。20歳以上に限ると52.2%です。同じ調査でアメリカは75.6%、ドイツは75.6%、中国は93.6%でした [ [ 107 ] ](https://www.soumu.go.jp/main_content/001082851.pdf) 。

2つの年度を同じ年齢層で比べると、日本は26.7%から52.2%へ、1年で約2倍になりました。他の3か国との差は残っていますが、縮まっています。日本の個人利用については[個人の利用の章](11-individual-adoption)で、企業の利用と合わせて詳しく扱います。

### 7. 何が変わり、何が変わらなかったか

2022年の転換点を、技術と接点の2つに分けて整理します。

| 項目 | 2020年の時点 | 2022年11月の時点 |
| --- | --- | --- |
| モデルの規模 | 1,750億パラメータ(GPT-3) | 同系列 |
| 学習の方式 | 次の語を当てる事前学習 | 事前学習にRLHFを追加 |
| 利用の形 | 開発者がAPIを呼ぶ | 誰でもブラウザで対話する |
| 費用 | 従量課金 | 無料で公開 |
| 利用者 | 開発者と研究者 | 2か月で1億人と報道 |

モデルの規模は変わっていません。変わったのは、人の意図に合わせる学習と、対話という接点、そして無料公開です。普及の速度は、この3つの組み合わせによって説明されます。

### 🗺️ 図：仕事での利用は、PCより速く広がった

![普及の速度 ―― PCは3年で25%、生成AIは2年で27%](/images/ai-transformation-blueprint/02-chatgpt-moment-2022.png)

#### 図の読み方

この図は、横に並んだ2本の棒で構成されています。左の棒は、IBMのPCが発売されて3年後の1984年に、アメリカでPCを仕事で使っていた人の割合25%です。右の棒は、ChatGPTの公開から2年後の2024年に、アメリカで生成AIを仕事で使っていた人の割合27%です。どちらも本文の第4節で引用したBickらの研究の数値です。

読み順は左から右です。右の棒は左の棒よりわずかに高く、しかも到達までの期間は1年短いことを示しています。図の下の添え書きにある「3年で世界人口の53%」は、同じく第4節で引用したAI Index 2026の数値であり、母集団が異なるため棒には含めていません。

図が示すのは速度だけです。使っている人の割合が高いことは、仕事の成果に効いていることを意味しません。その実証は[生産性の実証の章](13-productivity-evidence)で扱います。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、2022年の転換点はモデルの規模ではなく、RLHFという「人の意図に合わせる学習」と、対話という接点の形によって生まれました。第二に、普及の速度はPCやインターネットを上回り、公開から2年でアメリカの就業者の4分の1が仕事で使う水準に達しました。第三に、日本の個人利用は他国より1年から2年遅れて立ち上がり、2025年度に約半数へ達しました。

著者は、この転換点の本質を「利用の前提が消えたこと」と捉えます。それまでの情報技術は、使う側に操作の習得を求めました。ChatGPTは、文章を書ける人なら誰でも使える形で現れました。普及の速さは技術の優秀さの証明というより、習得の障壁が消えた結果です。障壁が消えたことは、裏返せば、会社が整備する前に社員が個人で使い始めることを意味します。[文化の形成の章](36-culture-formation)で扱う「統制の外で先に広がる」現象は、ここに起点があります。

### 経営層への含意

社員の多くは、会社の方針が決まる前に、すでに個人として生成AIを使った経験を持っています。日本でも2025年度の時点で成人の半数がそうです。したがって、導入の出発点は、使わせるかどうかの判断ではありません。すでに使っている状態を会社の仕組みへ取り込む設計です。本書の第Ⅴ部の導入フェーズ論は、この前提から始まります。
