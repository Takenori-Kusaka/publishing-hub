### 序論：本章が扱う範囲

本章は、本書の全体を1枚の図に圧縮し、どの章がどこに対応するかを示します。経営層が本書を会議で使うときに、全体の構造を10分で把握できることが目的です。

本章には新しい事実の記述はほとんどありません。各章で根拠とともに述べる内容を、構造として先に見せるだけです。数値と出典は各章にあります。

### 1. 砂時計と物差し

本書の構造は、左の砂時計と、右の物差しの2つからできています。

砂時計は、評価という営みの時間軸です。上半分の過去の系譜を第Ⅰ部で、くびれの現在地を第Ⅱ部で、下半分の未来の3つの道筋を第Ⅳ部で扱います。物差しは、自社の出力を測るための枠組みで、第Ⅲ部で定義します。2層10項目は「何を測るか」を、成熟度V0〜V4は「測る仕組みがどこまで回っているか」を表します。

社会の系譜と未来は、各社にとって外部環境です。自社が動かせるのは、物差しのほうだけです。

### 2. 第Ⅰ部：系譜 ―― 代役探しの歴史

第Ⅰ部は、出力の良否を測る方法を、1950年から2026年まで10章で追います。

| 章 | 時期 | 何が起きたか |
| --- | --- | --- |
| [人が測っていた時代の章](01-human-judgement-era) | 1950〜2001年 | 人の判定と、検索のテストコレクションが評価の起点になった |
| [参照との一致の章](02-reference-metrics) | 2002〜2018年 | BLEUとROUGEが人の判定の代わりになり、人と相関しないという批判が続いた |
| [意味の一致の章](03-learned-metrics) | 2019〜2021年 | 埋め込みと学習型の指標、忠実性の指標が現れた |
| [嗜好の学習の章](04-preference-learning) | 2022年 | 人の嗜好を学んだ報酬モデルで、評価が訓練の一部になった |
| [審判としてのLLMの章](05-llm-as-judge) | 2023〜2025年 | LLMが採点者になり、審判のバイアスが研究された |
| [RAG評価の成立の章](06-rag-evaluation) | 2023〜2025年 | 検索と生成を分けて測る指標が収斂した |
| [幻覚の計測の章](07-hallucination-measurement) | 2021〜2025年 | 幻覚の定義が分かれ、順位表と原因論が出た |
| [ガードレールの系譜の章](08-guardrails-lineage) | 2022〜2026年 | 有害な出力と注入攻撃を止める仕組みと、その評価が整った |
| [道具の氾濫の章](09-tool-proliferation) | 2023〜2026年 | 評価と観測の道具が並び、事実上の標準は現れなかった |
| [能力ベンチマークとの距離の章](10-capability-benchmarks-distance) | 通史 | 能力の試験を本書の主役にしない理由 |

10章を通して読むと、1本の線が見えます。2002年のBLEUは、熟練した人間の判定者の代役として提案されました [ [ 17 ] ](https://aclanthology.org/P02-1040/) 。2023年の審判モデル(AIの出力を別のAIに採点させる仕組み)の論文は、人の選好の近似としてLLMの審判を示しました [ [ 89 ] ](https://arxiv.org/abs/2306.05685) 。著者は、評価の歴史を代役探しの繰り返しとして読みます。人の判定の代役を探し、代役が目的からずれたと批判されると、次の代役を探してきました。

### 3. 第Ⅱ部：現在地 ―― 失敗・規制・日本・実務

第Ⅱ部は、2026年10月時点の現在地を5章で確かめます。公開された失敗の事例を、入力側・生成側・ガードレール・運用という失敗の4つの区分で読み([失敗の記録の章](11-failure-records))、何があれば防げたかを逆算します([失敗から逆算する評価の章](12-evaluation-from-failures))。続けて、規格と規制が求める評価([規格と規制が求める評価の章](13-standards-and-regulation))、日本の実践([日本の評価の実践の章](14-japan-practice))、事業者と調査が示す実務の分布([評価の現在地の章](15-state-of-2026))を整理します。

### 4. 第Ⅲ部：物差し ―― 2層10項目と成熟度

第Ⅲ部は、本書の枠組みを定義します。中心は、期待値への距離を入力側5項目と生成側5項目で測るモデルです。

| 層 | 項目 | 問い |
| --- | --- | --- |
| 入力側 | I1必要 | 入力だけで足りないものは何か |
| 入力側 | I2十分 | 必要な情報が集まったか |
| 入力側 | I3精度 | 集めた情報は関係があるか、雑音は少ないか |
| 入力側 | I4鮮度 | 情報は古くないか |
| 入力側 | I5出所 | 情報は信頼でき、使ってよいか |
| 生成側 | G1整形 | 期待した形になっているか |
| 生成側 | G2忠実 | 与えた根拠と一致しているか |
| 生成側 | G3事実 | 世界の事実と一致しているか |
| 生成側 | G4安全 | 有害・漏えい・権限の逸脱・注入が無いか |
| 生成側 | G5期待 | 有用で、課題を達成し、満足されたか |

定義と、項目の間の因果は[期待値への距離の章](16-distance-to-expectation)にあります。入力側の測り方は[入力側の評価の章](17-evaluating-input)、生成側の測り方は[生成側の評価の章](18-evaluating-generation)で扱います。

測る仕組みの段階は、V0(目視)、V1(固定セット)、V2(自動評価)、V3(本番評価)、V4(評価駆動)の5つです([評価の成熟度の章](19-evaluation-maturity))。本編の導入フェーズS1〜S6のどこでどの段階が要るかは、[導入フェーズと評価の章](20-adoption-stage-and-evaluation)で対応づけます。

### 5. 第Ⅳ部：3つの道筋と、最初の90日

第Ⅳ部は、評価の言説を分類し([言説の分類の章](21-discourse-taxonomy))、2031年までの3つの道筋を描きます([3つの道筋の章](22-three-paths))。

| 道筋 | 2031年に最後の判定をする者 | 主な分岐条件 |
| --- | --- | --- |
| A 自動化 | 審判モデル | 規制当局が自動評価を適合の証拠と認める |
| B 人手回帰 | ドメイン専門家 | 審判の失敗事例が累積し、専門職の評価の市場ができる |
| C 規制主導 | 規制と認証 | EU AI Actの執行と、認証の調達要件への組み込み |

表は、2031年に最後の判定をする者で3つの道筋を代表させています。道筋は排他ではなく、評価の軸ごとに同時に進みえます([言説の分類の章](21-discourse-taxonomy))。

本書は、3つのどれが正しいかを決めません。どの道筋でも無駄にならない手として、4つを挙げます。ゴールデンセット(期待する出力の要点と合否の基準を付けた、固定の試験の集まり)を作って更新すること、評価の記録を残すこと、審判の較正(審判モデルを人の採点に照らし、一致の度合いを記録すること)、評価のデータと記録を特定の事業者の基盤の外へ持ち出せる形で持つことです。最後の章([評価体制の立ち上げの章](23-launching-evaluation))は、1つの用途を90日でV2まで上げる手順(V0から始める組織も含む)と、経営会議に出す1枚の資料の型を示します。

#### 図の読み方

左の砂時計は上から下へ読みます。上の「過去：系譜」は第1章から第10章、くびれの「現在地」は第11章から第15章、下の「未来：3つの道筋」は第21章と第22章に対応します。くびれを細く描いたのは、系譜と未来の推論が、現在地の事実1点を通るためです。

右の物差しは第Ⅲ部です。上の2つの箱が2層10項目で、藍(紺)の箱は入力側のI1〜I5、もう1つの藍の箱は生成側のG1〜G5です。下の5つの区切りが成熟度V0〜V4で、左から右へ段階が上がります。色は[評価の成熟度の章](19-evaluation-maturity)の図と同じで、人が判定するV0とV1を丹(朱色)、機械の評価が加わるV2とV3を藍、到達点のV4を千歳緑(深い緑)にしています。砂時計のくびれから物差しへ伸びる点線は、社会の現在地が自社の物差しの前提になることを示します。

図の下の添え書きのとおり、自社が動かせるのは右の物差しだけです。第23章の90日の手順は、この物差しの上で、1つの用途をV2まで上げる手順です。V0から始める組織も、90日でV2を目指します。

### 本章の位置づけ

本章は全体の地図であり、新しい主張を含みません。読み方の要点を、著者の整理として2点記します。

第一に、どの章から読んでもかまいません。経営層は第0章の後に、[評価の現在地の章](15-state-of-2026)と[3つの道筋の章](22-three-paths)へ進むと、現在地と未来を短い時間で押さえられます。

第二に、物差しは道具の名前ではなく、問いの形で書かれています。2層10項目のそれぞれは「何が集まったか」「根拠と一致しているか」という問いです。特定の製品が答えを持つわけではありません。どの道具を使っても、同じ10の問いに答えられるかで評価の抜けを確かめられます。
