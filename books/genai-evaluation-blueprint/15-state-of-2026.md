### 序論：本章が扱う範囲

本章は、2024年から2026年10月までに公表された調査と報告から、生成AIの出力の評価が実務でどこまで行われているかを記録します。対象は、評価の道具を提供する事業者の利用者調査、ベンチャーキャピタルと調査会社の調査と予測、大学系の年次報告、評価の事業者の資金調達の発表です。

調査の多くは、評価の道具やAIの導入支援を売る立場の組織が行っています。本章は各調査について、誰が・いつ・何人に聞いたかと、発表者の立場を添えて書きます。数値は調査ごとに定義が違うため、本文では横に並べても足し合わせません。

第Ⅱ部の最後の章として、[失敗の記録の章](11-failure-records)から[日本の評価の実践の章](14-japan-practice)までの事実を、実務の分布という形で締めくくります。この分布を段階として整理する作業は、第Ⅲ部の[評価の成熟度の章](19-evaluation-maturity)で行います。

### 1. 利用者調査が示す評価の実践の割合

評価と観測の道具を提供するLangChainは、実務者への調査を2回公表しています。同社は自社の道具の普及に利害を持つ当事者です。

2024年12月の「State of AI Agents」は1,300名超の回答をまとめたもので、本番でAIエージェントを使う回答者は51%でした。評価の手法では、オフライン評価が39.8%、オンライン評価が32.5%です。性能の品質が最大の懸念として挙がりました [ [ 422 ] ](https://www.langchain.com/stateofaiagents) 。

2025年11月から12月に実施された「State of Agent Engineering」は1,340件の回答をまとめています [ [ 423 ] ](https://www.langchain.com/state-of-agent-engineering) 。

| 実践 | 回答の割合 |
| --- | --- |
| 何らかの観測(observability) | 89% |
| 詳細なトレーシング | 62% |
| 人手によるレビュー | 59.8% |
| 審判モデル(LLM-as-a-judge) | 53.3% |
| テストセットでのオフライン評価 | 52.4% |
| 本番でのオンライン評価 | 37.3% |

同じ調査で、品質を本番化の最大の障壁とした回答は32%でした。報告は、人手のレビューが繊細な場面やリスクの高い場面で依然として欠かせないと述べています [ [ 423 ] ](https://www.langchain.com/state-of-agent-engineering) 。

### 2. 企業はどう選び、どう測っているか

ベンチャーキャピタルの調査は、企業が公開のベンチマークより自社の評価を重く見ていることを報告しています。いずれも投資先の市場を描く立場の組織です。

- **a16zの2024年3月の調査。** 技術の共同体が公開ベンチマークの比較に注力する一方で、企業は複数のモデルを自社で試験し、APIの差し替えで切り替えられる設計にしていると報告しました [ [ 418 ] ](https://a16z.com/generative-ai-enterprise-2024/) 。
- **a16zの2025年6月の調査。** 最高情報責任者(CIO)100名への調査で、性能の評価には社内のベンチマーク、ゴールデンセット、開発者の反応が依然として重要だと報告しました。外部のベンチマークは、候補を絞るための目安として参照されています [ [ 409 ] ](https://a16z.com/ai-enterprise-2025/) 。
- **Menlo Venturesの2024年11月の調査。** アメリカの企業のIT意思決定者600名への調査です。組織は通常3つ以上の基盤モデルを併用していました。失敗した試行の理由として、実装の費用が26%、幻覚(ハルシネーション)を中心とする技術的な問題が15%挙がっています [ [ 421 ] ](https://menlovc.com/2024-the-state-of-generative-ai-in-the-enterprise/) 。
- **Menlo Venturesの2025年12月の調査。** 495名への調査で、AIの案件の47%が本番に到達したと報告しました [ [ 424 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise/) 。同じ調査によれば、計画を立てて実行し、結果を見て振る舞いを変える「真のエージェント」は、企業の案件の16%、スタートアップの27%にとどまります [ [ 424 ] ](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise/) 。

### 3. 調査会社とコンサルティング会社の数値

調査会社とコンサルティング会社は、予測と診断を売る立場から、評価やリスク管理の不足を失敗の理由に挙げています。

- Gartnerは2024年7月、生成AIのプロジェクトの少なくとも30%が2025年末までに、概念実証を終えた段階で放棄されると予測しました。理由は、データの品質の低さ、不十分なリスク管理、費用の増大、不明確な事業価値です [ [ 419 ] ](https://www.gartner.com/en/newsroom/press-releases/2024-07-29-gartner-predicts-30-percent-of-generative-ai-projects-will-be-abandoned-after-proof-of-concept-by-end-of-2025) 。
- Gartnerは2025年6月、エージェント型AIのプロジェクトの40%超が2027年末までに中止されると予測しました [ [ 656 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) 。
- Gartnerは2025年8月、AIの信頼・リスク・セキュリティ管理(AI TRiSM)は「過度な期待のピーク」の位置にあり、5年以内の主流化を見込みました。担当者は、AIは従来の統制では扱えない課題をもたらすと語っています [ [ 657 ] ](https://www.gartner.com/en/newsroom/press-releases/2025-08-05-gartner-hype-cycle-identifies-top-ai-innovations-in-2025) 。
- BCGは2024年10月、59か国1,000人の経営層への調査で、概念実証を超えて具体的な価値を生む能力を備えた企業は26%だったと発表しました [ [ 660 ] ](https://www.bcg.com/press/24october2024-ai-adoption-in-2024-74-of-companies-struggle-to-achieve-and-scale-value) 。
- Deloitteの2024年7月から9月の調査では、生成AIのツールに高い信頼を持つ回答者は世界で約3分の1でした [ [ 661 ] ](https://www.deloitte.com/ch/en/services/consulting/research/the-state-of-generative-ai-in-the-enterprise.html) 。

### 4. 年次報告：標準化された評価の不在

スタンフォード大学のAI Index 2024は、主要な知見の1つとして、LLMの責任に関する頑健で標準化された評価が著しく欠けていると述べました。OpenAI・Google・Anthropicが主に異なる責任あるAIのベンチマークで試験しているため、リスクの比較が難しいとしています [ [ 420 ] ](https://hai.stanford.edu/ai-index/2024-ai-index-report) 。

2025年版は、MMMU・GPQA・SWE-benchの得点が導入から1年でそれぞれ18.8・48.9・67.3ポイント上がったと報告しました。一方で、標準化された責任あるAIの評価は、主要な産業界の開発者の間で依然としてまれだと述べています [ [ 669 ] ](https://hai.stanford.edu/ai-index/2025-ai-index-report) 。

### 6. 人手評価の費用と、推奨される始め方

人手評価の費用の一部は、クラウドソーシングの料金として公開されています。Prolificの料金ページは、参加者への最低報酬を時給8.00ドル、企業向けの手数料を通常42.8%としています(2026年10月29日時点) [ [ 407 ] ](https://www.prolific.com/pricing) 。Amazon Mechanical Turkは、2026年9月30日に恒久的に閉鎖されました [ [ 408 ] ](https://www.mturk.com/pricing) 。

評価をどの規模で始めるかについては、実務家と事業者が具体的な数を示しています。

- Hamel HusainとShreya Shankarは、多様な100件のトレースから始め、最初の30件は自分で注釈を付けることを勧めています。審判モデルには、失敗の型ごとに100〜200件のラベルを付けるとしています [ [ 351 ] ](https://hamel.dev/blog/posts/evals-faq/) 。
- Anthropicは2026年1月、エージェントの評価は実際の失敗から作った20〜50件の単純な課題から始めるとよいと述べました [ [ 406 ] ](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) 。

### 🗺️ 図：観測は9割、本番の評価は4割弱

![2025年の調査の5つの評価の実践の割合を、観測89%から本番のオンライン評価37.3%まで並べた横棒の図](/images/genai-evaluation-blueprint/15-state-of-2026.png)

#### 図の読み方

図は、LangChainの2025年の調査の5つの実践を、割合の高い順に上から並べた横棒です。最上段の観測が89%で最も長く、最下段の本番でのオンライン評価が37.3%で最も短くなっています。図の下の一文は、両者の差が約50ポイントであることを示します。

中段の3本は、人手のレビュー、審判モデル、オフライン評価で、いずれも5割台から6割弱です。人が判定する人手のレビューの棒だけを丹で塗り、他は藍で塗りました。数値の出典と調査の時点は、本文の第1節にあります。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

- **観測は広がりましたが、評価は半分前後で止まっています。** 観測の89%に対し、オフライン評価と審判モデルは5割台、オンライン評価は4割弱でした。著者は、ログを取ることと、ログで期待への距離を測ることの間に段差があると考えます。調査したのが道具の提供者であるため、回答者は評価に関心の高い層に偏っている可能性があります。
- **企業は公開の順位表より自社の評価を重く見ています。** a16zの2つの調査とMenlo Venturesの調査は、複数のモデルを自社のゴールデンセットで比べる実務を報告しました。AI Indexは、責任あるAIの評価が標準化されていないと2年続けて述べています。著者は、デファクトの評価が無い状態は2026年10月時点でも続いていると考えます。
- **評価は市場になり始めましたが、その数値の多くは売り手の言説です。** 資金調達の規模は大きくなりました。一方で、調査会社の失敗率の予測や事業者の利用者調査は、評価やリスク管理を売る立場から出ています。

経営層と実務家への含意は、自社の評価の現在地を、本章の分布と比べて確かめることです。人手のレビューとオフライン評価があっても、本番での評価が無ければ、[失敗から逆算する評価の章](12-evaluation-from-failures)が記録した型の失敗を捕まえにくくなります。著者は、始める規模は20〜100件で足り、費用の大半は評価者の時間だと考えます。その段階の具体的な定義は、[評価の成熟度の章](19-evaluation-maturity)で扱います。
