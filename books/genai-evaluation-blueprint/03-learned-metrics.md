### 序論：本章が扱う範囲

本章は、語の表面ではなく意味の近さで出力を測る指標の時代を扱います。期間はおおむね2019年から2021年で、その延長として2022年から2024年の展開にも触れます。期待への近さの定義は、参照の文と意味が近いか、そして根拠の文と食い違っていないかへ移りました。

[参照との一致の章](02-reference-metrics)で見たとおり、BLEUやROUGEは語の並びの重なりを数える指標で、人の評価との食い違いを指摘されてきました。本章の指標は、その限界への応答です。

本章は3つの流れを記します。第一に、文脈を踏まえた単語の表現(埋め込み)で意味の近さを測る指標です。第二に、人の評価のデータで指標そのものを学習させる指標です。第三に、参照の文を使わない指標です。その中心は、出力が根拠の文と整合しているかを測る忠実性の指標で、対話の質や多次元の品質を測る指標も同じ時期に出ました。最後に、評価法の3類型の整理と、この時代の限界を記します。

長文の事実性の評価は[幻覚の計測の章](07-hallucination-measurement)で、検索拡張生成(RAG)の評価は[RAG評価の成立の章](06-rag-evaluation)で詳しく扱います。本章では起点だけを記します。

### 1. 埋め込みによる意味の一致

2019年4月、Tianyi Zhangらは、文章生成の評価指標BERTScoreを発表しました。BERTScoreは、候補の文と参照の文のトークンを完全一致で照合する代わりに、文脈を踏まえた埋め込みの類似度で照合します。機械翻訳と画像の説明文の363のシステムの出力で評価し、既存の指標より人の評価と高く相関したと報告しています [ [ 31 ] ](https://arxiv.org/abs/1904.09675) 。

同じ2019年、MoverScoreは文脈を踏まえた埋め込みと、分布の間の距離(Earth Mover距離)を組み合わせました。論文は、望ましい指標は表層の形ではなく意味に基づいて出力と参照を比べるものだと明言しています [ [ 32 ] ](https://arxiv.org/abs/1909.02622) 。

この段階の「期待への近さ」は、参照の文と意味が近いことです。言い換えた文でも意味が同じなら近いと判定できます。ただし、期待の中身は依然として、人が書いた参照の文に置かれています。

### 2. 人の評価を学習する指標

次の段階は、人の評価そのものを学習データにする指標です。

2020年4月、GoogleのThibault SellamらはBLEURTを発表しました。論文は、BLEUやROUGEのような最も広く使われる指標が人の判断と弱くしか相関しない可能性があると述べています。BLEURTはBERTに基づく英語の学習型の指標で、偏りを含みうる数千件の訓練例で人の判断を模倣できるとしています [ [ 33 ] ](https://arxiv.org/abs/2004.04696) 。

2020年9月、UnbabelのRicardo Reiらは、機械翻訳の評価枠組みCOMETを発表しました。COMETは、原文と参照訳の両方を入力に使う多言語の神経網の枠組みです。直接評価(DA)、人手による訳文の編集量(HTER)、多次元の品質指標(MQM)という3種の人の評価で、それぞれモデルを訓練しています [ [ 34 ] ](https://arxiv.org/abs/2009.09025) 。

学習型の指標では、「期待への近さ」の定義が一段変わります。参照の文との近さではなく、人の評価者がどう採点したかを再現できるかが基準になります。

### 3. 参照を使わない指標：忠実性と多次元の品質

要約や対話では、正しい出力が1つに決まりません。参照の文を使わずに測る指標が生まれました。まず、出力が根拠と整合しているかを測る忠実性の指標です。

- **QAGS(2020年4月)**: 要約と原文に同じ質問をして、答えが一致するかで事実の整合性を測ります。要約が原文と整合していれば、両者への質問の答えは似るはずだという直観に基づきます。動機は、既存の自動指標が要約の事実の誤りをほとんど捉えないことでした [ [ 35 ] ](https://arxiv.org/abs/2004.04228) 。
- **SummaC(2021年11月)**: 自然言語推論(NLI)のモデルを文単位で適用し、結果を集約する方法で、要約の不整合を検出できるようにしました。6つのデータセットのベンチマークで、balanced accuracy 74.4%を得ています [ [ 37 ] ](https://arxiv.org/abs/2111.09525) 。

QAGSとSummaCでの「期待への近さ」は、正解の文との近さではなく、与えられた根拠との整合です。本書の枠組みでは、生成側の「忠実」(与えた根拠と一致しているか)の項目の測り方の起点にあたります。

参照を使わない指標には、根拠との整合ではなく、対話の質や多次元の品質を測るものもあります。

- **USR(2020年5月)**: 対話の応答を、参照を使わず教師なしで評価する指標です。人の評価との相関は、Topical-Chatでターン単位0.42、PersonaChatでターン単位0.48でした。システム単位ではどちらも1.0です [ [ 36 ] ](https://arxiv.org/abs/2005.00456) 。システム単位の値は、比べるシステムの数が少ない条件での相関です。
- **UniEval(2022年10月)**: 人手評価は一貫性や流暢さなど多次元で行うのに、自動評価は類似度の指標が支配的だという不一致を問題にしました。評価を「はい/いいえ」で答える質問に置き換え、1つの評価器で複数の次元を評価します [ [ 38 ] ](https://arxiv.org/abs/2210.07197) 。

### 4. 根拠への整合から事実の支持へ

2023年以降、忠実性の考え方は、長い出力の事実性の評価と、検索拡張生成の評価へ広がりました。

2023年5月のFActScoreは、長い生成文を原子的な事実に分解し、信頼できる知識源に支持される事実の割合を測ります。13のモデルによる6,500の生成文を人手で評価すれば2.6万ドルかかるとし、自動の推定器を併せて提案しました [ [ 39 ] ](https://arxiv.org/abs/2305.14251) 。2024年3月、Google DeepMindのSAFEは、言語モデルのエージェントが長文を事実に分解し、Google検索で検証する評価器です。約1.6万の事実でクラウドソーシングの評価者と72%一致し、不一致の100件を調べ直すと76%でSAFEが正しく、費用は人手の20分の1以下と報告しています [ [ 40 ] ](https://arxiv.org/abs/2403.18802) 。

検索拡張生成では、2023年9月のRAGASが、検索の適合性、生成の忠実性、生成の品質を、人手の正解なしに評価する指標群を示しました [ [ 41 ] ](https://arxiv.org/abs/2309.15217) 。本書は、論文と手法をRAGAS、ライブラリをRagasと書き分けます。詳しくは[RAG評価の成立の章](06-rag-evaluation)で扱います。2023年11月のARESは、合成データで軽量の判定器を微調整し、数百件の人手ラベルで予測を補正します [ [ 42 ] ](https://arxiv.org/abs/2311.09476) 。

### 5. 評価法の3類型とこの時代の限界

2020年6月のサーベイは、言語生成の評価法を3つに分類しました。人を中心とした評価、訓練を要しない自動の指標、機械学習による指標です [ [ 16 ] ](https://arxiv.org/abs/2006.14799) 。[参照との一致の章](02-reference-metrics)のBLEUとROUGEは2つ目に、本章のBLEURTとCOMETは3つ目に入ります。

同じ時期、評価の対象を正解率だけで測ることへの批判も出ました。2020年5月のCheckListは、ソフトウェアの振る舞いのテストに倣い、言語能力とテストの種類の行列でモデルを検査する方法を示しました。動機は、取り置いたデータでの正解率がモデルの性能を過大に見せがちなことです [ [ 46 ] ](https://arxiv.org/abs/2005.04118) 。

この時代の指標の限界は、資料の記述から次のように整理できます。

- **人の評価の偏りを継承する**: BLEURTの論文自身が、訓練例は偏りを含みうると書いています [ [ 33 ] ](https://arxiv.org/abs/2004.04696) 。
- **検出の精度に上限がある**: SummaCの不整合検出は、当時の最良でもbalanced accuracy 74.4%でした [ [ 37 ] ](https://arxiv.org/abs/2111.09525) 。
- **結論が時代とともに古びる**: 古いデータセットでの指標の結論は、現代のシステムには必ずしも当てはまらないと報告されています [ [ 30 ] ](https://arxiv.org/abs/2010.07100) 。
- **人手評価の費用は残る**: FActScoreの2.6万ドルという見積もりは、事実ごとの人手の検証がなお高価であることを示しています [ [ 39 ] ](https://arxiv.org/abs/2305.14251) 。

| 指標 | 発表 | 期待への近さの定義 | 参照の文 | 報告された到達点 |
| --- | --- | --- | --- | --- |
| BERTScore | 2019年4月 | 参照と意味が近い | 使う | 363システムで既存指標より高い相関 |
| BLEURT | 2020年4月 | 人の採点を再現する | 使う | WMT Metricsの直近3年で最高 |
| COMET | 2020年9月 | 人の採点を再現する | 原文と参照を使う | 3種の人の評価で訓練 |
| QAGS | 2020年4月 | 原文と答えが一致する | 使わない | 既存指標が見逃す事実の誤りを対象にする |
| SummaC | 2021年11月 | 原文と矛盾しない | 使わない | balanced accuracy 74.4% |
| FActScore | 2023年5月 | 知識源に支持される | 使わない | 人手なら2.6万ドルの評価を自動推定 |

表のBLEURTの到達点は、同じ論文の要旨にある記述です [ [ 33 ] ](https://arxiv.org/abs/2004.04696) 。

#### 図の読み方

この図は、左下から右上へ上がる4段の階段で構成されています。各段は、出力を何と照らして測るかという「一致の単位」です。左から、語の一致(BLEU、2002年)、意味の一致(BERTScore、2019年)、人の採点の再現(BLEURTとCOMET、2020年)、根拠との整合(QAGSとSummaC、2020〜2021年)です。

読み順は左から右です。最初の3段は参照の文を使い、最後の段だけが参照を使いません。図の下の添え書きは、第5節で整理した限界のうち2つです。学習型の指標は人の評価の偏りを継承し、不整合の検出は当時の最良で74.4%でした。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、2019年から2021年にかけて、一致の単位は語から意味へ、意味から人の採点の再現へ移りました。第二に、正解が1つに決まらない要約や対話では、参照の文を使わず、根拠との整合で測る忠実性の指標が生まれました。これは本書の生成側の「忠実」の項目の起点です。第三に、どの指標も最後は人の評価との相関で正しさを示しており、人の評価の偏りと費用から自由になったわけではありません。

著者は、この時代の転換を「期待の置き場所が、正解の文から根拠の文へ移り始めた」と読みます。業務で生成AIを使う場面の多くは、社内文書や検索結果を根拠に回答や要約を作る形です。そこでは、正解の文を用意するより、根拠と矛盾しないかを測るほうが現実的です。ただし、74.4%という2021年時点の検出精度が示すように、自動の忠実性の検査は見落としを含みます。その後の検出器は[生成側の評価の章](18-evaluating-generation)で扱います。著者は、自動の検査を人による抜き取りの確認と組み合わせることが、実務家にとって妥当な出発点だと考えます。
