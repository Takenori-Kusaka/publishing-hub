### 序論：本章が扱う範囲

本章は、生成AIの出力に含まれる誤り、すなわち幻覚(ハルシネーション)がどう定義され、どう測られてきたかを記述します。幻覚は生成側の評価の中心にある主題です。ただし、同じ「幻覚率」という名前の数値でも、何と比べて誤りとするかによって意味が変わります。

扱う範囲は、用語の起源と定義の分岐・事実性(factuality)の計測・忠実性(faithfulness)の計測・提供事業者が運用する順位表、そして2024年から2025年に示された「なぜ幻覚するか」の説明です。最後に、法務の分野での実測と、日本語の評価データを記します。検索で集めた文脈に対する忠実性は、RAGの評価と重なります。その枠組みは[RAG評価の成立の章](06-rag-evaluation)で扱いました。

ガードレールによる実行時の検出と遮断は[ガードレールの系譜の章](08-guardrails-lineage)で扱います。本章の本文は、定義と計測の事実に限ります。

### 1. 語の起源と、3つの定義

「hallucination」という語は、自然言語生成より先に画像処理で使われていました。Jiらのサーベイ(2022年2月8日)によれば、超解像などの分野では肯定的な意味で使われ、画像の説明文で存在しない物体を述べる誤りを指すようになったのは後のことです [ [ 246 ] ](https://arxiv.org/abs/2202.03629) 。同じサーベイは、忠実性を「与えた情報源に一貫して忠実であること」と定義し、幻覚の反意語としました。一方で事実性は、何を事実とみなすか次第で忠実性と一致しない場合があると区別しています [ [ 246 ] ](https://arxiv.org/abs/2202.03629) 。

要約の分野では、2020年5月2日のMaynezらが大規模な人手評価で、ニューラル要約が入力文書に忠実でない内容を生みやすいことを示しました。題名でも忠実性と事実性を分けています [ [ 249 ] ](https://arxiv.org/abs/2005.00661) 。OpenAIのGPT-4 System Card(2023年3月)は、与えた文脈にない情報を作る「closed-domain」と、文脈なしに世界について誤情報を述べる「open-domain」に幻覚を分けました [ [ 253 ] ](https://cdn.openai.com/papers/gpt-4-system-card.pdf) 。

定義は、比べる相手によって次の3つに分かれます。

| 比べる相手 | 本書の呼び方 | 例 |
| --- | --- | --- |
| 与えた文脈・根拠 | 忠実性の誤り | GPT-4 System Cardのclosed-domain、要約の不整合 |
| 世界の事実 | 事実性の誤り | GPT-4 System Cardのopen-domain、事実質問への誤答 |
| 学習データ | 外在的な幻覚 | MetaのHalluLensの分類 |

MetaのHalluLens(2025年4月24日)は、幻覚を事実性から切り離し、外在的(extrinsic)と内在的(intrinsic)の分類で用語の統一を図りました。テスト集合の漏えいを防ぐため、問題を動的に作り直す設計をとっています [ [ 256 ] ](https://arxiv.org/abs/2504.17550) 。

用語そのものにも揺れがあります。NISTの生成AIプロファイル(AI 600-1、2024年7月)は、生成AI固有の12のリスクの1つを「Confabulation」と呼び、「hallucinations」を俗称と位置づけました [ [ 259 ] ](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf) 。Oxfordの研究者は2024年6月19日のNature論文で、誤りかつ乱数の種のような無関係な条件で答えが変わる部分集合を「confabulations」と呼び、意味的エントロピーで検出できると示しました [ [ 260 ] ](https://www.nature.com/articles/s41586-024-07421-0) 。

### 2. 事実性の計測(2021〜2024)

世界の事実との一致を測るベンチマークは、2021年から続きました。

- **TruthfulQA(2021年9月8日)**: 人が誤解のために誤答しやすい817問からなります。真実な回答の割合は、最良のモデル58%、人94%でした。大きなモデルほど真実でない傾向も示しました [ [ 126 ] ](https://arxiv.org/abs/2109.07958) 。
- **HaluEval(2023年5月19日)**: ChatGPTが特定の話題で、応答の約19.5%に検証できない情報の捏造を含むと報告しました [ [ 268 ] ](https://arxiv.org/abs/2305.11747) 。
- **FActScore(2023年5月23日)**: 長い文章を原子的な事実に分け、信頼できる知識源に支持される割合を測ります。人物伝でChatGPTは58%でした。自動の推定器で、人手なら2万6千ドルかかる評価を置き換えました [ [ 39 ] ](https://arxiv.org/abs/2305.14251) 。
- **SAFE(2024年3月27日)**: LLMのエージェントが長文を事実に分け、Google検索で検証します。人手の注釈との一致は72%で、費用は人手の20分の1以下でした [ [ 40 ] ](https://arxiv.org/abs/2403.18802) 。

外部の知識を使わずに検出する方法も試されました。2023年3月15日のSelfCheckGPTは、同じ問いへの複数の回答が食い違うかどうかで幻覚を検出します [ [ 266 ] ](https://arxiv.org/abs/2303.08896) 。2023年2月19日の意味的エントロピーは、言い換えで同じ意味の答えをまとめてから不確実性を測ります [ [ 265 ] ](https://arxiv.org/abs/2302.09664) 。

### 3. 忠実性の計測(2022〜2025)

与えた文脈との一致を測る指標も、別の系譜で整いました。2022年4月11日のTRUEは、要約の事実整合性の指標を11のデータセットで比べ、含意の判定と質問応答に基づく方法が強く、互いに補い合うと報告しました [ [ 283 ] ](https://arxiv.org/abs/2204.04991) 。2023年12月31日のRAGTruthは、RAGの設定で自然に生じた約1万8千の応答に、単語単位で幻覚を人手で注釈したコーパスです [ [ 178 ] ](https://arxiv.org/abs/2401.00396) 。2024年9月30日のFaithEvalは、最先端のモデルでも文脈に留まれない場合が多く、大きいモデルほど良いとは限らないと報告しました [ [ 284 ] ](https://arxiv.org/abs/2410.03727) 。

Google DeepMindは2024年12月17日、FACTS Groundingを発表しました。与えた文書に根拠づけた長文の応答を、3つの審判モデルが2段階で判定します。まず要求に応えていない応答を失格とし、次に根拠づけを判定します [ [ 281 ] ](https://deepmind.google/discover/blog/facts-grounding-a-new-benchmark-for-evaluating-the-factuality-of-large-language-models/) 。論文は、複数の審判の集計で評価のバイアスを和らげ、公開と非公開の分割で順位表の健全性を守る設計を記しています [ [ 184 ] ](https://arxiv.org/abs/2501.03200) 。同社のGemini 2.5の技術報告は、FACTS Groundingを業界標準のベンチマークと位置づけました [ [ 335 ] ](https://arxiv.org/abs/2507.06261) 。2025年12月9日には4部からなる「FACTS Benchmark Suite」に拡張され、評価した全モデルの総合精度が70%未満でした [ [ 282 ] ](https://deepmind.google/blog/facts-benchmark-suite-systematically-evaluating-the-factuality-of-large-language-models/) 。

### 4. 順位表：同じ名前の数値が連続しない

幻覚率の順位表を最も早く運用したのはVectaraです。同社は2023年11月6日、幻覚の評価モデルHHEMと順位表を公開しました。約1,000の文書を各LLMに要約させ、HHEMで採点した値です。2023年11月1日時点でGPT-4は3.0%、Claude 2は8.5%でした [ [ 275 ] ](https://vectara.com/cut-the-bull-detecting-hallucinations-in-large-language-models/) 。2024年8月5日のHHEM-2.1は、審判モデルではない純粋な分類モデルとして、幻覚の検出でGPT-4を上回ると主張しました [ [ 278 ] ](https://www.vectara.com/blog/hhem-2-1-a-better-hallucination-detection-model) 。

2026年10月22日に更新された順位表はHHEM-2.3を使い、gpt-4o-2024-08-06の幻覚率を9.6%としています [ [ 279 ] ](https://github.com/vectara/hallucination-leaderboard/) 。2023年の「GPT-4 3.0%」より悪化したように見えます。しかし評価モデルとデータが共に替わっており、2つの数値は直接比べられません。同社の2025年5月7日の論文は、既存の検出法の限界から、人手の注釈を使う審判モデル「FaithJudge」を導入したと述べています [ [ 280 ] ](https://arxiv.org/abs/2505.04847) 。

### 5. 「なぜ幻覚するか」：採点の仕方が誤答を促す

2024年11月7日のOpenAIのSimpleQAは、短い事実質問への回答を「正解」「不正解」「回答せず」の3値で採点します。知らない問いには答えないことを、理想の振る舞いとして評価に組み込みました [ [ 125 ] ](https://arxiv.org/abs/2411.04368) 。

同社のsystem cardは、正答率と幻覚率の2つを並べて報告しています。o1のsystem card(2024年12月5日版)では、SimpleQAの幻覚率はGPT-4oが0.61、o1が0.44でした [ [ 332 ] ](https://cdn.openai.com/o1-system-card-20241205.pdf) 。2025年4月16日のo3とo4-miniのsystem cardでは、人物の事実を問うPersonQAの幻覚率がo3で0.33、o4-miniで0.48となり、o1の0.16より悪化しました。同社は、o3がより多くの主張をするため、正しい主張と誤った主張の両方が増えると説明しています [ [ 334 ] ](https://cdn.openai.com/pdf/2221c875-02dc-4789-800b-e7758f3722c1/o3-and-o4-mini-system-card.pdf) 。

OpenAIのKalaiらは2025年9月4日の論文で、幻覚が残る理由を評価の側に求めました。学習と評価の手順が、不確実さを認めるより当て推量を報酬するからだという主張です。新しい幻覚の評価を足すより、順位表を支配する既存のベンチマークの採点を変えるべきだとしています [ [ 110 ] ](https://arxiv.org/abs/2509.04664) 。同社の解説記事は次の比較を示しました [ [ 262 ] ](https://openai.com/index/why-language-models-hallucinate/) 。

| SimpleQAの指標 | gpt-5-thinking-mini | o4-mini |
| --- | --- | --- |
| 回答せず | 52% | 1% |
| 正解 | 22% | 24% |
| 誤答 | 26% | 75% |

正解率だけを見るとo4-miniがわずかに上ですが、誤答の率ははるかに高くなっています。同じ記事は「幻覚は不可避」という主張に対し、不確かなときに回答を控えられるので不可避ではないと述べています [ [ 262 ] ](https://openai.com/index/why-language-models-hallucinate/) 。これは事業者の立場からの言説です。2024年1月22日には逆に、学習理論から幻覚の完全な除去は不可能だと論じる論文も出ています [ [ 261 ] ](https://arxiv.org/abs/2401.11817) 。

GPT-5のsystem card(2025年8月7日)は、応答から事実の主張を取り出し、o3が閲覧機能で真偽を判定する主張単位の誤り率を導入しました。gpt-5-thinkingの事実の誤りはo3より5倍超少ないと報告しています [ [ 304 ] ](https://cdn.openai.com/gpt-5-system-card.pdf) 。

### 6. 現場での実測：法務分野

幻覚が社会の費用になった分野として、法務の記録があります。2023年6月22日、ニューヨーク州南部地区の連邦地裁はMata v. Avianca事件で、ChatGPTが生成した存在しない判例を提出した弁護士らに5,000ドルの制裁を科しました。判事は、信頼できるAIの道具を使うこと自体は不適切でなく、提出物の正確さを担保する門番の役割は弁護士にあると述べています [ [ 289 ] ](https://national.clla.org/wp-content/uploads/2025/05/Mata-v-Avianca-Inc.pdf) 。

Stanfordの研究者は2024年1月2日、連邦裁判例について検証可能な質問をしたときの、法的な幻覚の割合を報告しました。その割合は、ChatGPT 4の58%からLlama 2の88%に及びます [ [ 288 ] ](https://arxiv.org/abs/2401.01301) 。2024年5月30日の事前登録研究は、「幻覚ゼロ」などを掲げるRAG型の法務AIが、200問超の質問で17%から33%の割合で幻覚すると示しました [ [ 290 ] ](https://arxiv.org/abs/2405.20362) 。同じ研究を紹介したStanford HAIの記事は、ある製品を34%超と記しており、論文の要旨と上限が1ポイント異なります [ [ 291 ] ](https://hai.stanford.edu/news/ai-trial-legal-models-hallucinate-1-out-6-or-more-benchmarking-queries) 。

### 7. 日本語の評価

日本語では、早稲田大学の研究者が2024年3月に日本語TruthfulQAを発表しました。18カテゴリ604問で、GPT-3.5-TurboとGPT-4は事実を問わない分野では人より高く、知識を問う分野では人を大きく下回りました [ [ 336 ] ](https://www.anlp.jp/proceedings/annual_meeting/2024/pdf_dir/P6-15.pdf) 。2025年3月には東北大学などが、RAGの設定での日本語の幻覚評価ベンチマークJHARSを発表しました。不適切な応答、内在的な幻覚、外在的な幻覚の3つに分類し、自動検出で適合率と再現率を両立させるのは難しいと報告しています [ [ 337 ] ](https://www.anlp.jp/proceedings/annual_meeting/2025/pdf_dir/Q2-17.pdf) 。

公的な側では、AIセーフティ・インスティテュートが2024年9月18日に「AIセーフティに関する評価観点ガイド」を公表しました。評価観点の1つに偽誤情報の出力の防止を置き、出力の事実を確認する仕組みを求めています [ [ 330 ] ](https://aisi.go.jp/effort/effort_framework/guide_to_evaluation_perspective_on_ai_safety/) 。生成AIの安全性のベンチマークを作るJAI-Trustの分科会は2026年5月21日、幻覚を「生成内容の正確性・忠実性」、誤情報と偽情報を「社会的影響や操作的利用」として分ける資料を公表しました [ [ 341 ] ](https://aisi.go.jp/assets/pdf/05_JAI-Trust_Disinformation-and-Misinformation.pdf) 。

### 🗺️ 図：同じ「幻覚率」でも、比べる相手で3つの別の数になる

![幻覚の定義を比べる相手で3つに分け、採点の仕方を添えた図](/images/genai-evaluation-blueprint/07-hallucination-measurement.png)

#### 図の読み方

この図は、上に3つの箱を横に並べ、その下に採点の仕方を示す帯を置いています。3つの箱は、出力を何と比べて誤りとするかを表します。左から、与えた文脈と比べる忠実性、世界の事実と比べる事実性、学習データと比べる外在的な幻覚です。各箱の下段にある代表的な尺度は、第2節から第4節で挙げたものです。

読み順は左の箱から右の箱へ進み、最後に下の帯を読みます。下の帯は、どの定義をとっても、正解・誤答・回答せずの3値で採点しなければ誤答の率が見えないことを表します。これは第5節のSimpleQAの3値の採点と、Kalaiらの主張に対応します。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、幻覚の定義は、比べる相手が与えた文脈か世界の事実か学習データかで3つに分かれます。2026年時点でも用語は統一されていません。第二に、順位表の幻覚率は、評価モデルとデータが替わると連続しません。数値は「時点・評価器・データ」の3点を揃えて初めて比べられます。第三に、2024年から2025年にかけて、正答率だけを採点する評価そのものが当て推量を促すという説明が、事業者自身から示されました。

著者は、実務家への含意を「幻覚率という1つの数で品質を語らない」ことだと考えます。社内の文書を根拠に答える用途なら、まず忠実性を測るべきです。一般知識を答えさせる用途なら、事実性と、知らないときに回答を控えた割合を併せて測るべきです。o3の例が示すように、正答率が上がっても誤答も増える場合があります。経営層にとっての含意は、提供事業者が掲げる「幻覚ゼロ」や「幻覚率○%」を、何と比べた値かを確かめずに導入の根拠にしないことです。法務分野の事前登録研究は、その確認を怠った場合の費用を記録しています。生成側の各層の測り方は[生成側の評価の章](18-evaluating-generation)で扱います。
