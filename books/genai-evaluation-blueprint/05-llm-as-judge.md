### 序論：本章が扱う範囲

本章は、大規模言語モデル(LLM)が別のモデルの出力を採点する「審判モデル(LLM-as-a-judge)」の時代を扱います。期間は2023年から2025年です。期待への近さの定義は、審判モデルが人の判定をどれだけ再現できるかに置かれました。

[人が測っていた時代の章](01-human-judgement-era)で見たとおり、人の判定は高価で、2020年以降はその不安定さも示されていました。[嗜好の学習の章](04-preference-learning)では、人の選好を学習した報酬モデルが訓練の目標になりました。審判モデルは、この2つの流れの上に現れています。人の判定の代役を、汎用の言語モデルに務めさせる試みです。

本章は、審判モデルの登場、利用者の投票によるアリーナ、審判の偏り(バイアス)の発見と校正、審判そのものの評価、2025年の懐疑への転換の順に記します。審判モデルを使う評価の道具と基盤は[道具の氾濫の章](09-tool-proliferation)で扱います。

### 1. 審判モデルの登場

2023年の前半に、言語モデルを評価者として使う報告が相次ぎました。

- **生成型の事前学習モデルによる採点(2023年2月8日)**: GPTScoreは、生成型の事前学習モデルの、ゼロショットで指示に従う能力などを使って生成文を採点する枠組みを提案しました [ [ 1603 ] ](https://arxiv.org/abs/2302.04166) 。
- **翻訳の品質の採点(2023年2月28日)**: KocmiとFedermannは、GPTに基づく翻訳品質の評価指標GEMBAを示しました。人の専門家によるMQMのラベルと比べて最高水準の精度を得たとし、この方法はGPT-3.5以上の規模のモデルでだけ機能すると述べています [ [ 1604 ] ](https://arxiv.org/abs/2302.14520) 。
- **初期の予備研究の一例(2023年3月7日)**: ChatGPTを人間の評価者とみなし、課題と観点ごとの指示を与えて言語生成の出力を評価させた研究が公開されました [ [ 85 ] ](https://arxiv.org/abs/2303.04048) 。
- **G-Eval(2023年3月29日)**: MicrosoftのG-Evalは、GPT-4に思考の連鎖と記入式の採点をさせ、要約の課題で人の評価とSpearman相関0.514を得ました。同時に、言語モデルの評価器が言語モデルの生成文を好む偏りの可能性を指摘しています [ [ 86 ] ](https://arxiv.org/abs/2303.16634) 。
- **人手評価の代わりになるか(2023年5月)**: Cheng-Han ChiangとHung-yi Leeは、人手評価と同じ指示、標本、質問を言語モデルに与えました。人の専門家が高く評価した文章は、言語モデルも高く評価したと報告しています。論文は動機として、人手評価は再現が非常に難しく、品質が不安定なことで知られると述べています [ [ 87 ] ](https://arxiv.org/abs/2305.01937) 。

2023年6月9日、Lianmin Zhengらは、審判モデルの代表的な検証を公開しました。複数の対話の往復を含む質問集MT-Benchと、後述のChatbot Arenaで、審判モデルと人の一致を調べています。GPT-4のような強い審判は、統制された人の選好とクラウドソーシングの人の選好の双方によく合うと報告されました。MT-BenchでのGPT-4と人の一致は、同点の票を除いた比較で85%、同点を含めた比較で66%です。人どうしの一致は、同じ2つの比較で81%と63%でした [ [ 89 ] ](https://arxiv.org/abs/2306.05685) 。同じ論文は、位置、冗長さ、自己強化の偏りと、推論能力の限界も列挙しています [ [ 89 ] ](https://arxiv.org/abs/2306.05685) 。

費用の面でも、審判モデルは人を大きく下回りました。2023年5月のAlpacaFarmは、人のフィードバックを模倣するプロンプトがクラウドワーカーより50倍安く、人と高い一致を示すとしています [ [ 68 ] ](https://arxiv.org/abs/2305.14387) 。評価の道具の側では、2023年1月に作成されたOpenAIのevalsのリポジトリが、モデルが採点する評価の雛形を含んでいます [ [ 54 ] ](https://github.com/openai/evals) 。

### 2. アリーナ：利用者の投票で順位を付ける

審判モデルと並んで、利用者の投票を集める方式も広まりました。

2023年5月3日、LMSYSはChatbot Arenaを公開しました。利用者は匿名の2つのモデルと同時に対話し、どちらが良いかに投票します。公開から1週間で4,700票を集め、チェスのEloレーティングで9つのモデルを順位づけました [ [ 67 ] ](https://lmsys.org/blog/2023-05-03-arena/) 。2023年12月7日、有効な投票が13万を超えた時点で、古典的なオンラインのEloの変動が大きいことを理由に、Bradley–Terryモデルへ移行しています [ [ 75 ] ](https://lmsys.org/blog/2023-12-07-leaderboard/) 。2024年3月の論文は、24万票を超える投票を集め、クラウドソーシングの投票が専門家の評価とよく一致すると報告しました [ [ 76 ] ](https://arxiv.org/abs/2403.04132) 。

アリーナの投票は、審判モデルの評価集の材料にもなりました。2024年6月のArena-Hard-Autoは、アリーナなどの実際のプロンプトから500問を自動で選び、審判モデルで採点します。MT-Benchの3倍の分離力、人の選好の順位との相関98.6%、費用20ドルと報告しています [ [ 79 ] ](https://arxiv.org/abs/2406.11939) 。

### 3. 偏りの発見と校正

2023年5月以降、審判モデルの偏りが種類ごとに報告され、それぞれに校正の方法が提案されました。

| 偏り | 報告 | 内容 | 提案された校正 |
| --- | --- | --- | --- |
| 位置 | 2023年5月 | 提示の順を入れ替えるだけで、Vicuna-13BがChatGPTの審判に80問中66問で勝つ | 複数の根拠、位置の均衡、人の介入 [ [ 88 ] ](https://arxiv.org/abs/2305.17926) |
| 位置 | 2023年9月 | 同上 | 分割と併合でGPT-4の一貫性を最大98%に [ [ 92 ] ](https://arxiv.org/abs/2310.01432) |
| 冗長さ | 2023年10月 | 設定の下でGPT-4が人より長い回答を好む | 偏りの測定指標 [ [ 94 ] ](https://arxiv.org/abs/2310.10076) |
| 長さ | 2024年4月 | 自動評価器が長い出力を好む既知の交絡 | 長さが同じならという反事実を回帰で推定 [ [ 78 ] ](https://arxiv.org/abs/2404.04475) |
| 見栄え | 2024年8月 | 長さと装飾による得点の上昇 | 長さ、見出し、太字、リストの4変数を回帰に加える [ [ 80 ] ](https://lmsys.org/blog/2024-08-28-style-control/) |
| 自己選好 | 2024年4月 | 自分の出力を見分ける能力と、自分を贔屓する強さが線形に相関 [ [ 98 ] ](https://arxiv.org/abs/2404.13076) | 異なる族の小型審判の合議 [ [ 99 ] ](https://arxiv.org/abs/2404.18796) |
| 選好の漏洩 | 2025年2月 | 合成データを作ったモデルと審判が同族だと「教え子」を贔屓する | ― [ [ 107 ] ](https://arxiv.org/abs/2502.01534) |

冗長さの偏りを検証した2023年10月の研究は、日本の研究者によるものです [ [ 94 ] ](https://arxiv.org/abs/2310.10076) 。自己選好の報告は2024年4月の研究です [ [ 98 ] ](https://arxiv.org/abs/2404.13076) 。表の合議による校正は、同じ月にCohereの研究者が報告したもので、GPT-4単独の審判より7倍以上安く、単独の大型の審判を上回ったとしています [ [ 99 ] ](https://arxiv.org/abs/2404.18796) 。表の「―」は、本章が依拠した資料の範囲に校正法の記述が無いことを示します。

偏りの研究は、校正のあとも新しい種類を見つけ続けました。2023年10月のLLMBarは、魅力的な語調のような欺く性質を持つ出力に、審判が誤導されることを示しました [ [ 95 ] ](https://arxiv.org/abs/2310.07641) 。2024年6月の体系的な研究は、15の審判と22の課題で、位置の偏りが偶然によるものではなく、審判と課題によって大きく異なることを確かめています [ [ 100 ] ](https://arxiv.org/abs/2406.07791) 。2024年10月には、12種の潜在的な偏りを特定し、自動で定量化する枠組みCALMが提案されました [ [ 1002 ] ](https://arxiv.org/abs/2410.02736) 。

### 4. 審判を誰が評価するか

審判モデルが人の代役になると、審判そのものの正しさを測る必要が生じました。

- **人との距離(2024年6月)**: 最良で最大のモデルだけが人と妥当に一致したものの、人どうしの一致にはなお遠く、人の採点と最大5点の差がありえると報告されました [ [ 628 ] ](https://arxiv.org/abs/2406.12624) 。
- **難問での審判(2024年10月)**: JudgeBenchは、事実と論理の正しさを問う難問で審判を評価しました。GPT-4oを含む多くの強いモデルは、ランダムな推測をわずかに上回る程度でした [ [ 104 ] ](https://arxiv.org/abs/2410.12784) 。
- **微調整した審判の汎化(2024年3月)**: 微調整したオープンの審判は、学習した領域ではGPT-4を上回ることもあります。しかし本質的には課題に特化した分類器として振る舞い、汎化に限界があると結論されました [ [ 97 ] ](https://arxiv.org/abs/2403.02839) 。
- **基準の漂流(2024年4月)**: UC Berkeleyの研究者らは、言語モデルが作る評価器は、評価される言語モデルの問題をそのまま継承するため、人による検証がさらに要ると述べました。人が出力を採点する過程で基準そのものが変わる現象を「criteria drift」と名づけています [ [ 346 ] ](https://arxiv.org/abs/2404.12272) 。

評価の形式を変える改善も報告されています。2023年10月のPrometheusは、採点のルーブリックと参照解答を与えた13Bのオープンの審判です。人の評価者とのPearson相関は0.897で、GPT-4の0.882と同等でした [ [ 93 ] ](https://arxiv.org/abs/2310.08491) 。2024年10月のTICKは、言語モデルが指示から「はい/いいえ」のチェックリストを作って採点する方法です。人の選好との完全一致の割合は、直接採点の46.4%から52.2%へ上がりました [ [ 103 ] ](https://arxiv.org/abs/2410.03608) 。

### 5. アリーナの信頼性をめぐる論争

2025年4月29日、Cohereなどの研究者は「The Leaderboard Illusion」を公開しました。Chatbot Arenaでは、公開前の非公開の試験と結果の撤回が、一部の提供事業者に有利に働いたと主張しています。Llama-4の公開前に、Metaが27の非公開の変種を試験したことを特定したとしています。GoogleとOpenAIはアリーナの全データのそれぞれ推定19.2%と20.4%を得ていたとも述べています [ [ 82 ] ](https://arxiv.org/abs/2504.20879) 。

アリーナの運営側は、2025年5月9日に反論を公開しました。未公開モデルの評価方針は2024年3月1日から公開しており、秘密の方針は無いとしています。公開されたモデルの結果だけを掲載するのが一貫した方針だとも述べています [ [ 83 ] ](https://arena.ai/blog/our-response) 。論文の著者は競合する提供事業者の研究者を含み、反論の著者はアリーナの運営者です。双方とも当事者です。

独立の研究者Andrej Karpathyは、2025年3月2日の投稿で「評価の危機がある」と述べました。Chatbot Arenaに注目が集まりすぎた結果、研究所がアリーナに過剰に適合し始めたとしています [ [ 646 ] ](https://x.com/karpathy/status/1896266683301659068) 。

### 6. 2025年の懐疑への転換

2025年には、審判モデルの成熟度を見直す発信が続きました。

2025年8月25日の立場論文は、審判モデルの採用が、評価者としての信頼性と妥当性の厳密な検証を追い越していると主張しました [ [ 359 ] ](https://arxiv.org/abs/2508.18076) 。コンサルティング企業ThoughtworksのTechnology Radarは、「LLM as a judge」を2024年10月版で「Trial」に置きました。2025年11月版では、その下の「Assess」に下げています。Technology Radarの定義では、Trialは使う準備ができているが十分には実証されていないもの、Assessは注目しておく価値があるものです [ [ 1609 ] ](https://www.thoughtworks.com/radar/faq) 。速さと規模の利点がある一方、人の判断の代理として信頼できないことが多いと評し、手法として強力だが「かつて信じられていたほど成熟していない」と述べています [ [ 358 ] ](https://www.thoughtworks.com/radar/techniques/llm-as-a-judge) 。

提供事業者の文書も、審判モデルの使い方に条件を付けています。Anthropicの開発者向けの文書は、評価には、評価される出力を生成したモデルとは別のモデルを使うのが一般に最良の慣行だとしています [ [ 130 ] ](https://platform.claude.com/docs/en/docs/test-and-evaluate/develop-tests) 。評価の講座を提供する実務家のHamel HusainとShreya Shankarは、審判で最終的に重要なのは人の判断とどれだけ一致するかだと述べています [ [ 351 ] ](https://hamel.dev/blog/posts/evals-faq/) 。

### 本章の要点と解釈

本節は、著者による解釈です。前節までの事実記述とは区別して読んでください。

要点は3つです。第一に、2023年に、言語モデルが人の判定の代役を務める審判モデルが広まりました。正しさの根拠は、同点を除いた比較で人との一致が85%と、人どうしの81%に並ぶという報告でした。同点を含めると、66%と63%に下がります。第二に、審判の偏りは、位置、冗長さ、自己選好、選好の漏洩と種類ごとに見つかり、校正の方法が提案されるたびに新しい種類が報告されました。第三に、2025年には、審判モデルの成熟度を見直す研究と実務の発信が続きました。

著者は、審判モデルの偏りを「人より劣る」ことの証拠としてではなく、「人と同じ種類の弱さを持つ」ことの証拠として読みます。長い回答を好む偏りは、[嗜好の学習の章](04-preference-learning)で見たとおり、人の訓練者にも見られました。審判モデルは人の判定を安く速く再現しますが、人の判定が抱えていた不安定さからは自由ではありません。著者は、組織が審判モデルを使うときの最低限の条件を2つと考えます。1つは、少数の出力を人が採点し、審判との一致を定期的に測ることです。もう1つは、評価される出力を作ったモデルとは別のモデルを審判に使うことです。
