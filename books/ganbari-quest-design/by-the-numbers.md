> リポジトリ: [Takenori-Kusaka/ganbari-quest](https://github.com/Takenori-Kusaka/ganbari-quest)

一人の人間が生成AIに実装を任せて 7 か月。その規模と速さと費用は、数字でどこまで言えるのか。2026 年 2 月 19 日から 9 月 16 日までの 210 日を、git、GitHub、そして著者の手元にある Claude Code のログから数えます。

数えられるものと数えられないものは分かれます。git と GitHub は全期間を持ちますが、トークンのログは直近 21 日分しか残っておらず、全期間の値は推定です。推定は推定と書き、取り方はすべて脚注に置きます。

## 速さ

直近 1,000 件のプルリクエスト（2026 年 6 月 15 日から 9 月 13 日）は、作成からマージまでの中央値が 1.9 時間、25 パーセンタイルが 0.8 時間、75 パーセンタイルが 13.6 時間です。大きさの中央値は 240 行、75 パーセンタイルは 596 行。作成者はオーナーの名義が 917、Dependabot が 57、統合の機械名義が 26 です[^gh]。

直近 1,000 件の Issue（5 月 30 日から 9 月 13 日）は、作成から完了までの中央値が 110.7 時間、25 パーセンタイルが 31.5 時間、75 パーセンタイルが 306.4 時間です。1,000 件のうち、対応しないと判断したもの（`wontfix`）が 98、重複（`duplicate`）が 47。[第Ⅳ部-2](label-mailbox) で見た受信箱のラベルは 251 件に付いています[^gh]。

プルリクエストの 1.9 時間は、[第Ⅳ部-1](one-human-many-sessions) の品質保証部のセッションが毎時レビューする体制の実測です。Issue の 110 時間は、起票から着手までの待ちを含みます。

## トークン

トークンは、Claude Code が手元に残すログから数えられます。ただし、ログは 30 日で整理されるため、2026 年 8 月 7 日から 9 月 16 日までの 21 日分しかありません。全期間の値は、この標本から推定するしかありません[^tokens]。

21 日分の実測は、こうです。「応答」は生成AIが 1 回返答するたびに 1 と数えます。

| 項目 | 値 |
| --- | --- |
| セッション | 36 |
| 生成AIの応答 | 88,352 |
| ツール呼び出し | 86,158（`Bash` 71,469、`Edit` 4,323、`Read` 3,445、`Write` 3,228） |
| 出力トークン | 4,281 万 |
| 思考トークン | 1,146 万 |
| キャッシュ読み取りトークン | 263.9 億 |
| キャッシュ作成トークン | 5.57 億 |
| 入力トークン（キャッシュ外） | 103 万 |

部署別では、品質保証部が 56,174 応答（64%）、開発部が 24,653、企画部が 5,577、監査部が 1,834、基盤部が 114 です。モデル別では、Opus 5 が 64,464 応答、Sonnet 5 が 10,856、Fable 5 が 10,010、Fable 5.1 が 2,659 です。品質保証部がこれほど多いのは、毎時のレビューと修正の往復が応答として積まれるためです[^tokens]。

1 日あたりに直すと、出力トークンが約 204 万、応答が約 4,200、ツール呼び出しが約 4,100 です。全期間 210 日に単純に掛けると、出力トークンは約 4.3 億、キャッシュ読み取りは約 2,600 億になります。ただし 8 月はコミットが最多の月で、この標本は忙しい方に偏っています。全期間の実値はこれより少ないと考えるのが自然です。

キャッシュ読み取りが出力の 600 倍あることは、[第Ⅵ部-1](claude-md-hierarchy) の「常時読ませる 16 万バイト」の実測です。応答のたびに、同じ文脈が読み直されます。

## 費用

| 費目 | 額 | 備考 |
| --- | --- | --- |
| Claude Code | Claude Max の定額 × 7 か月 | 従量ではない。トークンが増えても請求は変わらない |
| AWS | 6 月 1.44 ドル、7 月 1.32 ドル、8 月 3.19 ドル | [第Ⅲ部-1](serverless-cost) の実測 |
| Bedrock（AI 提案） | 月 0.0006 ドル | Haiku 4.5 と Sonnet 4.6。[第Ⅱ部-11](ai-suggest) |
| Gemini（画像生成と、その依頼文） | 少額の従量 | [第Ⅱ部-17](image-assets)。金額の記録なし |

開発の費用は、ほぼ Claude Max の定額です。定額の意味は、[第Ⅵ部-1](claude-md-hierarchy) で見た逼迫にあります。週間の上限があり、使い切ればリリースが止まる。金額ではなく、上限が制約でした。

顧客数、売上、家族の実使用は、本書には書きません。[第Ⅰ部-5](pre-pmf-scope) で見たとおり顧客が付く前の段階で、それらは判断の材料であって公開の材料ではありません。

## 従量で払っていたら

定額の意味を測るために、21 日分のトークンを公開の API の単価で換算します。単価は 2026 年 9 月時点の Claude API の一覧から取り、キャッシュ書き込みは 5 分の単価で見ます[^pricing]。

| モデル | 応答 | 換算（ドル） | うちキャッシュ読み取り |
| --- | --- | --- | --- |
| Opus 5 | 64,464 | 約 13,700 | 約 10,300 |
| Fable 5 | 10,010 | 約 2,900 | 約 1,900 |
| Sonnet 5 | 10,856 | 約 800 | 約 570 |
| Fable 5.1 | 2,659 | 約 600 | 約 250 |
| 合計 | 87,989 | 約 18,000 | 約 13,000 |

21 日で約 1 万 8 千ドル、1 日あたり約 850 ドルです。キャッシュ書き込みを 1 時間の単価で見ると約 2 万ドルになります。この 21 日が 7 か月のあいだ同じ密度で続いたと仮定すると、210 日で約 18〜20 万ドル、1 ドル 150 円なら約 2,700〜3,000 万円です。標本はコミットが最多の 8 月を含み、忙しい側に偏っているので、実値はこれより少ないはずです。それでも桁は変わりません。

内訳で目を引くのは、費用の 7 割がキャッシュ読み取りであることです。出力トークンの費用は全体の 6% しかありません。応答のたびに、常時読ませる指示書と会話の履歴が読み直され、その量が費用を決めています。[第Ⅵ部-1](claude-md-hierarchy) で 16 万バイトを減らした判断は、従量で払っていれば請求額の話でした。定額では、週間の上限の話です。

もう 1 つ、部署別の応答です。品質保証部が 64% を占めます。レビューと修正の往復が、そのまま応答として積まれるからです。従量なら、レビューの費用が実装の費用の 2 倍という数字が出ます。

## 数えられないもの

数えられなかったものを書いておきます。

- 2026 年 8 月 6 日以前のトークン。ログが整理されていて残っていない。統計の一時ファイル `stats-cache.json` に 1〜4 月の日次のメッセージ数（4 月は 30,338 メッセージ、28,610 ツール呼び出し）があるが、他のプロジェクトを含み、トークンではない
- 人が費やした時間。指示の 5,998 件が近似だが、1 件あたりの時間は分からない
- 「生成AIが書いた行」と「人が書いた行」の区別。コミットの共著記録はコミット単位で、行単位ではない。共著に人の名が無いコミットも、人が読んで承認している

## 効いたか、足りなかったか

数えるなら、初日から数えるべきでした。トークンのログは 30 日で消えます。7 か月の全期間を持っているのは git と GitHub だけで、それは「何が起きたか」を持ちますが「何を費やしたか」を持ちません。日次でログを別の場所に写す 1 行の定期実行があれば、この章の「推定」は「実測」になっていました。

数字で見て分かったのは、1 日 14 コミットと 10 プルリクエストという速度が、7 か月ほぼ一定だったことです。モデルが 7 回変わっても、ブランチの運用が 3 回変わっても、速度は変わりませんでした。変わったのは、[第Ⅴ部-1](pre-ready) と [第Ⅶ部-4](actions-portfolio) で見た「何を通すか」の方です。

## 持ち帰るもの

- 生成AIを使い始める日に、トークンのログを日次で別の場所へ写す。ログは消え、あとから推定するしかなくなる
- 費用の大半は出力ではなくキャッシュ読み取り、つまり毎回読み直す文脈の量である。減らすなら、常時読ませる文書から減らす
- 定額なら制約は金額ではなく上限である。上限を使い切ればリリースが止まるので、レビューの往復の量を見ておく

[^git]: git の実測。コミットは `git rev-list --count main` と `git log --format=%ad --date=format:%Y-%m`。全ブランチは `git log --all` を識別子で重複除去。共著は `git log --format=%b | grep -i co-authored-by`。ファイル数は各月初の状態を `git ls-tree` で数えた（2026-09-16、本番ブランチ 3af6c2e）。出典: [Takenori-Kusaka/ganbari-quest](https://github.com/Takenori-Kusaka/ganbari-quest/tree/3af6c2ed9fd4fe5766fc80c255656e940f8ec8f0)

[^gh]: GitHub の実測。総数は検索 API（`is:pr is:merged base:main` 等）、作成からマージまでの時間と完了までの時間は `gh pr list` / `gh issue list` の直近 1,000 件から算出（2026-09-16）。出典: [Pull requests](https://github.com/Takenori-Kusaka/ganbari-quest/pulls?q=is%3Apr+is%3Amerged)、[Issues](https://github.com/Takenori-Kusaka/ganbari-quest/issues?q=is%3Aissue)

[^prompts]: 著者の Claude Code の履歴（`~/.claude/history.jsonl`）を、作業ディレクトリのパスに `ganbari` を含むものと全体で月別に数えた。集計スクリプトは Gemini CLI に書かせ、入力は読むだけで、移動と削除はしていない。出典: [Claude Code のドキュメント](https://code.claude.com/docs/en/overview)

[^pricing]: Claude API の単価（2026 年 9 月）。Opus 5 は入力 5 ドル、出力 25 ドル、キャッシュ読み取り 0.5 ドル、キャッシュ書き込み 6.25 ドル（5 分）/ 10 ドル（1 時間）、いずれも 100 万トークンあたり。Sonnet 5 は 2 / 10 / 0.2 / 2.5 / 4、Fable 5 は 10 / 50 / 1 / 12.5 / 20、Fable 5.1 は 10 / 50 / 0.25 / 12.5 / 20 ドル。出典: [Claude API の pricing](https://platform.claude.com/docs/en/about-claude/pricing)

[^tokens]: 著者の Claude Code のセッションログ（`~/.claude/projects/` 配下の JSONL）の `message.usage` を、`message.id` で重複除去して集計した。対象はがんばりクエストの 5 つの部署の作業ディレクトリ、期間は残っていた 2026-08-07 から 09-16 の 21 日分。出典: [Claude Code のドキュメント](https://code.claude.com/docs/en/overview)
