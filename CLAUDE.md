# Project instructions (CLAUDE.md)

Read `AGENTS.md` before changing any file in this repository.
For content work, also read the guidelines under `docs/social-editorial-guide.md`.

- Never push to `main`. Work on a branch and open a PR; the human merging it is the approval gate. Publication switches may be set on a branch, never on `main` directly. The boundary is defined in AGENTS.md section 1.
- Run the validation commands listed in `AGENTS.md` section 3 before completion.
