## 新規の問題(最大 5 件、逐語引用と場所、重さ: 止める / 直す)

2. **直す。** 23-launching-evaluation.md:75「一致の度合いは、コーエンのκのような係数で表します」。同じ追加で、第19章 111 行目は「Cohenのκ」と書いている。章をまたいで表記が揺れているので、一方に揃える。

4. **直す。** glossary.md:81「適合するチャンクを適合しないものより上位に並べられたかを測るRAGASの指標」。X-12 で本文は「断片」に揃えたが、用語集のこの行は「チャンク」のままである。#41 の partial と同じ箇所。同じ行は後段で「Ragasの公式文書に加わった指標」とも書くので、冒頭の「RAGASの指標」は X-05 と X-12 の書き分けに合わせて「Ragasの指標」にするのが一貫する。
5. **直す。** 02-reference-metrics.md:31「自動評価指標を調べる評価の共通課題を、翻訳の課題と並べて設けています」。同じ段落で、直後は「この指標の共通評価課題」、29 行目は「指標の共通評価課題(Metrics Shared Task)」と書く。修正で足した文に「評価の共通課題」という3つ目の言い方が入った。同じ段落の「人の判定の相関」も、#61 で書いたとおり規則に反する。
