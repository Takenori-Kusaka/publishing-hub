# 『生成AI評価の設計図』のレビュー(多観点パネル)の計画

対象: books\genai-evaluation-blueprint\(ブランチ book/genai-evaluation-blueprint、初稿コミット c7c2dd1、published: false)と図 images\genai-evaluation-blueprint\*.png。

## 合格基準と回数(先に固定する)
- 回数: 最大 2 ラウンド。ラウンド 1 = 全員のレビュー → 採否 → 修正。ラウンド 2 = 各レビュアが自分の「止める」「直す」の反映を確認(accept / partial / reject / withdrawn / disagree)→ 残りを修正 → 終了。3 ラウンド目はしない。
- 合格: 「止める」0 件。「直す」はすべて「直した(レビュアが確認)」か「不採用(規則に基づく理由を採否表に記載)」。
- 採否の根拠にしてよいもの: 本の記述規範(はじめに の 5 規範)、AGENTS.md 2 章の編集規則、事実の捏造禁止、出典の一次性、読者(経営層と生成AIを仕事に組み込む実務家)の役割。根拠にしないもの: レビュアの感想、引用の無い指摘、レビュアの経験値や推定の数値。

## 出力の書式(全員共通)
ファイル: scratchpad\eval-book\review\<ID>.md
```
## 指摘
| # | 場所(ファイル:節 or 行) | 逐語引用(40 字以内) | 指摘 | 種別 | 重さ | 直し方 |
(種別: 事実 / 論理 / 実用 / 法務 / 表現 / 図。重さ: 止める / 直す / 参考)
## 全体の評価(5 文以内)

```
重さの基準: 止める = 事実の誤り・出典に無い主張・数値の不一致・法令の誤り・名誉毀損のおそれ・読めない図。直す = 誤解を招く書き方、用語の揺れ、論理の飛び、実用上の欠落、読者が止まる語。参考 = 好み。

## 工程
1. ラウンド 1: 10 名を並列で起動 → R-*.md
2. 取りまとめ(主担当): consolidated.md(章ごとの行、T-番号、採否、直し方)、decisions.md(対立点の判断)
3. 修正: 章のまとまりごとに修正担当 F1〜F5 → applied-F*.md。図は F-fig。
4. ラウンド 2: 各レビュアが verify-<ID>.md
5. 残りを修正 → 検査 → コミット → 記録(docs/records/reviews/zenn-book--genai-evaluation-blueprint.md と同名フォルダに .txt で原資料)
