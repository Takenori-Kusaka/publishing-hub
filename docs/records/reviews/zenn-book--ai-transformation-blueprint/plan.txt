# 第2次レビュー(多観点パネル)の計画

対象: 『AIトランスフォーメーションの設計図』(main にマージ済み、Zenn 公開中)と AX コンパス(公開中)。
作業ブランチ: publishing-hub `book/ax-review-round-2`、ax-compass は main に直接(アプリは人の門が無い)。

## 合格基準と回数(先に固定する)
- 回数: 最大 2 ラウンド。ラウンド 1 = 全員のレビュー → 採否 → 修正。ラウンド 2 = 各レビュアが自分の「止める」「直す」の反映を確認(accept / reject)→ 残りを修正 → 終了。
- 合格: 「止める」0 件。「直す」はすべて「直した(レビュアが確認)」か「不採用(規則に基づく理由を採否表に記載)」。
- 採否の根拠にしてよいもの: 本の記述規範(はじめに)、AGENTS.md 2 章の編集規則、事実の捏造禁止、出典の一次性、読者(経営層)の役割。根拠にしないもの: レビュアの感想、引用の無い指摘。
